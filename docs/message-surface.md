# 消息字段怎么进检测

这份清单从 README 和部署说明里移出来，方便对照。行为以代码和 ADR 为准。

## 总览

Webhook 已经能校验 Telegram 的 `secret_token`，并把普通消息、编辑后的消息和 `chat_member` 归一化成内部事件。编辑后的消息走同一套规则。见 ADR 0022。默认规则在 `apps/worker/rules/default.json`，某个群可以在 `chats.json` 里整份替换。热路径先读缓存，不读 D1。规则 schema 失败时该群放行。白名单和管理员豁免按租户和群存放；没有记录时仍豁免管理员，某个群可以关掉豁免。配了 KV 之后白名单进 KV，配了 D1 之后审计和入群挑战进 D1。两个绑定都可以不填，那时数据留在 isolate 内存里。配置中的管理员可以在私聊使用 `/help`、`/rules`、`/rule`、`/whitelist`、`/logs`、`/dryrun`、`/export`、`/forget`、`/blocklist`。`/rule` 可以改某一个群某一条规则的启用状态，也可以把动作换成一个处置。`file` 回到文件里的动作。文件规则仍是底稿。没配 `POLICY_KV` 时开关和动作都在内存里，重启后回到文件。配了之后，开关和 dry-run 留在原来的键，动作单独一个键。见 ADR 0034、ADR 0035 和 ADR 0458。群聊里的这些文本不会改配置。配了 `TELEGRAM_BOT_TOKEN` 之后，删除、禁言和封禁各发一次 Telegram 请求。没有 token 时只记在内存里。见 ADR 0020。规则可以写 `log` 或 `report`。上报只含标识和 reason，默认发给配置里的第一个管理员。私聊 `/report` 可以把这个群改到另一个编号，不能改回本群。没设置时仍是第一个管理员，回复不写这个编号。见 ADR 0021 和 ADR 0459。私聊 `/flood` 可以改这个群的洪泛条数和秒数。不设置时仍是 10 秒 5 条。见 ADR 0460。私聊 `/keyword` 可以给这个群追加关键词。内置词还在。见 ADR 0461。私聊 `/repeat` 可以改这个群的重复条数和秒数。不设置时仍是 60 秒 3 条。见 ADR 0462。私聊 `/rulemute` 可以改这个群在规则命中后的禁言秒数。不设置时仍是 3600 秒。见 ADR 0463。私聊 `/verifyfor` 可以改这个群的验证秒数。不设置时仍是 300 秒。入群验证和私聊 `/captcha` 用同一段时长。见 ADR 0464。私聊 `/verifyfail` 决定验证到期后留下、移出或封禁。不设置时成员留下。见 ADR 0465。私聊 `/allowhost` 可以让这个群放行指定主机。没添加时短链、邀请和裸 IP 仍删除。见 ADR 0466。规则可以写 `mute` 或 `ban`，严重度是 ban > mute > warn > delete > decline > captcha。新成员入群后，在点对加法得数之前不能发言。旁边的另一颗数字点了也不会通过。点错时会提示正确的得数。这条消息静音发出，成员仍看得到。昵称、姓氏、用户名或成员标签里出现关键词时直接封禁，不发验证按钮，日志不含这些字。已经在群里把标签改成新内容时同样封禁。见 ADR 0028、ADR 0358 和 ADR 0359。同一份可见名字里出现短链或邀请时同样封禁。进群用的邀请链接不读。公开的 `t.me/名字` 仍只验证。见 ADR 0117。从群外加入且文件夹邀请为 true 时带 `folderInvite`。邀请链接仍不进事件。见 ADR 0429。入群服务消息里的可见名字命中关键词或短链时删除这条服务消息。已有其它正文时只留主机名。退群的人和发送者姓名不进事件。见 ADR 0118。视频聊天邀请里的可见名字命中关键词或短链时同样删除。通话结束的时长不进事件。见 ADR 0119。群主变更里的新群主名字命中关键词或短链时同样删除。没有下一位时不读。见 ADR 0120。靠近提醒里两个人的可见名字命中关键词或短链时同样删除。距离不进事件。见 ADR 0121。富文本里的数学公式只留主机名，公式源码不进事件。见 ADR 0122。没有说明的富文本图片、语音、动图、视频、音频和文件按文件摘要参加重复判断。文件 id 不进事件。见 ADR 0123。没有说明的付费图片、视频和实况照片按文件摘要参加重复判断。文件 id 不进事件。见 ADR 0124。只给一个人看见的消息用临时消息 id 删除，删除请求带接收者 id。接收者姓名不进事件。见 ADR 0125。没有别的正文时，自定义表情的替代文字成为正文。已有正文时只留主机名。表情 id 不进事件。见 ADR 0126。代码块的语言标签只留主机名。标签原文不进事件。见 ADR 0127。普通消息、说明和媒体说明上的代码实体语言标签同样只留主机名。标签原文不进事件。见 ADR 0128。Telegram 代理和 socks 链接里的 server 只留主机名。secret、端口、用户名和密码不进证据。见 ADR 0129。分享链接和即时预览里的 url 只留主机名。路径和 rhash 不进证据。见 ADR 0130。私聊预填链接里的 text 只留主机名。路径和收件人用户名不进证据。见 ADR 0131。公开用户名和 `t.me/s/用户名` 上的 text 同样只留主机名。见 ADR 0137。`t.me/用户名/数字` 和 `用户名.t.me` 的 `text` 同样只留主机名。讨论串不读 text。用户名后再加一段应用名时，text 只留主机名。Passport 不读 text。见 ADR 0139。`tg:` 和 `t.me` 查询名 `domain`、`phone`、`server`、`host`、`invite`、`slug` 不区分大小写，先出现的值为准，值本身不改。空的 `SERVER` 仍算空。见 ADR 0140。小写 `t.me/folder/`、`telegram.me/folder/` 和 `telegram.dog/folder/` 记成邀请，邀请码不进事件。见 ADR 同样记成邀请。末尾斜杠、`#` 和子域不记。见 ADR 0144。Passport 的 `callback_url` 只留主机名。`nonce`、公钥和路径不进事件。见 ADR 0145。用户名后的应用名路径同样只留 text 里的主机名。子域上的应用名、讨论串仍不读。见 ADR 0146。更长的应用名、帖子数字和 Passport 路径段同样只留主机名。见 ADR 0147。`tg://resolve?domain=s&appname=` 同样只留 text 里的主机名。`domain` 必须正好是小写 `s`。见 ADR 0148。`s.t.me/用户名`、`share.t.me/url` 和 `msg.t.me/url` 同样只留主机名。见 ADR 0149。去掉预览 `s` 之后的一段同样只留主机名。见 ADR 0150。纯数字的 `t.me/+`、`telegram.me/+` 和 `telegram.dog/+` 是电话链接，不是邀请，`text` 只留主机名。带字母的加号路径仍是邀请。号码不进证据。见 ADR 0138。抽奖要加入的频道名字只留主机名。频道 id、用户名和中奖者姓名不进事件。见 ADR 0132。官方分享链接的另外几种写法，以及 `tg://iv` 和私聊预填上的 `url`，同样只留主机名。用户名上的 `url`、其它路径和 `rhash` 不读。见 ADR 0133。网页代理链接的 server 只留主机名。secret 和路径不进证据。见 ADR 0134。代理链接没有 server 时，host 同样只留主机名。名叫 proxy 的参数不读。见 ADR 0135。网页代理上 server 为空时改读 host，只留主机名。其它代理的空 server 不改读。见 ADR 0136。入群申请的简介命中关键词或短链时拒绝，不自动通过。安全的 `query_id` 会留下：命中答复 `decline`，未命中答复 `queue`。见 ADR 0116 和 ADR 0360。从群外加入的其它 bot 会被封禁，用户名不进事件。限制着但不在群里再回来同样封禁。新状态仍不在群里时不封。已经在群里的 bot 被提升时保留。见 ADR 0031 和 ADR 0357。共享名片会被删掉。电话、姓名和 vCard 不进事件。见 ADR 0032。经 inline bot 发出的消息默认保留。把规则 `via_inline` 打开后会删除，bot 用户名不进事件。见 ADR 0033。按钮回调要能送到 bot，`allowed_updates` 需要包含 `callback_query`。没有 bot token 时不会限制这个人。同一人 10 秒内第 5 条消息，或同一内容哈希 60 秒内第 3 次，会被删掉。这个计数在 isolate 内存里，超额时跳过，不拖住请求。见 ADR 0010。短链接和裸 IP 会被删掉。普通网址默认保留。信誉查询不在热路径上，超时就放过。见 ADR 0011。正文里看不见的 text_link 只贡献主机名，路径和查询不会进入事件。见 ADR 0029。`t.me`、`telegram.me`、`telegram.dog` 上的 `+`、`joinchat`、`addlist` 邀请会删掉，证据只有 `invite:` 加主机名。公开的 `t.me/名字` 保留。见 ADR 0030。跨群黑名单默认关闭。打开后只共享 actor id 或内容哈希，关掉后下一条消息不再读共享名单。见 ADR 0012。私聊里还可以用 `/blocklist`。`/appeal` 把一条审计标成误判或确认，样本进入审核队列，不改规则。见 ADR 0014。`/evals` 把这些样本导出成评测文档，只有哈希、特征和 spam/ham 标签。见 ADR 0016。LLM 分类默认关闭，也不绑定 Workers AI。打开后额度错误或超时会跳过。见 ADR 0015。正则检测默认关闭。模式在创建时限定长度和量词，命中只记 `regex:hit`。见 ADR 0023。频道转发默认删除，事件里只有类别，没有频道名。转载群可以关掉规则 `channel_forward`。用户转发默认保留。隐藏来源、群转发和用户转发可以按群打开。见 ADR 0025 和 ADR 0468。关联频道自动发到讨论组、且 `is_automatic_forward` 正好是 true 时，不记成频道转发。其它值仍删除。见 ADR 0443。这条原帖来源上的作者签名只留主机名。频道标题仍不读。见 ADR 0445。付费帖记成 `paid`，删除动作跳过。星星数量不进事件。禁言和封禁仍执行。见 ADR 0356。同一群 10 秒内超过 30 条更新时，webhook 返回 200 并且不再检测，避免 Telegram 重试把免费请求额度打满。见 ADR 0024。云模式默认每群每个 UTC 自然月 3000 次检测，超额只留基础规则。自部署默认关闭。管理员私聊 `/quota <chatId>` 只读已用次数。状态行末尾带窗口结束时间。超额时下一行列出基础检测器 id，名单仍是 ADR 0026 的默认值。见 ADR 0026、ADR 0042 和 ADR 0043。把 bot 拉进群并设为管理员后，操作者可以在私聊管理该群，`/chats` 列出群 id。额度打开时每一行带上已用次数和上限，查看不计数；名单放不下私聊时末尾是 `+` 和省略条数。没打开时仍只有群 id。没配 `POLICY_KV` 时这份目录在内存里，重启后要等下一次管理员变更。配了之后目录留在同一份 KV 里，不含群名。见 ADR 0027、ADR 0036 和 ADR 0045。拦截率、动作计数、检测器错误和存储失败从日志汇总，标签只有租户 id 和群 id。见 ADR 0017。外部插件要有完整性摘要和签名。自部署可以显式允许未签名插件，公共 bot 不可以。见 ADR 0018。规则包默认不订阅。私聊 `/packs` 打开后，刷新失败会沿用上一份通过校验的规则。配了 `POLICY_KV` 时订阅指针和上一份通过校验的规则都留在这份 KV 里。规则没变不写，超过 16384 个字符不写。订阅后私聊 `/rules` 列出正在执行的规则，标题带上 pack id，每一行标明 `file` 或 `switch`。超额后，不在基础检测器里的规则会标上 `paused`，标题末尾带上窗口结束时间。见 ADR 0019、ADR 0037、ADR 0038、ADR 0039、ADR 0040、ADR 0041、ADR 0044 和 ADR 0046。命令回复默认中文。`vars` 里写 `LOCALE=en` 后改成英文。见 ADR 0013。普通 `message` 或 `edited_message` 带非空字符串 `business_connection_id` 或 `guest_query_id` 时，在读正文前忽略。独立的 `business_message`、`edited_business_message`、`deleted_business_messages`、`guest_message` 和 `stopped_message_generation` 同样忽略。这些编号和正文不进事件。见 ADR 0437。`media_group_id` 是 1 到 20 位数字时记成 `albumId`。未编辑的这一组只算一次洪泛。编辑后的消息仍逐条计。其它编号不进事件。见 ADR 0438。`is_from_offline` 正好是 true 时记成 `offline`。未编辑且没有相册编号时，这些消息只算一次洪泛。其它值不记。见 ADR 0442。一组相册里有一条未付费消息被真正删除时，同组其它已知的未付费消息一并删除，后到的也删。付费帖仍留下。试运行不删除。公开的其余消息用一次 `deleteMessages` 送出。见 ADR 0440 和 ADR 0441。公开 `message_id` 为 0 且没有正整数 `ephemeral_message_id` 时，在读正文前忽略。有临时编号但没有接收者时仍用公开编号 0。见 ADR 0125 和 ADR 0439。

已有别的正文时，`unique_gift.gift.base_name` 去掉空白后，和没有附言时的型号、符号、背景名字，用空格拼起来，前 4096 字另留在 `giftLabel`。关键词或默认正则命中时删除。第 4097 字起不进事件。有附言时不读型号、符号和背景。短名、编号和发布者不进这个字段。这段自己就是正文时不设这个字段。见 ADR 0549。

已有别的正文时，`forum_topic_created.name` 或 `forum_topic_edited.name` 去掉空白后的前 128 字另留在 `topicName`。先看新建，再看改名。关键词或默认正则命中时删除。第 129 字起不进事件。图标颜色和自定义表情不进这个字段。`is_name_implicit` 不隐藏这段名字。这段自己就是正文时不设这个字段。见 ADR 0550。
