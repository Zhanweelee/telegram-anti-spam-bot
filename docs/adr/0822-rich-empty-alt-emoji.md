# ADR 0822：富文本替代文字为空时不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。富文本替代文字不是字符串时不读自定义表情。见 ADR 0821。Android 的 `formatRichText` 把自定义表情画在 `alternative_text` 上。长度为 0 的文字画不出表情。

现在空字符串仍会带 `asCustomEmoji`。打开 `custom_emoji` 后，没画出来的节点也会删掉这条消息。

## 决策

- 富文本节点 `type` 是 `custom_emoji`，编号非空，并且 `alternative_text` 是空字符串时，不从这一个节点读取自定义表情。
- 替代文字长度大于 0 时，仍按这个节点读取。一个空格仍读。不是字符串时仍不读。
- 编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。长度大于 0 的替代文字仍另留在 `richText`。
- 公式源码不在这条里。实体列表上的自定义表情仍按各自那段文字判断。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读空字符串 | 没有画出的文字，表情不该在打开规则后删掉这条消息。 |
| 一个空格也不读 | 空格有长度，客户端仍会把表情画在这段文字上。 |
| 公式源码一起改 | 公式画成固定说法，不是这段替代文字。 |
| 连实体列表一起改 | 实体列表已经按各自的文字判断。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 替代文字是空字符串时，不再从这一个节点带 `asCustomEmoji`。
- 替代文字长度大于 0 时，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 替代文字是空字符串时，自定义表情后来由 ADR 0822 不再读取。公式源码里的自定义表情后来由 ADR 0823 不再读取。预格式化块的语言标签里，自定义表情后来由 ADR 0824 不再读取。音频文件名里的自定义表情后来由 ADR 0825 不再读取。音频标题里的自定义表情后来由 ADR 0826 不再读取。音频表演者里的自定义表情后来由 ADR 0827 不再读取。视频文件名里的自定义表情后来由 ADR 0828 不再读取。动画文件名里的自定义表情后来由 ADR 0829 不再读取。文档文件名里的自定义表情后来由 ADR 0830 不再读取。文档类型里的自定义表情后来由 ADR 0831 不再读取。文档缩略图里的自定义表情后来由 ADR 0832 不再读取。视频缩略图里的自定义表情后来由 ADR 0833 不再读取。动画缩略图里的自定义表情后来由 ADR 0834 不再读取。动画类型里的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
