# ADR 0786：富文本链接的可见文字长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。气泡里的富文本链接来自 `RichTextUrl.url`，按钮地址来自按钮上的 `url`、`login_url`、`web_app` 和复制句子。见 ADR 0076。置顶预览和引用条只在可见文字画进那段预览时才读链接。见 ADR 0714。置顶文字预览上的文字链接，长度必须大于 0。见 ADR 0785。

Android 的 `formatRichText` 把链接画在内部文字上。内部文字是空字符串时，画出来的长度是 0，这段链接点不到。粗体包着空字符串也一样。行内公式会画成固定说法，源码不进正文。没画出来的按钮点不到。

现在空的可见文字仍会留下链接主机名。打开链接规则后，没画出来的链接也会删掉这条消息。

## 决策

- 气泡里的 `RichTextUrl`，只有可见文字长度大于 0 时才读 `url`。
- 可见文字按 `formatRichText` 会画出的字计算。空字符串和只包着空字符串的样式不算画出来。
- 行内公式是固定说法，包着公式的链接仍读。公式源码仍只留主机名，不进正文。
- 富文本按钮的标签长度是 0，并且不是公式时，不读这个按钮的地址、复制句子、登录地址、小程序地址和查询。
- 标签画出来时，这些地址仍只留主机名。`callback_data` 仍不读。
- 置顶预览和引用条仍只在可见文字画进那段预览时才读。内联按钮的文字后来由 ADR 0787 要求长度大于 0。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读空文字上的链接 | 没画出来的链接会删掉这条消息。 |
| 公式上的链接也不读 | 公式会画成固定说法，链接仍然包在这段说法上。 |
| 内联按钮一起改 | 那是另一条键盘。这条只改富文本。 |
| 把链接地址抄进正文 | 关键词会命中地址。内容哈希也会变。 |

## 后果

- 可见文字长度是 0 的富文本链接和没画出来的富文本按钮不再留下主机名。
- 看得见的短链、邀请或裸 IP 仍删除。证据只有主机名。
- 行内公式上的链接仍读。公式源码不进正文。
- 置顶预览和引用条的规则不变。
- 内联按钮的文字后来由 ADR 0787 要求长度大于 0。空文字和缺文字不再留下主机名。一个空格仍读。`callback_data` 仍不读。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
