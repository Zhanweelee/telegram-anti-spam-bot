# ADR 0728：勾完的任务上的文字链接不能越过正文

- 状态：已接受
- 日期：2026-11-07

## 背景

清单里的任务被标成完成或取消完成时，服务消息只画一条任务。完成名单非空时用第一项，否则用取消完成名单的第一项。见 ADR 0655。

Android 用 `formatTaskTitle` 画这条任务。它再交给 `formatTextWithEntities`。文字链接的起点大于或等于这条任务文字时，链接不会画上去。

现在对上的那条任务会读全部文字链接。起点已经越过正文的链接仍会留下主机名。

后加任务已经要求起点落在任务文字里。见 ADR 0727。勾完是另一条服务消息。

## 决策

- 完成提示上对上的那一条任务，文字链接的起点必须小于这条 `text` 的长度。
- 完成名单非空时仍只用第一项。否则仍用取消完成名单的第一项。
- 任务文字里的普通网址仍读。仍只留主机名。其余任务、标题和清单正文仍不读。
- 投票选项、游戏说明、礼物和引用不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`checklist_notice` 仍默认关闭。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条提示。 |
| 完成名单里的每一项都按正文长度过滤 | 客户端只把第一项画进这行。后面的项已经不读。 |
| 投票选项也按正文长度丢掉链接 | 选项是另一处字段。这条只改勾完的任务。 |

## 后果

- 起点越过画出的任务文字的文字链接不再留下主机名。仍落在这段文字里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。任务文字仍不进正文。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 投票选项上的文字链接后来由 ADR 0729 同样要求起点落在这条选项文字里。说明和描述仍不在那条里。
- 勾完的任务上的文字链接后来由 ADR 0777 要求长度大于 0。长度越过末尾时仍算画出来。任务文字不是字符串时，文字链接后来由 ADR 0788 不再读取。回复某一条任务时画出的那一行不在那条里。
