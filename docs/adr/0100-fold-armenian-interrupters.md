# ADR 0100：抽主机名时去掉亚美尼亚文

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0097 在抽主机名时去掉夹在标签里的西里尔、希腊和非 ASCII 拉丁字母。亚美尼亚文仍会把单词边界切开。`bաit.ly` 被扫成 `it.ly`，短链名单对不上。

这些字不映成拉丁字母。关键词比较不走这一层。

## 决策

- `foldHostInterrupters` 增加亚美尼亚文。抽主机名时删掉，不映成别的字母。
- 关键词和正则不走这一层。
- 汉字、谚文、假名、ASCII、全角数字和句号 `。` 保留。
- 事件里的正文和 `textSha256` 不变。不新增检测器，也不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把亚美尼亚文映成拉丁字母 | 会把普通词收成短链。ADR 0097 已经选择删掉而不是对照。 |
| 在关键词里也删 | 关键词比较会把这些字拆掉。这一项只服务主机名。 |
| 拒绝从亚美尼亚文后面开始主机名 | `点击bit.ly` 不受影响，但 `bաit.ly` 仍对不上 `bit.ly`。 |

## 后果

- `bաit.ly/…` 在扫描时变成 `bit.ly`，走现有短链规则。`点击bit.ly` 仍命中。
- `xաbit.ly` 变成 `xbit.ly`，不再被看成 `bit.ly`。
- `ա.me/+…` 变成 `.me/+…`，仍不是邀请。
- 关键词 `bit` 仍不命中 `bաit`。
- 重复计数仍按原文哈希。
