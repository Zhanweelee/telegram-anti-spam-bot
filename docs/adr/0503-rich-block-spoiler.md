# ADR 0503：富文本块上的剧透走同一条规则

- 状态：已接受
- 日期：2026-11-05

## 背景

普通照片、视频和动图用 `has_media_spoiler`。富文本块 `photo`、`video` 和 `animation` 另有 `has_spoiler`，意思同样是预览盖着剧透动画。ADR 0500 只读了前一个字段。富文本里的剧透图会留下，即使这个群已经打开 `media_spoiler`。

文件块和音频块没有这个字段。

## 决策

- 富文本块的 `type` 是 `photo`、`video` 或 `animation`，并且 `has_spoiler` 正好是 `true` 时，事件带 `asSpoiler: true`。嵌套在别的块里也同样。
- `false`、缺字段，以及文件块、音频块上的同名字段，不带这个标记。
- 顶层 `has_media_spoiler` 正好是 `true` 时仍带这个标记。两条来源任一成立即可。
- 文件号不进事件。说明仍是正文。已有 `text` 或 `caption` 时正文不变。
- 仍用检测器 `media_spoiler`。证据仍是 `media:spoiler`。不新增规则 id，也不新增命令。
- 付费帖仍不删除。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 另开一条规则 | 已经打开剧透的群还要再开一次，两层剧透是同一件事。 |
| 任何块上的 `has_spoiler` 都算 | 文件和音频没有这个字段。误放的值不该删文件。 |
| 把文件号写进证据 | ADR 0500 已经拒绝。 |

## 后果

- 规则关闭时，富文本里的剧透媒体留下。说明仍参与关键词。
- 打开 `media_spoiler` 后，这种富文本块会删除。打开贴纸、动图、语音、视频留言或骰子仍不删除它。付费帖仍留下。
- 没有新的规则 id。`chats.json` 不用为这件事再加一条。
- 30 天保留期没有改。
