# ADR 0733：游戏附加文字上的文字链接不能越过正文

- 状态：已接受
- 日期：2026-11-07

## 背景

游戏消息的正文是标题。附加文字在 `game.text`，短链在 `game.text_entities`。见 ADR 0078 与 ADR 0541。

Bot API 写明这些实体出现在 `text` 上。文字链接的起点大于或等于这段文字时，链接不会画上去。

现在附加文字会读全部文字链接。起点已经越过正文的链接仍会留下主机名。

引用已经要求起点落在摘录里。见 ADR 0732。游戏附加文字是另一段文字。

## 决策

- 游戏附加文字上的文字链接，起点必须小于 `game.text` 的长度。附加文字不是字符串时，仍按原来的方式读取。
- 附加文字里的普通网址仍读。游戏说明里的普通网址仍读。仍只留主机名。
- 投票描述和礼物不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条游戏消息。 |
| 游戏说明也按实体长度丢掉链接 | 说明没有自己的文字链接列表。这条只改附加文字。 |
| 礼物附言也一起改 | 那是另一条服务消息。这条只改游戏附加文字。 |

## 后果

- 起点越过附加文字的文字链接不再留下主机名。仍落在这段文字里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在附加文字里的路径仍留在 `gameText`。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 礼物附言上的文字链接后来由 ADR 0734 同样要求起点落在附言里。投票描述仍不在那条里。
- 游戏附加文字上的文字链接后来由 ADR 0770 要求长度大于 0。长度越过末尾时仍算画出来。测验说明不在那条里。
