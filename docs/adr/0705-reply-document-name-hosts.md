# ADR 0705：回复的文件名只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

回复一条没有说明的普通文件时，Android 把文件名放进这条消息的文字，再画在引用条上。文件名长过 150 个 UTF-16 码元时，只画前面这一段。有说明时改画说明，不再画文件名。动图、视频和音频只画固定字样。

任务行、选项行、引用、投票、外部媒体、游戏和账单已经占了这一行时，不再改画文件名。

ADR 0547 不把被回复的原文收进事件。这一行文件名仍会留下短链。

## 决策

- 前面的引用条都没有占住，且 `reply_to_message.document` 是对象时，从 `file_name` 的前 150 个码元留主机名。
- `caption` 或 `text` 的长度大于 0 时不读。说明和正文仍不进事件。
- 动图、视频、音频和贴纸的文件名不读。
- 没有 `reply_to_message` 时不读。外部回复上的文件名仍按 ADR 0704。
- 主机名仍进消息已有的 `hosts`。邀请仍进 `invites`。文件名不进正文，也不改内容哈希。关键词因此不命中。正文里已有短链时，证据仍先记正文的主机名。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 连说明一起读 | 有说明时引用条画的是说明。ADR 0547 仍把说明留在外面。 |
| 150 个码元之后也读 | 客户端只把前 150 个码元放进这一行。 |
| 动图文件名也读 | 动图这一行画的是固定字样。 |
| 把文件名收进正文 | 它是引用条上的一行。关键词仍只看这条消息自己的正文。 |

## 后果

- 画出的文件名出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。
- 说明、正文和被回复的原文仍不进事件。文件名不改内容哈希。关键词不命中文件名。
- 带引用、投票本身、任务行、选项行、外部媒体、游戏或账单时，不改读这份文件名。
- 第 151 个码元起的网址不读。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 回复改过名字的话题时，画出的新名字后来由 ADR 0706 只留主机名。图标编号和新建话题的名字仍不读。
- 动图、视频、音频、贴纸和图片再带一份 `document` 时，这份文件名后来由 ADR 0707 留在外面。只有普通文件时仍读。
