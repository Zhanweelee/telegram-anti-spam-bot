# ADR 0719：富文本短预览只读画出来的文字

- 状态：已接受
- 日期：2026-11-06

## 背景

置顶提示和引用条上的富文本预览来自 `formatRichMessage`，里面的文字来自 `formatRichText`。这个函数画出粗体、斜体、下划线、删除线、剧透、等宽、链接、邮箱、电话和按钮的可见文字。

提及、日期、下标、上标、标记、话题、命令、锚点、引用、银行卡和自定义表情的替代文字不在这份短预览里。气泡里的整篇文章仍画出它们。

ADR 0714 把带 `text` 的节点都拼进了预览。替代文字或提及里的短链会占满前 20 或 150 个码元，后面真正画出来的短链读不到。

## 决策

- 置顶提示和引用条拼富文本预览时，只展开 `formatRichText` 会画出的文字。
- 自定义表情不读 `alternative_text`。提及、日期和其它没画出来的节点不读，也不占满剩下的预览。
- 链接和按钮地址仍只在可见文字画进这段预览时才读。
- 气泡里的整篇文章仍按原来的规则读这些节点。预览不进正文，内容哈希不变。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 预览继续读所有带 `text` 的节点 | 短预览没有画出这些字。后面的短链会被挤掉。 |
| 这些节点占满剩下的预览 | 它们不是固定说法。后面画出来的短链会被漏掉。 |
| 气泡也不读这些节点 | 整篇文章里这些字是画出来的。 |
| 把替代文字抄进正文 | 关键词会命中没画在预览上的字。 |

## 后果

- 预览里这些节点后面的短链、邀请或裸 IP 会删掉这条消息。证据只有主机名。
- 提及、日期和表情替代文字里的路径不进置顶提示和引用条。气泡里的文章仍读。内容哈希不变。关键词不命中预览。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- `pin_notice` 仍默认关闭。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 行内公式后来由 ADR 0724 占满剩下的预览。公式原文不进这行。
