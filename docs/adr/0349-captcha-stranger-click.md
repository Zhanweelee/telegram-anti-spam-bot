# ADR 0349：别人点验证按钮时不删

- 状态：已接受
- 日期：2026-11-04

## 背景

ADR 0348 在点击者没有挑战时删掉点中的按钮。验证按钮是群里的公开消息。另一个成员点它时，查找用的是点击者自己的 id，取不到主人的挑战。这条路径会把还在用的按钮删掉，主人仍被限制，却没有按钮可点。

## 决策

- 点击者没有自己的挑战时，返回 `ignored`，不删点中的按钮，也不解除限制。
- 本人通过、到期、nonce 对不上，以及这次没取到时的删除，仍按 ADR 0348。这些路径都先读到了这个人的挑战。
- 日志不含 nonce 和按钮 id。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 没有挑战时仍删点中的按钮 | 别人一点就把主人的按钮删掉。 |
| 用按钮 id 反查主人再判断 | 存储按人查找。为一次点击扫描全表，也超出这一次要修的范围。 |

## 后果

- 别人点不掉还在用的验证按钮。
- 主人的挑战已经不在、只剩下一颗没人认领的按钮时，再点也不会删。这颗按钮留在群里。
- ADR 0348 里「挑战已经不在就删点中的这一颗」收窄为：先读到本人挑战、随后没取到或 nonce 对不上时才删。
- 30 天保留期不动。
