# ADR 0747：投票描述上的自定义表情必须落在描述里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。投票描述上的这种表情也走同一条规则。见 ADR 0571。测验说明必须整段落在说明里。见 ADR 0746。

`replaceAnimatedEmoji` 只在 `offset + length` 不超过这段文字时才放上表情。起点已经越过这段文字，或表情越过末尾，都不会画出来。文字链接已经要求起点落在整段描述里。见 ADR 0740。1024 只是事件字段 `pollDescription` 的上限，主机名和表情仍按整段原文。

现在描述会读全部 `description_entities`。一个越出描述的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条投票。

清单标题不在这条里。题干、选项和测验说明已经按各自的文字收过。

## 决策

- `poll.description` 是字符串时，`description_entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过整段描述。
- 描述不是字符串时，仍按原来的方式读取。
- 第 1025 字起的表情，只要整段仍落在描述里，就继续带 `asCustomEmoji`。事件里的 `pollDescription` 仍只留前 1024 字。
- 仍落在描述里的表情继续带 `asCustomEmoji`。编号仍不进事件。
- 清单标题不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条投票。 |
| 只要求起点小于描述 | 表情越过末尾时，客户端同样不会画。 |
| 也按 1024 字丢掉后面的表情 | 1024 只是事件字段的上限。整段原文更长时，后面的表情仍落在描述里。 |
| 描述不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的描述。 |
| 清单标题一起收 | 标题是另一段文字。 |

## 后果

- 起点加长度越过投票描述的自定义表情不再带 `asCustomEmoji`。空描述和长度为 0 的实体也不带。
- 仍落在描述里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。起点已经超过 1024、但仍整段落在描述里的表情也删除。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 清单标题上的自定义表情后来由 ADR 0748 要求整段落在标题里。标题不是字符串时仍按原来的方式读取。已有别的正文时，事件里的标题仍只留前 255 字。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
