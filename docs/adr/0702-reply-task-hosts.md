# ADR 0702：回复的任务和选项只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

回复清单里的某一条任务时，Android 把那条任务的文字画在引用条上。任务号对不上，就改画清单标题。回复投票里的某一个选项时，画那个选项的文字。编号对不上，就改画问题。其余任务、选项和被回复的原文不画在这一行。

Bot API 用 `reply_to_checklist_task_id` 和 `reply_to_poll_option_id` 标出这一行。清单和投票在 `reply_to_message` 上。外部回复里也能带清单和投票，但这条引用条只在原文已经加载时画任务或选项。

ADR 0547 不把被回复的原文收进事件。这一行仍会留下短链。

## 决策

- `reply_to_checklist_task_id` 是大于 0 的安全整数，且 `reply_to_message.checklist` 是对象时，从画出来的那一行留主机名。
- `tasks` 里 `id` 相同的那一项，读 `text` 和 `text_entities` 里的链接。读到就停。对不上，或没有任务数组，就读清单 `title` 和 `title_entities` 里的链接。其余任务不读。
- 上面的清单分支成立时，不再读投票。清单不存在时，`reply_to_poll_option_id` 是 1 到 256 字的字符串，且 `reply_to_message.poll` 是对象，才读投票。
- `options` 里 `persistent_id` 相同的那一项，读 `text` 和 `text_entities` 里的链接。读到就停。对不上，或没有选项数组，就读 `question` 和 `question_entities` 里的链接。其余选项、说明和描述不读。
- 没有 `reply_to_message` 时不读。外部回复上的清单和投票不读。被回复的原文不读。
- 主机名仍进消息已有的 `hosts`。邀请仍进 `invites`。这行不进正文，也不改内容哈希。关键词因此不命中。正文里已有短链时，证据仍先记正文的主机名。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 整份被回复的清单或投票都读 | 引用条只画对得上的那一行。对不上才改画标题或问题。 |
| 外部回复上的清单也读 | 原文没加载时，这行不画任务文字。 |
| 把这行收进正文 | 它是引用条上的一行。关键词仍只看这条消息自己的正文。 |
| 新命令 | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 画出的任务、标题、选项或问题出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。文字链接的起点不能超过这段文字。见 ADR 0725。
- 其余任务、选项、说明和被回复的原文仍不进事件。这行不改内容哈希。关键词不命中这行。
- 正文里已有短链时，证据仍先记正文的主机名。手动引用仍按原来的顺序排在前面。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 没有任务号时，已加载回复上画出的标题后来由 ADR 0709 只留前 150 个码元的主机名。任务仍不读。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 任务和选项都没有占住这一行时，游戏或账单标题后来由 ADR 0703 只留主机名。带引用或投票本身时仍不改读。
