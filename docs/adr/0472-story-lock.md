# ADR 0472：转发来的故事卡片按群删除

- 状态：已接受
- 日期：2026-11-04

## 背景

转发一条故事时，Bot API 的 `story` 对象没有说明。发布者的标题或姓名只抽出主机名，名字本身不进正文。见 ADR 0325。名字里没有短链、正文又是空的时候，这条故事卡片会留下。

回复一条故事时，成员自己写的正文仍在。那一条要按正文判断，不能因为带着 `reply_to_story` 就删掉。

## 决策

- `message.story` 是对象，并且 `story.chat` 也是对象时，事件带 `asStory: true`。不写发布者名字、用户名、聊天 id 和故事编号。
- 只有 `reply_to_story`、空的 `story`，或 `story` 里没有 `chat` 对象时，不带这个标记。名字里的主机名仍按 ADR 0325 抽取。
- 检测器在 `@tasb/detector-story`，id 是 `shared_story`。只在 `message.asStory` 为 true 时返回 score 1。证据是 `story:card`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这种故事卡片。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`shared_story` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部故事卡片 | 有的群允许转发故事。打开之前不改现有群。 |
| 连回复一条故事一起删 | 回复的正文是成员自己写的。短链和关键词仍按原规则删除。 |
| 把发布者名字当成正文 | 名字会进事件和哈希。见 ADR 0325。 |
| 新命令 `/story` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，转发来的故事卡片仍留下。名字里的短链仍按链接规则删除。
- 打开 `shared_story` 后，这个群里转发来的故事卡片会删除。只回复一条故事的消息仍留下。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `shared_story` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
