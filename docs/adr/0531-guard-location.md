# ADR 0531：私聊可以看到这个群是否绑在地点上

- 状态：已接受
- 日期：2026-11-05

## 背景

超级群可以绑在一个地图地点上。这和成员发出的位置图钉不是同一件事。`getChat` 把地点放在 `location` 里，里面有坐标和地址。`/guard` 已经读这一份 `ChatFullInfo`，但回复里没有这项。

地址是成员看得见的原文，坐标也不是反垃圾规则要记的数。管理员只需要知道这个群是不是地点群。

## 决策

- `/guard <chatId>` 在关联群后面多写一行：地点群。
- `location` 缺失时写关。官方把这个字段定义成「超级群所绑定的地点」，没返回就是没有绑定。
- 字段是普通对象，内层坐标是有限数字，并且地址是字符串时，写开。地址和坐标不进回复，也不进日志。
- 字段不是这种形状时，整份回复仍是「参数无效」，不露出已经读到的字段，也不露出地址。
- 不把坐标或地址写进事件。不调用 `setChatPermissions`。纯位置消息仍按 ADR 0473 处理。
- 不新增命令。菜单仍是 99 条。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 新命令只看地点 | 菜单已经 99 条。这项和关联群一样，都是这个群现在的姿态。 |
| 缺字段写成未知 | 这个字段不是只在为真时出现的管理员开关。没返回就是没绑定。 |
| 把地址或坐标写进回复 | 地址可以是原文。坐标不该进私聊日志。 |

## 后果

- `/guard -100` 能看到这个群现在有没有绑定地点。一次查看仍是一次 `getChat`。
- 地址和坐标仍留在 Telegram。纯位置消息的删除规则不变。
- 30 天保留期没有改。
