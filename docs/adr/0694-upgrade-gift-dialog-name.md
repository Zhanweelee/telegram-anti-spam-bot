# ADR 0694：升级独特礼物时只读私聊对方

- 状态：已接受
- 日期：2026-11-06

## 背景

独特礼物被升级，或升级是事后买下的，Android 的 `TL_messageActionStarGiftUnique` 走 `action.upgrade`。没有礼物所属对象时，这行用 `replaceWithLink` 画对话对方。那是 `UserObject.getUserName`。名和姓都先去掉两端空白，名在前。空白名不挡住姓。空格不截断。群和频道的对话不是用户，名字是空的。礼物所属的频道会换成另一句，Bot API 没有这个对象。

Bot API 把来源放在 `unique_gift.origin`。`upgrade` 是普通礼物升级来的。`gifted_upgrade` 是送出之后才买的升级。见 `UniqueGiftInfo`。

ADR 0691 仍从 `from` 或 `sender_chat.title` 留主机名。ADR 0693 只跳过购买报价。升级这行不画消息发送者。

## 决策

- `unique_gift.gift` 是对象，且没有更优先的普通礼物时，`origin` 正好是 `upgrade` 或 `gifted_upgrade` 就不从 `from` 留主机名，也不从 `sender_chat.title` 留主机名。
- `chat.type` 正好是 `private` 时，从私聊对方会画出来的全名留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。用户名和 `title` 不读。
- 群、超级群和频道不读群名，也不读群对象上的名字。
- 编号不同的聊天标题仍由通用代发规则读取。不从 `chat.title` 另读。
- 购买报价仍按 ADR 0693。转账和转售后来读对话。见 ADR 0695。普通礼物仍按 ADR 0691。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`gift_card` 仍默认关闭。短链仍走已有的 `links`。8 个主机名的上限不变。星星不退回。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读发送者 | 升级这行不画 `from`，也不画发送者标题。短链会删掉看不见的名字。 |
| 群里改读群名 | 群的对话不是用户。`replaceWithLink` 得到的是空名字。 |
| 连礼物所属的频道一起读 | 这条更新没有这个对象。 |
| 新命令 | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 群和频道里的升级不再因为占位名字或本群标题留下主机名。关掉管理员豁免也不因此删除。
- 私聊对方的全名里的短链会删掉这条提示。证据只有主机名。
- 别的聊天发到这个群时，标题仍由通用代发规则留下主机名。
- 购买报价和普通礼物仍按原来的规则。转账和转售后来读对话。见 ADR 0695。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。
- 30 天保留期没有改。
