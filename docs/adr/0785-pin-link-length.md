# ADR 0785：置顶预览上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。置顶一条文字消息时，提示只画前 20 个码元。起点落在这段里的文字链接只留主机名。见 ADR 0715。清单标题用同一段预览，任务不读。见 ADR 0716。引用条上说明和正文的文字链接，长度必须大于 0。见 ADR 0784。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达画出的这段末尾的实体。起点落在这 20 个码元里、长度越过末尾时，客户端把长度收到这段末尾，这段链接仍会画出来。第 21 个码元起不画。这行不进正文。代码块语言不画在这条预览上。账单说明不读消息上的实体。富文本预览另走一条。

现在这 20 个码元只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在画出的这段里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条置顶提示。

## 决策

- 置顶预览来自 `text` 时，`entities` 里的 `text_link`，起点必须大于或等于 0 且小于画出的这段长度，长度必须是大于 0 的安全整数。
- 置顶预览来自清单标题时，`title_entities` 里的 `text_link` 用同一条规则。任务仍不读。
- 画出的这段是这段文字长度和 20 个码元里较短的那个。
- 起点落在这段里、长度越过末尾时，仍留下主机名。
- 第 21 个码元起的链接仍不读。写在第 21 个码元起的普通网址仍不读。
- 代码块语言仍不读。账单说明仍不读消息上的实体。游戏仍只读标题。
- 富文本预览仍按原来的方式读取。这行仍不进正文。
- 写在画出的前 20 个码元里的普通网址仍从这段原文抽取。仍只留主机名。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`pin_notice` 仍默认关闭。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条置顶提示。 |
| 也要求长度落在这 20 个码元里 | 起点在这段里时，客户端会把越过末尾的长度收回来再画。 |
| 改成整段正文都读 | 置顶提示只画前 20 个码元。 |
| 代码块语言也读 | 这条预览不画代码块语言。 |
| 富文本预览一起改 | 那是另一条预览。这条只改文字和清单标题。 |

## 后果

- 置顶文字和清单标题预览上，长度小于或等于 0、不是安全整数的文字链接不再留下主机名。
- 起点落在画出的前 20 个码元里、长度越过末尾的短链、邀请或裸 IP 仍删除。第 21 个码元上的链接仍不删除。证据只有主机名。
- 写在画出的前 20 个码元里的普通网址仍会删除。被截断的路径不进事件。任务仍不读。这行仍不进正文。
- 代码块语言仍不读。账单说明仍不读消息上的实体。
- 气泡里的富文本链接后来由 ADR 0786 要求可见文字长度大于 0。置顶预览和引用条仍只在可见文字画出来时才读。内联按钮的文字后来由 ADR 0787 要求长度大于 0。任务文字不是字符串时，文字链接后来由 ADR 0788 不再读取。选项文字不是字符串时，文字链接后来由 ADR 0789 不再读取。测验说明不是字符串时，文字链接后来由 ADR 0790 不再读取。投票描述不是字符串时，文字链接后来由 ADR 0791 不再读取。投票题干不是字符串时，文字链接后来由 ADR 0792 不再读取。清单标题不是字符串时，文字链接后来由 ADR 0793 不再读取。礼物附言不是字符串时，文字链接后来由 ADR 0794 不再读取。游戏附加文字不是字符串时，文字链接后来由 ADR 0795 不再读取。消息说明不是字符串时，文字链接后来由 ADR 0796 不再读取。消息正文不是字符串时，文字链接仍按原来的方式读取。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- `pin_notice` 仍默认关闭。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
