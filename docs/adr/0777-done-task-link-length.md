# ADR 0777：勾完的任务上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。勾完或取消勾完时只画一条任务。完成名单非空时用第一项，否则用取消完成名单的第一项。文字链接的起点必须落在这条任务文字里。见 ADR 0728 与 ADR 0655。后加任务上的文字链接，长度必须大于 0。见 ADR 0776。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达任务末尾的实体。起点落在任务里、长度越过末尾时，客户端把长度收到任务末尾，这段链接仍会画出来。任务文字不进正文。其余任务、标题和清单正文不画。

现在画出的任务只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在任务里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条服务消息。代码块语言里的网址也走同一段实体。

回复某一条任务时画出的那一行不在这条里。

## 决策

- `checklist_tasks_done` 里对上的那一条任务，`text` 是字符串时，`text_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于这条任务的长度，长度必须是大于 0 的安全整数。
- 起点落在这条任务里、长度越过末尾时，仍留下主机名。
- 任务文字不是字符串时，仍按原来的方式读取。
- 完成名单非空时仍只用第一项。否则仍用取消完成名单的第一项。其余任务、标题和清单正文仍不读。
- 任务文字不进正文。写在这条任务里的普通网址仍从整段原文抽取。仍只留主机名。
- 回复某一条任务时画出的那一行不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`checklist_notice` 仍默认关闭。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条服务消息。 |
| 也要求长度落在任务里 | 起点在任务里时，客户端会把越过末尾的长度收回来再画。 |
| 按正文长度丢掉任务上的链接 | 任务文字不进正文。链接仍按这条任务判断。 |
| 完成名单里的每一项都改 | 客户端只把第一项画进这行。后面的项已经不读。 |
| 回复的任务一起改 | 那是引用条上的另一行。这条只改勾完的任务。 |

## 后果

- 画出的任务上，长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在任务里、长度越过末尾的短链、邀请或裸 IP 仍删除。证据只有主机名。
- 写在画出的任务里的普通网址仍会删除。被截断的路径不进事件。任务文字仍不进正文。
- 任务文字不是字符串时，文字链接后来由 ADR 0788 不再读取。按标识提及和自定义表情仍按原来的方式读取。
- 其余任务、标题和清单正文仍不读。完成名单非空时仍不读取消完成名单。
- 回复某一条任务时，对上的任务上的文字链接后来由 ADR 0778 要求长度大于 0。任务文字不是字符串时，文字链接后来由 ADR 0788 不再读取。长度越过末尾时仍算画出来。任务号对不上时的标题，以及投票选项，不在那条里。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
