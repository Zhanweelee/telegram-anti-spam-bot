# ADR 0787：内联按钮的文字长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。内联按钮的 `url`、复制句子、`login_url` 和 `web_app` 只留主机名。见 ADR 0053、ADR 0055 与 ADR 0074。没有更前面的正文时，按钮文字成为正文。见 ADR 0063。空文字不进这段正文。富文本按钮的标签长度是 0 时不再读地址。见 ADR 0786。

Android 只画文字长度大于 0 的内联按钮。空字符串和缺文字的按钮没有画出来，点不到。一个空格仍算有文字。`callback_data` 不是地址。回复键盘不出现在入站消息上。

现在空文字和缺文字的按钮仍会留下地址里的主机名。打开链接规则后，没画出来的按钮也会删掉这条消息。

## 决策

- `reply_markup.inline_keyboard` 里，`text` 必须是长度大于 0 的字符串，才读按钮上的网址。
- 读到的仍是可见文字里的网址、`url`、`copy_text`、`login_url.url`、`login_url.forward_text`、`web_app.url`，以及会写进输入框的查询。只留主机名。
- 空字符串和缺文字的按钮不读这些地址。
- 只有空格的文字仍读。这段文字仍按 ADR 0063 成为正文。
- `callback_data` 仍不读。回复键盘仍不读。富文本按钮仍按 ADR 0786。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读空文字上的地址 | 没画出来的按钮会删掉这条消息。 |
| 一个空格也不读 | 客户端仍会画出这个按钮。 |
| 连 `callback_data` 一起读 | 回调数据不是打开的地址。 |
| 把地址抄进正文 | 关键词会命中地址。内容哈希也会变。 |

## 后果

- 文字为空或缺少文字的内联按钮不再留下主机名。复制句子、登录地址、小程序地址和查询也不读。
- 文字长度大于 0 的短链、邀请或裸 IP 仍删除。证据只有主机名。
- 一个空格仍会留下主机名。已有别的正文时，这段文字仍留在 `buttonText`。
- `callback_data` 仍不读。回复键盘仍不读。
- 任务文字不是字符串时，文字链接后来由 ADR 0788 不再读取。选项文字不是字符串时，文字链接后来由 ADR 0789 不再读取。测验说明不是字符串时，文字链接后来由 ADR 0790 不再读取。投票描述不是字符串时，文字链接后来由 ADR 0791 不再读取。投票题干不是字符串时，文字链接后来由 ADR 0792 不再读取。清单标题不是字符串时，文字链接后来由 ADR 0793 不再读取。礼物附言不是字符串时，文字链接后来由 ADR 0794 不再读取。游戏附加文字不是字符串时，文字链接后来由 ADR 0795 不再读取。消息说明不是字符串时，文字链接后来由 ADR 0796 不再读取。消息正文不是字符串时，文字链接后来由 ADR 0797 不再读取。正文不是字符串时，按标识提及后来由 ADR 0798 不再读取。说明不是字符串时，按标识提及后来由 ADR 0799 不再读取。投票题干不是字符串时，按标识提及后来由 ADR 0800 不再读取。测验说明不是字符串时，按标识提及后来由 ADR 0801 不再读取。投票描述不是字符串时，按标识提及后来由 ADR 0802 不再读取。清单标题不是字符串时，按标识提及后来由 ADR 0803 不再读取。清单任务文字不是字符串时，按标识提及后来由 ADR 0804 不再读取。后加任务文字不是字符串时，按标识提及后来由 ADR 0805 不再读取。礼物附言不是字符串时，按标识提及后来由 ADR 0806 不再读取。游戏附加文字不是字符串时，按标识提及后来由 ADR 0807 不再读取。正文不是字符串时，自定义表情后来由 ADR 0808 不再读取。说明不是字符串时，自定义表情后来由 ADR 0809 不再读取。投票题干不是字符串时，自定义表情后来由 ADR 0810 不再读取。测验说明不是字符串时，自定义表情后来由 ADR 0811 不再读取。投票描述不是字符串时，自定义表情后来由 ADR 0812 不再读取。投票选项文字不是字符串时，自定义表情后来由 ADR 0813 不再读取。后加或删掉的选项文字不是字符串时，自定义表情后来由 ADR 0814 不再读取。清单标题不是字符串时，自定义表情后来由 ADR 0815 不再读取。清单任务文字不是字符串时，自定义表情后来由 ADR 0816 不再读取。后加任务文字不是字符串时，自定义表情后来由 ADR 0817 不再读取。礼物附言不是字符串时，自定义表情后来由 ADR 0818 不再读取。游戏附加文字不是字符串时，自定义表情后来由 ADR 0819 不再读取。手动引用不是字符串时，自定义表情后来由 ADR 0820 不再读取。富文本替代文字不是字符串时，自定义表情后来由 ADR 0821 不再读取。替代文字是空字符串时，自定义表情后来由 ADR 0822 不再读取。公式源码里的自定义表情后来由 ADR 0823 不再读取。预格式化块的语言标签里，自定义表情后来由 ADR 0824 不再读取。音频文件名里的自定义表情后来由 ADR 0825 不再读取。音频标题里的自定义表情后来由 ADR 0826 不再读取。音频表演者里的自定义表情后来由 ADR 0827 不再读取。视频文件名里的自定义表情后来由 ADR 0828 不再读取。动画文件名里的自定义表情仍按原来的方式读取。
