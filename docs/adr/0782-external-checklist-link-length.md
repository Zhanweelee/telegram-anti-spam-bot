# ADR 0782：外部回复清单标题上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。原文不在本群时，外部回复的清单画出整段标题，不按 150 个码元截断。任务不读。见 ADR 0704 与 ADR 0735。编号对不上时的问题上的文字链接，长度必须大于 0。见 ADR 0781。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达标题末尾的实体。起点落在标题里、长度越过末尾时，客户端把长度收到标题末尾，这段链接仍会画出来。这行不进正文。

现在这段标题只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在标题里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条回复。代码块语言里的网址也走同一段实体。

没有任务号时只取前 150 个码元的已加载清单标题不在这条里。标题不是字符串时仍按原来的方式读取。

## 决策

- 外部回复上的清单，`title` 是字符串时，`title_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于这段标题的长度，长度必须是大于 0 的安全整数。
- 起点落在这段标题里、长度越过末尾时，仍留下主机名。
- 标题不是字符串时，仍按原来的方式读取。
- 整段标题仍读，不改按 150 个码元截断。任务仍不读。这行仍不进正文。
- 写在这段标题里的普通网址仍从整段原文抽取。仍只留主机名。
- 没有任务号时只取前 150 个码元的已加载清单标题不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条回复。 |
| 也要求长度落在标题里 | 起点在标题里时，客户端会把越过末尾的长度收回来再画。 |
| 这行也只取前 150 个码元 | 外部回复的清单标题画出的是整段标题。 |
| 没有任务号的已加载标题一起改 | 那一行只取前 150 个码元。这条只改外部回复。 |

## 后果

- 外部回复上，长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在标题里、长度越过末尾的短链、邀请或裸 IP 仍删除。第 151 个码元上的链接，只要起点仍落在这段标题里、长度大于 0，也删除。证据只有主机名。
- 写在这段标题里的普通网址仍会删除。被截断的路径不进事件。任务仍不读。这行仍不进正文。
- 标题不是字符串时，长度不是正数的文字链接仍按原来的方式读取。
- 没有任务号时只取前 150 个码元的已加载清单标题，文字链接后来由 ADR 0783 要求长度大于 0。空标题和标题不是字符串时仍不读这些实体。有说明或正文时仍不读标题。长度越过末尾时仍算画出来。第 151 个码元起仍不读。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
