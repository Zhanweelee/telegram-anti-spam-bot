# ADR 0506：按用户标识的富文本提及按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

富文本可以按用户标识点一个人。字段是 `user`。看得见的字可以和这个人的名字不同。ADR 0076 让用户编号不进事件，关键词看不见被点的人。看得见的字已经可以成为正文。

ADR 0505 只认 `username`。打开 `rich_mention` 不会删除这种按标识的提及。

## 决策

- `type` 正好是 `text_mention`，并且 `user.id` 是大于 0 的安全整数时，事件带 `asRichTextMention: true`。嵌套在别的块里也同样。
- 缺用户、布尔值、字符串编号和 0 不带这个标记。用户名提及仍只带 `asRichMention`。
- 用户编号和名字不进事件，也不进证据。看得见的字仍是正文。已有 `text` 或 `caption` 时正文不变，编号不并进去。
- 检测器在 `@tasb/detector-rich`，id 是 `rich_text_mention`。只在 `message.asRichTextMention` 为 true 时返回 score 1。证据是 `rich:text_mention`。
- 默认规则关闭。私聊 `/rule <chatId> rich_text_mention on` 之后删除这种正文，`off` 回到留下。
- 不并进 `rich_mention`。不调用读取或改写用户的方法。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`rich_text_mention` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 并进用户名提及 | 只想删用户名的群会把按标识的提及也删掉。 |
| 把用户编号接到正文后面 | 同一条消息的哈希会变，编号也会进事件。ADR 0076 已经拒绝。 |
| 把用户编号写进证据 | 用户编号不进事件。 |
| 默认打开 | 有的群用富文本点名。打开之前不改现有群。 |
| 新命令 `/user` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，按标识的富文本提及留下。看得见的字仍参与关键词。用户编号仍不进事件。
- 打开 `rich_text_mention` 后，这个群里的这种提及会删除。打开 `rich_mention` 仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `rich_text_mention` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `rich_text_mention`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
