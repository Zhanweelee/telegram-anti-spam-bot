# ADR 0415：私聊可以查看 bot 的默认简介

- 状态：已接受
- 日期：2026-11-04

## 背景

默认简介已经可以设置。查看调用是 `getMyDescription`。

`language_code` 可选。不送时返回给没有专用语言简介的人看的那个简介。已经有单独语言简介的人不在这次结果里。

返回值是 `BotDescription`。字段 `description` 是这个 bot 的简介。

## 决策

- 私聊命令 `/mydesc`。没有参数。多出来的参数不发出请求。别的单词回复「参数无效」。群聊里的同样文本不执行。
- 只有配置里的管理员可以看。接入目录里的人即使管着自己的群也不能看。
- 调用 `ModerationPort.readBotDescription`。适配器调用 `getMyDescription`。正文是空对象。不送 `language_code`。
- 简介是 0 到 512 个字符、没有换行的字符串时，回复带上这个简介。空字符串回复「简介 空」。
- 缺字段、非字符串、超长或带换行时整份回复是「参数无效」，不露出已经读到的简介。其它字段不进回复，也不进日志。
- 日志只写 `operator_rejected` 或命令名，带上 eventId、chatId 和命令名 `mydesc`。不写简介、异常文本或 token。
- 没有 token 的 Worker 不编一份简介。
- 不调用 `setMyDescription`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 查看某一个语言的简介 | 那要送 `language_code`。这次只读默认简介。 |
| 空简介当成失败 | 清掉默认简介之后，空字符串是当前状态。 |
| 回复里不写简介 | 管理员私聊来就是为了看到当前简介。日志仍然不写。 |

## 后果

- 成功只表示 Telegram 返回了默认简介。已有单独语言简介的人不受这次查看影响。
- 一次查看是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
