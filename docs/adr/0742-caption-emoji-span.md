# ADR 0742：说明上的自定义表情必须落在说明里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。正文上的表情必须整段落在正文里。见 ADR 0741。

媒体说明由 `generateCaption` 交给 `replaceAnimatedEmoji`。表情只在 `offset + length` 不超过说明时才画出来。起点已经越过说明，或表情越过说明末尾，都不会画。长度为 0 的实体也不会画。

现在说明会读全部 `caption_entities`。一个越出说明的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条消息。

引用条上的说明只取前 150 个码元。本条说明按整段长度判断。投票、清单、礼物、游戏和手动引用不在这条里。

## 决策

- `caption` 是字符串时，`caption_entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过说明。
- `caption` 不是字符串时，仍按原来的方式读取。
- 起点已经超过 150 个码元、但仍整段落在说明里的表情，继续带 `asCustomEmoji`。
- 正文上的自定义表情不在这条里。编号仍不进事件。看得见的字仍是说明。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条消息。 |
| 也按 150 个码元丢掉后面的表情 | 150 是引用条的上限。本条说明按整段长度判断。 |
| 说明不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的说明。 |
| 投票题干一起收 | 题干是另一段文字。 |

## 后果

- 起点加长度越过说明的自定义表情不再带 `asCustomEmoji`。空说明和长度为 0 的实体也不带。
- 仍落在说明里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 说明不是字符串时，自定义表情后来由 ADR 0809 不再读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 投票题干上的自定义表情后来由 ADR 0743 要求整段落在题干里。题干不是字符串时仍按原来的方式读取。
