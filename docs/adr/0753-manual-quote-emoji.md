# ADR 0753：手动引用上的自定义表情必须落在摘录里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。游戏附加文字必须整段落在附加文字里。见 ADR 0752。手动引用上的自定义表情也走同一条规则。见 ADR 0574。

Android 引用条先把摘录里的换行换成空格，长度不变，再用 `replaceAnimatedEmoji` 把自定义表情画到整段摘录上。起点加长度越过摘录时，表情不会画出来。

已有别的正文时，事件里的 `quoteText` 只留前 4096 字。表情仍按整段摘录判断。

现在手动引用会读全部 `entities`。一个越出摘录的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条消息。

自动引用和被回复的原消息不在这条里。

## 决策

- `quote.is_manual` 正好是 `true`，并且 `quote.text` 是字符串时，这段 `entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过这段摘录。
- 摘录不是字符串时，仍按原来的方式读取。
- 第 4097 字起的表情，只要整段仍落在摘录里，就继续带 `asCustomEmoji`。已有别的正文时，事件里的 `quoteText` 仍只留前 4096 字。
- 仍落在摘录里的表情继续带 `asCustomEmoji`。编号和引用位置仍不进事件。
- 自动引用和被回复的原消息仍不带这个标记。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条消息。 |
| 只要求起点小于摘录 | 表情越过末尾时，客户端同样不会画。 |
| 也按 4096 字丢掉后面的表情 | 4096 只是旁路字段的上限。整段摘录更长时，后面的表情仍落在摘录里。 |
| 只取前 150 个码元 | 引用条画出整段摘录。150 是被回复正文自己的窗口。 |
| 连自动引用一起收 | 自动摘录不是发送者选的。这条只改手动引用。 |
| 摘录不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的摘录。 |

## 后果

- 起点加长度越过手动引用的自定义表情不再带 `asCustomEmoji`。空摘录和长度为 0 的实体也不带。
- 仍落在摘录里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。起点已经超过 4096、但仍整段落在摘录里的表情也删除。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 自动引用和被回复的原消息仍不带这个标记。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
