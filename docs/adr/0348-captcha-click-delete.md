# ADR 0348：点到的验证按钮也要删掉

- 状态：已接受
- 日期：2026-11-04

## 背景

通过和到期会删掉挑战上记下的那一颗按钮。再发时如果上一颗没删掉，群里会有两颗，nonce 相同，挑战只留着后一颗的 id。成员点前一颗时，取走挑战并删掉记下的那颗，点中的这一颗还在。再点一次时挑战已经没了，这颗按钮就留在群里。

nonce 对不上的旧按钮也一样。当前按钮还要留着，点中的那颗已经没用了。

## 决策

- 验证回调把按钮的 `message_id` 放进 `challenge.messageId`。没有合法 id 时不带。不带消息正文。
- 通过或到期时，记下的 id 和点中的 id 不同就两颗都删。
- 挑战已经不在，或这次没取到时，删掉点中的这一颗。
- nonce 对不上时只删点中的这一颗，记下的按钮和挑战都留着。
- 点中的 id 和记下的 id 相同，只删一次。
- 删除失败记 `captcha_prompt_delete_failed`。通过和到期的结果不变。日志只有事件 id 和群 id。
- 解除限制失败时不删按钮，挑战按原来的方式放回去。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 只删记下的 id | 点中的另一颗没有 id 可循，会留在群里。 |
| nonce 对不上时把两颗都删 | 当前这颗还点得中。 |
| 把按钮 id 放进 `message` | 那是消息正文的位置。验证回调不带正文。 |

## 后果

- 成员点中的验证按钮会被删掉，包括挑战上没记下的那一颗。
- 当前按钮在 nonce 对不上时还留着。
- 回调查不到合法 `message_id` 时，仍只删已经记下的那颗。
- 30 天保留期不动。
