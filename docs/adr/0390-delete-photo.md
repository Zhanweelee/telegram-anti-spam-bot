# ADR 0390：私聊可以删除一个群的头像

- 状态：已接受
- 日期：2026-11-04

## 背景

群头像被换成诈骗图时，管理员要能拿掉它，同时留下标题和简介。官方有一次只删头像的调用。

`deleteChatPhoto` 删除一个群的头像。参数只有 `chat_id`。私聊不能改头像。bot 必须是管理员，并且有相应的管理权限。成功时返回 True。

这条调用不上传新头像，也不改标题或简介。

没有 token 时，内存适配器可以把这次请求记下来。私聊如果复用这次成功，回复会写成头像已经删除。文件号不能进回复或日志。

## 决策

- 私聊命令 `/delphoto <chatId>`。群 id 匹配 `^-?\d{1,20}$`。多出来的参数不发出请求。群聊里的同样文本不执行。
- 配置中的管理员可以操作任意群。接入目录里的人只能操作自己的群。
- 调用 `ModerationPort.deletePhoto`。适配器调用 `deleteChatPhoto`，只带 `chat_id`。
- 不调用 `setChatPhoto`。不上传文件，也不读取文件号。
- 回复写明头像被请求删除，标题和简介还在。
- 没有 token、没有这个方法，群号不合法，或调用失败时回复「参数无效」。日志只写 `operator_rejected`，带上 eventId、chatId 和命令名。不写异常文本、token、原文或文件号。
- 没有 token 的 Worker 不把内存里的记录回复成已经成功。
- 不修改标题、简介、黑名单、白名单、封禁或禁言。不读取消息正文。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 先用 `getChat` 读出头像再删除 | 多一次子请求，还会带回标题、简介和邀请链接。删除本身不需要文件号。 |
| 上传一张空白头像代替删除 | 官方有直接删除的方法。上传会把一份新文件交给 Telegram。 |
| 私聊群号在本地直接拒绝 | 群号和私聊号的形状会重叠。私聊不能改头像时，由 Telegram 返回失败。 |
| 没有 token 时也回复「已删除」 | 头像还在。管理员会以为已经拿掉。 |

## 后果

- 成功只表示 Telegram 接受了这一次删除。私聊、没有头像，或缺少相应管理权限时，回复是「参数无效」。
- 标题和简介还在。
- 一次删除是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
