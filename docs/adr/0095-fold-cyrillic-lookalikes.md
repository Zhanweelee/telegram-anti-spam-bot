# ADR 0095：七个西里尔字母在比较前收成拉丁字母

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0094 收了全角拉丁字母。`bit.lу` 和 `t.mе/+…` 里的 `у`、`е` 仍是西里尔字母。URL 解析器把它们收成 punycode，所以 `bit.lу` 变成 `bit.xn--l-cub`，短链和邀请名单都对不上。带协议的地址也一样。

同形字库仍不引入。乌克兰语 `і` 和西里尔 `т` 先留着，避免把整段俄文收成拉丁字母。

## 决策

- 新增 `foldCyrillicLookalikes`。只收这 7 对：`а/А`、`е/Е`、`о/О`、`р/Р`、`с/С`、`у/У`、`х/Х`，对应 `a/A`、`e/E`、`o/O`、`p/P`、`c/C`、`y/Y`、`x/X`。
- 关键词和正则在全角拉丁字母之前做这一层。大小写开关仍先作用于原文。
- 链接检测、`hostFromUrl` 和从正文里抽网址的扫描，也在全角拉丁字母之前做这一层。
- 乌克兰语 `і/І`、西里尔 `т/Т`、全角数字、`U+FF0B`、`U+3002` 和普通空格保留。
- 事件里的正文和 `textSha256` 不变。不新增检测器，也不改 ADR 0026 的基础检测器名单。不引入同形字库。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 引入同形字库 | ADR 0054 已经拒绝。这一项只写死 7 个字母。 |
| 连 `і` 和 `т` 一起收 | `т` 在俄文里很常见。收了以后，普通句子更容易被扫成主机名。 |
| 只在链接检测里收 | `加微х` 仍会绕过默认正则。关键词和正则走同一层。 |
| 在归一化时改掉正文 | 哈希变了，重复计数会拆开。 |

## 后果

- `bit.lу/…` 和 `t.mе/+…` 会走现有短链和邀请规则。`еxample.com` 仍保留。
- `加微х` 会命中默认正则。`сору` 会命中关键词 `copy`。大小写敏感时小写形式仍不命中大写关键词。
- `привет` 比较时变成 `пpивeт`，仍不命中 `免费领取`。这一项不收 `і`。ADR 0096 随后把乌克兰语 `і` 收成 `i`。西里尔 `т` 仍保留。
- 重复计数仍按原文哈希。
