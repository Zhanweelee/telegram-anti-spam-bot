# ADR 0356：付费帖不删除

- 状态：已接受
- 日期：2026-11-04

## 背景

Telegram 把 `is_paid_post` 为 true 的消息标成付费帖，并写明 24 小时内不能删除，否则收不到这笔付款。检测仍会看见正文。命中关键词或短链时，删除动作会把这条帖子删掉。

## 决策

- `is_paid_post` 正好为 true 时，消息带 `paid: true`。星星数量不进事件。
- `false`、缺失和其它值都不带这个字段。
- 删除动作看到 `paid` 时返回 `skipped` / `paid_post`，不调用 `deleteMessage`。
- 禁言、封禁和其它动作仍按原规则执行。dry-run 仍先返回 `dry_run`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 整条付费帖直接放行 | 正文里的广告仍需要禁言或封禁。要留住的是帖子本身。 |
| 把星星数量写进事件 | 付款金额不是检测需要的证据。 |

## 后果

- 付费帖命中删除规则时，帖子留在聊天里。
- 同一条决策里的禁言或封禁仍会发出。
- 30 天保留期不动。
