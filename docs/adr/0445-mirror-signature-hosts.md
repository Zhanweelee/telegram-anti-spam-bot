# ADR 0445：讨论组原帖来源上的作者签名只留主机名

- 状态：已接受
- 日期：2026-11-04

## 背景

关联频道的帖子会自动出现在讨论组里。ADR 0443 不再把这种原帖记成频道转发。客户端仍在帖子下面画出原作者签名。这段字在 `forward_origin.author_signature`，不在这条消息自己的 `author_signature` 上。

ADR 0091 和 ADR 0101 不读转发来源上的签名，因为成员转发的频道帖本来就会被删掉。原帖留下之后，短链或关键词可以只写在这行签名里。频道标题仍不是这条签名。

## 决策

- `is_automatic_forward` 正好是布尔值 true，并且 `forward_origin.type` 是 `channel` 时，从 `forward_origin.author_signature` 抽出网址，只留主机名。长度、折叠、邀请判断和 8 个主机名的上限不变。
- 已有正文或这条消息自己的作者签名时，来源签名原文不进正文，也不改内容哈希。
- 没有更前面的正文，也没有自己的作者签名时，来源签名整段成为正文，并以此计算 `textSha256`。关键词因此能命中。
- `false`、数字和其它值不读这段签名。来源不是频道时不读，即使带上这个标记。
- 成员转发的频道帖仍不读来源签名。群来源上的签名、频道标题和真实用户姓名不读。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 来源签名整段都不读 | 短链可以只写在讨论组里看得见的这一行。 |
| 所有转发来源的签名都读 | 成员转发的频道帖已经按 ADR 0025 删除。群来源的签名仍按 ADR 0091 留在外面。 |
| 已有正文时把签名拼进去 | 签名会改变哈希。短链只需要主机名。 |
| 连频道标题一起抽 | 标题仍按 ADR 0025 留在事件外面。 |

## 后果

- 讨论组原帖的来源签名里出现短链、邀请或关键词时，会删掉这一条。已有正文时证据只有主机名。没有别的正文时，签名本身留在正文里。
- 已有正文时，签名原文、路径和邀请码不进事件，内容哈希不变。
- 成员转发的来源签名、群来源的签名、频道标题和这个标记不进事件。
- 成员转发的频道标题后来由 ADR 0610 只留下主机名。讨论组原帖的来源标题仍不读。来源签名仍按本决定。
- `example.com` 留着。付费帖仍不删除。见 ADR 0356。
- 云额度的基础检测器名单没有改。
- 已有正文时，来源签名看得见的前 256 字后来由 ADR 0536 交给关键词和默认正则。成员转发的来源签名仍不读。
