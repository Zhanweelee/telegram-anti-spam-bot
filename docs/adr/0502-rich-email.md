# ADR 0502：富文本邮箱按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

富文本里的邮箱可以和看得见的字不同。字段是 `email_address`。ADR 0076 让这个字段不进事件，关键词看不见地址。看得见的字已经可以成为正文。

ADR 0501 给电话和银行卡各开了一条默认关闭的规则，邮箱仍留下。

## 决策

- `type` 正好是 `email_address`，并且 `email_address` 去掉空白后非空时，事件带 `asRichEmail: true`。空白和布尔值不带标记。
- 地址不进事件，也不进证据。看得见的字仍是正文。已有 `text` 或 `caption` 时正文不变，地址不并进去。
- 检测器在 `@tasb/detector-rich`，id 是 `rich_email`。只在 `message.asRichEmail` 为 true 时返回 score 1。证据是 `rich:email`。
- 默认规则关闭。私聊 `/rule <chatId> rich_email on` 之后删除这种正文，`off` 回到留下。
- 不并进 `rich_phone` 或 `rich_card`。不调用读取或改写邮箱的方法。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`rich_email` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 并进电话或银行卡 | 只想删号码的群会把邮箱也删掉。 |
| 把地址接到正文后面 | 同一条消息的哈希会变，邮箱也会进事件。ADR 0076 已经拒绝。 |
| 把地址写进证据 | 证件号和邮箱不进事件。 |
| 默认打开 | 有的群用富文本留联系邮箱。打开之前不改现有群。 |
| 新命令 `/email` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，富文本邮箱留下。看得见的字仍参与关键词。地址仍不进事件。
- 打开 `rich_email` 后，这个群里的富文本邮箱会删除。打开电话或银行卡仍不删除邮箱。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `rich_email` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `rich_email`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
