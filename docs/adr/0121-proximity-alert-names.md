# ADR 0121：靠近提醒的可见名字命中就删除

- 状态：已接受
- 日期：2026-11-02

## 背景

两个人共享实时位置并靠近时，群里会出现一条服务消息，上面是触发者和设置者的昵称、姓氏和用户名。这条消息通常没有 `text`。名字里的短链或关键词会留在群里。

距离是一个整数。它不是广告，也不该进事件。

## 决策

- `proximity_alert_triggered` 的 `traveler` 和 `watcher` 的 `first_name`、`last_name`、`username` 按 ADR 0118 的同一套规则处理：去掉首尾空白，用一个普通空格拼起来，最长 4096 字符。先写触发者，再写设置者。
- 没有更前面的正文时，这段名字成为正文。关键词和链接规则因此能删除这条服务消息。
- 已有正文时，名字只贡献主机名。
- 不读取 `distance`、用户 id、`language_code` 和 `from` 上的姓名。
- 不新增检测器，不加新的默认规则。不改 ADR 0026 的默认次数、周期和基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 名字永远只留主机名 | 关键词广告名会留在靠近这行上。 |
| 把距离写进证据 | 距离不是主机名，也不是关键词。 |
| 读取发送者的 `from` 姓名 | 发送者姓名仍不进事件。 |

## 后果

- 可见名字里的默认关键词、短链或邀请会删掉这条靠近提醒。证据仍只有关键词或主机名。
- `example.com` 和普通名字留着。
- 距离不进事件。
- 名字干净时这行仍留下。某个群可以以后打开 `proximity_notice`，把整行删掉。距离和用户编号仍不进事件。见 ADR 0493。
