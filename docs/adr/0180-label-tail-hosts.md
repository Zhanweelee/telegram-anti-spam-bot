# ADR 0180：标签字符仍留在 Android 打开的主机名里

- 状态：已接受
- 日期：2026-11-02

## 背景

Android 的放松标签可以接上标签类里的字符。`http://bit.ly，广告`、`http://bit.ly` 加 U+200B 再接 `foo`，以及 `http://bit.ly点击`，都是一条链接，主机名不再是 `bit.ly`。高亮如果在这些字符前截断，就会把前缀记成短链。除号 U+2215 后面没有单词边界时，匹配会退回 `bit.ly`，`example.com` 仍单独打开。夹在 `bit` 和 `.ly` 中间的 U+200B 仍由整段折叠收成 `bit.ly`。

## 决策

- 带协议的标签继续吃进 Android 标签类里的字符。这段的主机名按整段计算，前缀不另记。
- 标签只能停在有单词边界的位置，并且不能停在连字符或下划线上。除号后面接不上边界时，仍退回前面的主机名。
- 整段折叠仍去掉 U+200B，所以 `bit` 加 U+200B 再接 `.ly` 仍按短链删除。
- 证据只留主机名。只拆一层。最多 8 个。不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 非 ASCII 一律从标签上截断 | `http://bit.ly，广告` 会删掉 Android 留成一条普通链接的消息。 |
| 除号也留在标签里 | U+2215 后面的 `example.com` 会打不开，前面的 `bit.ly` 也会漏掉。 |
| 整段折叠不再去掉 U+200B | `bit` 加 U+200B 再接 `.ly` 就不再按短链删除。 |

## 后果

- `http://bit.ly，广告`、`http://bit.ly` 加 U+200B 再接 `foo`，以及 `http://bit.ly点击`，留着。
- `http://bit.ly` 加 U+2215 再接 `@example.com/…` 仍按短链删除。证据只有 `bit.ly`。
- `http://bit` 加 U+200B 再接 `.ly/…` 仍按短链删除。路径不进证据。
- 没有协议的 `www.` 在点号处结束，后面的网址仍单独打开。见 ADR 0181。
