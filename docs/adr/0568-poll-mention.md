# ADR 0568：投票说明和描述上的按标识提及也走同一条规则

- 状态：已接受
- 日期：2026-11-05

## 背景

ADR 0514 在投票题干上认出 `text_mention`。Bot API 写明题干和选项只允许自定义表情。说明和描述的实体写的是用户名、网址和命令这一类，可以带按标识的提及。

答错或点灯时说明会显示出来。描述写在题干旁边。打开 `text_mention` 的群会删掉题干上的点名，说明和描述上的同一处仍留下。用户编号仍不能进事件。

## 决策

- `poll.explanation_entities` 和 `poll.description_entities` 里，`type` 正好是 `text_mention`，并且 `user.id` 是大于 0 的安全整数时，事件同样带 `asTextMention: true`。
- 缺用户、布尔值、字符串编号和 0 仍不带这个标记。投票选项、手动引用、富文本按标识提及和用户名实体仍不带。
- 用户编号、名字和用户名不进事件，也不进证据。说明和描述看得见的字仍留在原来的字段。正文和 `textSha256` 不变。
- 仍用检测器 `text_mention`。证据仍是 `entity:text_mention`。不新增规则，不新增命令。菜单仍是 99 条。
- 规则仍默认关闭。打开之后，说明和描述上的这种提及也删除。付费帖仍不删除。
- 不改 ADR 0026 的基础检测器名单。`text_mention` 仍不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 连投票选项一起认 | 官方只允许选项带自定义表情。那种点名不是入站消息。 |
| 另开一条规则 | 这是同一处隐藏的用户编号。分开开关会让群管开漏一处。 |
| 把用户编号写进证据 | 用户编号不进事件。 |
| 把说明拼进题干 | 会改变 `textSha256`。ADR 0543 已经拒绝。 |

## 后果

- 规则关闭时，投票说明和描述上的按标识提及留下。看得见的字仍参与关键词。用户编号仍不进事件。
- 打开 `text_mention` 后，这种说明和描述上的提及会删除。投票选项和手动引用仍留下。富文本提及仍由 `rich_text_mention` 决定。
- 付费帖仍留下。0 和缺用户不带这个标记。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `text_mention` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `text_mention`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
