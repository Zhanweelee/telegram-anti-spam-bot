# ADR 0468：隐藏来源、群转发和用户转发按群打开

- 状态：已接受
- 日期：2026-11-04

## 背景

频道转发默认删除。见 ADR 0025。用户转发、从别的群转发，以及隐藏了来源账号的转发，默认留下。

隐藏来源是常见广告：正文可以是一句普通的话，账号被藏起来。从别的群整段搬过来也常见。把这两种和用户之间转发的图片绑在同一个全局开关上，会让所有群一起改。ADR 0025 要求改检测器配置才能删，而这份配置是整个 Worker 共用的。

## 决策

- `message.forward` 仍只有 `user`、`chat`、`channel`、`hidden`。来源标题和来源 id 仍不进事件。
- 检测器 `forward` 仍只认 `channel`。默认规则 `channel_forward` 仍开启。
- 另外三个检测器各认一种：`forward_hidden`、`forward_chat`、`forward_user`。证据仍是 `forward:hidden`、`forward:chat`、`forward:user`。reason 仍是 `forward_hidden`、`forward_chat`、`forward_user`。
- 默认规则 `hidden_forward`、`chat_forward`、`user_forward` 存在，但是关闭的。某个群用现有的私聊 `/rule` 打开其中一条，就只删除这一种。没有新命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`forward` 仍在名单里，所以超额后频道转发继续删除。这三个新 id 不在名单里。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认连隐藏来源一起删 | ADR 0025 已经拒绝。正常聊天里也有人隐藏账号再转发。 |
| 三条合成一个开关 | 打开隐藏来源时会把朋友转发的消息一起删掉。 |
| 改全局 `kinds` | 一个群打开，所有群都跟着删。 |
| 新命令 `/forward` | 菜单只剩一个空位。现有 `/rule` 已经能打开一条规则。 |

## 后果

- 不打开这些规则的群，隐藏来源、群转发和用户转发仍留下。频道转发仍删除。讨论组里关联频道的自动转发仍留下。
- 打开 `hidden_forward` 后，这个群只多删隐藏来源。用户转发和群转发仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把对应的 id 写进 `QUOTA_BASIC`，否则超额时这条规则会停。频道转发不受影响。
- `chats.json` 整份替换的群要自己加上这三条规则，才会有这些开关。
- 30 天保留期不动。
