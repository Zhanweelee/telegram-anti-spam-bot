# ADR 0575：照片、视频、文件和音频按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

照片、视频、文件和音频已经带 `message.media`。ADR 0469 当时不给这四种日常内容加锁。一个只想禁文件、或只想禁视频的群，现在没有开关。

动图有时也带一份 `document`。语音不是音频。消息上的实况照片仍按照片读。付费帖仍不删除。

## 决策

- 仍用 `@tasb/detector-media`。再给四种 id：`media_photo`、`media_video`、`media_document`、`media_audio`。只在 `message.media` 正好是这一种时返回 score 1。证据是 `media:` 加类别。
- 文件号、文件名、MIME、尺寸和时长不进证据。说明和文件名仍参与关键词。
- 默认规则用同样的 id，全部关闭。某个群用现有的私聊 `/rule` 打开一种，就只删除这一种。没有新命令。菜单仍是 99 条。
- 同时带 `document` 的动图仍是 `animation`。语音仍是 `voice`。消息上带照片数组的实况照片仍是 `photo`。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。这四个 id 都不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉照片和视频 | 那是日常内容。打开之前不改现有群。 |
| 四种合成一个开关 | 只想禁照片的群会把视频一起删掉。 |
| 动图改记成文件 | 动图已经有 `media_animation`。再带的 `document` 不改类别。 |
| 语音并进音频 | 语音已经有 `media_voice`。 |
| 实况照片另开一类 | 消息上的实况照片仍读成照片。付费实况照片仍按原来的付费帖留下。 |
| 新命令 `/lock` | 菜单只剩一个空位。现有 `/rule` 已经能打开一条规则。 |

## 后果

- 不打开这些规则的群，照片、视频、文件和音频仍留下。关键词、短链和同一份正文的重复仍会删除。
- 打开 `media_photo` 后，这个群的照片和消息上的实况照片会删除。视频、文件和音频仍留下。付费帖仍留下。
- 打开 `media_document` 不删除动图。打开 `media_audio` 不删除语音。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把对应的 id 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这四条规则，才会有这些开关。
- 30 天保留期没有改。
