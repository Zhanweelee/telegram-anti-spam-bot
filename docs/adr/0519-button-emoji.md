# ADR 0519：内联按钮上的自定义表情按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

内联按钮可以在文字前面放一个自定义表情。编号和看得见的按钮文字不是同一件事。`custom_emoji` 只看消息实体和富文本里的自定义表情，看不见按钮上的图标。论坛话题的图标仍由 `topic_notice` 决定。

富文本按钮没有这个字段。回复键盘仍不读。

## 决策

- 内联键盘 `reply_markup.inline_keyboard` 里，`icon_custom_emoji_id` 去掉空白后非空时，事件带 `asButtonEmoji: true`。
- 空白、空字符串、布尔值和缺编号不带这个标记。只有网址的按钮不带。回复键盘不带。富文本按钮不带。正文里的自定义表情不带。登录按钮的替换文字不带。日期时间不带。论坛话题图标不带。
- 编号不进事件，也不进证据。看得见的按钮文字仍是正文。已有 `text` 或 `caption` 时正文不变，编号不并进去。
- 检测器在 `@tasb/detector-icon`，id 是 `button_emoji`。只在 `message.asButtonEmoji` 为 true 时返回 score 1。证据是 `button:button_emoji`。
- 默认规则关闭。私聊 `/rule <chatId> button_emoji on` 之后删除这种正文，`off` 回到留下。
- 不并进 `custom_emoji`。不读取回复键盘。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`button_emoji` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把编号接到正文后面 | 同一条消息的哈希会变，编号也会进事件。 |
| 把编号写进证据 | 编号不进事件。 |
| 并进自定义表情 | 只想删正文表情的群会把按钮图标也删掉。 |
| 默认打开 | 有的群会用按钮图标。打开之前不改现有群。 |
| 新命令 `/icon` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，按钮图标留下。看得见的按钮文字仍参与关键词。编号仍不进事件。
- 打开 `button_emoji` 后，这个群里的这种按钮会删除。打开 `custom_emoji` 仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `button_emoji` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `button_emoji`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
