# ADR 0518：登录按钮转发后的文字按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

登录按钮可以带 `login_url.forward_text`。消息被转发之后，按钮上看得见的字换成这一段。ADR 0444 只从这段文字里抽主机名，句子本身不进事件。口令、钱包地址和电话不是网址时，关键词和链接规则都看不见。

内联查询仍由 `switch_query` 决定。打开那条规则不会删除登录按钮的替换文字。

## 决策

- 内联键盘 `reply_markup.inline_keyboard` 里，或富文本按钮里，`login_url` 是对象并且 `forward_text` 去掉空白后非空时，事件带 `asLoginForward: true`。嵌套在拼贴或段落里也同样。
- 空白、空字符串、布尔值和缺句子不带这个标记。只有网址的登录按钮不带。只有 `bot_username` 不带。回调数据不带。回复键盘不带。内联查询、复制按钮、自定义表情和日期时间不带。
- 替换文字不进事件，也不进证据。用户名不进事件。看得见的按钮文字仍是正文。已有 `text` 或 `caption` 时正文不变，替换文字不并进去。
- 检测器在 `@tasb/detector-login`，id 是 `login_forward`。只在 `message.asLoginForward` 为 true 时返回 score 1。证据是 `button:login_forward`。
- 默认规则关闭。私聊 `/rule <chatId> login_forward on` 之后删除这种正文，`off` 回到留下。
- 不并进 `switch_query`。不读取 `bot_username` 和 `callback_data`。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`login_forward` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把替换文字接到正文后面 | 同一条消息的哈希会变，句子也会进事件。 |
| 把句子写进证据 | 句子不进事件。 |
| 并进内联查询 | 只想删查询的群会把登录按钮也删掉。 |
| 默认打开 | 有的群会用登录按钮转发后的文字发口令。打开之前不改现有群。 |
| 新命令 `/login` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，登录按钮留下。看得见的按钮文字仍参与关键词。替换文字里的网址仍只留主机名。句子和用户名仍不进事件。
- 打开 `login_forward` 后，这个群里的这种按钮会删除。打开 `switch_query` 仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `login_forward` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `login_forward`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
