# ADR 0740：投票描述上的文字链接不能越过描述

- 状态：已接受
- 日期：2026-11-07

## 背景

投票描述是另一段字。短链在 `description_entities`。见 ADR 0077 与 ADR 0563。Bot API 写明这些实体出现在描述里。描述可以长于事件里留下的 1024 字，主机名仍从整段原文抽取。

`addEntitiesToText` 对任何一段文字都丢掉起点大于或等于这段文字的实体。这份客户端的 `MessageObject` 把测验解答收成 `quizExplanation` 再交给这个函数。描述还没有单独的绘制函数。起点已经越过整段描述的链接，仍然没法出现在描述上。

现在描述会读全部文字链接。起点已经越过描述的链接仍会留下主机名。

手动引用自己就是正文时，已经要求起点落在摘录里。见 ADR 0739。描述是另一段文字。测验说明已经按说明长度收过。见 ADR 0730。

## 决策

- `poll.description` 是字符串时，`description_entities` 里的文字链接，起点必须小于整段描述。描述不是字符串时，仍按原来的方式读取。
- 描述里的普通网址仍从整段原文抽取，包括第 1025 字起。仍只留主机名。事件里的 `pollDescription` 仍只留前 1024 字。
- 测验说明不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 起点已经越过描述的链接不会出现在描述上，却会删掉这条投票。 |
| 也按 1024 字丢掉后面的链接 | 主机名仍从整段原文抽取。1024 只是事件字段的上限。 |
| 描述不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的描述。 |
| 测验说明再改一次 | 说明已经按自己的长度收过。 |

## 后果

- 起点越过整段描述的文字链接不再留下主机名。仍落在描述里的短链、邀请或裸 IP 会删除，包括起点已经超过 1024、但仍在整段描述里的链接。证据只有主机名。
- 空描述不再留下这些主机名。被截断的路径不进事件。写在描述里的路径仍留在 `pollDescription` 的前 1024 字里。关键词不命中没画上去的链接。内容哈希仍按题干或别的正文。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 正文上的自定义表情后来由 ADR 0741 要求整段落在正文里。文字链接仍按起点是否越过正文。
- 投票描述上的文字链接后来由 ADR 0772 要求长度大于 0。投票描述不是字符串时，文字链接后来由 ADR 0791 不再读取。长度越过末尾时仍算画出来。投票选项不在那条里。
