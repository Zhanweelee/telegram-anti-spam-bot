# ADR 0517：内联查询按钮按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

内联按钮和富文本按钮可以在按下后把一段查询插进输入框。看得见的按钮文字是另一句。ADR 0111 只从这段查询里抽主机名，查询本身不进事件。口令、钱包地址和电话不是网址时，关键词和链接规则都看不见。

复制到剪贴板的按钮仍由 `copy_text` 决定。打开那条规则不会删除内联查询按钮。空查询只插入 bot 用户名，不带隐藏句子。

## 决策

- 内联键盘 `reply_markup.inline_keyboard` 里，或富文本按钮里，`switch_inline_query`、`switch_inline_query_current_chat`，或 `switch_inline_query_chosen_chat.query` 去掉空白后非空时，事件带 `asSwitchQuery: true`。嵌套在拼贴或段落里也同样。
- 空白、空字符串、布尔值和缺查询不带这个标记。只有网址的按钮不带。回调数据不带。回复键盘不带。挑选范围本身不带。复制按钮、自定义表情和日期时间不带。
- 查询不进事件，也不进证据。看得见的按钮文字仍是正文。已有 `text` 或 `caption` 时正文不变，查询不并进去。
- 检测器在 `@tasb/detector-query`，id 是 `switch_query`。只在 `message.asSwitchQuery` 为 true 时返回 score 1。证据是 `button:switch_query`。
- 默认规则关闭。私聊 `/rule <chatId> switch_query on` 之后删除这种正文，`off` 回到留下。
- 不并进 `copy_text`。不读取 `callback_data`。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`switch_query` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把查询接到正文后面 | 同一条消息的哈希会变，查询也会进事件。 |
| 把查询写进证据 | 查询不进事件。 |
| 并进复制按钮 | 只想删复制按钮的群会把内联查询也删掉。 |
| 默认打开 | 有的群会用内联查询发口令。打开之前不改现有群。 |
| 新命令 `/query` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，内联查询按钮留下。看得见的按钮文字仍参与关键词。查询里的网址仍只留主机名。查询仍不进事件。
- 打开 `switch_query` 后，这个群里的这种按钮会删除。打开 `copy_text` 仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `switch_query` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `switch_query`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
