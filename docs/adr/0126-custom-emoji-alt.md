# ADR 0126：自定义表情的替代文字

- 状态：已接受
- 日期：2026-11-02

## 背景

富文本里的自定义表情没有普通 `text`。客户端在表情加载失败时显示 `alternative_text`。短链或关键词可以只写在这段替代文字里。`custom_emoji_id` 是表情编号，不是正文。

已有普通正文时，替代文字不是这条消息的正文。把它并进正文会改掉内容哈希。

## 决策

- 从富文本节点 `custom_emoji.alternative_text` 读取看得见的替代文字。折叠、长度、邀请判断和 8 个主机名的上限与旁路纯文本相同。
- 没有更前面的正文时，这段替代文字成为正文，并参与内容哈希。关键词因此能命中。
- 已有正文时，只从替代文字抽出主机名。原文不进入 `message.text`，也不改内容哈希。
- 不读取 `custom_emoji_id`。锚点名字、公式源码、邮箱、电话和银行卡号仍按 ADR 0076 留在事件外面。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 替代文字整段都不读 | 短链可以只写在加载失败时看得见的字里。 |
| 表情 id 也抽主机名 | id 不是给人看的地址。 |
| 已有正文时把替代文字并进正文 | 内容哈希会被一段备用文字改掉。 |

## 后果

- 替代文字里的默认短链、邀请或关键词会删掉这条富文本。证据仍只有主机名或关键词标记。
- 已有正文时，路径和邀请码不进事件。没有别的正文时，替代文字本身留在正文里。
- `custom_emoji_id` 不进事件。`example.com` 留着。
- 已有正文时，替代文字后来由 ADR 0564 另留在 `richText`。表情编号仍不进事件。写在替代文字里的路径留在这个字段，不进审计。
- 非空的自定义表情编号可以另开 `custom_emoji`。编号仍不进事件。看得见的字和替代文字仍是正文。见 ADR 0515。
- 替代文字不是字符串时，自定义表情后来由 ADR 0821 不再读取。
