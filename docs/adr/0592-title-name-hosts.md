# ADR 0592：改名的人，名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

群名被改掉时，客户端把这个人的名字画在服务消息上。名字写在 `from`。新群名当时只留主机名，不进正文。见 ADR 0114。这条消息通常没有正文。短链可以只写在改名的人的名字里。

把 `from` 收成正文会让普通发言者的姓名也进检测。`chat_title` 默认关闭，干净的提示仍留下。这次不调用 `setChatTitle`。空字符串仍不是改名。本群群名仍不读。

## 决策

- 只在已经会标成 `asTitle` 的提示上，从 `from` 的可见名字留主机名。`new_chat_title` 是非空字符串时读。空字符串不读。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 新群名仍按 ADR 0114 只留主机名。名字不进正文，也不改内容哈希。关键词因此不命中。本群群名和群说明不读。
- 普通消息不读 `from`。换头像和删头像不因此读这次的发送者。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`chat_title` 仍默认关闭。8 个主机名的上限不变。不调用 `setChatTitle`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 关键词会命中人名。普通消息的 `from` 也会被打开。见 ADR 0114。 |
| 每条消息都扫改名的人 | 没有新群名时，这不是改名提示。发言人的名字会跟着每条消息重复计一次。 |
| 把新群名收成正文 | 群名会进事件和内容哈希。见 ADR 0114。 |
| 新命令 `/titlename` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 改名的人，名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。群名本身不变。
- 名字原文、路径和用户名不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。新群名原文仍不进事件。
- 改名后来按全名只留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。见 ADR 0632。换背景仍只读名。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 空字符串和普通消息仍不读发送者。本群群名仍不读。干净的提示在 `chat_title` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
