# ADR 0593：换背景的人，名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

群背景被换掉时，客户端把这个人的名字画在服务消息上。名字写在 `from`。壁纸和图案的文件名当时只留主机名，不进正文。见 ADR 0430。纯色和内置主题没有可检测的正文。短链可以只写在换背景的人的名字里。

把 `from` 收成正文会让普通发言者的姓名也进检测。`chat_background` 默认关闭，干净的提示仍留下。文件号和主题名仍不读。空对象和其它类型仍不是这条提示。

## 决策

- 只在已经会标成 `background` 的提示上，从 `from` 的可见名字留主机名。壁纸、图案、纯色和内置主题都读。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 壁纸和图案的文件名仍按 ADR 0430 只留主机名。文件号和主题名不读。名字不进正文，也不改内容哈希。关键词因此不命中。本群群名不读。
- 空的 `chat_background_set` 和其它类型不读发送者。普通消息不读 `from`。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`chat_background` 仍默认关闭。8 个主机名的上限不变。不改群背景。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 关键词会命中人名。普通消息的 `from` 也会被打开。见 ADR 0430。 |
| 只在壁纸和图案上读发送者 | 纯色和内置主题同样画出这个人。文件名里没有短链时，名字里仍可以有。 |
| 把文件号或主题名写进证据 | 文件号可以下载壁纸。主题名通常是表情。见 ADR 0480。 |
| 新命令 `/bgname` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 换背景的人，名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。背景本身不变。
- 名字原文、路径和用户名不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。文件名原文、文件号和主题名仍不进事件。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 空对象、其它类型和普通消息仍不读发送者。本群群名仍不读。干净的提示在 `chat_background` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
