# ADR 0082：游戏和账单标题里的网址只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0058 在没有更前面的正文时，用 `game.title` 或 `invoice.title` 当正文。已有正文时，标题留在事件外面。ADR 0078 从说明和附加文字抽出主机名，标题里的短链或邀请在已有正文时仍然看不到。

把标题拼进已有正文会改变 `textSha256`。封面文件 id、币种、金额和 `start_parameter` 仍不能进事件。

## 决策

- 从 `game.title` 和 `invoice.title` 里抽出网址，只留主机名。长度、折叠、邀请判断和 8 个主机名的上限不变。顺序在各自的说明之前。
- 已有正文时，标题原文不进正文，也不改内容哈希。
- 没有更前面的正文时，标题仍整段成为正文。这条正文里的网址由链接规则从正文看见，同时也记在主机名列表里。
- 不读取封面、`file_id`、币种、金额和 `start_parameter`。说明和附加文字仍按 ADR 0078。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 已有正文时把标题拼进去 | 标题会改变哈希。短链只需要主机名。 |
| 只在标题不是正文时才抽 | 多一条分支。标题成为正文时，主机名列表仍应带上同一条网址。 |
| 连启动参数和币种一起读 | 启动参数和币种不是给群成员看的链接。 |

## 后果

- 已有正文时，标题里的 `https://bit.ly/…` 会走现有短链删除。`https://t.me/+…` 和 `https://t.me/%2B…` 只留下 `t.me`，并记成邀请。
- 普通域名仍保留。标题原文、路径和邀请码在已有正文时不进事件。
- 标题成为正文时，整段标题仍参与关键词和内容哈希。
- 说明里的关键词仍然看不到。封面文件 id 和启动参数仍不进事件。
- 标题原文后来由 ADR 0545 留在旁路字段。已有正文时，关键词和默认正则看游戏标题和账单标题。封面和启动参数仍不进事件。
