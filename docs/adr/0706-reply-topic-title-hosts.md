# ADR 0706：回复的话题名只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

回复一条改过名字的话题提示时，Android 用较短的一句把新名字画在引用条上。换图标并改名时，这句里仍有新名字。只换图标时没有名字。关掉、重开、隐藏和重新显示不走这句。

新建话题的回复条只画固定字样，不画话题名。

带引用、投票、外部媒体已经占了这一行时，不再改画话题名。

ADR 0088 读的是话题提示自己的名字。别人回复这行时，新名字仍会留在引用条上。

## 决策

- 前面的引用条都没有占住，且 `reply_to_message.forum_topic_edited.name` 是字符串时，从这段名字留主机名。
- `icon_custom_emoji_id` 不读。没有 `name` 时不占这一行。
- `forum_topic_created.name` 不读。关掉、重开、隐藏和重新显示不读。
- 带 `quote.text` 时不读。
- 主机名仍进消息已有的 `hosts`。邀请仍进 `invites`。名字不进正文，也不改内容哈希。关键词因此不命中。正文里已有短链时，证据仍先记正文的主机名。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 新建话题的名字也读 | 回复新建话题时，引用条不画话题名。 |
| 图标编号也读 | 只换图标时，这一行没有名字。 |
| 把名字收进正文 | 它是引用条上的一行。关键词仍只看这条消息自己的正文。 |

## 后果

- 画出的话题名出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。
- 图标编号、新建话题的名字和被回复的原文仍不进事件。名字不改内容哈希。关键词不命中名字。
- 带引用、投票本身或外部媒体时，不改读话题名。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
