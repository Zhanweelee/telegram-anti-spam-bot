# ADR 0353：验证通过时打开全部成员权限

- 状态：已接受
- 日期：2026-11-04

## 背景

`restrictChatMember` 在 `use_independent_chat_permissions: true` 时，没写上的权限保持原样。通过验证时只打开了发言和邀请。置顶、话题、改群资料、反应和标签编辑仍关着。限制和禁言也没显式关掉反应和标签。

官方说明是：把每一项权限都设为 true，才能解除这个成员身上的限制。群默认的禁止项仍然生效。故事和管理员权利不属于 `ChatPermissions`。

## 决策

- 验证限制和禁言把当前全部 `ChatPermissions` 设为 false，包括 `can_react_to_messages` 和 `can_edit_tag`。
- 验证通过时把同样这些字段设为 true，不带 `until_date`。
- 不增加管理员权利，也不增加故事权限。
- 群默认禁止的权限仍然限制这名成员。公开超级群里，Telegram 会忽略置顶和改群资料。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 通过时只补上话题和置顶 | 反应和标签仍靠默认值。独立权限打开后，没写上的字段不会跟着发言权限打开。 |
| 通过时授予发故事 | 故事是管理员权利，不是成员权限。验证通过不应提升身份。 |

## 后果

- 通过验证的成员可以在群默认允许的范围内创建话题、置顶、改资料、发表反应和编辑标签。
- 还在验证或被禁言的成员不能发表反应，也不能编辑标签。
- 30 天保留期不动。
