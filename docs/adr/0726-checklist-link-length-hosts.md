# ADR 0726：清单标题和任务上的文字链接不能越过正文

- 状态：已接受
- 日期：2026-11-07

## 背景

清单气泡画出标题和每一条任务。标题上的短链在 `checklist.title_entities`。任务上的短链在 `tasks[].text_entities`。见 ADR 0057 与 ADR 0077。

Android 用 `formatTextWithEntities` 画这两处。文字链接的起点大于或等于这段文字时，链接不会画上去。

现在标题会读全部文字链接，任务也会读全部文字链接。起点已经越过正文的链接仍会留下主机名。

引用条上的任务和标题已经要求起点落在那段文字里。见 ADR 0725。气泡是另一行。

## 决策

- 清单标题上的文字链接，起点必须小于 `checklist.title` 的长度。标题不是字符串时，仍按原来的方式读取。
- 每一条任务上的文字链接，起点必须小于这条 `text` 的长度。任务文字里的普通网址仍读。
- 仍只留主机名。任务文字不进正文。标题在没有更前面的正文时仍是正文。
- 后加任务、勾完的任务、投票选项、游戏说明、礼物和引用不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条清单。 |
| 后加任务和勾完的任务也一起改 | 那是服务消息上的另一行。这条只改清单气泡。 |
| 投票选项也按正文长度丢掉链接 | 选项是另一处字段。这条只改清单。 |

## 后果

- 起点越过标题或任务文字的文字链接不再留下主机名。仍落在这段文字里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在任务里的路径仍留在 `checklistTask`。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 后加任务上画出的文字链接后来由 ADR 0727 同样要求起点落在这条任务文字里。勾完的任务仍不在那条里。
- 清单标题上的文字链接后来由 ADR 0767 要求长度大于 0。长度越过末尾时仍算画出来。手动引用不在那条里。
- 清单任务上的文字链接后来由 ADR 0774 要求长度大于 0。长度越过末尾时仍算画出来。后加选项不在那条里。
