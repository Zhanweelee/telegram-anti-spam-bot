# ADR 0107：投票媒体上的名称只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0106 读取投票媒体上的 `link.url`。同一块媒体还可以是动图、视频、音频、普通文件或场馆。文件名、音频标题、表演者、场馆标题和地址是群里看得见的字。短链可以只写在这些字段里。

照片、贴纸、位置和文件 id 仍然不是网址。

## 决策

- 从 `poll.media`、`poll.explanation_media` 和 `poll.options[].media` 里读取 `animation.file_name`、`video.file_name`、`audio.title`、`audio.file_name`、`audio.performer`、`document.file_name`、`venue.title` 和 `venue.address`。
- 抽出的网址走和旁路纯文本相同的折叠，事件里只留主机名。长度、邀请判断和 8 个主机名的上限不变。
- 顺序跟在该块媒体的 `link.url` 之后。三处媒体的顺序仍是投票、解释、选项。
- 音频先标题，再文件名，再表演者。场馆先标题，再地址。
- 不读取照片、实况照片、贴纸、位置、地点 id 和文件 id。
- 这些名称不进入正文，也不改内容哈希。路径和邀请码不进事件。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把文件名拼进题干 | 同一条消息的哈希会变，路径也会进事件。 |
| 连贴纸包名和文件 id 一起读 | 这两处在消息本身上也不读。 |
| 只读投票媒体，不读选项媒体 | 选项上的文件名同样看得见。 |

## 后果

- 这些名称里的短链、邀请或裸 IP 按现有链接规则命中。
- 普通域名仍保留。路径和邀请码不进主机名名单。这些名称后来由 ADR 0562 另留在 `pollMedia`。审计仍不留原文。
- 照片、贴纸、位置和文件 id 里的字符串仍不进事件。
