# ADR 0443：讨论组里的频道原帖留下

- 状态：已接受
- 日期：2026-11-04

## 背景

频道帖会自动出现在它关联的讨论组里。这条消息带 `is_automatic_forward`，来源仍是频道。默认规则 `channel_forward` 会把一切频道来源删掉。见 ADR 0025。讨论组里于是只剩评论，频道自己的公告也被删掉。

这个标记只有 Telegram 会加在关联频道的原帖上。成员把别的频道转发进群时没有它。

## 决策

- `is_automatic_forward` 正好是布尔值 true，并且转发类别本来是 `channel` 时，事件不带 `forward`。
- `false`、数字和其它值不改变类别，也不写进事件。
- 用户、群和隐藏来源即使带上这个标记，类别仍按 ADR 0025。
- 编辑后的原帖同样不记成频道转发。
- 正文里的关键词和短链仍逐条判断。付费帖仍不删除。见 ADR 0356。
- 不因为这条原帖去禁止来源频道。见 ADR 0370。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续按频道转发删除 | 讨论组会丢掉频道自己的公告。 |
| 新增一种默认关闭的类别 | 要多一条规则。这个标记的意思已经是“不是成员转发”。 |
| 原样保存任意值 | 这个字段会把正文带进事件。只认 true。 |
| 命中后禁止来源频道 | 会把讨论组或关联频道一起挡住。 |

## 后果

- 讨论组留下关联频道的原帖。成员转发进来的频道帖仍删除。
- 原帖正文里的广告词或短链仍会删掉这一条。
- 频道标题和这个标记不进事件、证据和日志。
- 30 天保留期不动。
