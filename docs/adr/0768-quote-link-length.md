# ADR 0768：引用上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。引用上的文字链接，起点必须落在摘录里。见 ADR 0732。手动引用自己就是正文时同样要求起点落在摘录里。见 ADR 0739。清单标题上的文字链接，长度必须大于 0。见 ADR 0767。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达摘录末尾的实体。起点落在摘录里、长度越过末尾时，客户端把长度收到摘录末尾，这段链接仍会画出来。手动引用和自动引用都画在这段摘录上。

已有别的正文时，手动引用另留在 `quoteText`，只留前 4096 字。摘录自己就是正文时，事件正文只留前 4096 字，不再另留 `quoteText`。自动引用不进正文，也不进 `quoteText`。链接仍按整段摘录判断。写在摘录里的普通网址仍从整段摘录抽取。

现在引用只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在摘录里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条消息。代码块语言里的网址也走同一段实体。

礼物附言不在这条里。

## 决策

- `quote.text` 是字符串时，`quote.entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于摘录长度，长度必须是大于 0 的安全整数。手动引用和自动引用都一样。
- 起点落在摘录里、长度越过末尾时，仍留下主机名。
- 摘录不是字符串时，仍不读这段引用。
- 已有别的正文时，第 4097 字上的链接，只要起点仍落在摘录里、长度大于 0，就继续留下主机名。事件里的手动引用仍只留前 4096 字。
- 手动引用自己就是正文时，第 4097 字上的链接，只要起点仍落在摘录里、长度大于 0，就继续留下主机名。事件正文仍只留前 4096 字，不再另留 `quoteText`。
- 写在摘录里的普通网址仍从整段摘录抽取。仍只留主机名。自动引用的原文仍不进事件。
- 礼物附言上的 `entities` 不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条消息。 |
| 也要求长度落在摘录里 | 起点在摘录里时，客户端会把越过末尾的长度收回来再画。 |
| 只改成为正文的手动引用 | 已有别的正文时，自动引用和手动引用仍画在摘录上。 |
| 礼物附言一起改 | 附言是另一段文字。这条只改引用。 |

## 后果

- 摘录上长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在摘录里、长度越过末尾的短链、邀请或裸 IP 仍删除。起点已经超过 4096、但仍落在摘录里的链接也删除。证据只有主机名。
- 写在摘录里的普通网址仍会删除。被截断的路径不进事件。自动引用的原文仍不进事件。
- 摘录不是字符串时，仍不读这段引用。
- 礼物附言上长度不是正数的文字链接仍按原来的方式读取。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
