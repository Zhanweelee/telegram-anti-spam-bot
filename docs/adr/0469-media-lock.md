# ADR 0469：贴纸、动图、语音、视频留言和骰子按群删除

- 状态：已接受
- 日期：2026-11-04

## 背景

没有说明的贴纸、动图、语音和视频留言已经带 `message.media`。重复检测只认同一份文件摘要。每条都不一样时，这些消息会留下。骰子没有正文，也还没有类别，点数和表情会一直留在群里。

照片、视频、文件和音频通常是群里要留的内容。这次不给它们加锁。

## 决策

- `message.dice` 是对象，并且 `emoji` 是 1 到 16 个字符时，事件带 `media: "dice"`。不写点数，不写表情，也不写文件摘要。
- 已有贴纸、动图、语音或视频留言时，仍用原来的类别，不改成骰子。
- 检测器在 `@tasb/detector-media`。每种一个 id：`media_sticker`、`media_animation`、`media_voice`、`media_video_note`、`media_dice`。只在 `message.media` 正好是这一种时返回 score 1。证据是 `media:sticker` 这种类别。贴纸包名、文件名、文件 id、点数和表情不进证据。
- 默认规则用同样的 id，全部关闭。某个群用现有的私聊 `/rule` 打开一种，就只删除这一种。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。这五个 id 都不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部贴纸和骰子 | 正常群会发贴纸和骰子。打开之前不改现有群。 |
| 五种合成一个开关 | 只想禁骰子的群会把贴纸一起删掉。 |
| 连照片和视频一起锁 | 那是另一类日常内容。这次先锁没有正文、又躲过重复检测的种类。 |
| 新命令 `/lock` | 菜单只剩一个空位。现有 `/rule` 已经能打开一条规则。 |

## 后果

- 不打开这些规则的群，贴纸、动图、语音、视频留言和骰子仍留下。关键词、短链和同一份文件的重复仍会删除。
- 打开 `media_sticker` 后，这个群的贴纸会删除，动图和骰子仍留下。付费贴纸仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把对应的 id 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这五条规则，才会有这些开关。
- 30 天保留期不动。
