# ADR 0718：富文本预览不读思考块

- 状态：已接受
- 日期：2026-11-06

## 背景

置顶提示和引用条上的富文本预览来自 `formatRichMessage`。这个函数不画 `pageBlockThinking`。思考块只出现在气泡里的整篇文章。

ADR 0714 和 ADR 0717 把思考块的文字拼进了这段预览。思考块里的短链会被当成已经画出来，后面真正画出来的块反而读不到。

气泡里的整篇文章仍由原来的富文本遍历读取。这段预览不进正文。

## 决策

- 置顶提示和引用条拼富文本预览时，跳过 `type` 为 `thinking` 的块，不读它的文字和链接。
- 思考块不占满剩下的预览。后面的块仍按 ADR 0714 拼接，置顶只读前 20 个码元，引用条只读前 150 个码元。
- 只有思考块时，这行不留主机名，也不改读旁边的 `text`。
- 气泡里的整篇文章仍读思考块。预览不进正文，内容哈希不变。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 预览继续读思考块 | 置顶提示和引用条没有画出这段文字。 |
| 思考块占满剩下的预览 | 它不是固定说法。后面画出来的短链会被漏掉。 |
| 只有思考块时改读 `text` | 有富文本时客户端画的不是 `text`。 |
| 气泡也不读思考块 | 整篇文章里这段文字是画出来的。 |

## 后果

- 预览里思考块后面的短链、邀请或裸 IP 会删掉这条消息。证据只有主机名。
- 思考块里的路径不进置顶提示和引用条。气泡里的文章仍读。内容哈希不变。关键词不命中预览。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- `pin_notice` 仍默认关闭。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
