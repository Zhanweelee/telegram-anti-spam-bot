# ADR 0228：主机名里的忽略标记不影响后面的文字字母

- 状态：已接受
- 日期：2026-11-03

## 背景

ADR 0227 只把紧贴在文字字母前面的忽略标记看成透明。标记写在主机名更前面时，这些字母仍被删掉。删掉以后标记自己也被折掉，短链或裸 IP 重新打开。

`http://bit​.lyα/…`、`http://bit.l​yα/…`、`http://bi​t.lyα/…`、`http://bit.ly​.α/…` 和 `http://203.0.113​.10ա/…` 在 Android 上各是一条链接。地址解析器给出的主机名不是前面的短链或裸 IP。`http://bit​.lyα/http://t.co/…` 的路径仍属于这一条。`see http://bit​.lyα/…` 也是。

`http://bit​.lyα.bit.ly/…` 的主机名仍以 `bit.ly` 结尾。没有协议的 `bit​.lyα/…` 和 `bit.ly​.α/…` 只打开前面的短链。`http://bit​.lyα#…`、`http://bit​.lyα@evil.com/…`、换行和中间有空格的写法也退回短链。标签放不下时，短链单独打开。`bαit.ly` 仍是短链。`bit​.ly` 仍是短链。

## 决策

- 只改主机名扫描。公开的折叠不改。
- 判断带协议的主机名时，先拿掉地址解析会忽略、Android 仍算进标签的标记，再看后面的这类字母。Android 仍把这段字母算进这条链接时留下。
- 这种标记包括零宽字符、软连字符、变体选择符和 U+034F。制表符、换行和不换行空格不在里面。
- 后面是 `#`、`@` 或空格，或者这段字母让标签超过 63 个字符时，仍删掉这些字母。
- 没有协议时仍删掉。夹在两个 ASCII 字母中间、前后都没有这种标记时仍删掉。
- 每段仍走现有的短链、裸 IP、邀请和 denylist 判断。只拆一层。最多 8 个。证据只留主机名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 只认紧贴在字母前面的标记 | `http://bit​.lyα/…` 会按短链删除。Android 打开的不是 `bit.ly`。 |
| 换行也拿掉再判断 | `http://bit.ly` 换行再接 `α/…` 会漏掉。Android 只打开 `bit.ly`。 |
| 没有协议也留下 | `bit​.lyα/…` 会漏掉。Android 只打开 `bit.ly`。 |

## 后果

- `http://bit​.lyα/…`、`http://bit.l​yα/…`、`http://bi​t.lyα/…` 和 `http://bit.ly​.α/…` 留着。
- `http://www.bit.ly​.α/…` 和 `http://203.0.113​.10ա/…` 留着。
- `http://bit​.lyα/http://t.co/…` 留着。路径里的短链不另记。
- `see http://bit​.lyα/…` 留着。
- `bit​.lyα/…`、`bit.ly​.α/…`、`www.bit.ly​.α/…` 和 `203.0.113.10​.α/…` 仍删除。
- `http://bit​.lyα#…`、`http://bit​.lyα@evil.com/…` 和换行后面的字母仍按短链删除。
- `http://bit​.lyα.bit.ly/…` 仍按短链删除。证据是收成 `x` 的主机名。
- `bαit.ly` 和 `bit​.ly` 仍按短链删除。放不下的标签仍让短链单独打开。路径不进证据。
