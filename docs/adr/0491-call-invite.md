# ADR 0491：视频聊天邀请按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

有人把别人拉进视频聊天时，群里有一条服务消息。被邀请者的名字已经按 ADR 0119 成为正文。名字干净时，这行会留下。开始、结束和预约由 `call_notice` 处理，而且明确不包含这份邀请名单。见 ADR 0475。

用户编号不是这行看得见的字。

## 决策

- `video_chat_participants_invited.users` 里至少有一个用户对象时，事件带 `asCallInvite: true`。不写用户编号。被邀请的名字仍按 ADR 0119 成为正文。
- 空对象、空数组、没有用户对象的数组和单独的布尔值不带这个标记。已有正文时，正文仍按原来的优先级。
- 同时出现开始、结束或预约时，`call` 仍按 ADR 0475 决定。邀请标记另记，不改那三种的优先级。
- 检测器在 `@tasb/detector-call-invite`，id 是 `call_invite`。只在 `message.asCallInvite` 为 true 时返回 score 1。证据是 `invite:video`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这种邀请提示。没有新命令。菜单仍是 99 条。不调用视频聊天相关的方法。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`call_invite` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部邀请 | 有的群靠这行知道谁被拉进了通话。打开之前不改现有群。 |
| 并进 `call_notice` | 打开通话提示的群并不一定要删邀请。ADR 0475 把邀请留在外面。 |
| 把用户编号写进证据 | 编号不是这行的正文。 |
| 新命令 `/invite` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，邀请提示仍留下。名字里的关键词和短链仍删除。
- 名字里的默认正则后来由 ADR 0533 删除这行。关掉 `call_invite` 不会关掉它。
- 打开 `call_invite` 后，这个群里的邀请提示会删除。开始、结束和预约仍只看 `call_notice`。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `call_invite` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
