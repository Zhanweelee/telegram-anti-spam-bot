# ADR 0809：说明不是字符串时不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。说明是字符串时，自定义表情必须整段落在说明里。见 ADR 0742。正文不是字符串时不读自定义表情。见 ADR 0808。

Android 只能把表情画在一段字符串上。说明不是字符串时，没有可以落点的文字，自定义表情画不出来。

现在这种说明仍会把 `caption_entities` 整份读进来。打开 `custom_emoji` 后，没画出来的表情也会删掉这条消息。

## 决策

- `caption` 不是字符串时，不从 `caption_entities` 读取自定义表情。
- 说明是字符串时，仍要求起点大于或等于 0，长度大于 0，并且起点加长度不能越过说明。空字符串仍是字符串。
- 起点已经超过 150 个码元、但仍整段落在说明里的表情，继续带 `asCustomEmoji`。引用条仍只取前 150 个码元。本条说明按整段长度判断。
- 编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。说明自己就是正文时，看得见的字仍是说明。
- 投票题干上的自定义表情不在这条里。按标识提及不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，表情不该在打开规则后删掉这条消息。 |
| 把数字说明当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 也按 150 个码元丢掉后面的表情 | 150 是引用条的上限。本条说明按整段长度判断。 |
| 投票题干上的表情一起改 | 题干是另一段文字。这条只改说明。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 说明不是字符串时，不再带 `asCustomEmoji`。
- 说明是字符串且表情整段落在说明里时，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 按标识提及在说明不是字符串时仍不读取。见 ADR 0799。
- 说明不是字符串时，自定义表情后来由 ADR 0809 不再读取。投票题干不是字符串时，自定义表情后来由 ADR 0810 不再读取。测验说明不是字符串时，自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
