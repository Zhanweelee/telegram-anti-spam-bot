# ADR 0784：引用条上说明和正文的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。没有更早的标题时，普通消息的引用条画出被回复消息的说明。没有说明时改画正文。两段都只取前 150 个码元。见 ADR 0711。没有任务号时的清单标题，文字链接长度必须大于 0。见 ADR 0783。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达画出的这段末尾的实体。起点落在这 150 个码元里、长度越过末尾时，客户端把长度收到这段末尾，这段链接仍会画出来。第 151 个码元起不画。这行不进正文。有说明时不读正文。服务公告不画这行。

现在这 150 个码元只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在画出的这段里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条回复。代码块语言里的网址也走同一段实体。

置顶预览不在这条里。

## 决策

- 没有更早标题时画出的说明，`caption` 是非空字符串时，`caption_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于画出的这段长度，长度必须是大于 0 的安全整数。
- 没有说明时，改看 `text` 和 `entities`，规则相同。
- 画出的这段是这段文字长度和 150 个码元里较短的那个。
- 起点落在这段里、长度越过末尾时，仍留下主机名。
- 第 151 个码元起的链接仍不读。写在第 151 个码元起的普通网址仍不读。
- 有说明时仍不读正文。服务公告仍不画这行。这行仍不进正文。
- 写在画出的前 150 个码元里的普通网址仍从这段原文抽取。仍只留主机名。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条回复。 |
| 也要求长度落在这 150 个码元里 | 起点在这段里时，客户端会把越过末尾的长度收回来再画。 |
| 改成整段说明或正文都读 | 引用条只画前 150 个码元。 |
| 置顶预览一起改 | 那一行只画前 20 个码元。这条只改引用条。 |

## 后果

- 没有更早标题时，长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在画出的前 150 个码元里、长度越过末尾的短链、邀请或裸 IP 仍删除。第 151 个码元上的链接仍不删除。证据只有主机名。
- 写在画出的前 150 个码元里的普通网址仍会删除。被截断的路径不进事件。有说明时正文仍不读。这行仍不进正文。
- 服务公告仍不读这行。
- 置顶预览上的文字链接后来由 ADR 0785 要求长度大于 0。代码块语言仍不读。账单说明仍不读消息上的实体。富文本预览仍按原来的方式读取。长度越过末尾时仍算画出来。第 21 个码元起仍不读。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
