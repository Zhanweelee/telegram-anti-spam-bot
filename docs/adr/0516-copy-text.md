# ADR 0516：复制到剪贴板的按钮按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

内联按钮和富文本按钮可以把一段句子放进剪贴板。看得见的按钮文字是另一句。ADR 0055 和 ADR 0075 只从这段句子里抽主机名，句子本身不进事件。口令、钱包地址和电话不是网址时，关键词和链接规则都看不见。

自定义表情仍由 `custom_emoji` 决定。打开那条规则不会删除复制按钮。

## 决策

- 内联键盘 `reply_markup.inline_keyboard` 里，或富文本按钮里，`copy_text` 是对象并且 `text` 去掉空白后非空时，事件带 `asCopyText: true`。嵌套在拼贴或段落里也同样。
- 空白、布尔值、缺句子不带这个标记。只有网址的按钮不带。回调数据不带。回复键盘不带。自定义表情和日期时间不带。
- 复制句子不进事件，也不进证据。看得见的按钮文字仍是正文。已有 `text` 或 `caption` 时正文不变，句子不并进去。
- 检测器在 `@tasb/detector-copy`，id 是 `copy_text`。只在 `message.asCopyText` 为 true 时返回 score 1。证据是 `button:copy_text`。
- 默认规则关闭。私聊 `/rule <chatId> copy_text on` 之后删除这种正文，`off` 回到留下。
- 不并进 `custom_emoji`。不读取 `callback_data`。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`copy_text` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把复制句子接到正文后面 | 同一条消息的哈希会变，句子也会进事件。 |
| 把句子写进证据 | 句子不进事件。 |
| 并进自定义表情 | 只想删表情的群会把复制按钮也删掉。 |
| 默认打开 | 有的群会用复制按钮发口令。打开之前不改现有群。 |
| 新命令 `/copy` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，复制按钮留下。看得见的按钮文字仍参与关键词。句子里的网址仍只留主机名。句子仍不进事件。
- 打开 `copy_text` 后，这个群里的这种按钮会删除。打开 `custom_emoji` 仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `copy_text` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `copy_text`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
- 按下后插入输入框的查询后来由 ADR 0517 另开 `switch_query`。打开复制按钮仍不删除这种按钮。查询仍不进事件。
