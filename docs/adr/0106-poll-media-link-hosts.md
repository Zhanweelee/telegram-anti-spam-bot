# ADR 0106：投票媒体链接只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

投票可以在题干、测验解释和选项上挂一条 HTTP 链接。字段是 `poll.media.link`、`poll.explanation_media.link` 和 `poll.options[].media.link`。题干已经是正文时，这条链接不在正文里。链接规则现在看不到。

同一块媒体还可以是照片、位置或文件。那些字段不是这条链接。

## 决策

- 这三处 `link.url` 走和按钮 `url` 相同的解析：长度、协议、折叠和邀请判断都不变。事件里只留主机名。
- 顺序是投票媒体、解释媒体，然后按选项顺序。
- 不读取照片、贴纸、位置、场馆、动图、视频、音频、文件和文件 id。
- 链接不进入正文，也不改内容哈希。路径和邀请码不进事件。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把链接拼进题干 | 同一条消息的哈希会变，路径也会进事件。 |
| 连照片文件 id 一起读 | 文件 id 不是网址。ADR 0062 已经不读它。 |
| 只在短链或邀请时才读取 | 普通域名的媒体链接也会被漏记。现有规则已经会放过普通域名。 |

## 后果

- 媒体链接指向短链、邀请或裸 IP 时，按现有链接规则命中。
- 指向普通域名时仍保留。路径、查询和邀请码不进事件。
- 照片、位置和文件 id 里的字符串仍不进事件。
