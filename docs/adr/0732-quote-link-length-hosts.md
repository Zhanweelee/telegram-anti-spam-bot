# ADR 0732：引用上的文字链接不能越过正文

- 状态：已接受
- 日期：2026-11-07

## 背景

回复条画出手动引用和自动引用。摘录上的短链在 `quote.entities`。见 ADR 0085 与 ADR 0712。

Android 先把摘录里的换行换成空格，长度不变，再用 `addEntitiesToText` 把实体画到整段摘录上。文字链接的起点大于或等于这段文字时，链接不会画上去。

现在引用会读全部文字链接。起点已经越过摘录的链接仍会留下主机名。

后加或删除的选项已经要求起点落在选项文字里。见 ADR 0731。引用是另一段文字。

## 决策

- `quote.text` 是字符串时，这段引用上的文字链接，起点必须小于摘录的长度。手动引用和自动引用都一样。
- 摘录不是字符串时，仍不读这段引用。
- 摘录里的普通网址仍读。仍只留主机名。
- 投票描述、游戏说明和礼物不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条消息。 |
| 只改手动引用 | 自动引用也用同一段摘录画出来。 |
| 按五行再丢掉后面的链接 | 客户端先把实体画到整段摘录上，再按宽度省略。这条只丢掉起点已经越过摘录的链接。 |

## 后果

- 起点越过摘录的文字链接不再留下主机名。仍落在摘录里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在手动引用里的路径仍留在正文或 `quoteText`。自动引用的原文仍不进事件。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 游戏附加文字上的文字链接后来由 ADR 0733 同样要求起点落在附加文字里。投票描述和礼物仍不在那条里。
- 手动引用自己就是正文时，文字链接后来由 ADR 0739 同样要求起点小于这段摘录。
