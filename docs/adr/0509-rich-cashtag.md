# ADR 0509：富文本行情标签按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

富文本里的行情标签可以和看得见的字不同。字段是 `cashtag`。这个字段不进事件，关键词看不见行情代码。看得见的字已经可以成为正文。

话题标签是另一类字段，由 `rich_hashtag` 决定。

## 决策

- `type` 正好是 `cashtag`，并且 `cashtag` 去掉空白后非空时，事件带 `asRichCashtag: true`。嵌套在别的块里也同样。
- 空白、布尔值和缺行情代码不带这个标记。话题标签不带这个标记。话题标签仍只带 `asRichHashtag`。
- 行情代码不进事件，也不进证据。看得见的字仍是正文。已有 `text` 或 `caption` 时正文不变，行情代码不并进去。
- 检测器在 `@tasb/detector-rich`，id 是 `rich_cashtag`。只在 `message.asRichCashtag` 为 true 时返回 score 1。证据是 `rich:cashtag`。
- 默认规则关闭。私聊 `/rule <chatId> rich_cashtag on` 之后删除这种正文，`off` 回到留下。
- 不并进 `rich_hashtag`。不调用读取或改写行情代码的方法。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`rich_cashtag` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 并进话题标签 | 只想删话题的群会把行情标签也删掉。 |
| 把行情代码接到正文后面 | 同一条消息的哈希会变，行情代码也会进事件。 |
| 把行情代码写进证据 | 行情代码不进事件。 |
| 默认打开 | 有的群用富文本发行情。打开之前不改现有群。 |
| 新命令 `/cash` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，富文本行情标签留下。看得见的字仍参与关键词。行情代码仍不进事件。
- 打开 `rich_cashtag` 后，这个群里的这种行情会删除。打开 `rich_hashtag` 仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `rich_cashtag` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `rich_cashtag`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
- 锚点后来由 ADR 0510 另开 `rich_anchor`。打开行情标签仍不删除这种锚点。行情代码仍不进事件。
