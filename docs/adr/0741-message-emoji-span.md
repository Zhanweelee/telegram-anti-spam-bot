# ADR 0741：正文上的自定义表情必须落在正文里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。

Android 的 `replaceAnimatedEmoji` 只在 `offset + length` 不超过这段文字时才放上表情。起点已经越过正文，或表情越过正文末尾，都不会画出来。长度为 0 的实体也不会画。

现在正文会读全部 `entities`。一个越出正文的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条消息。

说明、投票、清单、礼物、游戏和手动引用不在这条里。富文本里的自定义表情仍按结构化节点读取。

## 决策

- `text` 是字符串时，`entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过正文。
- `text` 不是字符串时，仍按原来的方式读取。
- 说明上的自定义表情不在这条里。
- 仍落在正文里的表情继续带 `asCustomEmoji`。编号仍不进事件。看得见的字仍是正文。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条消息。 |
| 只要求起点小于正文 | 表情越过末尾时，客户端同样不会画。 |
| 说明也一起收 | 说明是另一段文字，这条只改正文。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 起点加长度越过正文的自定义表情不再带 `asCustomEmoji`。空正文和长度为 0 的实体也不带。
- 仍落在正文里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 说明上的自定义表情后来由 ADR 0742 要求整段落在说明里。说明不是字符串时仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
