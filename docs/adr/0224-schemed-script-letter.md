# ADR 0224：带协议的文字字母留在标签里

- 状态：已接受
- 日期：2026-11-03

## 背景

抽主机名时会去掉希腊文、西里尔文、亚美尼亚文和非 ASCII 拉丁字母。夹在两个 ASCII 字母中间时，`bαit.ly` 仍是短链。

`http://bit.lyα/…`、`https://t.coт?…`、`http://203.0.113.10ա/…` 和 `http://bit.lyœ:80/…` 在 Android 上各是一条链接。地址解析器给出的主机名不是前面的短链或裸 IP。`http://bit.lyα/http://t.co/…` 的路径仍属于这一条。`see http://bit.lyт/…` 也是。

`http://bit.lyα.bit.ly/…` 的主机名仍以 `bit.ly` 结尾。没有协议的 `bit.lyα/…`、`www.bit.lyα/…` 和 `203.0.113.10α/…` 只打开前面的短链或裸 IP。`http://bit.lyα#…`、`http://bit.lyα@evil.com/…` 和中间有空格的写法也退回前面的短链。标签放不下第 62 个字母时，短链单独打开。`bαit.ly` 仍是短链。

## 决策

- 只改主机名扫描。公开的折叠不改。
- 写完的带协议主机名后面，一段这类字母在 Android 仍把它算进这条链接时留下。
- 后面是 `#`、`@` 或空格，或者这段字母让标签超过 63 个字符时，仍删掉这些字母。
- 没有协议时仍删掉。夹在两个 ASCII 字母中间时仍删掉。
- 这段字母后面是点号和严格域名时，仍按原来的规则收成 `x`。
- 每段仍走现有的短链、裸 IP、邀请和 denylist 判断。只拆一层。最多 8 个。证据只留主机名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 粘连扫描继续删掉全部这类字母 | `http://bit.lyα/…` 会按短链删除。Android 打开的不是 `bit.ly`。 |
| 没有协议也把字母留下 | `bit.lyα/…` 会漏掉。Android 只打开 `bit.ly`。 |
| 夹在 ASCII 中间的字母也留下 | `bαit.ly` 会漏掉。 |

## 后果

- `http://bit.lyα/…`、`https://t.coт?…`、`http://203.0.113.10ա/…` 和 `http://bit.lyœ/…` 留着。
- `http://bit.lyα/http://t.co/…` 留着。路径里的短链不另记。
- `see http://bit.lyт/…` 留着。
- `http://bit.lyα.evil.com/…` 留着。
- `bit.lyα/…`、`www.bit.lyα/…` 和 `203.0.113.10α/…` 仍删除。
- `http://bit.lyα#…`、`http://bit.lyα@evil.com/…` 和 `bαit.ly` 仍按短链删除。
- `http://bit.lyα.bit.ly/…` 仍按短链删除。证据是收成 `x` 之后的主机名。
- 第 62 个字母仍让短链单独打开。路径不进证据。
