# ADR 0775：后加或删除的选项上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。后加或删除的选项上的文字链接，起点必须落在这条选项文字里。见 ADR 0731。清单任务上的文字链接，长度必须大于 0。见 ADR 0774。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达选项末尾的实体。起点落在选项里、长度越过末尾时，客户端把长度收到选项末尾，这段链接仍会画出来。新加和删除用同一段选项文字。

已有别的正文时，事件里的 `addedText` 只留前 100 字。选项和正文相同、不再另留时，事件正文只留前 4096 字。链接仍按整段选项判断。写在选项里的普通网址仍从整段原文抽取，包括第 101 字起。

现在这两条服务消息只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在选项里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条服务消息。代码块语言里的网址也走同一段实体。

后加任务不在这条里。

## 决策

- `poll_option_added.option_text` 和 `poll_option_deleted.option_text` 是字符串时，对应的 `option_text_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于这条选项的长度，长度必须是大于 0 的安全整数。
- 起点落在这条选项里、长度越过末尾时，仍留下主机名。
- 选项文字不是字符串时，仍按原来的方式读取。
- 已有别的正文时，第 101 字上的链接，只要起点仍落在这条选项里、长度大于 0，就继续留下主机名。事件里的 `addedText` 仍只留前 100 字。
- 选项和正文相同、不再另留时，第 4097 字上的链接，只要起点仍落在这条选项里、长度大于 0，就继续留下主机名。事件正文仍只留前 4096 字。
- 写在选项里的普通网址仍从整段原文抽取，包括第 101 字起。仍只留主机名。
- 后加任务上的 `text_entities` 不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条服务消息。 |
| 也要求长度落在选项里 | 起点在选项里时，客户端会把越过末尾的长度收回来再画。 |
| 也按 100 字丢掉后面的链接 | 100 只是旁边选项的上限。整段选项更长时，后面的链接仍落在这条选项里。 |
| 只改新加选项 | 删除提示画出同一段选项文字。两条共用这一处读取。 |
| 后加任务一起改 | 任务是另一段文字。这条只改后加和删除的选项。 |

## 后果

- 后加或删除的选项上，长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在选项里、长度越过末尾的短链、邀请或裸 IP 仍删除。起点已经超过 100 或 4096、但仍落在这条选项里的链接也删除。证据只有主机名。
- 写在选项里的普通网址仍会删除，包括第 101 字起。被截断的路径不进事件。
- 选项文字不是字符串时，文字链接后来由 ADR 0789 不再读取。按标识提及和自定义表情仍按原来的方式读取。
- 后加任务上的文字链接后来由 ADR 0776 要求长度大于 0。任务文字不是字符串时，文字链接后来由 ADR 0788 不再读取。长度越过末尾时仍算画出来。第四条仍不读。勾完的任务不在那条里。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
