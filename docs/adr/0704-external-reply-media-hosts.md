# ADR 0704：外部回复的媒体标题只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

原文不在本群时，Android 用 `getMediaTitle` 把外部回复的媒体画在引用条上。普通文件画文件名。清单画标题。账单画说明。图片、贴纸、视频和游戏只画固定字样，不画文件名或标题。

任务行、选项行、引用和投票本身已经占了这一行时，不再改画这份媒体。

ADR 0700 读外部来源的名字，预览正文仍留在外面。这一行标题仍会留下短链。

## 决策

- `external_reply` 是对象，且任务行、选项行、引用和投票本身都没有占住引用条时，从画出来的媒体标题留主机名。
- `checklist` 是对象时，只读 `title` 和 `title_entities` 里的链接。任务不读。
- 没有清单时，`invoice` 是对象就只读 `description`。标题不读。
- 再没有账单时，`document` 是对象就只读 `file_name`。
- 图片、贴纸、视频、语音、游戏、投票、抽奖、地点、名片和付费媒体占住这一行，但不读它们的名字。本条回复上的游戏标题和账单标题也不再改读。
- 没有 `external_reply` 时不读。带 `quote.text` 时不读。
- 主机名仍进消息已有的 `hosts`。邀请仍进 `invites`。标题不进正文，也不改内容哈希。关键词因此不命中。正文里已有短链时，证据仍先记正文的主机名。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 外部回复的游戏标题也读 | `getMediaTitle` 对游戏不画 `game.title`。 |
| 外部账单的标题也读 | 这一行画的是说明，不是标题。 |
| 连图片和视频的文件名一起读 | 客户端画的是固定字样。 |
| 把标题收进正文 | 它是引用条上的一行。关键词仍只看这条消息自己的正文。 |

## 后果

- 画出的文件名、清单标题或账单说明出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。
- 任务、账单标题、图片和视频仍不进事件。标题不改内容哈希。关键词不命中标题。
- 带引用、投票本身、任务行或选项行时，不改读这份媒体。
- 本条已经加载的游戏标题和账单标题，在外部媒体占住这一行时不再读。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 本条回复里没有说明的普通文件，文件名后来由 ADR 0705 只留主机名。有说明时仍不读。
- 外部回复同时带固定字样和 `document` 时，这份文件名后来由 ADR 0707 留在外面。只有普通文件时仍读。
- 清单标题上的文字链接后来由 ADR 0735 要求起点小于这段标题。清单标题不是字符串时，文字链接后来由 ADR 0793 不再读取。已加载回复仍只取前 150 个码元。外部回复上的清单标题后来由 ADR 0782 要求长度大于 0。长度越过末尾时仍算画出来。
