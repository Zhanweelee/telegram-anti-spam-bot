# ADR 0318：小程序回传的数据只留主机名

- 状态：已接受
- 日期：2026-11-03

## 背景

Bot API 的 `web_app_data` 是小程序用 `sendData` 回给 bot 的服务消息。`data` 和 `button_text` 都可以由恶意客户端随意填写。短链可以只放在这两处，链接规则现在看不到。

`button_text` 是打开小程序的按钮文字，用户看得见。`data` 是回传载荷，可以带密钥或任意正文。把它整段放进事件会把载荷留在正文里。

## 决策

- `data` 和 `button_text` 里的网址只留主机名。解析、折叠、邀请判断和 8 个主机名的上限与别的旁路字段相同。
- 没有更前面的正文时，`button_text` 成为正文。已有正文时，按钮文字不并进去。
- `data` 不进正文，也不参与内容哈希。路径不进证据。
- 不读取嵌套的别的消息。不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 两处都不读 | `data` 里的 `https://bit.ly/…` 会漏掉。 |
| `data` 整段成为正文 | 回传载荷会进内容哈希。里面可以是密钥，不只是用户看见的字。 |
| 已有正文时丢掉这两处的主机名 | 正文是日常句子时，短链仍能藏在回传数据里。 |

## 后果

- 已有正文时，`data` 和 `button_text` 里的短链、邀请仍删除。正文和哈希不变。路径、邀请码和按钮文字不进事件。
- 没有正文时，`button_text` 成为正文。`data` 里的短链仍删除。路径不进证据。
- `button_text` 为空时，正文仍是空字符串。`data` 里的普通域名留下主机名，不按短链删除。
- 云额度的基础检测器名单没有改。
