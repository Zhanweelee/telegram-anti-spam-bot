# ADR 0582：退群的人，名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

有人离开群时，客户端把这个人的名字画在退群那一行。名字写在 `left_chat_member`。这行通常没有别的正文。短链可以只写在名字里。

入群名单已经会成为正文。退群的人当时留在事件外面，避免关键词把正常离开的人删掉。见 ADR 0118。`service_notice` 默认关闭，干净的退群提示仍留下。见 ADR 0467。

## 决策

- 只读本条消息上的 `left_chat_member`。按可见名字留主机名。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 名字不进正文，不进 `memberName`，也不改内容哈希。关键词和默认正则因此不命中。用户 id 不读。
- 发送者的 `from` 和本群的 `chat.title` 不读。嵌套的原消息不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`service_notice` 仍默认关闭。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 关键词会命中人名。正常离开的人会被误删。见 ADR 0118。 |
| 连用户名一起抽 | 客户端画出的是名字。用户名不是这段可见字。 |
| 连发送者姓名一起读 | 发送者不是退群那一行画出的人。 |
| 新命令 `/leave` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 退群的人名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。
- 名字原文、路径和用户名不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 干净的退群提示在 `service_notice` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
