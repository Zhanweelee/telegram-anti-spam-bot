# ADR 0820：手动引用不是字符串时不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。手动引用的摘录是字符串时，自定义表情必须整段落在摘录里。见 ADR 0753。游戏附加文字不是字符串时不读自定义表情。见 ADR 0819。

Android 只能把表情画在一段字符串上。摘录不是字符串时，没有可以落点的文字，自定义表情画不出来。自动引用本来就不读。

现在这种手动引用仍会把 `entities` 整份读进来。打开 `custom_emoji` 后，没画出来的表情也会删掉这条消息。

## 决策

- `quote.is_manual` 正好是 `true`，并且 `quote.text` 不是字符串时，不从 `entities` 读取自定义表情。
- 摘录是字符串时，仍要求起点大于或等于 0，长度大于 0，并且起点加长度不能越过这段摘录。空字符串仍是字符串。
- 第 4097 字起的表情，只要整段仍落在摘录里，就继续带 `asCustomEmoji`。已有别的正文时，事件里的 `quoteText` 仍只留前 4096 字。
- 编号和引用位置仍不进事件。已有别的正文时，看得见的字仍是那段正文。
- 自动引用和被回复的原消息仍不带这个标记。富文本里的自定义表情仍按结构化节点读取。按标识提及不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，表情不该在打开规则后删掉这条消息。 |
| 把数字摘录当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 连自动引用一起改 | 自动摘录不是发送者选的。这条只改手动引用。 |
| 富文本一起改 | 富文本按节点画，不是这段摘录的实体列表。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 摘录不是字符串时，不再带 `asCustomEmoji`。
- 摘录是字符串且表情整段落在摘录里时，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 手动引用不是字符串时，自定义表情后来由 ADR 0820 不再读取。富文本替代文字不是字符串时，自定义表情后来由 ADR 0821 不再读取。替代文字是空字符串时，自定义表情后来由 ADR 0822 不再读取。公式源码里的自定义表情后来由 ADR 0823 不再读取。预格式化块的语言标签里，自定义表情后来由 ADR 0824 不再读取。音频文件名里的自定义表情后来由 ADR 0825 不再读取。音频标题里的自定义表情后来由 ADR 0826 不再读取。音频表演者里的自定义表情后来由 ADR 0827 不再读取。视频文件名里的自定义表情后来由 ADR 0828 不再读取。动画文件名里的自定义表情后来由 ADR 0829 不再读取。文档文件名里的自定义表情后来由 ADR 0830 不再读取。文档类型里的自定义表情后来由 ADR 0831 不再读取。文档缩略图里的自定义表情后来由 ADR 0832 不再读取。视频缩略图里的自定义表情后来由 ADR 0833 不再读取。动画缩略图里的自定义表情后来由 ADR 0834 不再读取。动画类型里的自定义表情后来由 ADR 0835 不再读取。视频类型里的自定义表情后来由 ADR 0836 不再读取。音频类型里的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
