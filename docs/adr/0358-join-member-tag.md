# ADR 0358：入群时的成员标签并进昵称

- 状态：已接受
- 日期：2026-11-04

## 背景

`ChatMemberMember` 和 `ChatMemberRestricted` 可以带 `tag`。这是成员自己的标签，会出现在成员列表里，也就是消息上的 `sender_tag`。人从群外回来时，标签可以还在。ADR 0028 只把昵称、姓氏和用户名放进 `profile`，所以 `join_name` 和 `join_link` 看不见这行字。开口之后，ADR 0112 才会读到消息上的标签。

## 决策

- 从群外加入时，`new_chat_member.tag` 去掉首尾空白后，接在昵称、姓氏和用户名后面，仍用一个普通空格，最长 256 字符。
- 只有空白的标签丢掉。没有名字、只有标签时，`profile` 就是这行标签。
- 已经在群里的升降级、离群和 bot 不带 `profile`。邀请链接的名字不读。
- 默认规则仍是 `join_name` 和 `join_link`。不改 ADR 0026 的基础检测器。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 等对方发言再读 `sender_tag` | 标签在开口前就已经出现在成员列表里。 |
| 单独再加一条规则 | 标签和昵称是同一份看得见的身份。现有入群规则已经会封禁。 |

## 后果

- 带着广告标签回来的人，会和广告昵称一样被封禁，不发验证按钮。
- 人还在群里时改标签，仍要等下一条消息。那条消息上的 `sender_tag` 继续按 ADR 0112 处理。
- 30 天保留期不动。
