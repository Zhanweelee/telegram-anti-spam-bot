# ADR 0114：改群名只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

群名被改掉时，成员看见一条服务消息，新名字在 `new_chat_title`。这句名字里可以只放短链或邀请。消息往往没有 `text`。

ADR 0027 规定群名不进事件、目录或日志。`chat.title` 和 `chat.description` 会附在每一条消息上，不是这一次改名的内容。真实姓名也不是群名。

把新群名当成正文会把群名写进事件和内容哈希。

## 决策

- 从 `new_chat_title` 抽出网址，只留主机名。折叠、长度、邀请判断和 8 个主机名的上限与旁路纯文本相同。
- 新群名不进入 `message.text`，也不参与内容哈希。没有别的正文时，正文仍是空字符串。
- 不读取 `chat.title`、`chat.description` 和用户姓名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把新群名当成正文 | 群名会进事件。ADR 0027 拒绝的就是这个。 |
| 每条消息都扫 `chat.title` | 群名会跟着每条消息重复计一次主机名。 |
| 改名服务消息整段都不读 | 短链可以只写在这次看得见的新名字里。 |

## 后果

- 改名服务消息里的短链、邀请或裸 IP 按现有链接规则命中。路径和邀请码不进事件。
- 新群名里的关键词仍然看不到。群名原文不进事件。某个群后来可以打开 `chat_title` 删除这条改名服务消息。新群名仍不进事件，群名本身也不改回去。见 ADR 0476。
- 附在其它消息上的群名、群说明和真实姓名不进事件。
- 加入或移入社区的名字后来由 ADR 0115 只留下主机名。名字本身仍不进事件。
- 设置聊天背景时，壁纸和图案的文件名后来由 ADR 0430 只留下主机名。文件名本身仍不进事件。
- 改名的人后来由 ADR 0592 只留下主机名。名字本身仍不进事件。空字符串和普通消息仍不读发送者。本群群名仍不读。
