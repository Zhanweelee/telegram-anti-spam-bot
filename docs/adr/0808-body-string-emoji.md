# ADR 0808：正文不是字符串时不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。正文是字符串时，自定义表情必须整段落在正文里。见 ADR 0741。游戏附加文字不是字符串时不读按标识提及。见 ADR 0807。

Android 只能把表情画在一段字符串上。正文不是字符串时，没有可以落点的文字，自定义表情画不出来。

现在这种正文仍会把 `entities` 整份读进来。打开 `custom_emoji` 后，没画出来的表情也会删掉这条消息。

## 决策

- `text` 不是字符串时，不从 `entities` 读取自定义表情。
- 正文是字符串时，仍要求起点大于或等于 0，长度大于 0，并且起点加长度不能越过正文。空字符串仍是字符串。
- 编号仍不进事件。正文是字符串时，看得见的字仍是正文。
- 说明上的自定义表情不在这条里。按标识提及不在这条里。富文本里的自定义表情仍按结构化节点读取。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，表情不该在打开规则后删掉这条消息。 |
| 把数字正文当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 只要求起点小于正文 | 表情越过末尾时，客户端同样不会画。这条不改已经画出的规则。 |
| 说明上的表情一起改 | 说明是另一段文字。这条只改正文。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 正文不是字符串时，不再带 `asCustomEmoji`。
- 正文是字符串且表情整段落在正文里时，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 按标识提及在正文不是字符串时仍不读取。见 ADR 0798。
