# ADR 0746：测验说明上的自定义表情必须落在说明里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。后加和删掉的选项必须整段落在选项里。见 ADR 0745。

测验解答由 `replaceAnimatedEmoji` 画成 `quizExplanation`。表情只在 `offset + length` 不超过这段说明时才画出来。起点已经越过说明，或表情越过说明末尾，都不会画出来。

现在测验说明会读全部 `explanation_entities`。一个越出说明的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条投票。

投票描述不在这条里。题干和选项已经按各自的文字收过。

## 决策

- `poll.explanation` 是字符串时，`explanation_entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过这段说明。
- 说明不是字符串时，仍按原来的方式读取。
- 仍落在说明里的表情继续带 `asCustomEmoji`。编号仍不进事件。
- 投票描述不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条投票。 |
| 只要求起点小于说明 | 表情越过末尾时，客户端同样不会画。 |
| 投票描述一起收 | 描述是另一段文字。 |
| 说明不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的说明。 |

## 后果

- 起点加长度越过测验说明的自定义表情不再带 `asCustomEmoji`。空说明和长度为 0 的实体也不带。
- 仍落在说明里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 投票描述上越出描述的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
