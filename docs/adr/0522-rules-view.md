# ADR 0522：私聊可以只看打开或关闭的规则

- 状态：已接受
- 日期：2026-11-05

## 背景

默认规则有 76 条，其中 12 条是打开的。`spam_keywords`、洪泛、重复、链接和频道转发在第一页。`new_member`、入群昵称、入群短链、入群 bot、入群申请和共享名片在第一页之后。管理员要确认这个群正在执行什么，得先数到 64 再 `skip`。

## 决策

- `/rules [chatId] [on|off] [skip <count>]`。`on` 只列启用的规则，`off` 只列关闭的规则。不写时仍列出全部。
- 筛选之后再按 ADR 0521 的 `skip` 跳过。`skip` 数的是筛选结果里的条数。
- 标题在群号后面带上 `on` 或 `off`。已订阅时 pack id 仍在中间。超额时窗口结束时间仍接在标题后面。
- 筛选结果是空的，回复标题和 `none`。在空结果上再 `skip` 大于 0，回复「参数无效」。
- 不改规则文件，也不改每一行的字段。菜单仍是 99 条。`/rules` 的菜单描述改为带上 `on|off`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把打开的规则挪到文件前面 | 文件顺序也是检测顺序。 |
| 只提供 `on` | 管理员也会想核对哪些规则仍是关闭的。 |
| 让 `skip` 仍按全表计数 | `on skip 1` 会跳过第一页里的关闭规则，打开的规则对不上。 |

## 后果

- `/rules <chatId> on` 能在一页里看到默认打开的 12 条，包括入群验证。
- 不写 `on` 或 `off` 时，回复与 ADR 0521 相同。
- 已经设过命令菜单的部署，要再执行一次设置命令，菜单描述才会带上 `on|off`。
- 没列出来的规则仍在执行。30 天保留期没有改。
