# ADR 0455：入群验证改成两颗数字按钮

- 状态：已接受
- 日期：2026-11-04

## 背景

ADR 0447 在「我不是机器人」旁边加了「我是机器人」。点错的那颗不会通过。按钮上的字是固定的，脚本只要点写着人的那一颗就会通过。ADR 0447 把问答留了下来，因为把答案另存一列要改 `captcha_challenges`。

验证期间成员不能发言，只能点按钮。题目必须做在按钮上。

## 决策

- 题目由这一次 nonce 的前三个十六进制位决定。前两位相加，得数是 0 到 30，写在会通过的那颗按钮上。第三位用来算出另一颗不同的数字。
- 得数不写入 `captcha_challenges`。回调仍是 `n:` 和 `c:` 加同一段 nonce。
- 错误的数字放在前面。正确的数字放在后面。
- 正文是「请点「得数」。点「另一颗」不会通过。」
- 点 `n:` 加 16 位小写十六进制时，`answerCallbackQuery` 带上「请点「得数」。」不弹窗。nonce 不进应答，也不进日志。
- 点 `c:` 加同一段 nonce 仍只放行一次，应答不带这句。
- 同一份 nonce 再发按钮时，题目不变。
- 不改挑战表，不新增命令。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把得数存进 D1 | 得数能从 nonce 再算出来。已经建好的表不用加列。 |
| 每次随机，并且不由 nonce 决定 | 点错时的提示要对上同一道题。没有存答案时，只能从 nonce 再算。 |
| 让成员打字回答 | 验证期间不能发言。打出的字也进不了群。 |

## 后果

- 固定去点「我不是机器人」的脚本不再通过。
- 重发的按钮仍是同一道题。
- 云额度的基础检测器名单没有改。30 天保留期没有改。
