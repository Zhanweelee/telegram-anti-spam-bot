# ADR 0776：后加任务上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。后加任务上的文字链接，起点必须落在这条画出的任务文字里。四条起只看前三条。见 ADR 0727 与 ADR 0660。后加或删除的选项上的文字链接，长度必须大于 0。见 ADR 0775。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达任务末尾的实体。起点落在任务里、长度越过末尾时，客户端把长度收到任务末尾，这段链接仍会画出来。每条画出的任务单独画。拼起来的 `addedText` 不改变这条任务上的起点。

已有别的正文时，前三条用一个普通空格拼起来，事件里只留前 3029 字。任务和正文相同、不再另留时，事件正文只留前 4096 字。链接仍按每一条画出的任务判断。写在任务里的普通网址仍从整段原文抽取，包括第 3030 字起，也包括拼进去之后被截掉的后面几条。第四条仍不读。

现在画出的任务只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在任务里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条服务消息。代码块语言里的网址也走同一段实体。

勾完或取消勾完时画出的那条任务不在这条里。

## 决策

- `checklist_tasks_added` 里会画出来的任务，`text` 是字符串时，`text_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于这条任务的长度，长度必须是大于 0 的安全整数。
- 起点落在这条任务里、长度越过末尾时，仍留下主机名。
- 任务文字不是字符串时，仍按原来的方式读取。
- 四条起只看前三条。第四条上的文字链接和普通网址仍不读。
- 已有别的正文时，第 3030 字上的链接，只要起点仍落在这条任务里、长度大于 0，就继续留下主机名。后面几条画出的任务被截出 `addedText` 时也一样。事件里的 `addedText` 仍只留前 3029 字。
- 任务和正文相同、不再另留时，第 4097 字上的链接，只要起点仍落在这条任务里、长度大于 0，就继续留下主机名。事件正文仍只留前 4096 字。
- 写在画出的任务里的普通网址仍从整段原文抽取，包括第 3030 字起。仍只留主机名。
- 勾完或取消勾完时画出的那条任务不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条服务消息。 |
| 也要求长度落在任务里 | 起点在任务里时，客户端会把越过末尾的长度收回来再画。 |
| 也按 3029 字丢掉后面的链接 | 3029 只是旁边任务的上限。整段任务更长时，后面的链接仍落在这条任务里。 |
| 第四条也读 | 第四条本来就不画。 |
| 勾完的任务一起改 | 那是另一条服务消息。这条只改后加任务。 |

## 后果

- 画出的任务上，长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在任务里、长度越过末尾的短链、邀请或裸 IP 仍删除。起点已经超过 3029 或 4096、但仍落在这条任务里的链接也删除。被截出 `addedText` 的后面几条画出的任务也删除。证据只有主机名。
- 写在画出的任务里的普通网址仍会删除，包括第 3030 字起。被截断的路径不进事件。
- 任务文字不是字符串时，文字链接后来由 ADR 0788 不再读取。按标识提及和自定义表情仍按原来的方式读取。
- 第四条上的文字链接和普通网址仍不读。
- 勾完的任务上的文字链接后来由 ADR 0777 要求长度大于 0。任务文字不是字符串时，文字链接后来由 ADR 0788 不再读取。长度越过末尾时仍算画出来。回复某一条任务时画出的那一行不在那条里。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
