# ADR 0477：社区服务消息按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

群被移入社区，或自己加入社区时，成员看见一条服务消息。社区名字只留主机名，不进正文。见 ADR 0115。名字里没有短链时，关键词看不到这句名字，服务消息会留下。

移出社区的服务消息目前不带名字。它同样会留在群里。

社区名字仍然不能写进事件。删掉这条服务消息也不会把群移出社区。

## 决策

- `community_chat_added.community` 是对象时，事件带 `community: "added"`。`community_chat_joined.community` 是对象时带 `joined`。`community_chat_removed` 是对象时带 `removed`。几种同时出现时，先认移入，再认加入，再认移出。不写社区名字和社区 id。
- 没有 `community` 对象的移入或加入不带这个标记。移出对象上的其它字段仍不抽主机名。已有正文时，正文仍按原来的优先级。移入和加入的名字里的主机名仍按 ADR 0115 抽取。
- 检测器在 `@tasb/detector-community`，id 是 `community_notice`。`message.community` 是这三种之一时返回 score 1。证据是 `community:added`、`community:joined` 或 `community:removed`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这三种服务消息。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`community_notice` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部社区提示 | 有的群自己加入社区。打开之前不改现有群。 |
| 把社区名字收成正文 | 名字会进事件和内容哈希。见 ADR 0115。 |
| 移入、加入和移出各一条规则 | 这三行是同一类服务消息。分开开关以后再做。 |
| 从移出对象里抽主机名 | 移出服务消息目前不带社区名字。见 ADR 0115。 |
| 新命令 `/community` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，移入、加入和移出仍留下。移入和加入的名字里的短链和邀请仍删除。
- 打开 `community_notice` 后，这个群里的这三种服务消息会删除。群是否留在社区不变。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `community_notice` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
- 移入、加入或移出社区的人后来由 ADR 0594 只留下主机名。名字本身仍不进事件。没有社区对象的移入或加入仍不读发送者。社区编号和移出对象上的其它字段仍不读。
