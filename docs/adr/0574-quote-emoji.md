# ADR 0574：手动引用上的自定义表情也走同一条规则

- 状态：已接受
- 日期：2026-11-05

## 背景

回复可以手动摘一段原文。官方会在这段引用里留下自定义表情。打开 `custom_emoji` 的群会删掉正文上的这种表情，手动引用上的同一处仍留下。自动附上的摘录不是发送者选的。被回复的原消息是另一条消息。

引用位置不在看得见的字里。日期时间和按标识提及仍按原来的决定留下。

## 决策

- `quote.is_manual` 正好是 `true` 时，`quote.entities` 里 `type` 正好是 `custom_emoji`，并且 `custom_emoji_id` 去掉空白后非空，事件同样带 `asCustomEmoji: true`。
- 自动引用不带这个标记。空白、布尔值和缺编号仍不带。嵌套的 `reply_to_message` 不读。引用上的 `text_mention` 和 `date_time` 仍不带。
- 编号和引用位置不进事件，也不进证据。引用看得见的字仍留在原来的字段。正文和 `textSha256` 不变。
- 仍用检测器 `custom_emoji`。证据仍是 `entity:custom_emoji`。不新增规则，不新增命令。菜单仍是 99 条。
- 规则仍默认关闭。打开之后，这种手动引用也删除。付费帖仍不删除。
- 不改 ADR 0026 的基础检测器名单。`custom_emoji` 仍不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 另开一条规则 | 这是同一处隐藏的表情编号。分开开关会让群管开漏一处。 |
| 连自动引用一起扫 | 自动摘录是服务器附上的，不是这条消息的发送者选的。 |
| 连被回复的原消息一起扫 | `reply_to_message` 是另一条消息。原消息发出时已经扫过。 |
| 把引用上的按标识提及和日期时间也标上 | 官方在引用里不保留按标识提及。日期时间的 Unix 时间仍留在事件外面。 |

## 后果

- 规则关闭时，手动引用上的自定义表情留下。看得见的字仍参与关键词。编号仍不进事件。
- 打开 `custom_emoji` 后，这种手动引用会删除。引用位置仍不进事件。
- 付费帖仍留下。空白编号不带这个标记。自动引用和原消息上的表情不因为嵌套再标一次。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `custom_emoji` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `custom_emoji`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
- 手动引用上的自定义表情后来由 ADR 0753 要求整段落在摘录里。摘录不是字符串时仍按原来的方式读取。自动引用仍不带这个标记。已有别的正文时，事件里的摘录仍只留前 4096 字。
