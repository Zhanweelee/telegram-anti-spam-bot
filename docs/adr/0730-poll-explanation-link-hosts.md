# ADR 0730：测验说明上的文字链接不能越过正文

- 状态：已接受
- 日期：2026-11-07

## 背景

答错或点灯时，投票气泡画出测验说明。说明上的短链在 `poll.explanation_entities`。见 ADR 0077 与 ADR 0543。

Android 的 `generateExplanation` 用 `addEntitiesToText` 把实体画到 `solution` 上。文字链接的起点大于或等于这段文字时，链接不会画上去。

现在说明会读全部文字链接。起点已经越过正文的链接仍会留下主机名。

投票选项已经要求起点落在选项文字里。见 ADR 0729。测验说明是另一段文字。

## 决策

- 测验说明上的文字链接，起点必须小于 `poll.explanation` 的长度。说明不是字符串时，仍按原来的方式读取。
- 说明里的普通网址仍读。仍只留主机名。
- 投票描述、后加或删除的选项、游戏说明、礼物和引用不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条投票。 |
| 投票描述也按正文长度丢掉链接 | 这份客户端还没有画出描述。这条只改已经画出的说明。 |
| 后加选项的服务消息也一起改 | 那是另一条服务消息。这条只改测验说明。 |

## 后果

- 起点越过说明的文字链接不再留下主机名。仍落在这段文字里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在说明里的路径仍留在 `pollExplanation`。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 后加或删除的选项上的文字链接后来由 ADR 0731 同样要求起点落在选项文字里。投票描述仍不在那条里。
- 测验说明上的文字链接后来由 ADR 0771 要求长度大于 0。长度越过末尾时仍算画出来。投票描述不在那条里。
