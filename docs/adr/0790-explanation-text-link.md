# ADR 0790：测验说明不是字符串时不读文字链接

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。测验说明是字符串时，文字链接的起点必须落在说明里，长度必须大于 0。见 ADR 0771。选项文字不是字符串时不读文字链接。见 ADR 0789。

Android 只能把实体画在一段字符串上。说明不是字符串时，没有可以落点的文字，文字链接和代码块语言都画不出来。

现在这种说明仍会把 `explanation_entities` 整份读进来。打开链接规则后，没画出来的链接也会删掉这条投票。

## 决策

- `poll.explanation` 不是字符串时，不读 `explanation_entities`。
- 说明是字符串时，仍要求起点落在说明里，长度是大于 0 的安全整数。长度越过末尾时仍留下主机名。
- 已有别的正文时，事件里的说明仍只留前 200 字。写在说明里的普通网址仍从整段说明抽取。
- 按标识提及和自定义表情不在这条里。投票描述不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，链接不该删掉这条投票。 |
| 把数字说明当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 提及和表情一起改 | 那是另一套标记。这条只改文字链接。 |
| 投票描述一起改 | 描述是另一段文字。 |
