# ADR 0729：投票选项上的文字链接不能越过正文

- 状态：已接受
- 日期：2026-11-07

## 背景

投票气泡画出每一个选项。选项上的短链在 `poll.options[].text_entities`。见 ADR 0077。

Android 用 `addEntitiesToText` 把实体画到选项文字上。文字链接的起点大于或等于这段文字时，链接不会画上去。

现在每个选项会读全部文字链接。起点已经越过正文的链接仍会留下主机名。

勾完的任务已经要求起点落在任务文字里。见 ADR 0728。投票选项是另一处字段。

## 决策

- 每一个投票选项上的文字链接，起点必须小于这条 `text` 的长度。
- 选项文字里的普通网址仍读。仍只留主机名。
- 测验说明、投票描述、后加或删除的选项、游戏说明、礼物和引用不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条投票。 |
| 说明和描述也按正文长度丢掉链接 | 那是另外两段文字。这条只改选项。 |
| 后加选项的服务消息也一起改 | 那是另一条服务消息。这条只改投票气泡。 |

## 后果

- 起点越过选项文字的文字链接不再留下主机名。仍落在这段文字里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在选项里的路径仍留在 `pollOption`。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 测验说明上的文字链接后来由 ADR 0730 同样要求起点落在说明里。投票描述仍不在那条里。
- 投票选项上的文字链接后来由 ADR 0773 要求长度大于 0。选项文字不是字符串时，文字链接后来由 ADR 0789 不再读取。长度越过末尾时仍算画出来。清单任务不在那条里。
