# ADR 0840：视频笔记缩略图里不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。语音类型里不读自定义表情。见 ADR 0839。视频笔记缩略图不进正文。

现在视频笔记块 `video_note.thumbnail` 里如果嵌着自定义表情，仍会带 `asCustomEmoji`。打开 `custom_emoji` 后，没画在正文上的表情也会删掉这条消息。

## 决策

- 视频笔记块 `video_note.thumbnail` 里不读取自定义表情。
- 视频笔记说明仍按原来的方式读取。画出来的段落、替代文字长度大于 0 的节点仍读。
- 编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。缩略图仍不进正文。
- 贴纸缩略图不在这条里。实体列表上的自定义表情仍按各自那段文字判断。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读视频笔记缩略图 | 缩略图不进正文，里面的表情不会画在这段正文上。 |
| 整个视频笔记块都不看 | 这条只改缩略图。说明仍可能画出来。 |
| 贴纸缩略图一起改 | 贴纸缩略图是另一段没画进正文的字段。 |
| 连实体列表一起改 | 实体列表已经按各自的文字判断。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 视频笔记缩略图里的自定义表情不再带 `asCustomEmoji`。
- 旁边仍画出来的节点，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 视频笔记缩略图里的自定义表情后来由 ADR 0840 不再读取。贴纸缩略图里的自定义表情后来由 ADR 0841 不再读取。贴纸包名里的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
