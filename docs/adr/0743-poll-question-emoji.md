# ADR 0743：投票题干上的自定义表情必须落在题干里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。正文和说明上的表情必须整段落在各自的文字里。见 ADR 0741 与 ADR 0742。

投票气泡把题干画在标题上。题干和选项只允许自定义表情这种实体。见 ADR 0056。`replaceAnimatedEmoji` 只在 `offset + length` 不超过这段文字时才放上表情。起点已经越过题干，或表情越过题干末尾，都不会画出来。

现在题干会读全部 `question_entities`。一个越出题干的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条投票。

测验说明、投票描述和选项不在这条里。

## 决策

- `poll.question` 是字符串时，`question_entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过题干。
- 题干不是字符串时，仍按原来的方式读取。
- 测验说明、投票描述和选项上的自定义表情不在这条里。
- 仍落在题干里的表情继续带 `asCustomEmoji`。编号仍不进事件。看得见的字仍是题干。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条投票。 |
| 只要求起点小于题干 | 表情越过末尾时，客户端同样不会画。 |
| 选项一起收 | 选项是另一段文字。 |
| 题干不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的题干。 |

## 后果

- 起点加长度越过题干的自定义表情不再带 `asCustomEmoji`。空题干和长度为 0 的实体也不带。
- 仍落在题干里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 题干不是字符串时，自定义表情后来由 ADR 0810 不再读取。
- 测验说明上的自定义表情后来由 ADR 0746 要求整段落在说明里。说明不是字符串时仍按原来的方式读取。投票描述后来由 ADR 0747 要求整段落在描述里。
- 投票选项上的自定义表情后来由 ADR 0744 要求整段落在这条选项里。选项文字不是字符串时仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
