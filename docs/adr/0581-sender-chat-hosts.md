# ADR 0581：别的聊天代发时，标题只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

频道或别的群可以用自己的身份往这个群里发消息。客户端把那份标题画成发送者。标题写在 `sender_chat.title`。正文可以是一句普通的话，短链只写在标题里。

本群匿名管理员的 `sender_chat` 就是本群，标题等于群名。群名不能跟着每条消息再计一次主机名。转发来源上的频道标题仍然留在事件外面。见 ADR 0091 和 ADR 0579。

`channel_sender` 默认关闭。不打开时，别的频道代发仍会留下，除非正文或标题里的链接命中。见 ADR 0471。

## 决策

- 只读本条消息上的 `sender_chat.title`。发送者聊天的编号和本群不同时，标题只留主机名。抽出之前不截断。
- 编号相同，或任何一边没有编号时，不读标题。本群自己的身份因此留在外面。
- 用户名不读。标题不进正文，也不改内容哈希。关键词因此不命中。聊天编号不读。
- 转发来源上的频道标题仍不读。讨论组自动转发只读这条消息自己的 `sender_chat.title`。嵌套的原消息不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`channel_sender` 仍默认关闭。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把标题整段当成正文 | 会改变哈希，关键词也会命中频道名。短链只需要主机名。 |
| 连本群自己的身份一起读 | 群名会跟着匿名管理员的每条消息重复计一次。 |
| 连转发来源的频道标题一起读 | 频道转发默认已经删除。标题仍留在事件外面。见 ADR 0091。 |
| 新命令 `/sendertitle` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 别的聊天代发时，标题里出现短链、邀请或裸 IP，会删掉这一条。证据只有主机名。
- 标题原文、路径和用户名不进事件，内容哈希不变。标题里的关键词不命中。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 本群自己的身份、转发来源上的频道标题和嵌套的原消息仍不读。
- 云额度的基础检测器名单没有改。30 天保留期没有改。
