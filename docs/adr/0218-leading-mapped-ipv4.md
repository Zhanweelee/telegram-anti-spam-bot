# ADR 0218：裸 IP 前面的单字母不再粘上去

- 状态：已接受
- 日期：2026-11-03

## 背景

Android 的点分 IPv4 只认数字。`ª203.0.113.10/…`、`aª203.0.113.10/…`、`А203.0.113.10/…` 和 `Ａ203.0.113.10/…` 都只打开 `203.0.113.10`。这个字母不是 Java 的词字符，地址从它后面重新开始。

把这个字母收成 ASCII 会粘到第一段数字上。`ª203.0.113.10/…` 变成 `a203.0.113.10`，裸 IP 漏掉。字母前面已经有 ASCII 时也一样。`aª203.0.113.10/…` 若把字母删掉或收成 `x`，会变成 `a203.0.113.10` 或 `ax203.0.113.10`。

后面还有域名时，Android 把整段收成一条主机名。`ª203.0.113.10.evil.com/…` 不是裸 IP。带协议的 `http://ª203.0.113.10/…`、`http://user:pass@А203.0.113.10/…` 和 `http://example.com/ª203.0.113.10/…` 也是一条，字母留在这条网址里。

## 决策

- 只改主机名扫描。公开的 `foldCyrillicLookalikes`、`foldFullwidthLatin` 和关键词比较不改。
- 裸点分 IPv4 前面的 IDNA 单字母、西里尔形近字母或全角拉丁字母不再映成 ASCII，除非后面还有域名。
- 这个字母若留在原文里，不再从主机名扫描里删掉，也不再收成 `x`。否则前面的 ASCII 会粘到地址上。
- 字母还在 `http://` 或 `https://` 里时仍映射。写完的主机名后面的规则仍按 ADR 0215。
- 每段仍走现有的短链、裸 IP、邀请和 denylist 判断。只拆一层。最多 8 个。证据只留主机名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 一律映射 | `ª203.0.113.10/…` 会变成 `a203.0.113.10`。Android 已经单独打开这条裸 IP。 |
| 裸 IP 前一律删掉 | `aª203.0.113.10/…` 会变成 `a203.0.113.10`。地址又被盖住。 |
| 协议里的字母也留下 | `http://example.com/ª203.0.113.10/…` 会另记一条裸 IP。Android 只打开 `example.com`。 |

## 后果

- `ª203.0.113.10/…`、`aª203.0.113.10/…`、`А203.0.113.10/…` 和 `Ａ203.0.113.10/…` 按裸 IP 删除。证据是 `203.0.113.10`。
- `http://ª203.0.113.10/…`、`http://example.com/ª203.0.113.10/…` 和 `ª203.0.113.10.evil.com/…` 留着。
- `ª203.0.113.10a/…` 留着。路径不进证据。
