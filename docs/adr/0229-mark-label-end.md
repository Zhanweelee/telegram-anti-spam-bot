# ADR 0229：非间距标记可以留在带协议标签的末尾

- 状态：已接受
- 日期：2026-11-03

## 背景

ADR 0228 把地址解析会忽略的标记从主机名里拿掉，再决定后面的文字字母留不留下。非间距标记不算词边界。它紧挨在点号前面时，标签被截在标记之前，点号和后面的字母都不再算进这条链接。字母被删掉以后，标记自己也被折掉，短链重新打开。

`http://bit͏.lyα/…`、`http://bit.ly͏.α/…`、`http://www.bit͏.lyα/…` 和 `http://203.0.113͏.10ա/…` 在 Android 上各是一条链接。地址解析器给出的主机名不是前面的短链或裸 IP。`http://bit͏.lyα/http://t.co/…` 的路径仍属于这一条。`see http://bit͏.lyα/…` 也是。变体选择符和蒙古文自由变体选择符同样算非间距标记。

`http://bit͏.lyα.bit.ly/…` 的主机名仍以 `bit.ly` 结尾。没有协议的 `bit͏.lyα/…` 只打开前面的短链。`http://bit͏.lyα#…`、`http://bit͏.lyα@evil.com/…` 和中间有空格的写法也退回短链。标签放不下时，短链单独打开。`bαit.ly` 仍是短链。`http://bit͏.ly/…` 仍是短链。`http://bit.lỳ/…` 的组合附加符号留在标签里，点开的主机名不是短链。

## 决策

- 只改主机名扫描里对 Android 高亮范围的判断。公开的折叠不改。
- 非间距标记可以结束一个带协议的标签，只要后面是点号再加一个标签、路径、查询或写完的端口。
- 后面没有词边界，也不是这些延续时，标签仍结束在标记前面的字母上。
- 这样判断之后，Android 仍把后面的希腊文、西里尔文、亚美尼亚文和非 ASCII 拉丁字母算进这条链接时，这些字母留下。
- 每段仍走现有的短链、裸 IP、邀请和 denylist 判断。只拆一层。最多 8 个。证据只留主机名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 非间距标记一律结束在前面的字母上 | `http://bit͏.lyα/…` 会按短链删除。Android 打开的不是 `bit.ly`。 |
| 非间距标记后面一律算进同一条链接 | `http://bit͏.lyα#…` 会漏掉。Android 只打开前面的短链。 |
| 没有协议也留下 | `bit͏.lyα/…` 会漏掉。Android 只打开前面的短链。 |

## 后果

- `http://bit͏.lyα/…` 和 `http://bit.ly͏.α/…` 留着。
- `http://www.bit͏.lyα/…` 和 `http://203.0.113͏.10ա/…` 留着。
- `http://bit͏.lyα/http://t.co/…` 留着。路径里的短链不另记。
- `see http://bit͏.lyα/…` 留着。
- `bit͏.lyα/…`、`www.bit͏.lyα/…` 和 `203.0.113.10͏.α/…` 仍删除。
- `http://bit͏.lyα#…`、`http://bit͏.lyα@evil.com/…` 和空格后面的字母仍按短链删除。
- `http://bit͏.lyα.bit.ly/…` 仍按短链删除。证据是收成 `x` 的主机名。
- `bαit.ly` 和 `http://bit͏.ly/…` 仍按短链删除。放不下的标签仍让短链单独打开。路径不进证据。
- `http://bit.lỳ/…` 留着。点开的主机名不是 `bit.ly`。
