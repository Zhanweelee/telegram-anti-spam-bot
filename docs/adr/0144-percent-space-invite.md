# ADR 0144：百分号编码空格开头的邀请

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0030 把 `t.me/+邀请码` 记成邀请。桌面端 `TryConvertUrlToLocal` 在同一条 `join` 正则里还有第三种开头：字面量 `%20`。

`https://t.me/%20邀请码` 会收成 `tg://join?invite=`。主机只认 `t.me`、`telegram.me`、`telegram.dog`，可以再加一层 `www.`。邀请码后面可以是结尾，也可以立刻是 `?`。末尾斜杠、紧挨着的 `#` 和多出来的路径不收。纯数字的 `%20` 走这条邀请，不走前面的电话号码规则。电话号码只认 `+` 加数字。

## 决策

- 去掉一层 `www.` 之后，主机必须是 `t.me`、`telegram.me` 或 `telegram.dog`。
- 原始字符串在这台主机后面是 `/%20`，再加 1 到 128 位字母、数字、`_` 或 `-`。后面可以没有查询，也可以立刻是 `?` 加任意查询。查询里再出现的 `#` 仍算命中。
- 邀请码后面紧挨 `/` 或 `#`、多出来的路径、子域和其它网站不记。邀请码里的 `.` 不记。
- 全是数字的 `%20` 仍是邀请，不读 `text`。
- 证据是 `invite:` 加这条链接自己的主机名。邀请码不进事件。不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续只认 `+` | 桌面端点 `t.me/%20邀请码` 会加入该群。 |
| 用去掉末尾斜杠后的路径判断 | `t.me/%20邀请码/` 会被收成命中。桌面端要求邀请码后面立刻是 `?` 或结束。 |
| 子域也记 | 这条正则只跑在精确主机上。`durov.t.me/%20邀请码` 不收成 `tg://join`。 |
| 邀请码里允许 `.` | 桌面端字符类含点。现有邀请码仍是字母、数字、`_` 和 `-`。 |
| 全数字时改读 `text` | 纯数字加号路径才改写成电话。`%20` 加数字仍是邀请。 |

## 后果

- `https://t.me/%20…`、`https://www.telegram.dog/%20…?x=1` 和 `https://telegram.me/%20…` 按现有邀请规则删除。证据仍是 `invite:` 加主机名。
- `https://t.me/%20…/`、`https://t.me/%20…#room`、`https://durov.t.me/%20…` 和 `https://t.me/%20ab.cd` 留着。
- 邀请码不进证据。公开的 `t.me/名字` 仍保留。
