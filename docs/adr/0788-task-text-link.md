# ADR 0788：任务文字不是字符串时不读文字链接

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。清单任务、后加任务、勾完的任务和引用条对上的任务，文字是字符串时，文字链接的起点必须落在这段文字里，长度必须大于 0。见 ADR 0774、ADR 0776、ADR 0777 与 ADR 0778。内联按钮的文字长度必须大于 0。见 ADR 0787。

Android 只能把实体画在一段字符串上。任务文字不是字符串时，没有可以落点的文字，文字链接和代码块语言都画不出来。

现在这种任务仍会把 `text_entities` 整份读进来。打开链接规则后，没画出来的链接也会删掉这条消息。

## 决策

- `checklist.tasks`、`checklist_tasks_added` 里会画出来的任务、`checklist_tasks_done` 对上的任务，以及引用条对上的任务，`text` 不是字符串时，不读 `text_entities`。
- `text` 是字符串时，仍要求起点落在这段文字里，长度是大于 0 的安全整数。长度越过末尾时仍留下主机名。
- 后加任务仍只看前三条。勾完的任务仍只用名单里的第一项。引用条的任务号对不上时仍改读标题。
- 按标识提及和自定义表情不在这条里。投票选项不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，链接不该删掉这条消息。 |
| 把数字任务当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 提及和表情一起改 | 那是另一套标记。这条只改文字链接。 |
| 投票选项一起改 | 选项文字是另一段。 |

## 后果

- 任务文字不是字符串时，文字链接和代码块语言不再留下主机名。
- 文字是字符串时，短链、邀请或裸 IP 仍删除。证据只有主机名。
- 按标识提及在任务文字不是字符串时，后来由 ADR 0804 不再读取。自定义表情在任务文字不是字符串时仍按原来的方式读取。
- 选项文字不是字符串时，文字链接后来由 ADR 0789 不再读取。测验说明不是字符串时，文字链接后来由 ADR 0790 不再读取。投票描述不是字符串时，文字链接后来由 ADR 0791 不再读取。投票题干不是字符串时，文字链接后来由 ADR 0792 不再读取。清单标题不是字符串时，文字链接后来由 ADR 0793 不再读取。礼物附言不是字符串时，文字链接后来由 ADR 0794 不再读取。游戏附加文字不是字符串时，文字链接后来由 ADR 0795 不再读取。消息说明不是字符串时，文字链接后来由 ADR 0796 不再读取。消息正文不是字符串时，文字链接后来由 ADR 0797 不再读取。正文不是字符串时，按标识提及后来由 ADR 0798 不再读取。说明不是字符串时，按标识提及后来由 ADR 0799 不再读取。投票题干不是字符串时，按标识提及后来由 ADR 0800 不再读取。测验说明不是字符串时，按标识提及后来由 ADR 0801 不再读取。投票描述不是字符串时，按标识提及后来由 ADR 0802 不再读取。清单标题不是字符串时，按标识提及后来由 ADR 0803 不再读取。清单任务文字不是字符串时，按标识提及后来由 ADR 0804 不再读取。后加任务文字不是字符串时，按标识提及后来由 ADR 0805 不再读取。礼物附言不是字符串时，按标识提及后来由 ADR 0806 不再读取。游戏附加文字不是字符串时，按标识提及后来由 ADR 0807 不再读取。正文不是字符串时，自定义表情后来由 ADR 0808 不再读取。说明不是字符串时，自定义表情后来由 ADR 0809 不再读取。投票题干不是字符串时，自定义表情后来由 ADR 0810 不再读取。测验说明不是字符串时，自定义表情后来由 ADR 0811 不再读取。投票描述不是字符串时，自定义表情后来由 ADR 0812 不再读取。投票选项文字不是字符串时，自定义表情后来由 ADR 0813 不再读取。后加或删掉的选项文字不是字符串时，自定义表情后来由 ADR 0814 不再读取。清单标题不是字符串时，自定义表情后来由 ADR 0815 不再读取。清单任务文字不是字符串时，自定义表情后来由 ADR 0816 不再读取。后加任务文字不是字符串时，自定义表情后来由 ADR 0817 不再读取。礼物附言不是字符串时，自定义表情后来由 ADR 0818 不再读取。游戏附加文字不是字符串时，自定义表情后来由 ADR 0819 不再读取。手动引用不是字符串时，自定义表情仍按原来的方式读取。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。`checklist_notice` 仍默认关闭。
