# ADR 0749：清单任务上的自定义表情必须落在任务里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。清单标题必须整段落在标题里。见 ADR 0748。

每一条任务由 `formatTextWithEntities` 画出来，再交给 `replaceAnimatedEmoji`。表情只在 `offset + length` 不超过这条任务文字时才画出来。起点已经越过这条任务，或表情越过末尾，都不会画出来。

已有别的正文时，事件里的 `checklistTask` 把各条任务拼起来，最多留 3029 字。表情仍按每一条任务自己的文字判断。

现在任务会读全部 `text_entities`。一个越出这条任务的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条清单。

后加任务不在这条里。

## 决策

- `checklist.tasks` 里，`text` 是字符串时，这条任务的 `text_entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过这条任务文字。
- 任务文字不是字符串时，仍按原来的方式读取。
- 另一条仍落在自己文字里的表情继续带 `asCustomEmoji`。
- 第 3030 字起的表情，只要整段仍落在这条任务里，就继续带上。已有别的正文时，事件里的 `checklistTask` 仍只留前 3029 字。
- 编号仍不进事件。
- 后加任务不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条清单。 |
| 只要求起点小于任务 | 表情越过末尾时，客户端同样不会画。 |
| 也按 3029 字丢掉后面的表情 | 3029 只是拼起来的旁路字段上限。一条更长的任务里，后面的表情仍落在这条任务上。 |
| 按引用条的 150 字丢掉后面的表情 | 这条消息自己画出整段任务。150 是引用条的窗口。 |
| 任务文字不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的任务。 |
| 后加任务一起收 | 后加任务是另一条服务消息。 |

## 后果

- 起点加长度越过这条任务的自定义表情不再带 `asCustomEmoji`。空任务和长度为 0 的实体也不带。
- 仍落在任务里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。起点已经超过 3029、但仍整段落在这条任务里的表情也删除。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 清单任务文字不是字符串时，自定义表情后来由 ADR 0816 不再读取。
- 后加任务上的自定义表情后来由 ADR 0750 要求整段落在这条任务里。任务文字不是字符串时仍按原来的方式读取。第四条起仍不读。已有别的正文时，事件里的后加文字仍只留前 3029 字。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
