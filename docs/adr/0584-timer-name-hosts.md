# ADR 0584：改自动删除计时的人，名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

管理员改自动删除计时，或把它关掉时，客户端把这个人的名字画在提示上。名字写在 `from`。秒数在 `message_auto_delete_timer_changed.message_auto_delete_time`。0 表示关掉。这行通常没有别的正文。短链可以只写在名字里。

秒数和名字当时留在事件外面。见 ADR 0486。把 `from` 收成正文会让普通发言者的姓名也进检测。`autodelete_notice` 默认关闭，干净的提示仍留下。

## 决策

- 只在 `message_auto_delete_time` 是大于等于 0 的安全整数时，从 `from` 的可见名字留主机名。0 也读，因为关掉计时同样画出这个人。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 空对象、负数、小数、字符串和布尔值不读发送者。普通消息因此仍不读 `from`。
- 名字不进正文，也不改内容哈希。关键词因此不命中。秒数不读。本群群名不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`autodelete_notice` 仍默认关闭。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 关键词会命中人名。普通消息的 `from` 也会被打开。见 ADR 0486。 |
| 0 不读名字 | 关掉计时同样把名字画在群里。短链可以只写在这一行。 |
| 每条消息都读 `from` | 发言人的名字会跟着每条消息重复计一次。 |
| 新命令 `/timername` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 改计时的人名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。计时本身还在。
- 名字原文、路径和用户名不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。秒数不进事件。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 没有真实秒数时，发送者仍不读。干净的提示在 `autodelete_notice` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
