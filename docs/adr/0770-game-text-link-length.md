# ADR 0770：游戏附加文字上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。游戏附加文字上的文字链接，起点必须落在附加文字里。见 ADR 0733。礼物附言上的文字链接，长度必须大于 0。见 ADR 0769。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达附加文字末尾的实体。起点落在附加文字里、长度越过末尾时，客户端把长度收到附加文字末尾，这段链接仍会画出来。说明写在附加文字前面，不改变这段起点。

已有别的正文时，说明和附加文字各自只留前 4096 字，用一个空格接成 `gameText`。没有别的正文时，游戏标题成为正文，仍只留前 4096 字。链接仍按整段附加文字判断。写在附加文字和说明里的普通网址仍各自抽取。

现在附加文字只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在附加文字里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条游戏消息。代码块语言里的网址也走同一段实体。

测验说明不在这条里。

## 决策

- `game.text` 是字符串时，`text_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于附加文字长度，长度必须是大于 0 的安全整数。
- 起点落在附加文字里、长度越过末尾时，仍留下主机名。
- 附加文字不是字符串时，仍按原来的方式读取。
- 说明写在 `gameText` 前面时，不改变附加文字上的起点。
- 已有别的正文时，第 4097 字上的链接，只要起点仍落在附加文字里、长度大于 0，就继续留下主机名。事件里的说明和附加文字仍各自只留前 4096 字。
- 写在附加文字和说明里的普通网址仍各自抽取。仍只留主机名。
- 测验说明上的 `explanation_entities` 不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条游戏消息。 |
| 也要求长度落在附加文字里 | 起点在附加文字里时，客户端会把越过末尾的长度收回来再画。 |
| 按拼好的 `gameText` 计算起点 | 说明写在前面，客户端仍把实体画在附加文字上。 |
| 测验说明一起改 | 说明是另一段文字。这条只改游戏附加文字。 |

## 后果

- 附加文字上长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在附加文字里、长度越过末尾的短链、邀请或裸 IP 仍删除。起点已经超过 4096、但仍落在附加文字里的链接也删除。证据只有主机名。
- 写在附加文字和说明里的普通网址仍会删除。被截断的路径不进事件。
- 附加文字不是字符串时，长度不是正数的文字链接仍按原来的方式读取。
- 测验说明上的文字链接后来由 ADR 0771 要求长度大于 0。说明不是字符串时仍按原来的方式读取。长度越过末尾时仍算画出来。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
