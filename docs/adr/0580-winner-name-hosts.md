# ADR 0580：公开中奖者的名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

抽奖结束且中奖者公开时，结束公告画出每一位中奖者的名字。Bot API 把这些人放在 `giveaway_winners.winners`。客户端只画名，名为空时才画姓。名字里可以只有一条短链，奖品说明和举办频道标题仍然是另一段字。

举办频道的标题已经交给链接规则。见 ADR 0132。中奖者姓名当时留在事件外面。进行中的 `giveaway` 没有中奖者名单。嵌套在 `giveaway_completed.giveaway_message` 里的结束公告是另一条消息。

## 决策

- 只读本条消息上的 `giveaway_winners.winners`。每一位公开中奖者按可见名字留主机名。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 举办频道标题仍按 ADR 0132 先抽出。中奖者主机名排在它后面。8 个主机名的上限不变。
- 名字不进正文，也不改内容哈希。关键词因此不命中。用户 id、`winner_count` 和 `winners_selection_date` 不读。
- 进行中的 `giveaway` 没有 `winners`，不从那里读中奖者。嵌套的 `giveaway_message` 不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`giveaway_card` 仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 会改变哈希，关键词也会命中人名。短链只需要主机名。 |
| 连用户名一起抽 | 客户端画出的是名字。用户名不是这段可见字。 |
| 连嵌套的结束公告一起扫 | 嵌套的是另一条消息。本条只读自己的 `giveaway_winners`。 |
| 新命令 `/winner` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 公开中奖者的名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。
- 名字原文、路径和邀请码不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。用户 id、中奖人数和开奖时间不进事件。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 进行中的抽奖和嵌套的 `giveaway_message` 仍不读中奖者。创建公告和私下结束上画出的发送者后来由 ADR 0590 只留下主机名。嵌套原文仍不读。进行中卡片的发送者仍不读。云额度的基础检测器名单没有改。30 天保留期没有改。
- 这行名字后来按全名只留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。见 ADR 0640。举办频道标题仍先抽出。进行中的抽奖和嵌套的 `giveaway_message` 仍不读。
