# ADR 0386：私聊可以查看一个群的人数

- 状态：已接受
- 日期：2026-11-04

## 背景

清理或突袭时，管理员要知道这个群现在有多少人。官方 `getChatMemberCount` 返回一个整数。参数只有 `chat_id`。成功时返回 Integer。

下一段 `getChatMember` 才写管理员权限。人数这一次不在本地另加条件。

返回的 JSON 里如果还带着标题、邀请链接、简介或置顶消息，这些不能进回复或日志。

0 是真实人数。小数、负数或缺少结果都是失败。

没有 token 时不能编一个数字。编成 0 会让管理员以为群是空的。

## 决策

- 私聊命令 `/count <chatId>`。群 id 匹配 `^-?\d{1,20}$`。多出来的参数不发出请求。群聊里的同样文本不执行。
- 配置中的管理员可以查看任意群。接入目录里的人只能查看自己的群。
- 调用 `ModerationPort.readMemberCount`。适配器调用 `getChatMemberCount`，只带 `chat_id`。
- 只接受非负安全整数。0 写进回复。小数、负数、缺失或不是整数时回复「参数无效」。
- 回复只有群号和人数。标题、邀请链接、简介和置顶消息不进回复，也不进日志。
- 没有 token、没有这个方法，群号不合法，或调用失败时回复「参数无效」。日志只写 `operator_rejected`，带上 eventId、chatId 和命令名。不写异常文本、token 或原文。
- 没有 token 的 Worker 不编造人数。内存适配器抛出 `count_unavailable`。
- 不修改黑名单、白名单、封禁或禁言。不读取消息正文。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 没有 token 时回复 0 | 0 是真实人数。编出来会让管理员以为群是空的。 |
| 把标题或邀请链接一起回复 | 这些字段能认出群，邀请链接是秘密。人数已经够用。 |
| 改读 `getChat` 再找人数字段 | 人数有自己的方法，返回的就是整数。`getChat` 会带上标题和其它字段。 |
| 在本地要求管理员权限 | 官方对这一次没有这样写。权限失败由 Telegram 返回，回复「参数无效」。 |

## 后果

- 成功只表示 Telegram 返回了一个非负整数。bot 不在群里或调用失败时，回复是「参数无效」。
- 0 会写成「0 人」。
- 一次查看是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
