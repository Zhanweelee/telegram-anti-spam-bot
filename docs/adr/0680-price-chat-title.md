# ADR 0680：改价的发送者是聊天时只读聊天标题

- 状态：已接受
- 日期：2026-11-06

## 背景

有人改付费发言的星星数量，或改私信开关时，Android 的 `TL_messageActionPaidMessagesPrice` 用 `replaceWithLink` 画出发送者。发送者是用户时，画出全名。发送者是聊天时，画出这个聊天的标题。标题不截断。广播频道、群和超级群都走这条。自己发出的那条不画名字。Bot 不区分是不是自己发出。

Bot API 把付费发言放在 `paid_message_price_changed`，把私信开关放在 `direct_message_price_changed`。发送者是聊天时，`sender_chat` 是那个聊天，`from` 是占位用户。见 `telegram-bot-api` 的 `messageSenderChat`。匿名管理员的 `sender_chat` 就是本群。

ADR 0671 只在 `sender_chat.type` 是 `channel` 时读标题。群和超级群仍从 `from` 留主机名。占位用户的名字不是这行画出的字。编号和本群相同时，通用的代发规则也不读标题，所以本群匿名改价的标题进不了主机名。

## 决策

- 已经会标成 `priceNotice` 的提示上，`sender_chat` 是对象就只从 `sender_chat.title` 留主机名，不从 `from` 留主机名。标题不截断。用户名不读。频道、群和超级群都一样。编号和本群相同时也读。
- 没有 `sender_chat` 时，仍从 `from` 的全名留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。
- 不从 `chat.title` 另读。发送者是用户时，本群群名仍不读。
- 同时出现时仍先认付费发言。星星数量和开关不读。标题不进正文。
- 编号和本群相同时仍按已有的管理员豁免。关掉豁免后，标题里的短链会删除这条提示。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`price_notice` 仍默认关闭。短链仍走已有的 `links`。8 个主机名的上限不变。不调用改价接口。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 群和超级群继续读 `from` | 占位用户的名字不在这行里。短链会删掉一条没有这个名字的提示，标题上的短链又会留下。 |
| 只读和本群不同的聊天 | 匿名管理员画出的就是本群标题。通用代发规则在编号相同时不读。 |
| 用户改价也读本群群名 | 这行画的是这个人的全名，不画本群群名。 |
| 新命令 | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 改价的发送者是聊天时，标题里的短链、邀请或裸 IP 会留下主机名。证据只有主机名。价格和私信开关不变。
- 本群自己改价的这条提示，默认仍因管理员豁免而留下。关掉豁免后会删。别的聊天发到这个群时不豁免。
- 占位用户的名字不再留下主机名。用户仍按全名。
- 标题原文、路径、用户名、星星数量和开关不进事件。内容哈希不变。关键词不命中标题和全名。
- 正文里已有短链时，证据仍先记正文的主机名。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 助推和付款成功仍只读名。空对象、负数、小数、字符串、布尔值和普通消息仍不读发送者。管理员仍豁免。干净的提示在 `price_notice` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
