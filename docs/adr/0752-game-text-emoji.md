# ADR 0752：游戏附加文字上的自定义表情必须落在附加文字里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。礼物附言必须整段落在附言里。见 ADR 0751。

游戏消息的正文是标题。附加文字在 `game.text`，实体在 `game.text_entities`。见 ADR 0078 与 ADR 0541。Android 把这段文字当成游戏消息的正文，再用 `replaceAnimatedEmoji` 画自定义表情。起点加长度越过这段文字时，表情不会画出来。

已有别的正文时，事件里的 `gameText` 把说明和附加文字各自留到 4096 字。表情仍按整段附加文字判断。

现在这段会读全部 `text_entities`。一个越出附加文字的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条游戏消息。

手动引用不在这条里。

## 决策

- `game.text` 是字符串时，这段 `text_entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过这段附加文字。
- 附加文字不是字符串时，仍按原来的方式读取。
- 第 4097 字起的表情，只要整段仍落在附加文字里，就继续带 `asCustomEmoji`。已有别的正文时，事件里的 `gameText` 仍只留前 4096 字。
- 仍落在附加文字里的表情继续带 `asCustomEmoji`。编号仍不进事件。
- 手动引用不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条游戏消息。 |
| 只要求起点小于附加文字 | 表情越过末尾时，客户端同样不会画。 |
| 也按 4096 字丢掉后面的表情 | 4096 只是旁路字段的上限。整段附加文字更长时，后面的表情仍落在附加文字里。 |
| 游戏说明也按实体长度丢掉表情 | 说明没有自己的自定义表情列表。这条只改附加文字。 |
| 附加文字不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的附加文字。 |
| 手动引用一起收 | 引用是另一段文字。 |

## 后果

- 起点加长度越过游戏附加文字的自定义表情不再带 `asCustomEmoji`。空附加文字和长度为 0 的实体也不带。
- 仍落在附加文字里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。起点已经超过 4096、但仍整段落在附加文字里的表情也删除。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 游戏附加文字不是字符串时，自定义表情后来由 ADR 0819 不再读取。
- 手动引用上的自定义表情后来由 ADR 0753 要求整段落在摘录里。摘录不是字符串时仍按原来的方式读取。自动引用仍不带这个标记。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
