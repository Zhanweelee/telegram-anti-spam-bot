# ADR 0122：数学公式里的网址只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

富文本可以只有一块数学公式。客户端把 LaTeX 渲染出来，短链可以写在公式里。ADR 0076 让公式源码不进事件，避免把整段公式落下来。链接规则因此看不见这段网址。

公式里也可以夹着普通词。把整段源码当成正文会把公式写进事件和内容哈希。

## 决策

- 从块级 `mathematical_expression.expression` 和行内同类型节点抽出网址，只留主机名。折叠、长度、邀请判断和 8 个主机名的上限与旁路纯文本相同。
- 公式源码不进入 `message.text`，也不参与内容哈希。没有别的正文时，正文仍是空字符串。
- 不把公式里的关键词交给关键词检测器。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 公式整段成为正文 | 源码会进事件。和 ADR 0076 冲突。 |
| 公式整段都不读 | 短链可以只写在渲染出来的公式里。 |
| 连邮箱、电话和银行卡一起抽主机名 | 那些字段仍按 ADR 0076 留在事件外面。 |

## 后果

- 公式里的默认短链或邀请会删掉这条富文本。证据仍只有主机名。
- `example.com` 留着。公式里的关键词留着。
- 源码、路径和邀请码不进事件。
