# ADR 0320：分享的聊天只留主机名

- 状态：已接受
- 日期：2026-11-03

## 背景

Bot API 的 `chat_shared` 是用户通过按钮把一个聊天分享给 bot 的服务消息。标题和用户名由对方填写。短链可以只放在标题里，这条消息往往另有正文，或者完全没有 `text`。

标题是聊天名字。ADR 0027 规定群名不进事件。把分享来的标题写进正文，会把名字留在内容哈希里。

## 决策

- 从 `chat_shared.title` 和 `chat_shared.username` 抽出网址，只留主机名。解析、折叠、邀请判断和 8 个主机名的上限与别的旁路字段相同。
- 标题和用户名不进入 `message.text`，也不参与内容哈希。没有别的正文时，正文仍是空字符串。
- 不读取 `request_id`、`chat_id`、头像、`chat.title`、`chat.description` 和发送者姓名。路径不进证据。
- 不读取 `users_shared`。不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 分享来的聊天不读 | 标题里的 `https://bit.ly/…` 会漏掉。 |
| 标题成为正文 | 聊天名字会进内容哈希。ADR 0027 拒绝的就是这个。 |
| 每条消息都扫 `chat.title` | 群名会跟着每条消息重复计一次主机名。 |

## 后果

- 已有正文时，分享标题里的短链和邀请仍删除。正文和哈希不变。路径、邀请码和标题原文不进事件。
- 没有正文时，正文仍是空字符串。普通域名留下主机名，不按短链删除。
- 用户名本身是主机名时留下这个主机名。不是主机名的用户名、头像、请求编号和被分享的聊天编号不进事件。
- 这条消息自己的群名和发送者姓名仍不读。
- 云额度的基础检测器名单没有改。
