# ADR 0351：升为管理员时删掉验证按钮

- 状态：已接受
- 日期：2026-11-04

## 背景

验证会把成员限制到按钮通过或到期。这段时间里如果有人把该成员升为管理员或群主，挑战和按钮还在。离群才会删按钮。升管理员不是离群，也不是从群外入群，所以原来的两条路径都不会清掉这颗按钮。

## 决策

- `membership` 增加 `promote`。人从 `member` 或 `restricted` 变成 `administrator` 或 `creator` 时带上它。不带昵称。
- 从群外直接成为管理员、bot、旧状态缺失，以及已经是 `administrator` 或 `creator` 的变化，都不带。
- `promoteChallenge` 删掉还在的按钮和挑战。没有按钮 id 时只删挑战。删不掉或没有删除端口时留下这一行。
- 不解除限制，不写 `captcha_expired`。日志是 `captcha_promoted`，只有事件 id 和群 id。
- 删除这一行失败时记 `captcha_promote_failed`，流水线继续。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 升管理员时调用解除限制 | 这时对方已经是管理员。`restrictChatMember` 打在管理员身上会失败，按钮反而清不掉。 |
| 把它当成离群 | 人还在群里。离群的含义要留给 `left` 和 `kicked`。 |

## 后果

- 还在验证的成员被升为管理员或群主后，按钮和挑战会清掉。
- 原来的限制保留到 `until_date`。管理员身份本身不受这条成员限制约束。
- 30 天保留期不动。
