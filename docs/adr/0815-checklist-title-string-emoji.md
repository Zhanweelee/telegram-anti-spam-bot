# ADR 0815：清单标题不是字符串时不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。清单标题是字符串时，自定义表情必须整段落在标题里。见 ADR 0748。后加或删掉的选项文字不是字符串时不读自定义表情。见 ADR 0814。

Android 只能把表情画在一段字符串上。标题不是字符串时，没有可以落点的文字，自定义表情画不出来。

现在这种清单仍会把 `title_entities` 整份读进来。打开 `custom_emoji` 后，没画出来的表情也会删掉这条消息。

## 决策

- `checklist.title` 不是字符串时，不从 `title_entities` 读取自定义表情。
- 标题是字符串时，仍要求起点大于或等于 0，长度大于 0，并且起点加长度不能越过整段标题。空字符串仍是字符串。
- 第 256 字起的表情，只要整段仍落在标题里，就继续带 `asCustomEmoji`。已有别的正文时，事件里的 `checklistTitle` 仍只留前 255 字。
- 编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。标题自己就是正文时，看得见的字仍是这段标题。
- 清单任务上的自定义表情不在这条里。按标识提及不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，表情不该在打开规则后删掉这条消息。 |
| 把数字标题当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 清单任务一起改 | 任务是另一段文字。这条只改标题。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 标题不是字符串时，不再带 `asCustomEmoji`。
- 标题是字符串且表情整段落在标题里时，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 清单标题不是字符串时，自定义表情后来由 ADR 0815 不再读取。清单任务文字不是字符串时，自定义表情后来由 ADR 0816 不再读取。后加任务文字不是字符串时，自定义表情后来由 ADR 0817 不再读取。礼物附言不是字符串时，自定义表情后来由 ADR 0818 不再读取。游戏附加文字不是字符串时，自定义表情后来由 ADR 0819 不再读取。手动引用不是字符串时，自定义表情后来由 ADR 0820 不再读取。富文本里的自定义表情仍按结构化节点读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
