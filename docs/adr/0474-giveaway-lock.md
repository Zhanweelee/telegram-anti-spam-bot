# ADR 0474：抽奖卡片按群删除

- 状态：已接受
- 日期：2026-11-04

## 背景

抽奖消息列出必须加入的频道。奖品说明会成为正文，频道名字只留主机名。见 ADR 0056 和 ADR 0132。奖品说明是空的、频道名字里又没有短链时，这张卡片会留下。频道名字里的关键词也留着。

结束公告是 `giveaway_winners`。中奖者名字不进事件。没有奖品说明时，正文同样是空的。

投票题干已经是正文。这一轮不给投票加开关。

## 决策

- `giveaway.chats` 里至少有一个聊天对象时，事件带 `asGiveaway: true`。`giveaway_winners.chat` 是对象时同样带上。不写频道名字、用户名、频道 id、中奖人数、开奖时间和中奖者姓名。
- 空的 `giveaway`、没有聊天对象的 `chats`，以及没有 `chat` 的结束公告不带这个标记。奖品说明仍按原来的优先级成为正文。频道名字里的主机名仍按 ADR 0132 抽取。
- 检测器在 `@tasb/detector-giveaway`，id 是 `giveaway_card`。只在 `message.asGiveaway` 为 true 时返回 score 1。证据是 `giveaway:card`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这种抽奖卡片和结束公告。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`giveaway_card` 不在里面。投票仍靠题干。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部抽奖 | 有的群自己办抽奖。打开之前不改现有群。 |
| 把频道名字收成正文 | 名字会进事件和哈希。见 ADR 0132。 |
| 只删进行中的抽奖，留下结束公告 | 结束公告同样是这张卡片，而且常常没有正文。 |
| 连投票一起删 | 题干已经能被关键词和正则看到。见 ADR 0056。 |
| 新命令 `/giveaway` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，抽奖卡片仍留下。奖品说明里的关键词和频道名字里的短链仍删除。
- 打开 `giveaway_card` 后，这个群里的抽奖卡片和公开中奖者的结束公告会删除。投票仍留下。付费帖仍留下。
- 创建公告和没有公开中奖者的结束公告不由这条规则删除。星星数量、中奖人数和嵌套的抽奖消息仍不读。某个群后来可以打开 `giveaway_notice`。见 ADR 0483。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `giveaway_card` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
