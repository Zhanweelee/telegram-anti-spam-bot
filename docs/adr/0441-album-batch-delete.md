# ADR 0441：相册其余公开消息一次删除

- 状态：已接受
- 日期：2026-11-04

## 背景

一组相册里有一条未付费消息被真正删除后，其余已知的未付费消息也要删。见 ADR 0440。免费计划一次调用只有很少的外部子请求。逐条 `deleteMessage` 会把这一次请求的额度用完。官方 `deleteMessages` 一次可以带 1 到 100 个消息号。见 ADR 0374。

## 决策

- 同一组里尚未删除的公开消息合成一次 `deleteMessages`。只带 `chat_id` 和 `message_ids`。不循环调用 `deleteMessage`。
- 命中的那一条仍由删除动作自己调用 `deleteMessage`。它不重复放进这一批。
- 带接收者的消息仍逐条 `deleteMessage`。`deleteMessages` 不能带接收者。
- 这一批失败时，这些公开消息都不记成已删除。同组再来一条时再送一次。日志仍是 `album_delete_failed`，只带事件 id 和群 id。
- 付费帖、试运行和 `duplicate` 仍不删除。见 ADR 0440。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续逐条 `deleteMessage` | 一组十张照片就要十次子请求。免费计划一次调用装不下。 |
| 把命中的那一条也并进这一批 | 删除动作已经发出自己的请求。再并进去会删两次。 |
| 接收者也并进 `deleteMessages` | 这个方法没有接收者字段。临时消息会删错，或删不掉。 |

## 后果

- 一组公开相册在命中之后最多再占一次 Telegram 子请求。
- 只给一个人看见的消息仍是一条一次请求。
- 官方会跳过找不到的消息，成功仍返回 True。这些编号记成已删除，不再重试。
- 30 天保留期不动。
