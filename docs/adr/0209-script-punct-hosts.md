# ADR 0209：文字标点不再收成短链

- 状态：已接受
- 日期：2026-11-03

## 背景

抽主机名时会去掉亚美尼亚文、西里尔文、希腊文和非 ASCII 拉丁字母。实现按整个文字脚本匹配，标点和符号也被删掉。

Android 把这些标点留在主机名标签里。`b՚it.ly/…`、`http://bit.՚ly/…` 和 `http://b҂t.ly/…` 都是一条链接，打开的主机名不是 `bit.ly`。删掉标点以后，前后的 ASCII 粘成 `bit.ly`。

希腊吨号、西里尔千位号也一样。字母仍然要删：`bաit.ly/…` 和 `bαit.ly/…` 还是短链。标点写在短链前面时，单词边界仍从 ASCII 开始，`՚bit.ly/…` 继续删除。`example.com՚http://bit.ly/…` 会再打开后面的短链。

## 决策

- 只删这些文字里的字母，以及 Android 标签里没有的字。Android 留在标签里的标点和符号留下。
- 停住扫描也只删字母。夹在 ASCII 中间的标点仍按标签字收成 `x`。写在 `http://` 或 `https://` 前面的标点留下。
- 按钮网址走同一条字母折叠。
- 每段仍走现有的短链、裸 IP、邀请和 denylist 判断。只拆一层。最多 8 个。证据只留主机名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续删掉整个文字脚本 | `b՚it.ly` 会变成短链。Android 打开的不是 `bit.ly`。 |
| 平面 1 的字也留下 | Android 不把这些字收进标签。`b` 和 `it.ly` 仍要粘成短链。 |
| 标点也挡住后面的主机名 | `՚bit.ly` 和 `点击bit.ly` 仍要从 ASCII 单词开始。 |
| 只改正文扫描，按钮网址仍删标点 | 按钮打开的地址同样不是 `bit.ly`。 |

## 后果

- `b՚it.ly/…`、`http://bit.՚ly/…`、`b΄it.ly/…` 和 `http://b҂t.ly/…` 留着。
- `bաit.ly/…`、`bαit.ly/…` 和 `՚bit.ly/…` 仍按短链删除。Android 标签里没有的字仍删掉，`b` 和 `it.ly` 还是短链。
- `example.com՚http://bit.ly/…` 按后面的短链删除。路径不进证据。
