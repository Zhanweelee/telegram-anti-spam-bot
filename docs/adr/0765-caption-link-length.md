# ADR 0765：说明上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。说明上的文字链接，起点必须落在说明里。见 ADR 0738。正文上的文字链接，长度必须大于 0。见 ADR 0764。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达说明末尾的实体。起点落在说明里、长度越过末尾时，客户端把长度收到说明末尾，这段链接仍会画出来。

说明自己就是正文时，事件正文只留前 4096 字。链接仍按整段说明判断。

现在说明只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在说明里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条媒体。代码块语言里的网址也走同一段实体。

投票题干不在这条里。

## 决策

- `caption` 是字符串时，`caption_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于说明长度，长度必须是大于 0 的安全整数。
- 起点落在说明里、长度越过末尾时，仍留下主机名。
- `caption` 不是字符串时，仍按原来的方式读取。
- 说明自己就是正文时，第 4097 字上的链接，只要起点仍落在说明里、长度大于 0，就继续留下主机名。事件正文仍只留前 4096 字。
- 写在说明里的普通网址仍由链接检测从正文读取。仍只留主机名。
- 投票题干上的 `question_entities` 不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条媒体。 |
| 也要求长度落在说明里 | 起点在说明里时，客户端会把越过末尾的长度收回来再画。 |
| 也按 4096 字丢掉后面的链接 | 4096 只是事件正文的上限。整段说明更长时，后面的链接仍落在说明里。 |
| 投票题干一起改 | 题干是另一段文字。这条只改说明。 |

## 后果

- 说明上长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在说明里、长度越过末尾的短链、邀请或裸 IP 仍删除。起点已经超过 4096、但仍落在说明里的链接也删除。证据只有主机名。
- 写在说明里的普通网址仍会删除。被截断的路径不进事件。
- 说明不是字符串时，长度不是正数的文字链接仍按原来的方式读取。
- 投票题干上的文字链接后来由 ADR 0766 要求长度大于 0。题干不是字符串时仍按原来的方式读取。长度越过末尾时仍算画出来。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
