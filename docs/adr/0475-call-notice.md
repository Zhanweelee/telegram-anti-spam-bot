# ADR 0475：视频聊天提示按群删除

- 状态：已接受
- 日期：2026-11-04

## 背景

视频聊天开始、结束和预约是服务消息。它们没有成员名字。时长和开始时间不进事件。见 ADR 0119。邀请名单已经按可见名字成为正文，关键词仍能看到。

没有正文时，开始、结束和预约会留下。

## 决策

- `video_chat_started` 是对象时，事件带 `call: "started"`。`video_chat_ended.duration` 是有限且不小于 0 的数字时带 `ended`。`video_chat_scheduled.start_date` 同样带 `scheduled`。不写时长和开始时间。
- 空的结束或预约、以及只有 `video_chat_participants_invited` 的消息不带这个标记。几种同时出现时，先认开始，再认结束，再认预约。邀请名单仍按 ADR 0119 成为正文。
- 检测器在 `@tasb/detector-call`，id 是 `call_notice`。`message.call` 是这三种之一时返回 score 1。证据是 `call:started`、`call:ended` 或 `call:scheduled`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这三种服务消息。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`call_notice` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部通话提示 | 有的群自己开视频聊天。打开之前不改现有群。 |
| 把时长或开始时间收成正文 | 时长不是广告。见 ADR 0119。 |
| 连邀请名单一起删 | 邀请上的名字已经能被关键词和链接看到。见 ADR 0119。 |
| 新命令 `/call` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，开始、结束和预约仍留下。邀请名单里的关键词和短链仍删除。
- 打开 `call_notice` 后，这个群里的这三种服务消息会删除。邀请名单仍留下。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `call_notice` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
