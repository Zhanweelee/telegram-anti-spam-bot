# ADR 0507：富文本机器人命令按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

富文本里的机器人命令可以和看得见的字不同。字段是 `bot_command`。这个字段不进事件，关键词看不见命令。看得见的字已经可以成为正文。

话题标签和行情标签是另外的字段。这一轮不给它们加标记。

## 决策

- `type` 正好是 `bot_command`，并且 `bot_command` 去掉空白后非空时，事件带 `asRichCommand: true`。嵌套在别的块里也同样。
- 空白、布尔值和缺命令不带这个标记。按标识提及仍只带 `asRichTextMention`。
- 命令不进事件，也不进证据。看得见的字仍是正文。已有 `text` 或 `caption` 时正文不变，命令不并进去。
- 检测器在 `@tasb/detector-rich`，id 是 `rich_command`。只在 `message.asRichCommand` 为 true 时返回 score 1。证据是 `rich:command`。
- 默认规则关闭。私聊 `/rule <chatId> rich_command on` 之后删除这种正文，`off` 回到留下。
- 不并进 `rich_text_mention`。不调用读取或改写命令的方法。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`rich_command` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 并进按标识提及 | 只想删点名的群会把机器人命令也删掉。 |
| 把命令接到正文后面 | 同一条消息的哈希会变，命令也会进事件。 |
| 把命令写进证据 | 命令不进事件。 |
| 默认打开 | 有的群用富文本放机器人命令。打开之前不改现有群。 |
| 新命令 `/cmd` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，富文本机器人命令留下。看得见的字仍参与关键词。命令仍不进事件。
- 打开 `rich_command` 后，这个群里的这种命令会删除。打开 `rich_text_mention` 仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `rich_command` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `rich_command`，否则 `/rule` 会拒绝。
- 话题标签后来由 ADR 0508 另开 `rich_hashtag`。打开机器人命令仍不删除这种标签。标签仍不进事件。行情标签仍不带标记。
- 30 天保留期没有改。
