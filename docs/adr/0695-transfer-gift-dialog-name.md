# ADR 0695：转账和转售独特礼物时读对话

- 状态：已接受
- 日期：2026-11-06

## 背景

独特礼物被转走，或从别人那里买来，Android 的 `TL_messageActionStarGiftUnique` 在没有成交金额时走转账，有成交金额且不是购买报价时走转售。`action.from_id` 为空时，这行用 `replaceWithLink` 画对话。私聊的对话是用户，名字是 `UserObject.getUserName`。名和姓都先去掉两端空白，名在前。空白名不挡住姓。空格不截断。群和频道的对话是聊天，名字是完整的 `title`，不截断。礼物所属的另一边和 `from_id` 都不在 Bot API 这条更新上。

Bot API 把来源放在 `unique_gift.origin`。`transfer` 是从别人或别的频道转来的。`resale` 是从别人那里买来的。见 `UniqueGiftInfo`。

ADR 0691 仍从 `from` 或 `sender_chat.title` 留主机名。转账和转售这行不画消息发送者。

## 决策

- `unique_gift.gift` 是对象，且没有更优先的普通礼物时，`origin` 正好是 `transfer` 或 `resale` 就不从 `from` 留主机名，也不从 `sender_chat.title` 留主机名。
- `chat.type` 正好是 `private` 时，从私聊对方会画出来的全名留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。用户名和私聊 `title` 不读。
- `chat.type` 是 `group`、`supergroup` 或 `channel` 时，从会画出来的群名留主机名。群名不截断。用户名和群对象上的名字不读。
- 编号不同的聊天标题仍由通用代发规则读取。
- 购买报价仍按 ADR 0693。升级和事后升级仍按 ADR 0694。普通礼物仍按 ADR 0691。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`gift_card` 仍默认关闭。短链仍走已有的 `links`。8 个主机名的上限不变。星星不退回。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读发送者 | 转账和转售不画 `from`，也不画发送者标题。短链会删掉看不见的名字。 |
| 群里也不读群名 | 群的对话是聊天。`replaceWithLink` 画出完整群名。群名里的短链会出现在这行提示里。 |
| 连礼物所属的另一边一起读 | 这条更新没有这个对象。`from_id` 也不在更新上，所以按没有它时的对话来读。 |
| 新命令 | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 群和频道里的转账、转售从群名留主机名。本群标题上的短链会删掉这条提示。关掉管理员豁免后也会删。
- 私聊对方的全名里的短链会删掉这条提示。证据只有主机名。
- 发送者的名字和本群发送者标题不再因此留下主机名。
- 别的聊天发到这个群时，标题仍由通用代发规则留下主机名。群名仍另外留下。
- 购买报价、升级和普通礼物仍按原来的规则。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。
- 30 天保留期没有改。
