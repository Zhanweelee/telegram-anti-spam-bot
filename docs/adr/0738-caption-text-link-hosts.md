# ADR 0738：说明上的文字链接不能越过说明

- 状态：已接受
- 日期：2026-11-07

## 背景

照片、视频、文件和音频把说明画在媒体下面。短链在 `caption_entities`。见 ADR 0029。

Android 的 `generateCaption` 在媒体不是空、也不是游戏，并且说明不是空时，把这段说明收成 `caption`，再调用 `addEntitiesToText`。文字链接的起点大于或等于这段说明时，链接不会画上去。空说明不会生成这段文字。

现在说明会读全部文字链接。起点已经越过说明的链接仍会留下主机名。

正文已经要求起点落在正文里。见 ADR 0737。说明是另一段文字。引用条上的说明仍只取前 150 个码元。见 ADR 0711。

## 决策

- `caption` 是字符串时，`caption_entities` 里的文字链接，起点必须小于这段说明。`caption` 不是字符串时，仍按原来的方式读取。
- 写在说明里的普通网址仍由链接检测从正文读取。仍只留主机名。
- 引用条上的说明不在这条里。投票描述不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条媒体消息。 |
| 说明也只取前 150 个码元 | 媒体下面画出的是整段说明，不是引用条上的 150 个码元。 |
| 没有说明字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的说明。 |
| 投票描述也按说明长度丢掉链接 | 这份客户端还没有画出描述。这条只改说明。 |

## 后果

- 起点越过说明的文字链接不再留下主机名。仍落在说明里的短链、邀请或裸 IP 会删除，包括起点已经超过 150 个码元、但仍在说明里的链接。证据只有主机名。
- 空说明不再留下这些主机名。被截断的路径不进事件。写在说明里的路径仍留在说明。关键词不命中没画上去的链接。内容哈希仍按说明。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 手动引用自己就是正文时，文字链接后来由 ADR 0739 要求起点小于这段摘录。
- 说明上的文字链接后来由 ADR 0765 要求长度大于 0。说明不是字符串时，文字链接后来由 ADR 0796 不再读取。长度越过末尾时仍算画出来。投票题干不在那条里。
