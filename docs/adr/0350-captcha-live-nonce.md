# ADR 0350：别人还在用的验证按钮不删

- 状态：已接受
- 日期：2026-11-04

## 背景

ADR 0348 在 nonce 对不上，或点击者的挑战已经到期时，删掉点中的另一颗按钮。那是为了清掉自己没删掉的旧按钮。验证按钮在群里，别的成员也能点。点中的 nonce 如果还挂在另一名成员的挑战上，这条路径会把对方还在用的按钮删掉。对方仍被限制，却没有按钮可点。

## 决策

- `CaptchaStore.findByNonce` 按 tenant、chat 和 nonce 找出还在的挑战。别的租户、别的群和对不上的 nonce 返回 null。
- 点中的 id 和自己记下的 id 不同，而且这个 nonce 属于另一名成员时，不删点中的按钮。
- nonce 没有主人，或仍属于点击者自己时，删除仍按 ADR 0348。
- 点击者自己的挑战到期时，仍只处理点击者这一行。别人的按钮留着。
- 日志不含 nonce 和按钮 id。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| nonce 对不上时一律不删 | 自己没删掉的旧按钮会留在群里。 |
| 按按钮 id 反查 | 回调里可靠的是 nonce。按钮 id 可能还没写上。 |

## 后果

- 别人还在用的验证按钮不会被一次点错删掉。
- 没有主人的旧按钮仍会删。
- 每个 `CaptchaStore` 都要实现 `findByNonce`，并继续跑原来的契约。
- 30 天保留期不动。
