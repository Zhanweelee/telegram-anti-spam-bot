# ADR 0448：点错验证按钮时提示去点另一颗

- 状态：已接受
- 日期：2026-11-04

## 背景

ADR 0447 在验证消息上先放「我是机器人」。点它仍忽略，配了 token 时只清掉转圈。成员看到转圈消失，不知道刚才那一下没有通过。

## 决策

- 回调的 `data` 正好是 `n:` 加 16 位小写十六进制时，`answerCallbackQuery` 带上固定的一句「请点「我不是机器人」。」
- 不设置 `show_alert`。客户端只在聊天顶部提示，不弹窗。
- 大写、短一截或其它回调仍只送 `callback_query_id`。`c:` 加同一段 nonce 仍收成挑战，应答不带这句。
- nonce、按钮所在消息的正文和 token 不进应答，也不进日志。
- 不放行，不删验证消息，不改 `captcha_challenges`。不新增命令。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 弹窗挡住聊天 | 正文里已经写明点错不会通过。顶部一句够用。 |
| 把 nonce 写进提示 | 成员不需要看见 nonce。日志也不该多一段回调数据。 |
| 任何 `n:` 开头都提示 | 对不上这颗按钮的数据仍按其它回调处理。 |

## 后果

- 点对格式的「我是机器人」时，成员看到去点另一颗。验证消息还在，限制还在。这条消息静音发出。见 ADR 0449。
- 点「我不是机器人」仍只放行一次，应答不带这句。
- 云额度的基础检测器名单没有改。30 天保留期没有改。
