# ADR 0772：投票描述上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。投票描述上的文字链接，起点必须落在整段描述里。见 ADR 0740。测验说明上的文字链接，长度必须大于 0。见 ADR 0771。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达描述末尾的实体。起点落在描述里、长度越过末尾时，客户端把长度收到描述末尾，这段链接仍会画出来。

已有别的正文时，事件里的描述只留前 1024 字。描述和正文相同、不再另留时，事件正文只留前 4096 字。链接仍按整段描述判断。写在描述里的普通网址仍从整段原文抽取，包括第 1025 字起。

现在描述只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在描述里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条投票。代码块语言里的网址也走同一段实体。

投票选项不在这条里。

## 决策

- `poll.description` 是字符串时，`description_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于描述长度，长度必须是大于 0 的安全整数。
- 起点落在描述里、长度越过末尾时，仍留下主机名。
- 描述不是字符串时，仍按原来的方式读取。
- 已有别的正文时，第 1025 字上的链接，只要起点仍落在描述里、长度大于 0，就继续留下主机名。事件里的描述仍只留前 1024 字。
- 描述和正文相同、不再另留描述时，第 4097 字上的链接，只要起点仍落在描述里、长度大于 0，就继续留下主机名。事件正文仍只留前 4096 字。
- 写在描述里的普通网址仍从整段原文抽取，包括第 1025 字起。仍只留主机名。
- 投票选项上的 `text_entities` 不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条投票。 |
| 也要求长度落在描述里 | 起点在描述里时，客户端会把越过末尾的长度收回来再画。 |
| 也按 1024 字丢掉后面的链接 | 1024 只是旁边描述的上限。整段描述更长时，后面的链接仍落在描述里。 |
| 投票选项一起改 | 选项是另一段文字。这条只改描述。 |

## 后果

- 描述上长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在描述里、长度越过末尾的短链、邀请或裸 IP 仍删除。起点已经超过 1024 或 4096、但仍落在描述里的链接也删除。证据只有主机名。
- 写在描述里的普通网址仍会删除，包括第 1025 字起。被截断的路径不进事件。
- 描述不是字符串时，长度不是正数的文字链接仍按原来的方式读取。
- 投票选项上长度不是正数的文字链接仍按原来的方式读取。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
