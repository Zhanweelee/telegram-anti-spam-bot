# ADR 0693：购买报价成交的独特礼物不读发送者

- 状态：已接受
- 日期：2026-11-06

## 背景

独特礼物通过购买报价成交时，Android 的 `TL_messageActionStarGiftUnique` 走 `from_offer`。成交金额已经写在这行里。这行不调用 `replaceWithLink`，也不画消息发送者。

Bot API 把这种来源放在 `unique_gift.origin`，值正好是 `offer`。见 `UniqueGiftInfo`。

ADR 0648 和 ADR 0691 仍从 `from` 的全名或 `sender_chat.title` 留主机名。报价成交不画这些人。编号和本群相同时，通用代发规则本来就不读标题。转账和转售仍画发送者。

## 决策

- `unique_gift.gift` 是对象，且没有更优先的普通礼物时，`origin` 正好是 `offer` 就不从 `from` 留主机名，也不从 `sender_chat.title` 留主机名。频道、群和超级群都一样。编号和本群相同也跳过。
- 没有 `sender_chat` 时也不读用户全名。
- 编号不同的聊天标题仍由通用代发规则读取。不从 `chat.title` 另读。
- `origin` 不是 `offer` 时仍按 ADR 0691。普通礼物同时出现时仍先认卡片，并仍读发送者。
- 收藏名、附言和发布者用户名仍按原来的方式。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`gift_card` 仍默认关闭。短链仍走已有的 `links`。8 个主机名的上限不变。星星不退回。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读发送者 | 报价成交不画这个人。短链会删掉一条没有这个名字的提示。 |
| 所有独特礼物都不读 | 转账和转售仍画出发送者。 |
| 升级改读私聊对方 | 升级画的是对话对象，不是这条报价。另一次再改。 |
| 新命令 | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 购买报价成交时，不再因为占位名字、用户全名或本群标题留下主机名。
- 别的聊天发到这个群时，标题仍由通用代发规则留下主机名。
- 转账、转售、升级和普通礼物仍读发送者。用户在这些来源上仍按全名。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。
- 30 天保留期没有改。
