# ADR 0811：测验说明不是字符串时不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。测验说明是字符串时，自定义表情必须整段落在说明里。见 ADR 0746。投票题干不是字符串时不读自定义表情。见 ADR 0810。

Android 只能把表情画在一段字符串上。测验说明不是字符串时，没有可以落点的文字，自定义表情画不出来。

现在这种说明仍会把 `explanation_entities` 整份读进来。打开 `custom_emoji` 后，没画出来的表情也会删掉这条投票。

## 决策

- `poll.explanation` 不是字符串时，不从 `explanation_entities` 读取自定义表情。
- 说明是字符串时，仍要求起点大于或等于 0，长度大于 0，并且起点加长度不能越过说明。空字符串仍是字符串。
- 起点已经超过 150 个码元、但仍整段落在说明里的表情，继续带 `asCustomEmoji`。引用条仍只取前 150 个码元。本段说明按整段长度判断。
- 编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。
- 投票描述上的自定义表情不在这条里。按标识提及不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，表情不该在打开规则后删掉这条投票。 |
| 把数字说明当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 也按 150 个码元丢掉后面的表情 | 150 是引用条的上限。本段说明按整段长度判断。 |
| 投票描述上的表情一起改 | 描述是另一段文字。这条只改测验说明。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 测验说明不是字符串时，不再带 `asCustomEmoji`。
- 说明是字符串且表情整段落在说明里时，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 按标识提及在测验说明不是字符串时仍不读取。见 ADR 0801。
- 测验说明不是字符串时，自定义表情后来由 ADR 0811 不再读取。投票描述不是字符串时，自定义表情后来由 ADR 0812 不再读取。投票选项文字不是字符串时，自定义表情后来由 ADR 0813 不再读取。后加或删掉的选项文字不是字符串时，自定义表情后来由 ADR 0814 不再读取。清单标题不是字符串时，自定义表情后来由 ADR 0815 不再读取。清单任务文字不是字符串时，自定义表情后来由 ADR 0816 不再读取。后加任务文字不是字符串时，自定义表情后来由 ADR 0817 不再读取。礼物附言不是字符串时，自定义表情后来由 ADR 0818 不再读取。游戏附加文字不是字符串时，自定义表情后来由 ADR 0819 不再读取。手动引用不是字符串时，自定义表情后来由 ADR 0820 不再读取。富文本替代文字不是字符串时，自定义表情后来由 ADR 0821 不再读取。替代文字是空字符串时，自定义表情后来由 ADR 0822 不再读取。公式源码里的自定义表情后来由 ADR 0823 不再读取。预格式化块的语言标签里，自定义表情后来由 ADR 0824 不再读取。音频文件名里的自定义表情后来由 ADR 0825 不再读取。音频标题里的自定义表情后来由 ADR 0826 不再读取。音频表演者里的自定义表情后来由 ADR 0827 不再读取。视频文件名里的自定义表情后来由 ADR 0828 不再读取。动画文件名里的自定义表情后来由 ADR 0829 不再读取。文档文件名里的自定义表情后来由 ADR 0830 不再读取。文档类型里的自定义表情后来由 ADR 0831 不再读取。文档缩略图里的自定义表情后来由 ADR 0832 不再读取。视频缩略图里的自定义表情后来由 ADR 0833 不再读取。动画缩略图里的自定义表情后来由 ADR 0834 不再读取。动画类型里的自定义表情后来由 ADR 0835 不再读取。视频类型里的自定义表情后来由 ADR 0836 不再读取。音频类型里的自定义表情后来由 ADR 0837 不再读取。音频缩略图里的自定义表情后来由 ADR 0838 不再读取。语音类型里的自定义表情后来由 ADR 0839 不再读取。视频笔记缩略图里的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
