# ADR 0504：富文本地图按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

富文本可以放一块地图。字段是块类型 `map`，中心点在 `location`。说明可以是另一句话。坐标不进事件。见 ADR 0059。关键词看不见这张地图本身。

ADR 0473 只认消息顶层的纯位置。打开 `bare_location` 不会删除富文本里的地图。

## 决策

- 块 `type` 正好是 `map`，并且 `location` 同时有有限纬度和经度时，事件带 `asRichMap: true`。嵌套在别的块里也同样。
- 只有一个坐标、字符串坐标、缺位置，以及普通图钉，不带这个标记。普通图钉仍只带 `asLocation`。
- 坐标、缩放、宽高不进事件，也不进证据。说明仍是正文。已有 `text` 或 `caption` 时正文不变。
- 检测器在 `@tasb/detector-location`，id 是 `rich_map`。只在 `message.asRichMap` 为 true 时返回 score 1。证据是 `map:rich`。
- 默认规则关闭。私聊 `/rule <chatId> rich_map on` 之后删除这种地图，`off` 回到留下。
- 不并进 `bare_location`。不调用读取位置的方法。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`rich_map` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 并进纯位置 | 只想删图钉的群会把带说明的地图也删掉。 |
| 把坐标接到正文后面 | 坐标会进事件和哈希。ADR 0059 已经拒绝。 |
| 默认打开 | 有的群用地图发集合点。打开之前不改现有群。 |
| 新命令 `/map` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，富文本地图留下。说明仍参与关键词。坐标仍不进事件。
- 打开 `rich_map` 后，这个群里的富文本地图会删除。打开 `bare_location` 仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `rich_map` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `rich_map`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
