# ADR 0527：私聊可以接着看后面的管理员

- 状态：已接受
- 日期：2026-11-05

## 背景

`/admins` 按 Telegram 返回的顺序逐行列出管理员。一行放不下时仍写在同一行。全部行放不下时留下前面的人，末尾写 `+N`。突袭之后，新加的、能删消息或能拉人的管理员可能就在这一页外面。回复里只剩个数。

只打开删除权限时，400 人的中文名单第一页留下 248 人。英文里写满权限的一行大约 146 字，二十多人就会超出一页。

## 决策

- `/admins <chatId> [skip <count>]`。
- `count` 是 0 到 99999 的整数，不允许前导零。不写 `skip` 或 `count` 为 0 时，回复与原来相同。
- `count` 大于 0 时，先按返回顺序跳过前面的 `count` 个人，再从下一个人开始列。放不下时仍保留完整行，末尾写 `+N`。`+N` 只数这一页没列出的人。
- 跳过的个数已经不少于人数，或空名单写了大于 0 的 `count` 时，回复「参数无效」。缺数字、数字不合法也是「参数无效」。多出来的词回复用法。
- 没有这个群权限时仍回复「没有权限」，不调用 `readAdministrators`。
- 姓名、用户名、自定义头衔和 `can_be_edited` 仍不进回复。创建者的权限列表仍为空。
- 不新增命令。菜单仍是 99 条。`/admins` 的菜单描述改为带上 `skip`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 在 `+N` 后面写下一页的命令 | 现有回复用 `+N` 解析。下一页的起点就是已经看过的人数。 |
| 缩短权限词 | 权限词是管理员对照能力用的。缩短之后菜单和回复都更难读。 |
| 只给全局管理员 | 只接入一个群的人用 `skip 0` 仍应看到原来的名单。 |

## 后果

- 400 个只打开删除权限的管理员时，`/admins -100 skip 248` 能看到后面的人。不写 `skip` 时第一页不变。
- 已经设过命令菜单的部署，要再执行一次设置命令，菜单描述才会带上 `skip`。
- 一次查看仍是一次 `getChatAdministrators`。跳过不减少这次请求，只少写回复里的行。
- 没列出来的人仍是管理员。30 天保留期没有改。
