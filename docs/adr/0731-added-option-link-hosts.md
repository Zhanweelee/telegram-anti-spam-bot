# ADR 0731：后加或删除的选项上的文字链接不能越过正文

- 状态：已接受
- 日期：2026-11-07

## 背景

投票允许补选项时，新选项以服务消息画出。删掉选项时，删除提示仍画出那段选项文字。短链在 `poll_option_added.option_text_entities` 和 `poll_option_deleted.option_text_entities`。见 ADR 0089。

Android 对 `TL_messageActionPollAppendAnswer` 和 `TL_messageActionPollDeleteAnswer` 都调用 `formatTextWithEntities`。它再用 `addEntitiesToText` 把实体画到选项文字上。文字链接的起点大于或等于这段文字时，链接不会画上去。

现在这两条服务消息会读全部文字链接。起点已经越过正文的链接仍会留下主机名。

测验说明已经要求起点落在说明里。见 ADR 0730。后加或删除的选项是另一条服务消息。

## 决策

- 新加选项和被删选项上的文字链接，起点必须小于这条 `option_text` 的长度。选项文字不是字符串时，仍按原来的方式读取。
- 选项文字里的普通网址仍读。仍只留主机名。
- 投票描述、游戏说明、礼物和引用不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条服务消息。 |
| 只改新加选项，被删选项仍读全部 | 删除提示同样把选项文字画给群成员。 |
| 投票描述也按正文长度丢掉链接 | 这份客户端还没有画出描述。这条只改已经画出的选项。 |

## 后果

- 起点越过选项文字的文字链接不再留下主机名。仍落在这段文字里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在选项里的路径仍留在正文或 `addedText`。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
