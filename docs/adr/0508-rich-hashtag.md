# ADR 0508：富文本话题标签按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

富文本里的话题标签可以和看得见的字不同。字段是 `hashtag`。这个字段不进事件，关键词看不见标签。看得见的字已经可以成为正文。

行情标签是另一类字段。这一轮不给它加标记。

## 决策

- `type` 正好是 `hashtag`，并且 `hashtag` 去掉空白后非空时，事件带 `asRichHashtag: true`。嵌套在别的块里也同样。
- 空白、布尔值和缺标签不带这个标记。行情标签不带这个标记。机器人命令仍只带 `asRichCommand`。
- 标签不进事件，也不进证据。看得见的字仍是正文。已有 `text` 或 `caption` 时正文不变，标签不并进去。
- 检测器在 `@tasb/detector-rich`，id 是 `rich_hashtag`。只在 `message.asRichHashtag` 为 true 时返回 score 1。证据是 `rich:hashtag`。
- 默认规则关闭。私聊 `/rule <chatId> rich_hashtag on` 之后删除这种正文，`off` 回到留下。
- 不并进 `rich_command`。不调用读取或改写标签的方法。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`rich_hashtag` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 并进机器人命令 | 只想删命令的群会把话题标签也删掉。 |
| 把标签接到正文后面 | 同一条消息的哈希会变，标签也会进事件。 |
| 把标签写进证据 | 标签不进事件。 |
| 默认打开 | 有的群用富文本发话题。打开之前不改现有群。 |
| 新命令 `/tag` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，富文本话题标签留下。看得见的字仍参与关键词。标签仍不进事件。
- 打开 `rich_hashtag` 后，这个群里的这种标签会删除。打开 `rich_command` 仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `rich_hashtag` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `rich_hashtag`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
