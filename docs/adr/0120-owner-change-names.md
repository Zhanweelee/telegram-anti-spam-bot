# ADR 0120：群主变更的可见名字命中就删除

- 状态：已接受
- 日期：2026-11-02

## 背景

群主换人，或群主离开并指定下一位时，群里会出现一条服务消息，上面是新群主的昵称、姓氏和用户名。这条消息通常没有 `text`。名字里的短链或关键词会留在群里。

离开的人在 `from` 上。那是发送者姓名，不该因为这次服务消息被读进来。没有 `new_owner` 时，这行没有指定下一位。

## 决策

- `chat_owner_changed.new_owner` 和 `chat_owner_left.new_owner` 的 `first_name`、`last_name`、`username` 按 ADR 0118 的同一套规则处理：去掉首尾空白，用一个普通空格拼起来，最长 4096 字符。
- 没有更前面的正文时，这段名字成为正文。关键词和链接规则因此能删除这条服务消息。
- 已有正文时，名字只贡献主机名。
- 没有 `new_owner` 时不读这行。不读取用户 id、`language_code` 和 `from` 上的姓名。
- 不新增检测器，不加新的默认规则。不改 ADR 0026 的默认次数、周期和基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 名字永远只留主机名 | 关键词广告名会留在换群主这行上。 |
| 读取离开者的 `from` 姓名 | 发送者姓名仍不进事件。 |
| 没有新群主也封禁离开者 | 离开本身不是广告。 |

## 后果

- 新群主名字里的默认关键词、短链或邀请会删掉这条服务消息。证据仍只有关键词或主机名。
- `example.com` 和普通名字留着。
- 只有离开、没有下一位时，正文仍是空的。
- 名字干净时这行仍留下。某个群可以以后打开 `owner_notice`，把换人和离开整行删掉。没有下一位时也会删。用户编号仍不进事件。见 ADR 0492。
- 靠近提醒上的两个人的名字后来由 ADR 0121 按同一套规则删除。距离仍不读。
- 已有别的正文时，新群主的名字后来由 ADR 0554 另留在 `memberName`。关键词和默认正则可以删除。没有下一位时仍不读。
