# ADR 0430：聊天背景文件名只留主机名

- 状态：已接受
- 日期：2026-11-04

## 背景

群背景被换掉时，成员看见一条服务消息。壁纸和图案的原文件在 `chat_background_set.type.document`。文件名由发送者填写，里面可以只放短链或邀请。这条服务消息往往没有 `text`。

文件名不像普通文件那样显示成消息正文。纯色填充和内置主题没有这份文件。`theme_name` 通常是一个表情。

把文件名当成正文会把文件名写进事件和内容哈希。文件 id 可以用来下载壁纸，不能进事件。

## 决策

- 壁纸（`type` 为 `wallpaper`）和图案（`type` 为 `pattern`）只从 `document.file_name` 抽出网址，只留主机名。折叠、长度、邀请判断和 8 个主机名的上限与旁路纯文本相同。
- 文件名不进入 `message.text`，也不参与内容哈希。没有别的正文时，正文仍是空字符串。
- 不读取 `file_id`、`file_unique_id`、缩略图和 `theme_name`。
- 纯色填充（`fill`）和内置主题（`chat_theme`）不读。类型不是这两种带文件的背景时，即使旁边放了 `document` 也不读。
- 不读取 `chat.title`、`chat.description` 和用户姓名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把文件名当成正文 | 文件名会进事件和内容哈希。这条服务消息并不把文件名画成正文。 |
| 连 `theme_name` 一起读 | 主题名通常是表情，不是这次看得见的链接。 |
| 背景服务消息整段都不读 | 短链可以只写在壁纸或图案的文件名里。 |

## 后果

- 设置背景的服务消息里，壁纸或图案文件名中的短链、邀请或裸 IP 按现有链接规则命中。路径和邀请码不进事件。
- 文件名里的关键词仍然看不到。文件名原文、文件 id 和主题名不进事件。
- 纯色填充、内置主题，以及附在其它消息上的群名、群说明和真实姓名不进事件。
