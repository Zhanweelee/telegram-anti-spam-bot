# ADR 0703：回复的游戏和账单标题只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

回复一条游戏时，Android 把游戏标题画在引用条上。回复一条账单时，画账单标题。说明、附加文字和被回复的原文不画在这一行。任务、选项或引用已经占了这一行时，不再改画游戏或账单标题。

付款成功那行服务文字仍先画私聊对方的名字，再画账单标题。那条顺序已经由 ADR 0618 定下。

ADR 0547 不把被回复的原文收进事件。标题上仍会留下短链。

## 决策

- 任务行和投票选项行都没有占住引用条，且 `quote.text` 不是字符串，`reply_to_message.poll` 也不是对象时，才读后面的标题。
- `reply_to_message.game` 是对象时，只从 `title` 留主机名。说明和附加文字不读。
- 没有游戏时，`reply_to_message.invoice` 是对象，且这条不是付款成功，才从 `title` 留主机名。说明不读。
- 付款成功仍按 ADR 0618 把账单标题排在私聊对方的名字后面。这里不再提前读。
- 没有 `reply_to_message` 时不读。外部回复上的游戏和账单不读。被回复的原文不读。
- 主机名仍进消息已有的 `hosts`。邀请仍进 `invites`。标题不进正文，也不改内容哈希。关键词因此不命中。正文里已有短链时，证据仍先记正文的主机名。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 连游戏说明和账单说明一起读 | 引用条只画标题。说明仍按 ADR 0547 留在外面。 |
| 外部回复上的游戏也读 | 原文没加载时，这行不画游戏标题。 |
| 付款成功也在这里提前读标题 | 名字会排到标题后面，和 ADR 0618 的顺序相反。 |
| 把标题收进正文 | 它是引用条上的一行。关键词仍只看这条消息自己的正文。 |

## 后果

- 画出的游戏标题或账单标题出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。
- 说明、附加文字和被回复的原文仍不进事件。标题不改内容哈希。关键词不命中标题。
- 带引用、投票本身、任务行或选项行时，不改读游戏或账单标题。
- 付款成功的账单标题仍排在名字后面。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
