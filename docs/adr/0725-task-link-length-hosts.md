# ADR 0725：任务和选项上的文字链接不能越过正文

- 状态：已接受
- 日期：2026-11-07

## 背景

回复清单里的某一条任务时，引用条画出那条任务的整段文字。任务号对不上就改画清单标题。回复投票里的某一个选项时，画出那个选项的整段文字。编号对不上就改画问题。见 ADR 0702。

Android 用 `formatTextWithEntities` 画这行。文字链接的起点大于或等于这段文字时，链接不会画上去。

现在这四行会读全部文字链接。起点已经越过正文的链接仍会留下主机名。

没有任务号时，清单标题仍只取前 150 个码元。见 ADR 0709 与 ADR 0722。

## 决策

- 对得上的任务文字、对不上时的清单标题、对得上的选项文字、对不上时的问题，文字链接的起点必须小于这段文字的长度。
- 起点落在这段文字里时，仍只留主机名。整段文字仍读，不改按 150 截断。
- 其余任务、选项和被回复的原文仍不读。这行不进正文。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条回复。 |
| 这四行也只取前 150 个码元 | 引用条画出的是整段任务、标题、选项或问题。 |
| 清单气泡里的任务也一起改 | 那是另一行。这条只改引用条。 |

## 后果

- 起点越过正文的文字链接不再留下主机名。仍落在这段文字里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。关键词不命中这行。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 清单气泡里的标题和任务后来由 ADR 0726 同样要求文字链接的起点落在这段文字里。后加任务和勾完的任务仍不在那条里。
