# ADR 0500：剧透媒体按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

照片、视频和动图可以盖上剧透动画。字段是 `has_media_spoiler`。说明可以是另一句普通的话，也可以是空的。空说明时关键词看不见这张图。同一份文件仍走重复检测。每张都不一样时，盖着剧透的照片和视频会留下。

ADR 0469 不给普通照片、视频、文件和音频加锁。剧透是盖在媒体上的一层，不是那四种日常内容本身。

## 决策

- `has_media_spoiler` 正好是 `true` 时，事件带 `asSpoiler: true`。`false` 不带这个标记。
- 已有说明时说明不变。文件号不进事件。媒体类别仍按原来的字段。
- 检测器在 `@tasb/detector-spoiler`，id 是 `media_spoiler`。只在 `message.asSpoiler` 为 true 时返回 score 1。证据是 `media:spoiler`。
- 默认规则关闭。私聊 `/rule <chatId> media_spoiler on` 之后删除这种媒体，`off` 回到留下。
- 不调用设置剧透的方法。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`media_spoiler` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认打开 | 有的群用剧透发剧情。打开之前不改现有群。 |
| 并进贴纸或动图规则 | ADR 0469 的那几条只认自己的类别。盖着剧透的照片不是贴纸。 |
| 连普通照片和视频一起锁 | ADR 0469 已经拒绝。没有剧透的照片仍要留下。 |
| 把文件号写进证据 | 文件号不是看得见的说明。 |
| 新命令 `/spoiler` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，剧透媒体留下。说明仍参与关键词。同一份文件仍走重复检测。
- 打开 `media_spoiler` 后，这个群里盖着剧透的媒体会删除。打开贴纸、动图、语音、视频留言或骰子仍不删除一张剧透照片。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `media_spoiler` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `media_spoiler`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
- 富文本照片、视频和动图上的 `has_spoiler` 后来由 ADR 0503 同样带上 `asSpoiler`。文件号仍不进事件。
- 普通照片、视频、文件和音频后来由 ADR 0575 各有一条默认关闭的规则。没有剧透时要另开那一条。剧透仍走 `media_spoiler`。
