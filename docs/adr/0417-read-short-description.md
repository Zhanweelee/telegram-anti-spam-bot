# ADR 0417：私聊可以查看 bot 的默认短简介

- 状态：已接受
- 日期：2026-11-04

## 背景

默认短简介已经可以设置。查看调用是 `getMyShortDescription`。

`language_code` 可选。不送时返回给没有专用语言短简介的人看的那个短简介。已经有单独语言短简介的人不在这次结果里。

返回值是 `BotShortDescription`。字段 `short_description` 是这个 bot 的短简介。

## 决策

- 私聊命令 `/myshort`。没有参数。多出来的参数不发出请求。别的单词回复「参数无效」。群聊里的同样文本不执行。
- 只有配置里的管理员可以看。接入目录里的人即使管着自己的群也不能看。
- 调用 `ModerationPort.readBotShortDescription`。适配器调用 `getMyShortDescription`。正文是空对象。不送 `language_code`。
- 短简介是 0 到 120 个字符、没有换行的字符串时，回复带上这个短简介。空字符串回复「短简介 空」。
- 缺字段、非字符串、超长或带换行时整份回复是「参数无效」，不露出已经读到的短简介。其它字段不进回复，也不进日志。
- 日志只写 `operator_rejected` 或命令名，带上 eventId、chatId 和命令名 `myshort`。不写短简介、异常文本或 token。
- 没有 token 的 Worker 不编一份短简介。
- 不调用 `setMyShortDescription`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 查看某一个语言的短简介 | 那要送 `language_code`。这次只读默认短简介。 |
| 空短简介当成失败 | 清掉默认短简介之后，空字符串是当前状态。 |
| 回复里不写短简介 | 管理员私聊来就是为了看到当前短简介。日志仍然不写。 |

## 后果

- 成功只表示 Telegram 返回了默认短简介。已有单独语言短简介的人不受这次查看影响。
- 一次查看是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
