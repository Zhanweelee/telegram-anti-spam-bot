# ADR 0367：私聊可以删除一条消息

- 状态：已接受
- 日期：2026-11-04

## 背景

规则命中之后会调用 `deleteMessage`。管理员从群里看到一条消息号，仍然要到客户端里删除。`/ban` 和 `/mute` 处理的是人，不会删掉这一条。

`deleteMessage` 的官方说明：可以删除普通消息和服务消息。发出不足 48 小时的消息可以删。超级群、频道或论坛话题的创建服务消息不能删。私聊里的骰子要超过 24 小时才能删。bot 在群里是管理员时可以删除那里的任何消息。在超级群或频道里要有 `can_delete_messages`。只给一个人看见的消息走 `deleteEphemeralMessage`，并要带上接收者。见 ADR 0125。

没有 token 时，流水线的 `deleteMessage` 记在内存里。私聊如果复用这次成功，回复会写成已经删除。

## 决策

- 私聊命令 `/delete <chatId> <messageId>`。群 id 匹配 `^-?\d{1,20}$`。消息号是没有前导零的正十进制整数，并且是安全整数。群聊里的同样文本不执行。
- 配置中的管理员可以操作任意群。接入目录里的人只能操作自己的群。
- 命令调用 `ModerationPort.deleteMessage`，只带 tenant、chat 和 message。不带 `audienceId`，因此不调用 `deleteEphemeralMessage`。
- 不先读取这条消息。原文、姓名和文件都不进入这次命令。
- 没有 token、没有这个方法，或调用失败时回复「参数无效」。日志只写 `operator_rejected`，带上 eventId、chatId 和命令名。不写异常文本、token 或原文。
- 没有 token 的 Worker 不把内存里的删除记录回复成已经成功。流水线在没有 token 时仍按 ADR 0020 记在内存里。
- 不修改黑名单、白名单、封禁或禁言。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 先拉取消息再决定删不删 | 会把原文带进这次请求。管理员已经给出消息号。 |
| 没有接收者时改调临时消息删除 | 普通消息号和临时消息号不是同一套。缺接收者会删错。 |
| 没有 token 时也回复「已删除」 | 群里的消息还在。管理员会以为已经删掉。 |

## 后果

- 删不掉时回复「参数无效」。48 小时、服务消息种类和 bot 权限都由 Telegram 决定。
- 一次删除是一次 Telegram 子请求。作者仍留在群里。一次多条见 ADR 0374。
- 30 天保留期不动。
