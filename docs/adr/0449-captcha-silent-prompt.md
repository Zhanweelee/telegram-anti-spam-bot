# ADR 0449：入群验证静音发出

- 状态：已接受
- 日期：2026-11-04

## 背景

每个新人都会让 bot 发一条验证。`sendMessage` 默认带声音。人多的群会被这一条条提示打断。按钮和正文仍要留在聊天里，新人才点得到。

## 决策

- 验证消息的 `sendMessage` 带 `disable_notification: true`。
- 正文、两颗按钮和关闭的链接预览不动。点错的提示和点对后的放行不动。
- 置顶和其它发出的消息不带这个字段。
- 不改 `captcha_challenges`，不新增命令。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 不发验证消息，只限制 | 成员看不到按钮，验证完不成。 |
| 顺手把置顶也改成静音 | 置顶的通知是另一项的行为。这一项只改验证。 |

## 后果

- 验证消息仍出现在群里，没有声音。成员仍能点按钮。
- 限制时长和通过后的权限没有改。
- 云额度的基础检测器名单没有改。30 天保留期没有改。
