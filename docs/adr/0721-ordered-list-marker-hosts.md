# ADR 0721：富文本有序列表按画出来的编号占位

- 状态：已接受
- 日期：2026-11-07

## 背景

置顶提示和引用条上的有序列表来自 `formatRichBlock`。编号是 `num`，后面再加 `. `。Bot API 在标签为空时用 `value` 和 `type` 表示这个编号。`1` 是十进制，`a` 和 `A` 是字母，`i` 和 `I` 是罗马数字。

ADR 0714 在标签为空时一律写成十进制。`18` 画出来是 `xviii`，比 `18` 多三个码元，窗口边上的短链会被多算进来。`26` 画出来是 `z`，比 `26` 短，画出来的短链会被漏掉。

## 决策

- 列表项有非空 `label` 时，短预览仍用这个标签，再加 `. `。
- 标签为空且 `value` 是整数时，`type` 为 `a` 或 `A` 用字母，`i` 或 `I` 用罗马数字。`1`、缺省和其它类型仍用十进制。
- 字母从 1 开始，26 是 `z`，27 是 `aa`。0 和负数退回十进制。罗马数字只覆盖 1 到 3999，之外退回十进制。不是整数时仍用原来的十进制写法。
- 只影响置顶提示和引用条的预览长度。气泡里的整篇文章仍不把编号拼进正文。预览不进正文，内容哈希不变。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续一律用十进制 | 罗马数字更长，窗口边上没画出来的短链会被删掉。 |
| 编号占满剩下的预览 | 编号长度是算得出来的。后面画出来的短链会被漏掉。 |
| 把编号拼进正文 | 关键词会命中编号。整篇文章本来不画这一截进正文。 |

## 后果

- 编号把短链推出前 20 或 150 个码元时，这条消息不再因为那个主机名被删。仍落在窗口里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 写了标签时仍用标签。被截断的路径不进事件。内容哈希不变。关键词不命中预览。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- `pin_notice` 仍默认关闭。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
