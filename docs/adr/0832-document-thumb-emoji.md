# ADR 0832：文档缩略图里不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。文档类型里不读自定义表情。见 ADR 0831。文档缩略图不进正文。

现在文档块 `document.thumbnail` 里如果嵌着自定义表情，仍会带 `asCustomEmoji`。打开 `custom_emoji` 后，没画在正文上的表情也会删掉这条消息。

## 决策

- 文档块 `document.thumbnail` 里不读取自定义表情。
- 文档说明仍按原来的方式读取。画出来的段落、替代文字长度大于 0 的节点仍读。文件名和类型仍不读。
- 编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。缩略图仍不进正文。
- 视频缩略图不在这条里。实体列表上的自定义表情仍按各自那段文字判断。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读文档缩略图 | 缩略图不进正文，里面的表情不会画在这段正文上。 |
| 整个文档块都不看 | 这条只改缩略图。说明仍可能画出来。 |
| 视频缩略图一起改 | 视频缩略图是另一段没画进正文的字段。 |
| 连实体列表一起改 | 实体列表已经按各自的文字判断。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 文档缩略图里的自定义表情不再带 `asCustomEmoji`。
- 旁边仍画出来的节点，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 文档缩略图里的自定义表情后来由 ADR 0832 不再读取。视频缩略图里的自定义表情后来由 ADR 0833 不再读取。动画缩略图里的自定义表情后来由 ADR 0834 不再读取。动画类型里的自定义表情后来由 ADR 0835 不再读取。视频类型里的自定义表情后来由 ADR 0836 不再读取。音频类型里的自定义表情后来由 ADR 0837 不再读取。音频缩略图里的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
