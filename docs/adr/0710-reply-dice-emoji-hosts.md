# ADR 0710：骰子预览行上的表情只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

没有说明时，Android 把骰子的表情放进这条消息的预览。聊天列表画这行。回复一条已经加载的骰子时，引用条也画这行的前 150 个 UTF-16 码元。外部回复的骰子直接用这份表情，不取当前消息的文件。画出之前会去掉变体选择符 U+FE0F。表情为空时改画默认骰子。有说明时改画说明。

ADR 0469 让骰子带上 `media: "dice"`，并写明点数和表情不进事件。短链可以只写在这个表情里。点数仍然不是文字。

## 决策

- 没有 `caption` 和 `text`，并且 `dice` 是对象时，从 `emoji` 去掉 U+FE0F 之后的前 150 个码元留主机名。
- 这条骰子自己的列表预览，和已加载回复的引用条，都按这一行读。
- `external_reply.dice` 也读这份表情。旁边的 `document.file_name` 仍不读。
- `caption` 或 `text` 的长度大于 0 时不读这条骰子自己的表情。说明和正文仍不进事件。
- 表情为空时仍占住这一行。`value` 不读。表情原文不进正文，也不改内容哈希。关键词因此不命中。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 外部骰子的表情不读 | 外部回复那一行画的就是这份表情。 |
| 连变体选择符一起扫描 | 客户端先把它删掉，画出来的是删掉之后的字。 |
| 有说明时也读表情 | 有说明时列表和引用条改画说明。 |
| 把点数或表情收进正文 | 点数不是文字。表情是预览行。关键词仍只看这条消息自己的正文。 |

## 后果

- 没有说明的骰子，表情里的短链会删除这条消息。回复一张这样的骰子，或外部回复它，也会删除。证据只有主机名。
- 有说明时，这条短链不删除。点数、路径和表情原文不进事件。
- 表情不改内容哈希。关键词不命中表情。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
