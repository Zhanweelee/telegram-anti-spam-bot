# ADR 0763：游戏附加文字上的按标识提及必须从附加文字里开始

- 状态：已接受
- 日期：2026-11-07

## 背景

按标识提及可以按群删除。用户编号不进事件。见 ADR 0514。礼物附言上的按标识提及必须从附言里开始。见 ADR 0762。

游戏附加文字走这一条。Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达附加文字末尾的实体。起点落在附加文字里、长度越过末尾时，客户端把长度收到附加文字末尾，这段提及仍会画出来。

已有别的正文时，事件把游戏说明和附加文字各自留前 4096 字，中间一个空格。游戏标题自己就是正文时，标题仍只留前 4096 字。提及仍按整段附加文字判断，不按拼好的说明来量。

现在附加文字会读全部 `text_entities`。一个起点已经越过附加文字的按标识提及仍会带上 `asTextMention`。打开这条规则后，没画出来的提及也会删掉这条游戏。

手动引用不在这条里。引用上的按标识提及仍不带 `asTextMention`。见 ADR 0574。

## 决策

- `game.text` 是字符串时，`text_entities` 里的按标识提及，起点必须大于或等于 0 且小于附加文字长度，长度必须大于 0。
- 起点落在附加文字里、长度越过末尾时，仍带 `asTextMention`。
- 附加文字不是字符串时，仍按原来的方式读取。
- 已有别的正文时，第 4097 字上的提及，只要起点仍落在附加文字里，就继续带 `asTextMention`。事件里的附加文字仍只留前 4096 字。说明另留前 4096 字，不改变这条起点。
- 手动引用上的按标识提及仍不读取。
- 仍落在附加文字里的提及继续带 `asTextMention`。用户编号和名字仍不进事件。封面和动图文件编号仍不进事件。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的提及会在打开规则后删掉这条游戏。 |
| 也要求长度落在附加文字里 | 起点在附加文字里时，客户端会把越过末尾的长度收回来再画。 |
| 按说明加附加文字的整段来量起点 | 实体画在附加文字上。说明是另一段，拼在一起只是事件里的保存方式。 |
| 也按 4096 字丢掉后面的提及 | 4096 只是旁边附加文字的上限。整段附加文字更长时，后面的提及仍落在附加文字里。 |
| 手动引用也一起读 | 引用上的按标识提及仍不带这个标记。见 ADR 0574。 |
| 默认打开 | 有的群会点名。打开之前不改现有群。 |

## 后果

- 起点已经到达或越过游戏附加文字末尾的按标识提及不再带 `asTextMention`。空附加文字、长度为 0 和负起点也不带。
- 起点落在附加文字里的提及，打开 `text_mention` 后删除。证据仍是 `entity:text_mention`。用户编号不进事件。长度越过末尾的提及也删除。起点已经超过 4096、但仍落在附加文字里的提及也删除。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 手动引用上的按标识提及仍不带 `asTextMention`。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
