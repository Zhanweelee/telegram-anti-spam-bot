# ADR 0127：代码块语言标签只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

富文本代码块可以带 `pre.language`。这是语法高亮用的语言标签，发送者能写成一条网址。代码正文已经在扫。标签里的短链还看不见。

把标签拼进正文会改变 `textSha256`。`python` 这种普通语言名不该成为正文，也不该进事件。

## 决策

- 从富文本块 `pre.language` 抽出网址，只留主机名。折叠、长度、邀请判断和 8 个主机名的上限与旁路纯文本相同。
- 语言标签不进入 `message.text`，也不参与内容哈希。代码正文仍按原来的富文本规则成为正文。
- 不把语言标签里的关键词交给关键词检测器。
- 不读取公式源码、锚点名字、表情 id、邮箱、电话和银行卡号。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 语言标签整段都不读 | 短链可以只写在代码块的语言标签上。 |
| 没有别的正文时让标签成为正文 | 普通语言名会改掉内容哈希。 |
| 连关键词一起匹配标签 | 语言名不是这段代码的正文。 |

## 后果

- 语言标签里的默认短链或邀请会删掉这条富文本。证据仍只有主机名。
- `example.com` 留着。语言标签里的关键词留着。代码正文里的关键词仍会命中。
- 标签原文、路径和邀请码不进事件。
