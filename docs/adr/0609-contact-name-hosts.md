# ADR 0609：名片上的名字只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

分享的联系人会画出一张名片。卡片标题是 `contact.first_name`，名为空时才画姓。电话、用户编号和 vCard 当时整段丢掉。见 ADR 0032。vCard 里的 `URL` 行已经只留主机名。见 ADR 0151。

短链可以只写在这行标题上，vCard 里没有 `URL`。`shared_contact` 默认会删掉整张名片。关掉这条之后，标题里的短链仍会留下。

把名字收成正文会让关键词命中人名，也和原文默认不落盘冲突。

## 决策

- `contact` 是对象时，从可见名字留主机名。名的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。抽出之前不截断。
- 主机名仍进消息已有的 `hosts`。邀请仍进 `invites`。vCard 里 `URL` 行的主机名仍排在前面。名字不进正文，也不改内容哈希。关键词因此不命中这个名字。
- 电话、用户编号、邮箱、备注、`X-URL` 和群名不读。布尔值的 `contact` 不读。发送者姓名不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`shared_contact` 仍默认打开。关掉之后，短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字拼进正文 | 关键词会命中人名，电话旁边的姓名也会落盘。见 ADR 0032。 |
| 只靠 `shared_contact` | 关掉名片规则后，标题里的短链仍留下。 |
| 连备注和邮箱一起读 | 备注只复制，邮箱打开的是邮件。见 ADR 0151。 |
| 新命令 `/contactname` | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 关掉 `shared_contact` 后，名片标题里的短链、邀请或裸 IP 仍会删除这条消息。证据只有主机名。
- 这个人的名字原文、路径、电话和用户编号不进事件。内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓不进事件。vCard 里已有 `URL` 短链时，证据仍先记那一行的主机名。
- `example.com` 和公开的 `t.me/名字` 在名片规则关掉时留下。默认仍由 `shared_contact` 删除整张名片。付费帖仍不删除。见 ADR 0356。
- 电话、邮箱、备注和布尔值的 `contact` 仍不读。发送者姓名和群名仍不读。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 气泡副标题里的公司名后来由 ADR 0613 只留下主机名。公司名本身仍不进事件。名字的主机名仍排在公司名前面。
- 名和姓去掉空白后都是空的时，标题后来由 ADR 0614 改读原始电话。电话本身仍不进事件。已有姓名时，带数字的电话仍不读。
