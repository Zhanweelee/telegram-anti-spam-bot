# ADR 0745：后加和删掉的选项上的自定义表情必须落在选项里

- 状态：已接受
- 日期：2026-11-07

## 背景

后加和删掉的投票选项也走自定义表情这条规则。编号不进事件。见 ADR 0573。原投票上的选项必须整段落在选项里。见 ADR 0744。

这两条服务消息把选项文字画出来。`replaceAnimatedEmoji` 只在 `offset + length` 不超过这段文字时才放上表情。起点已经越过选项，或表情越过选项末尾，都不会画出来。

现在这两条会读全部 `option_text_entities`。一个越出选项的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条服务消息。

嵌套的原投票不读。测验说明和投票描述不在这条里。

## 决策

- `poll_option_added.option_text` 或 `poll_option_deleted.option_text` 是字符串时，`option_text_entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过这段选项文字。
- 选项文字不是字符串时，仍按原来的方式读取。
- 仍落在选项里的表情继续带 `asCustomEmoji`。编号和选项编号仍不进事件。
- 嵌套的 `poll_message` 仍不读。原投票上的选项仍按 ADR 0744。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条服务消息。 |
| 只要求起点小于选项 | 表情越过末尾时，客户端同样不会画。 |
| 连原投票一起扫 | `poll_message` 是另一条消息。原投票发出时已经扫过。 |
| 选项文字不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的选项。 |

## 后果

- 起点加长度越过选项的自定义表情不再带 `asCustomEmoji`。空选项和长度为 0 的实体也不带。
- 仍落在选项里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 测验说明上的自定义表情后来由 ADR 0746 要求整段落在说明里。说明不是字符串时仍按原来的方式读取。
