# ADR 0585：改价的人，名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

超级群改付费发言的星星数量，或频道改私信开关时，客户端把这个人的名字画在提示上。名字写在 `from`。星星数量和开关当时留在事件外面。见 ADR 0487。这行通常没有别的正文。短链可以只写在名字里。

把 `from` 收成正文会让普通发言者的姓名也进检测。`price_notice` 默认关闭，干净的提示仍留下。这次不改价格，也不改私信开关。

## 决策

- 只在已经会标成 `priceNotice` 的提示上，从 `from` 的可见名字留主机名。付费发言的星星数量大于等于 0 的安全整数时读。私信开关正好是布尔值时也读。两条同时出现时仍先认付费发言。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 空对象、负数、小数、字符串和单独的布尔值不读发送者。普通消息因此仍不读 `from`。
- 名字不进正文，也不改内容哈希。关键词因此不命中。星星数量和开关不读。本群群名不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`price_notice` 仍默认关闭。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 关键词会命中人名。普通消息的 `from` 也会被打开。见 ADR 0487。 |
| 按星星数量新开一条规则 | 数量不是广告。删除仍走已有的链接规则。 |
| 每条消息都读 `from` | 发言人的名字会跟着每条消息重复计一次。 |
| 新命令 `/pricename` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 改价的人名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。价格和私信开关不变。
- 名字原文、路径和用户名不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。星星数量和开关不进事件。
- 改价后来按全名只留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。见 ADR 0629。发送者是频道时后来由 ADR 0671 只读频道标题。助推和付款成功仍只读名。加选项或删选项仍只读名。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 不是真实改价提示时，发送者仍不读。干净的提示在 `price_notice` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
