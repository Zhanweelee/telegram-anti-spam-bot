# ADR 0656：创建抽奖上画出的群名只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

创建抽奖的服务消息会把所在聊天的名字画进这行。Android 的 `TL_messageActionGiveawayLaunch` 用频道或群的 `title` 填进 “%s just started a giveaway…”。星星抽奖同样用这个名字。用户名不画。见 ADR 0483。

Bot API 把这条公告放在 `giveaway_created`。名字在这条消息的 `chat.title`。星星数量在 `prize_star_count`，不画成网址。

私下结束、进行中的抽奖卡片和公开中奖者都不把这条消息所在聊天的名字画进正文。发送者仍按 ADR 0590 只读名。

## 决策

- `giveaway_created` 是对象时，从 `chat.title` 留主机名。空对象也读。空字符串不读。
- 不读 `chat.username`、星星数量、发送者姓名以外已经读过的字段。群名不进正文，内容哈希不变。
- `giveaway_completed`、`giveaway` 和 `giveaway_winners` 不因这条规则改读 `chat.title`。进行中卡片里列出的其他聊天仍按原来的标题。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`giveaway_notice` 仍默认关闭。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 每条消息都读所在聊天的名字 | 普通消息不把群名画进正文。群名改了会让旧消息突然被删。 |
| 私下结束也读群名 | 结束这行只画中奖人数，不画群名。 |
| 把群名抄进正文 | 关键词会命中群名。群名只需要主机名。 |
| 连用户名一起读 | 这行画的是标题，不是 `@用户名`。 |

## 后果

- 创建公告上画出的群名里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。抽奖本身不取消。星星不退回。
- 群名原文、路径、用户名和星星数量不进事件。内容哈希不变。关键词不命中群名。
- 私下结束和进行中的卡片仍不读这条消息所在聊天的名字。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 创建抽奖的人后来不再读。见 ADR 0664。`giveaway_notice` 仍默认关闭。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
