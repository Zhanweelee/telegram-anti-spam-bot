# ADR 0322：新建受管 bot 的可见名字命中就删除

- 状态：已接受
- 日期：2026-11-03

## 背景

Bot API 的 `managed_bot_created` 是用户新建了一个由当前 bot 管理的 bot。服务消息上看得见的是新 bot 的名字、姓氏和用户名。短链或关键词可以只放在这些名字里。这条消息通常没有 `text`。

令牌不在这个对象里，要用 `getManagedBotToken` 另取。bot id、创建者的 `from` 姓名和所在聊天的标题都不是这行看得见的名字。

## 决策

- `managed_bot_created.bot` 的 `first_name`、`last_name`、`username` 去掉首尾空白后，用一个普通空格拼起来，最长 4096 字符。
- 没有更前面的正文时，这段名字成为正文。关键词和链接规则因此能删除这条服务消息。路径留在正文里。
- 已有正文时，名字只贡献主机名。路径、用户名片段和关键词不进事件。
- 不读取 bot id、`is_bot`、`language_code`、令牌字段、`from` 上的姓名和 `chat.title`。
- 入群名单和分享来的用户名单仍排在前面。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 名字永远只留主机名 | 关键词广告名会留在「新建了 bot」这行上。 |
| 把令牌或 bot id 写进事件 | 令牌不是看得见的字。id 也不该留在日志里。 |
| 读取每条消息的 `from` 姓名 | 会把普通发言者的姓名送进检测。 |

## 后果

- 没有正文时，可见名字里的默认关键词、短链或邀请会删掉这条服务消息。证据仍只有关键词或主机名。路径留在正文里。
- 已有正文时，名字里的短链和邀请仍删除。正文和哈希不变。路径和用户名片段不进事件。
- 已有别的正文时，新建受管 bot 的可见名字后来由 ADR 0556 另留在 `managedName`。关键词和默认正则可以删除。bot 编号和令牌仍不进事件。
- `example.com` 和普通名字留着。bot id、令牌、创建者姓名和所在聊天的标题不进事件。
- 云额度的基础检测器名单没有改。
- 用户允许 bot 发消息时带上的小程序名字后来由 ADR 0323 按同一套规则处理。来源布尔值不进事件。
- 新 bot 画出的名字后来按全名成为正文。名和姓都去掉两端空白，名在前。用户名不进。见 ADR 0643。
