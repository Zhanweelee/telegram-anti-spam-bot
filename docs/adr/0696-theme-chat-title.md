# ADR 0696：内置主题由聊天换时读聊天标题

- 状态：已接受
- 日期：2026-11-06

## 背景

换壁纸、图案或纯色时，Android 的 `TL_messageActionSetChatWallPaper` 在发送者是聊天时不画人，也不画标题。见 ADR 0673。

换内置主题走另一条动作 `TL_messageActionSetChatTheme`。发送者是用户时，名字仍是 `UserObject.getFirstName`。发送者是聊天时，`fromUser` 为空，这行把 `fromChat.title` 填进句子。标题不截断。

Bot API 把两种都放在 `chat_background_set`。类型 `chat_theme` 是内置主题。壁纸、图案和纯色仍是另外三种。发送者是聊天时，`sender_chat` 是那个聊天，`from` 是占位用户。

ADR 0673 把四种都跳过了。壁纸、图案和纯色仍不画标题。内置主题会画出这个聊天的标题。

## 决策

- 已经会标成 `background`，类型是 `theme`，且 `sender_chat` 是对象时，从 `sender_chat.title` 留主机名。标题不截断。不从 `from` 留主机名。用户名不读。
- 频道、群和超级群都一样。编号和本群相同时也读。
- 壁纸、图案和纯色由聊天换时仍不读 `from`，也不读标题。
- 没有 `sender_chat` 时，四种仍从 `from` 的可见名字留主机名。名的长度大于 0 时只读名。空白也算有名。
- 编号不同的聊天标题仍由通用代发规则读取。同一条标题只留一次。不从 `chat.title` 另读。
- 文件名仍只在壁纸和图案上留主机名。文件号和主题名不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`chat_background` 仍默认关闭。短链仍走已有的 `links`。8 个主机名的上限不变。不改群背景。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 四种都不读标题 | 内置主题会画出这个聊天的标题。标题里的短链会出现在这行提示里。 |
| 壁纸也读标题 | 换壁纸的句子不画标题。 |
| 改读所在群的 `chat.title` | 画出来的是发送者这个聊天。所在群的名字可以不是这一行。 |
| 新命令 | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 聊天换内置主题时，这个聊天标题里的短链、邀请或裸 IP 会删掉这条提示。关掉管理员豁免后也会删。
- 占位用户的名字仍不留下主机名。壁纸、图案和纯色的聊天标题仍不留下。
- 用户换主题时，可见名字里的短链仍会删。证据只有主机名。
- 别的聊天换主题时，标题仍留下主机名。
- 名字原文、路径、用户名、文件号和主题名不进事件。内容哈希不变。关键词不命中这些名字。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 空对象、其它类型和普通消息仍不读发送者。干净的提示在 `chat_background` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
