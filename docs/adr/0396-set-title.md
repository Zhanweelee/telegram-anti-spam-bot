# ADR 0396：私聊可以修改一个聊天的标题

- 状态：已接受
- 日期：2026-11-04

## 背景

管理员想改一个群或频道的标题。官方有一次只改标题的调用。

`setChatTitle` 修改一个聊天的标题。私聊不能改标题。bot 必须是这个聊天的管理员，并有相应的管理权限。成功时返回 True。

参数是 `chat_id` 和 `title`。`title` 必填，长度 1 到 128 个字符。

简介和头像是另外的调用。没有 token 时不能把内存记录回复成已经修改。标题本身不能进回复或日志。

## 决策

- 私聊命令 `/title <chatId> <title>`。群 id 匹配 `^-?\d{1,20}$`。标题是其余参数按空白折叠后拼起来的字符串。不写标题时不发出请求。长度超过 128 时不发出请求。群聊里的同样文本不执行。
- 正数编号也原样送出。私聊不能改标题时，由 Telegram 拒绝。
- 配置中的管理员可以操作任意群。接入目录里的人只能操作自己的群。
- 调用 `ModerationPort.setTitle`。适配器调用 `setChatTitle`，带 `chat_id` 和 `title`。
- 回复不重复标题，并写明简介和头像还在。
- 没有 token、没有这个方法，编号或标题不合法，或调用失败时回复「参数无效」。日志只写 `operator_rejected`，带上 eventId、chatId 和命令名。不写异常文本、token、标题或原文。
- 没有 token 的 Worker 不把内存记录回复成已经修改。
- 不调用 `setChatDescription`、`setChatPhoto` 或 `getChat`。不修改黑名单、白名单、封禁或禁言。不读取消息正文。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 回复里重复新标题 | 标题可能是管理员刚粘贴的原文。回复只确认这一次请求。 |
| 按编号形状拒绝私聊 | 文档只说私聊不能改标题。失败仍是「参数无效」。 |
| 先调用 `getChat` 读出现有标题 | 多一次子请求，还会把简介和邀请链接读回来。 |

## 后果

- 成功只表示 Telegram 接受了这一次 `setChatTitle`。私聊、缺少权限或标题不合法时，回复是「参数无效」。
- 简介和头像还在。
- 一次修改是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
