# ADR 0479：换头像和删头像按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

群头像被换掉或拿掉时，成员看见一条服务消息。新头像是一组图片尺寸，删头像是一个布尔值。文件号和尺寸不进事件。见 ADR 0476。这条消息通常没有正文，关键词看不到图里的字。

删掉这条服务消息不会把群头像改回去。真正拿掉头像仍走私聊 `/delphoto`。见 ADR 0390。

## 决策

- `new_chat_photo` 里至少有一个对象时，事件带 `photo: "set"`。不写文件号、唯一号和尺寸。
- `delete_chat_photo` 正好是 true 时带 `photo: "cleared"`。几种同时出现时先认换头像。空数组和 false 不带这个标记。已有正文时，正文仍按原来的优先级。
- 检测器在 `@tasb/detector-photo`，id 是 `chat_photo`。只在 `message.photo` 是 `set` 或 `cleared` 时返回 score 1。证据是 `photo:set` 或 `photo:cleared`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这两种服务消息。没有新命令。菜单仍是 99 条。不调用 `deleteChatPhoto` 或 `setChatPhoto`。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`chat_photo` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部头像提示 | 有的群会自己换头像。打开之前不改现有群。 |
| 打开规则时顺便调用 `deleteChatPhoto` | 那会改掉群头像。这条更新里没有旧头像。见 ADR 0390。 |
| 把文件号写进证据 | 文件号可以下载图片，不能进事件。 |
| 连聊天背景一起删 | 那是另外的服务消息。见 ADR 0430。后来由 ADR 0480 另开一条规则。 |
| 新命令 `/photo` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。`/delphoto` 仍负责拿掉群头像。 |

## 后果

- 不打开这条规则的群，换头像和删头像的服务消息仍留下。
- 打开 `chat_photo` 后，这个群里的这两种服务消息会删除。群头像本身不变。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `chat_photo` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
