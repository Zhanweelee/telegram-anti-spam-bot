# ADR 0391：私聊可以让 bot 退出一个聊天

- 状态：已接受
- 日期：2026-11-04

## 背景

管理员想让 bot 离开一个群、超级群或频道时，要能从私聊发出这一次请求。官方有一次只退出的调用。

`leaveChat` 让 bot 离开一个群、超级群或频道。参数只有 `chat_id`。频道的私聊对话不支持，要改为离开对应的频道。成功时返回 True。

这条调用不读取标题，也不删除消息。

没有 token 时，内存适配器可以把这次请求记下来。私聊如果复用这次成功，回复会写成 bot 已经退出。标题不能进回复或日志。

## 决策

- 私聊命令 `/leave <chatId>`。群 id 匹配 `^-?\d{1,20}$`。多出来的参数不发出请求。群聊里的同样文本不执行。
- 配置中的管理员可以操作任意群。接入目录里的人只能操作自己的群。
- 调用 `ModerationPort.leaveChat`。适配器调用 `leaveChat`，只带 `chat_id`。
- 不调用 `getChat`。不读取标题。
- 回复写明 bot 被请求退出，消息还在。
- 没有 token、没有这个方法，群号不合法，或调用失败时回复「参数无效」。日志只写 `operator_rejected`，带上 eventId、chatId 和命令名。不写异常文本、token 或原文。
- 没有 token 的 Worker 不把内存里的记录回复成已经成功。
- 不修改黑名单、白名单、封禁或禁言。不读取消息正文。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 先用 `getChat` 确认类型再退出 | 多一次子请求，还会带回标题、简介和邀请链接。退出本身只需要群号。 |
| 私聊群号在本地直接拒绝 | 群号和私聊号的形状会重叠。频道私聊对话不支持时，由 Telegram 返回失败。 |
| 没有 token 时也回复「已退出」 | bot 还在。管理员会以为已经离开。 |

## 后果

- 成功只表示 Telegram 接受了这一次退出。频道的私聊对话，或 bot 本来就不在这个聊天时，回复是「参数无效」。
- 消息还在。
- 一次退出是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
