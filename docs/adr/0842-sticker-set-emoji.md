# ADR 0842：贴纸包名里不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。贴纸缩略图里不读自定义表情。见 ADR 0841。贴纸包名不进正文。

现在贴纸块 `sticker.set_name` 里如果嵌着自定义表情，仍会带 `asCustomEmoji`。打开 `custom_emoji` 后，没画在正文上的表情也会删掉这条消息。

## 决策

- 贴纸块 `sticker.set_name` 里不读取自定义表情。
- 贴纸说明和表情仍按原来的方式读取。画出来的段落、替代文字长度大于 0 的节点仍读。
- 编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。包名仍不进正文。缩略图里的自定义表情仍不读。
- 照片不在这条里。实体列表上的自定义表情仍按各自那段文字判断。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读贴纸包名 | 包名不进正文，里面的表情不会画在这段正文上。 |
| 整个贴纸块都不看 | 这条只改包名。说明和表情仍可能画出来。 |
| 照片一起改 | 照片是另一段没画进正文的字段。 |
| 连实体列表一起改 | 实体列表已经按各自的文字判断。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 贴纸包名里的自定义表情不再带 `asCustomEmoji`。
- 旁边仍画出来的节点，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 贴纸包名里的自定义表情后来由 ADR 0842 不再读取。照片里的自定义表情后来由 ADR 0843 不再读取。地图坐标里的自定义表情后来由 ADR 0844 不再读取。地图缩放里的自定义表情后来由 ADR 0845 不再读取。地图宽度里的自定义表情后来由 ADR 0846 不再读取。地图高度里的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
