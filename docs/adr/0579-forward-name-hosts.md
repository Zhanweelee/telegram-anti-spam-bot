# ADR 0579：已知用户和群的转发抬头只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

转发到群里的消息会在抬头画出原来的发送者。已知用户画出名，名为空时画出姓。群画标题。隐藏来源画的是另一段显示名，已经交给链接规则。

已知用户写在 `forward_origin.type === "user"` 的 `sender_user`，旧字段是 `forward_from`。群写在 `type === "chat"` 的 `sender_chat`，旧字段是 `forward_from_chat`。名字里可以只有一条短链，正文仍是一句普通的话。

频道转发默认已经删除。频道标题仍留在事件外面。

## 决策

- 现代 `forward_origin` 存在时只读这一处。`type === "user"` 时按可见名字留主机名。`type === "chat"` 时只读 `sender_chat.title`。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 没有现代来源、也没有隐藏显示名时，改读 `forward_from`。仍没有时，`forward_from_chat.type` 不是 `channel` 才读标题。
- 已有 `forward_sender_name` 或 `type === "hidden_user"` 时，不读旁边的真实用户。隐藏显示名仍按 ADR 0091。
- `type === "channel"` 的频道标题不读。来源上的 `author_signature` 不读。`external_reply` 不读。
- 这段名字不进正文，也不改内容哈希。关键词因此不命中。用户 id、群 id 和转发时间不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`channel_forward` 仍默认删除频道转发。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 会改变哈希，关键词也会命中人名。短链只需要主机名。隐藏显示名也只留主机名，见 ADR 0091。 |
| 连频道标题一起抽 | ADR 0091 已经放弃。频道转发默认删除，标题仍留在事件外面。 |
| 连外部回复一起扫 | 外部回复是另一条消息的预览。 |
| 隐藏显示名旁边再读真实姓名 | 客户端画出的是隐藏显示名。旁边的账号不是这段抬头。 |
| 新命令 `/forwardname` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 已知用户或群的抬头里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。
- 名字原文、路径和邀请码不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。群用户名不进事件。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 频道标题、来源签名、外部回复和隐藏显示名旁边的真实姓名仍不读。
- 成员转发的频道标题后来由 ADR 0610 只留下主机名。标题本身仍不进事件。讨论组原帖的来源标题、来源签名和外部回复仍不读。
- 云额度的基础检测器名单没有改。30 天保留期没有改。
