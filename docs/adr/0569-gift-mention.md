# ADR 0569：礼物附言上的按标识提及也走同一条规则

- 状态：已接受
- 日期：2026-11-05

## 背景

ADR 0548 让礼物附言在已有别的正文时留在 `giftText`。没有别的正文时，附言成为正文。普通礼物、唯一礼物和升级购买的 `entities` 可以带 `text_mention`。用户编号不在看得见的字里。

打开 `text_mention` 的群会删掉正文上的点名，附言上的同一处仍留下。发布者用户名、贴纸和收藏名仍不能因为这次进入事件。

## 决策

- `gift.entities`、`unique_gift.entities` 和 `gift_upgrade_sent.entities` 里，`type` 正好是 `text_mention`，并且 `user.id` 是大于 0 的安全整数时，事件同样带 `asTextMention: true`。
- 缺用户、布尔值、字符串编号和 0 仍不带这个标记。发布者用户名、短名、型号、符号和背景仍不进事件。
- 用户编号、名字和用户名不进事件，也不进证据。附言看得见的字仍留在原来的字段。正文和 `textSha256` 不变。
- 仍用检测器 `text_mention`。证据仍是 `entity:text_mention`。不新增规则，不新增命令。菜单仍是 99 条。
- 规则仍默认关闭。打开之后，这三种附言上的这种提及也删除。付费帖仍不删除。`is_private` 仍不隐藏这段附言。
- 不改 ADR 0026 的基础检测器名单。`text_mention` 仍不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 连发布者用户名一起认 | 用户名不是附言上的实体。ADR 0087 已经把它留在事件外面。 |
| 另开一条规则 | 这是同一处隐藏的用户编号。分开开关会让群管开漏一处。 |
| 把用户编号写进证据 | 用户编号不进事件。 |
| `is_private` 时不标记 | 附言原文已经按 ADR 0548 交给关键词。标记跟着同一段文字。 |

## 后果

- 规则关闭时，礼物附言上的按标识提及留下。看得见的字仍参与关键词。用户编号仍不进事件。
- 打开 `text_mention` 后，普通礼物、唯一礼物和升级购买的这种附言会删除。发布者用户名仍不进事件。
- 付费帖仍留下。0 和缺用户不带这个标记。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `text_mention` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `text_mention`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
- 游戏附加文字上的按标识提及后来由 ADR 0570 也带上 `asTextMention`。封面和动图文件编号仍不进事件。
