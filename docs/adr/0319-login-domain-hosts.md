# ADR 0319：登录网站只留主机名

- 状态：已接受
- 日期：2026-11-03

## 背景

Bot API 的 `connected_website` 是用户用 Telegram 登录网站之后，附在这条消息上的域名。短链可以只放在这个域名上，正文仍是普通句子。链接规则现在看不到它。

域名不是用户写下的句子。把它整段放进事件会把登录网站写进内容哈希。

## 决策

- 从 `connected_website` 抽出网址，只留主机名。解析、折叠、邀请判断和 8 个主机名的上限与别的旁路字段相同。
- 域名不进入 `message.text`，也不参与内容哈希。没有别的正文时，正文仍是空字符串。
- 不读取 `chat.title`、`chat.description` 和用户姓名。路径不进证据。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 这个域名不读 | `bit.ly` 会漏掉。正文可以是日常句子。 |
| 域名成为正文 | 登录网站会进内容哈希。它不是这条消息看得见的字。 |
| 每条消息都扫用户资料里的网站 | 这个字段只出现在登录之后的消息上。 |

## 后果

- 已有正文时，登录域名里的短链仍删除。正文和哈希不变。路径不进事件。
- 没有正文时，正文仍是空字符串。普通域名留下主机名，不按短链删除。
- 裸 `t.me` 只留主机名，不算邀请。群名和发送者姓名里的短链仍不读。
- 云额度的基础检测器名单没有改。
