# ADR 0712：自动引用画出的摘录只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

回复带摘录时，Android 把 `quote_text` 整段画在引用条上，再按宽度截断。有摘录时不再画被回复消息的说明或正文。服务器附上的自动引用同样画这行。手动选中的摘录已经只留主机名。

ADR 0085 不读自动引用，避免回复别人的短链时把自己的消息删掉。这行现在确实画在这条消息上。ADR 0711 已经按同一条引用条读取没有摘录时画出的说明和正文。

## 决策

- `quote.text` 是字符串时，从这段摘录和 `quote.entities` 里的文字链接留主机名。`is_manual` 不是 `true` 时也读。
- 自动引用不进 `quoteText`，也不进正文，也不改内容哈希。关键词因此不命中。
- 有摘录时不改读被回复消息的说明或正文。外部回复上的摘录不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 自动引用仍不读 | 引用条画的就是这段摘录。没有摘录时，同一行的说明和正文已经只留主机名。 |
| 把自动引用收进 `quoteText` | 那是别人写的句子。关键词仍只看这条消息自己的正文和手动引用。 |
| 只读前 150 个码元 | 客户端先排整段摘录，再按宽度截断。手动引用也读整段。 |
| 外部回复上的摘录也读 | 这条消息的引用条不画那份摘录。 |

## 后果

- 自动引用里的短链会删除这条消息。证据只有主机名。
- 摘录原文、路径和位置不进事件。关键词不命中摘录。
- 有摘录时，被回复消息里没被摘出来的短链不删除。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 自动引用上的文字链接后来由 ADR 0732 要求起点小于摘录。手动引用同样要求。投票描述、游戏说明和礼物仍不在那条里。
