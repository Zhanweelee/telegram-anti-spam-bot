# ADR 0769：礼物附言上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。礼物附言上的文字链接，起点必须落在附言里。见 ADR 0734。引用上的文字链接，长度必须大于 0。见 ADR 0768。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达附言末尾的实体。起点落在附言里、长度越过末尾时，客户端把长度收到附言末尾，这段链接仍会画出来。普通礼物、唯一礼物和升级购买的附言都走这一步。

已有别的正文时，事件里的附言只留前 128 字。附言自己就是正文时，事件正文只留前 4096 字，不再另留附言。链接仍按整段附言判断。写在附言里的普通网址仍从整段附言抽取。

现在附言只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在附言里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条礼物消息。代码块语言里的网址也走同一段实体。

游戏附加文字不在这条里。

## 决策

- `gift`、`unique_gift` 和 `gift_upgrade_sent` 的附言是字符串时，`entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于附言长度，长度必须是大于 0 的安全整数。
- 起点落在附言里、长度越过末尾时，仍留下主机名。
- 附言不是字符串时，仍按原来的方式读取。
- 已有别的正文时，第 129 字上的链接，只要起点仍落在附言里、长度大于 0，就继续留下主机名。事件里的附言仍只留前 128 字。
- 附言自己就是正文时，第 4097 字上的链接，只要起点仍落在附言里、长度大于 0，就继续留下主机名。事件正文仍只留前 4096 字，不再另留附言。
- 写在附言里的普通网址仍从整段附言抽取。仍只留主机名。顺序仍是普通礼物、唯一礼物、升级购买。
- 游戏附加文字上的 `text_entities` 不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条礼物消息。 |
| 也要求长度落在附言里 | 起点在附言里时，客户端会把越过末尾的长度收回来再画。 |
| 只改普通礼物 | 唯一礼物和升级购买的附言也用同一套实体画出来。 |
| 游戏附加文字一起改 | 附加文字是另一段文字。这条只改礼物附言。 |

## 后果

- 附言上长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在附言里、长度越过末尾的短链、邀请或裸 IP 仍删除。起点已经超过 128 或 4096、但仍落在附言里的链接也删除。证据只有主机名。
- 写在附言里的普通网址仍会删除。被截断的路径不进事件。
- 附言不是字符串时，文字链接后来由 ADR 0794 不再读取。按标识提及和自定义表情仍按原来的方式读取。
- 游戏附加文字上的文字链接后来由 ADR 0770 要求长度大于 0。附加文字不是字符串时仍按原来的方式读取。长度越过末尾时仍算画出来。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
