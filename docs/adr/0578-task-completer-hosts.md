# ADR 0578：清单任务完成者的名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

清单任务可以标成完成。客户端在任务旁边画出完成者的名字。用户画出名，名为空时画出姓。群或频道画出标题。

这个名字写在 `checklist.tasks` 和 `checklist_tasks_added.tasks` 的 `completed_by_user` 或 `completed_by_chat`。任务文字已经交给链接规则。名字本身还没有。广告可以把短链写进这个名字。

标成完成或取消完成的服务消息只带任务编号。原清单在嵌套的 `checklist_message` 里，那是另一条消息。

## 决策

- `completed_by_user` 是对象，且 `first_name` 的长度大于 0 时，从这段名抽出网址，只留主机名。空白也算有名。长度、折叠、邀请判断和 8 个主机名的上限不变。抽出之前不截断。
- `first_name` 缺失或正好是空字符串，且 `last_name` 的长度大于 0 时，改从姓里留主机名。名是空白或不是字符串时不读姓。
- 没有用户对象时，`completed_by_chat.title` 只留主机名。群用户名不读。
- 用户对象和群对象同时存在时只读用户。有名时不读姓，也不读群标题。
- 这段名字不进正文，也不改内容哈希。关键词因此不命中。
- 用户名、用户 id、群 id、任务 id 和 `completion_date` 不读。
- 同一条消息上的清单任务和新加任务都读。嵌套的 `checklist_message` 不读。`checklist_tasks_done` 上没有完成者字段。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 会改变哈希，关键词也会命中人名。短链只需要主机名。投票选项添加者的名字也只留主机名，见 ADR 0577。 |
| 连用户名一起抽 | 客户端画出的是名或标题，不是用户名。 |
| 姓只要存在就读 | 名为空时才画姓。空白也算有名。 |
| 连嵌套的原清单一起扫 | `checklist_message` 是另一条消息。原消息发出时已经扫过。 |
| 新命令 `/completer` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 画出的名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。
- 名字原文、路径和邀请码不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓、用户名和群标题不进事件。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 云额度的基础检测器名单没有改。30 天保留期没有改。
