# ADR 0119：视频聊天邀请的可见名字命中就删除

- 状态：已接受
- 日期：2026-11-02

## 背景

有人把别人拉进视频聊天时，群里会出现一条服务消息，上面是被邀请者的昵称、姓氏和用户名。这条消息通常没有 `text`。名字里的短链或关键词会留在群里。

通话开始、结束和预约只有时间或时长，没有这段看得见的名字。

## 决策

- `video_chat_participants_invited.users` 里每个用户的 `first_name`、`last_name`、`username` 按 ADR 0118 的同一套规则处理：去掉首尾空白，用一个普通空格拼起来，最长 4096 字符。
- 没有更前面的正文时，这段名字成为正文。关键词和链接规则因此能删除这条服务消息。
- 已有正文时，名字只贡献主机名。
- 不读取用户 id、`language_code`，也不读取 `video_chat_scheduled`、`video_chat_started` 和 `video_chat_ended`。
- 不新增检测器，不加新的默认规则。不改 ADR 0026 的默认次数、周期和基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 名字永远只留主机名 | 关键词广告名会留在邀请行上。 |
| 读取通话时长 | 时长不是广告。 |
| 把邀请者的 `from` 姓名也送进去 | 普通发言者的姓名仍不进事件。 |

## 后果

- 可见名字里的默认关键词、短链或邀请会删掉这条邀请服务消息。证据仍只有关键词或主机名。
- `example.com` 和普通名字留着。
- 通话结束的服务消息仍是空正文。
- 某个群后来可以打开 `call_notice` 删除开始、结束和预约。时长和开始时间仍不进事件。邀请名单仍按可见名字成为正文。见 ADR 0475。
- 群主变更上的新群主名字后来由 ADR 0120 按同一套规则删除。没有下一位时仍不读。
