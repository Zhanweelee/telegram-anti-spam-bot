# ADR 0723：富文本预览不读语音

- 状态：已接受
- 日期：2026-11-07

## 背景

置顶提示和引用条上的富文本预览来自 `formatRichMessage`。语音块对应 HTML 的 `audio`，Bot API 类型是 `voice_note`。`formatRichBlock` 不画这个块，也不画它的说明。

预览把语音当成固定说法，占满剩下的窗口。后面画出来的短链就被挡住，没有留在主机名里。

ADR 0714 的固定说法是图片、视频、动图、拼图、幻灯片、地图和公式。语音不在这份名单里。动图仍占满窗口。

## 决策

- 置顶提示和引用条的富文本预览不读 `voice_note`。说明不读。后面的块仍按原来的预览规则读取。
- 语音前后的块之间仍留两个空格。语音自己不占码元。
- 气泡里的整篇文章仍不把语音文件读进主机名。
- 图片、视频、动图、拼图、幻灯片、地图和公式仍占满剩下的窗口。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续占满窗口 | 语音后面画出来的短链会被漏掉。 |
| 改读语音说明 | 这条预览不画说明。没画出来的地址会被删掉。 |
| 动图也改成不占位 | 动图对应视频。固定说法的长度随语言变，仍按 ADR 0714 占满。 |

## 后果

- 语音后面的短链、邀请或裸 IP 会删除这条消息。证据只有主机名。语音说明和文件编号不进事件。
- 预览不进正文。内容哈希不变。关键词不命中预览。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- `pin_notice` 仍默认关闭。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
