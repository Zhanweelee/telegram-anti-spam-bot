# ADR 0594：动社区的人，名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

群被移入社区、自己加入，或移出社区时，客户端把这个人的名字画在服务消息上。名字写在 `from`。移入和加入的社区名字当时只留主机名，不进正文。见 ADR 0115。移出目前不带社区名字。短链可以只写在这个人的名字里。

把 `from` 收成正文会让普通发言者的姓名也进检测。`community_notice` 默认关闭，干净的提示仍留下。社区编号仍不读。移出对象上的其它字段仍不抽主机名。没有社区对象的移入或加入仍不是这条提示。

## 决策

- 只在已经会标成 `community` 的提示上，从 `from` 的可见名字留主机名。移入和加入要有社区对象。移出只要是对象，空对象也读。几种同时出现时仍先认移入，再认加入，再认移出。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 移入和加入的社区名字仍按 ADR 0115 只留主机名。名字不进正文，也不改内容哈希。关键词因此不命中。社区编号不读。移出对象上的其它字段不读。本群群名不读。
- 没有社区对象的移入或加入不读发送者。普通消息不读 `from`。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`community_notice` 仍默认关闭。8 个主机名的上限不变。不把群移出社区。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 关键词会命中人名。普通消息的 `from` 也会被打开。见 ADR 0115。 |
| 移出不读发送者 | 移出同样画出这个人。社区名字不在时，名字里仍可以有短链。 |
| 从移出对象里抽主机名 | 移出服务消息目前不带社区名字。见 ADR 0115。 |
| 新命令 `/communityname` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 移入、加入或移出社区的人，名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。群是否留在社区不变。
- 名字原文、路径和用户名不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。社区名字原文和社区编号仍不进事件。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 没有社区对象的移入或加入，以及普通消息，仍不读发送者。移出对象上的其它字段仍不读。本群群名仍不读。干净的提示在 `community_notice` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
- 加入后来按全名只留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。见 ADR 0636。移入和移出后来按短名，从下标 2 起的第一个空格后面不读。见 ADR 0658。自己加入时这行不画自己，现有条件仍读 `from`。
