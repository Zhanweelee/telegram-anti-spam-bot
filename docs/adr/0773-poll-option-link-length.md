# ADR 0773：投票选项上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。投票选项上的文字链接，起点必须落在这条选项文字里。见 ADR 0729。投票描述上的文字链接，长度必须大于 0。见 ADR 0772。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达选项末尾的实体。起点落在选项里、长度越过末尾时，客户端把长度收到选项末尾，这段链接仍会画出来。每个选项单独画。拼起来的 `pollOption` 不改变这条选项上的起点。

已有别的正文时，几个选项用一个普通空格拼起来，事件里只留前 1211 字。选项和正文相同、不再另留时，事件正文只留前 4096 字。链接仍按每一条选项判断。写在选项里的普通网址仍从整段原文抽取，包括第 1212 字起，也包括拼进去之后被截掉的后面几条。

现在选项只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在选项里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条投票。代码块语言里的网址也走同一段实体。

清单任务、后加或删除的选项，以及回复某一条选项时画出的那一行，不在这条里。

## 决策

- `poll.options[].text` 是字符串时，`text_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于这条选项的长度，长度必须是大于 0 的安全整数。
- 起点落在这条选项里、长度越过末尾时，仍留下主机名。
- 选项文字不是字符串时，仍按原来的方式读取。
- 已有别的正文时，第 1212 字上的链接，只要起点仍落在这条选项里、长度大于 0，就继续留下主机名。后面几条选项被截出 `pollOption` 时也一样。事件里的选项仍只留前 1211 字。
- 选项和正文相同、不再另留选项时，第 4097 字上的链接，只要起点仍落在这条选项里、长度大于 0，就继续留下主机名。事件正文仍只留前 4096 字。
- 写在选项里的普通网址仍从整段原文抽取，包括第 1212 字起。仍只留主机名。
- 清单任务、后加或删除的选项，以及回复某一条选项时画出的那一行，不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条投票。 |
| 也要求长度落在选项里 | 起点在选项里时，客户端会把越过末尾的长度收回来再画。 |
| 也按 1211 字丢掉后面的链接 | 1211 只是旁边选项的上限。整段选项更长时，后面的链接仍落在这条选项里。 |
| 清单任务一起改 | 任务是另一段文字。这条只改投票气泡上的选项。 |

## 后果

- 选项上长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在选项里、长度越过末尾的短链、邀请或裸 IP 仍删除。起点已经超过 1211 或 4096、但仍落在这条选项里的链接也删除。被截出 `pollOption` 的后面几条选项也删除。证据只有主机名。
- 写在选项里的普通网址仍会删除，包括第 1212 字起。被截断的路径不进事件。
- 选项文字不是字符串时，文字链接后来由 ADR 0789 不再读取。按标识提及和自定义表情仍按原来的方式读取。
- 清单任务上的文字链接后来由 ADR 0774 要求长度大于 0。任务文字不是字符串时，文字链接后来由 ADR 0788 不再读取。长度越过末尾时仍算画出来。后加选项不在那条里。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
