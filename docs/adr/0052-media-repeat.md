# ADR 0052：无正文的文件参加重复判断

- 状态：已接受
- 日期：2026-11-01

## 背景

ADR 0010 让空正文不参加 `repeat`。贴纸、动图和没有说明的图片因此可以反复发送。把 `file_id` 或文件名放进事件会把平台标识带进日志和审计。

## 决策

- `message.media` 只取一个类别：`sticker`、`animation`、`video`、`video_note`、`voice`、`audio`、`document`、`photo`。同时出现时按这个顺序取第一个。
- 能读到长度在 1 到 256 的 `file_unique_id` 时，再写 `mediaSha256`。摘要是类别和这份 id 的 sha256。id、文件名和贴纸包标题不进事件。
- 过长或缺失的 id 只留类别，不写摘要。
- `repeat` 在正文非空时仍用 `textSha256`。正文为空时用 `mediaSha256`。两者都没有则跳过。证据仍是 `repeat:N`。
- 不新增检测器，也不改 ADR 0026 的基础检测器名单。`repeat` 本来就在这份名单里。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删除每一种贴纸 | 正常群聊会大量使用贴纸。重复三次再删，误伤更小。 |
| 另做一个 `media` 检测器并默认关闭 | 操作者要先发现并打开它。同一条 `repeat` 已经默认开启。 |
| 把 `file_unique_id` 原样放进事件 | 审计和日志会带上平台文件标识。 |

## 后果

- 60 秒内同一份文件出现 3 次，且没有正文时，现有 `repeat` 规则会删除。
- 不同文件各自计数。只有类别、没有摘要的消息仍不参加重复。
- 有说明文字的图片仍按说明文字计重复，不按文件摘要。
- 云额度的基础检测器名单不变。
