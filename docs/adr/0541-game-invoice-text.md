# ADR 0541：游戏说明和账单说明也走关键词和默认正则

- 状态：已接受
- 日期：2026-11-05

## 背景

ADR 0058 让游戏标题和账单标题成为正文，并明确不读说明和附加文字。ADR 0078 只从 `game.description`、`game.text` 和 `invoice.description` 抽出主机名。标题干净时，「免费领取」和「加微x」可以整段留在说明或附加文字上。短链仍会删除，关键词看不见。

Bot API 写明 `game.text` 是 0 到 4096 字，账单 `description` 是 1 到 255 字。收到的 `game.description` 没有写长度。两段游戏文字各自截到 4096。

## 决策

- 已有别的正文，且游戏说明或附加文字去掉两端空白后仍有字时，事件另留 `gameText`。先说明，再附加文字，中间一个普通空格。两段各自只留前 4096 字，合起来最多 8193 字。这段文字自己就是正文时不设这个字段。正文和 `textSha256` 仍按 ADR 0058，标题优先。
- 已有别的正文，且账单说明去掉两端空白后仍有字时，事件另留 `invoiceText`。只留前 255 字。说明自己就是正文时不设这个字段。
- 第 4097 字和第 256 字起不进事件。主机名仍从整段说明和附加文字抽取，包括被截掉的尾巴。
- 封面、`file_id`、动图文件名、币种、金额和 `start_parameter` 不进这两个字段。
- 关键词和 `regex` 同时看正文、`senderTag`、`buttonText`、`authorSignature`、`mirrorSignature`、`pollOption`、`checklistTask`、`mediaName`、`performer`、`gameText`、`invoiceText` 和 `profile`。证据仍是原来的摘要。说明原文不进证据，也不进日志。
- `regex` 命中时带上 `places`，只写命中的字段名。`gameText` 和 `invoiceText` 加入这份名单。`game_text_regex` 只在 `places` 含有 `gameText` 时算命中。`invoice_text_regex` 只认 `invoiceText`。检测器没有 `places` 时仍按分数。
- 规则条件增加 `gameText: true` 和 `invoiceText: true`。消息上有对应字段时为真。
- 新规则 `game_text_regex` 和 `invoice_text_regex` 默认打开。条件是各自的字段，检测器是现有的 `regex`，命中后 `delete`。
- 「免费领取」和「加微信」仍走已经打开的关键词规则。
- `regex_hint` 仍默认关闭。正文里的「加微x」不会因为旁边有干净的说明就被删掉。
- 不改 ADR 0026 的基础检测器名单。`keyword` 和 `regex` 已经在里面，超额后这两条仍会跑。
- `chats.json` 整份替换的群不会自动带上这两条规则。
- 不新增命令。菜单仍是 99 条。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认打开 `regex_hint` | 普通消息会被同一份模式删除。这次要读的是标题旁边的说明。 |
| 把说明拼进标题 | 会改变 `textSha256`。ADR 0058 已经拒绝。 |
| 游戏和账单共用一个字段 | 长度上限不一样。关掉其中一种时，另一种还要留着。 |
| 给说明单独做一个检测器 | 关键词和正则已经会扫旁路字段。名单不用再加一项。 |

## 后果

- 游戏说明、附加文字或账单说明含「免费领取」或「加微信」时按关键词删除。含 `t.me/+`、「加微x」或「加微X」时按对应规则删除。证据不含说明原文。
- 说明干净时消息留下。说明自己就是正文时，「加微x」仍要打开 `regex_hint`。
- 游戏两段各自从第 4097 个字符起不进事件。账单说明从第 256 个字符起不进事件。主机名仍从整段抽取。写在说明里的路径会留在字段里，不进审计。
- 附加文字上的文字链接后来由 ADR 0733 要求起点小于 `game.text`。附加文字里直接写出的网址仍从整段抽取。
- 封面、文件 id、动图文件名、币种、金额和启动参数仍不进这两个字段。
- 关掉其中一条规则后，那种说明回到只看关键词和短链。另一条不受影响。
- 整份替换规则的群要自己加上这两条，才会删除说明上的「加微x」。
- 30 天保留期没有改。
- `places` 后来由 ADR 0542 加上 `venueAddress`。地点地址的规则只认自己的字段。
