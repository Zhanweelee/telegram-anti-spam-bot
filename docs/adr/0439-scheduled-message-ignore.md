# ADR 0439：还没发出的消息先忽略

- 状态：已接受
- 日期：2026-11-04

## 背景

大群里的视频有时会先变成一条 `message_id` 为 0 的更新。Bot API 写明这条消息还不能用，真正发出时会再来一条带正常编号的更新。现在这条占位更新仍会读正文、计入洪泛，并尝试删除编号 0。删除会被平台拒绝。

临时消息的公开编号也是 0，但真正的编号在 `ephemeral_message_id`。那条路径仍按 ADR 0125。

## 决策

- `message` 和 `edited_message` 的公开 `message_id` 是 0，且没有正整数 `ephemeral_message_id` 时，在读取正文、主机名和摘要之前忽略。
- 有正整数临时编号、但没有接收者时，仍用公开编号 0。这是 ADR 0125 已经接受的路径。
- 临时编号和接收者都是正整数时，仍用临时编号。
- 占位更新的正文不进事件，也不进日志。不新增命令。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续按编号 0 删除 | 平台会拒绝。这条消息用户还看不见，洪泛却已经计数。 |
| 连没有接收者的临时消息一起忽略 | ADR 0125 仍要按公开编号尝试删除。 |
| 先把占位更新存下来，等真正的编号再合并 | 编号和正文都不能落盘。真正发出时会有一条新更新。 |

## 后果

- 还没发出的视频不占洪泛名额。真正发出后按那条新更新审核。
- 没有接收者的临时消息仍是编号 0，平台可能拒绝删除。
- 30 天保留期不动。
