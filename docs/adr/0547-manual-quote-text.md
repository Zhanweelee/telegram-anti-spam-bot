# ADR 0547：手动引用也走关键词和默认正则

- 状态：已接受
- 日期：2026-11-05

## 背景

ADR 0061 在没有更前面的正文时，用手动引用当正文。ADR 0085 在已有正文时只从这段引用抽出主机名。被别的正文挤开时，「免费领取」和「加微x」仍整段留在外面。短链会删，关键词看不见。这段文字是发送者自己选中的。

Bot API 的 `TextQuote.text` 没有写长度。正文回退本来就截到 4096。自动引用和被回复的原消息是别人写的，仍不进事件。

## 决策

- 已有别的正文时，`quote.is_manual === true` 的 `quote.text` 去掉两端空白后仍有字，且自己不是正文时，另留前 4096 字。这段自己就是正文时不设这个字段。
- 字段名是 `quoteText`。正文和 `textSha256` 仍按 ADR 0061，没有更前面的正文时这段成为正文。
- 第 4097 字起不进事件。主机名仍从整段引用抽取，包括被截掉的尾巴。
- 自动引用、`reply_to_message`、`external_reply`、`position` 和引用上的实体不进这个字段。自定义表情编号和被点名的用户不进事件。
- 关键词和 `regex` 同时看正文、`senderTag`、`buttonText`、`authorSignature`、`mirrorSignature`、`pollOption`、`checklistTask`、`mediaName`、`performer`、`gameText`、`invoiceText`、`venueAddress`、`pollExplanation`、`pollQuestion`、`prizeText`、`checklistTitle`、`gameTitle`、`invoiceTitle`、`venueTitle`、`webAppButtonText`、`quoteText` 和 `profile`。证据仍是原来的摘要。引用原文不进证据，也不进日志。审计仍只留 `textSha256`。
- `regex` 命中时带上 `places`。`quoteText` 加入这份名单。`quote_text_regex` 只在 `places` 含有这个字段时算命中。检测器没有 `places` 时仍按分数。
- 规则条件增加 `quoteText: true`。消息上有这个字段时为真。
- 规则默认打开。条件是这个字段，检测器是现有的 `regex`，命中后 `delete`。
- 「免费领取」和「加微信」仍走已经打开的关键词规则。
- `regex_hint` 仍默认关闭。正文里的「加微x」不会因为旁边有干净的引用就被删掉。
- 不改 ADR 0026 的基础检测器名单。`keyword` 和 `regex` 已经在里面，超额后这条仍会跑。
- `chats.json` 整份替换的群不会自动带上这条规则。
- 不新增命令。菜单仍是 99 条。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认打开 `regex_hint` | 普通消息会被同一份模式删除。这次要读的是被别的正文挤开的手动引用。 |
| 把引用拼进已有正文 | 会改变 `textSha256`。ADR 0061 和 ADR 0085 已经拒绝。 |
| 自动引用也收进字段 | 回复别人的消息时，自己的正文会因为别人的句子被删掉。 |
| 按客户端常见的 1024 字截断 | 官方类型没有写这个上限。截到 1024 会漏掉后面的关键词。正文回退已经用 4096。 |
| 连 `reply_to_message` 一起收 | 那是上一条消息，不是这一条要审的正文。 |

## 后果

- 手动引用含「免费领取」或「加微信」时按关键词删除。含 `t.me/+`、「加微x」或「加微X」时按 `quote_text_regex` 删除。证据不含引用原文。
- 引用干净时消息留下。它自己就是正文时，「加微x」仍要打开 `regex_hint`。
- 第 4097 字起不进事件。主机名仍从整段抽取。写在引用里的路径会留在这个字段，不进审计。
- 自动引用、被回复的原消息、位置和实体仍不进事件。
- 关掉 `quote_text_regex` 后，这种引用回到只看关键词和短链。别的旁路字段不受影响。
- 整份替换规则的群要自己加上这条，才会删除引用上的「加微x」。
- 30 天保留期没有改。
- `places` 后来由 ADR 0548 加上 `giftText`。礼物附言的规则只认自己的字段。
- 回复抬头上画出的名字后来由 ADR 0699 只留主机名。被回复的原文仍不进事件。外部回复仍不读。外部来源上画出的名字后来由 ADR 0700 只留主机名。预览仍不进事件。回复某一条清单任务或投票选项时，画出来的那一行后来由 ADR 0702 只留主机名。回复一条游戏或账单时，画出来的标题后来由 ADR 0703 只留主机名。外部回复上画出的文件名、清单标题和账单说明后来由 ADR 0704 只留主机名。回复一条没有说明的普通文件时，画出的文件名后来由 ADR 0705 只留主机名。
