# ADR 0269：隐藏草稿里的裸 IP 仍留下主机名

- 状态：已接受
- 日期：2026-11-03

## 背景

Android 在没有协议时也会打开点分 IPv4。分享草稿和用户名草稿里的这段地址会进高亮。

看得见的正文已经按这套规则抽出地址。隐藏的 `text_link` 只认带协议或字母结尾的网址，裸 IP 会漏掉。写在路径里的地址仍属于前一条网址，不能另算。

第一段是 `0` 的四段数字，Android 不把它当地址。

## 决策

- 分享 `text`、分享 `url`、私聊预填 `tg://msg` 的 `text` 和用户名草稿的 `text`，按 Android 的点分 IPv4 抽出主机名。
- 地址可以带 1 到 5 位端口，以及 `/` 或 `?` 后面的路径。路径不进证据。
- 第一段是 `0` 的四段数字不抽。
- 已经属于另一条网址路径的地址不另算。
- 查询值不进入正文，也不参与关键词。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 只认带协议的地址 | 草稿里的裸 IP 会漏。 |
| 任意四段数字都抽 | 第一段是 `0` 时，Android 不会打开。 |
| 路径里的地址也抽 | 它仍属于前一条网址。 |

## 后果

- `t.me/share/url?text=203.0.113.236/…` 和 `url=` 里同样的地址删除。证据仍只有主机名。
- `https://example.com/203.0.113.236/…` 留着。
- `0.0.0.1` 留着。
- 用户名超过 64 或密码超过 25 时，后面的短链后来同样留下。见 ADR 0270。
