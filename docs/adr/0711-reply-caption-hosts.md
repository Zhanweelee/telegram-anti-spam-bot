# ADR 0711：引用条上的说明和正文只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

任务、选项、引用、投票、外部媒体、话题名、游戏、账单、清单标题、骰子、贴纸和文件名都没有占住引用条时，Android 画出被回复消息的说明。没有说明时改画正文。两段都只取前 150 个 UTF-16 码元，并把换行画成空格。文字链接的起点落在这段里才会画出来。

这行画在普通消息的气泡上。服务公告走另一块，不画被回复的说明或正文。

ADR 0547 不把被回复的原文收进事件，关键词也不看它。短链可以只写在这 150 个码元里。

## 决策

- 当前消息有正文、说明或普通媒体，前面的引用条都没有占住，且 `reply_to_message.caption` 的长度大于 0 时，从前 150 个码元留主机名。`caption_entities` 里 `offset` 小于 150 的文字链接也读。
- 没有说明时，改从 `reply_to_message.text` 的前 150 个码元留主机名。`entities` 里 `offset` 小于 150 的文字链接也读。
- 服务公告不读这行。有引用或投票时不改读。
- 说明和正文仍不进事件，也不改内容哈希。关键词因此不命中。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 服务公告也读被回复的正文 | 公告气泡不画这行。 |
| 150 个码元之后也读 | 客户端只把前 150 个码元放进这一行。 |
| 把说明或正文收进事件 | ADR 0547 已经拒绝。关键词仍只看这条消息自己的正文。 |
| 有文件名时不读说明 | 有说明时引用条画的是说明，不再画文件名。 |

## 后果

- 普通回复的引用条上，说明或正文前 150 个码元里的短链会删除这条回复。证据只有主机名。
- 第 151 个码元起不读。起点落在外面的文字链接不读。
- 服务公告仍不因被回复的正文删掉。原文不进事件。关键词不命中这行。没有正文和说明的富文本后来由 ADR 0713 也读这行。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
