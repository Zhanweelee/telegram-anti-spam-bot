# ADR 0110：游戏动图文件名只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0078 和 ADR 0082 从游戏标题、说明和附加文字抽出主机名。游戏还可以带一条动图。动图的 `file_name` 是发送者写的文件名，可以只放短链或邀请。标题和说明是普通句子时，链接规则看不到这个文件名。

封面是一组照片尺寸，没有文件名。动图的 `file_id` 和 `mime_type` 也不是给群成员看的链接。

## 决策

- 从 `game.animation.file_name` 抽出网址，只留主机名。折叠、长度、邀请判断和 8 个主机名的上限与旁路纯文本相同。
- 文件名不进入 `message.text`，也不参与内容哈希。已有正文时正文不变。没有 `text` 时，标题仍按 ADR 0058 成为正文。
- 不读取封面、`file_id`、`mime_type`、宽高和时长。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把文件名拼进正文 | 同一条消息的哈希会变，路径也会进事件。 |
| 只在没有标题时才扫描 | 游戏标题几乎总在。短链可以只写在文件名上。 |
| 连封面文件 id 和 MIME 类型一起读 | 那不是网址。 |

## 后果

- 标题或正文是另一句普通的话时，动图文件名里的短链、邀请或裸 IP 按现有链接规则命中。路径和邀请码不进事件。
- 标题仍是没有更前面正文时的正文。文件名里的关键词仍然看不到。
- 封面、文件 id 和 MIME 类型不进事件。
