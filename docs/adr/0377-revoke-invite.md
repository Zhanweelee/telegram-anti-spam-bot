# ADR 0377：私聊可以撤销机器人自己的邀请链接

- 状态：已接受
- 日期：2026-11-04

## 背景

泄漏的 `t.me/+` 链接是突袭进群的入口。管理员要在私聊里把机器人自己发出的那条作废，并且只花一次子请求。

官方 `revokeChatInviteLink` 撤销机器人创建的一条邀请链接。bot 必须是管理员，并有相应权限。成功时返回被撤销的 `ChatInviteLink`。主链接被撤销后，Telegram 会另生成一条主链接。这个结果是旧链接，不是新链接。别人创建的链接，机器人撤不掉。

返回对象里有链接、创建者和可选名称。这些都不能进回复或日志。命令参数本身就是这条链接，日志也不能记下原文。

没有 token 时，内存适配器可以把这次请求记下来。私聊如果复用这次成功，回复会写成链接已经作废。内存记录如果留下链接，就等于把秘密存了下来。

## 决策

- 私聊命令 `/revoke <chatId> <inviteLink>`。群 id 匹配 `^-?\d{1,20}$`。群聊里的同样文本不执行。
- 链接必须是 `t.me`、`telegram.me` 或 `telegram.dog` 上的 `+` 邀请或 `joinchat` 邀请，长度 16 到 128。`http`、`www` 和大写主机收成 `https` 加上小写主机。`joinchat.t.me/码` 收成 `https://t.me/joinchat/码`。邀请码的大小写保持原样。全数字的加号路径、文件夹链接、用户名和其它网址回复「参数无效」，并且不调用端口。
- 配置中的管理员可以操作任意群。接入目录里的人只能操作自己的群。
- 命令调用 `ModerationPort.revokeInvite`，带 tenant、chat 和收好的链接。适配器调用 `revokeChatInviteLink`。不像邀请的字符串在发出请求前失败。返回的链接、创建者和名称丢掉。
- 回复只说明这是机器人自己发的链接，别人发的撤不掉，新的主链接不在这条回复里。回复不包含链接。
- 没有 token、没有这个方法，或调用失败时回复「参数无效」。日志只写 `operator_rejected`，带上 eventId、chatId 和命令名。不写异常文本、token 或链接。
- 没有 token 的 Worker 不把内存里的记录回复成已经成功。内存记录只留 tenant 和 chat。
- 不修改黑名单、白名单、封禁或禁言。不读取消息正文。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 调用 `exportChatInviteLink` 轮换主链接 | 它只轮换机器人自己的主链接，并且把新链接作为字符串返回。别人泄漏的附加链接还在，回复也更容易带上新秘密。 |
| 原样保存或回显链接 | 命令参数就是邀请码。日志、回复和内存记录再写一遍，等于把入口留下来。 |
| 把 Telegram 返回的新主链接告诉管理员 | 成功结果是被撤销的旧链接。新链接不在这个结果里。 |
| 接受任意字符串再交给 Telegram | `请免费领取礼品` 这类参数会离开 Worker。先在本地拒绝。 |

## 后果

- 成功只表示 Telegram 接受了这一次 `revokeChatInviteLink`。别人创建的链接、普通群以外的聊天，或 bot 缺少相应权限时，回复是「参数无效」。
- 主链接被撤后，Telegram 会另给一条。这条命令不显示它。
- 一次撤销是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
