# ADR 0494：投票选项增删按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

投票允许补选项时，`poll_option_added` 带上新选项文字。删掉选项时，`poll_option_deleted` 仍带上那段文字。没有别的正文时，这段文字已经按 ADR 0089 成为正文。文字干净时这行会留下。原投票在 `poll_message` 里，是另一条消息。选项编号不是广告。把它并进投票题干会违反 ADR 0056：题干已经是正文，投票本身不另做检测器。

## 决策

- `poll_option_added.option_text` 是非空字符串时，事件带 `pollNotice: "added"`。`poll_option_deleted.option_text` 满足同样条件时带 `deleted`。同时出现时先认新加。空字符串落到另一种。不写选项编号，也不写原投票。
- 选项文字仍按 ADR 0089 成为正文。已有正文时正文不变。
- 空对象、布尔值和空字符串不带这个标记。投票题干不带这个标记。
- 检测器在 `@tasb/detector-poll`，id 是 `poll_notice`。`message.pollNotice` 是新加或删除时返回 score 1。证据是 `poll:added` 或 `poll:deleted`。
- 默认规则关闭。私聊 `/rule <chatId> poll_notice on` 之后删除这两种提示，`off` 回到留下。
- 不调用 `stopPoll`。投票本身还在。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`poll_notice` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认打开 | 正常补选项会被删掉。群要自己打开。 |
| 给投票题干做一个检测器 | ADR 0056 已经拒绝。题干仍是正文。 |
| 把选项编号写进证据 | 编号不是广告。文字仍留在正文里。 |
| 新命令 `/poll` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，后加和删除选项都留下。文字干净时关键词仍看不见这行，除非文字里本身有关键词或短链。
- 打开 `poll_notice` 后，这个群里的这两种提示会删除。投票题干仍只靠正文。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `poll_notice` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `poll_notice`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
- 加选项或删选项的人后来由 ADR 0604 只留下主机名。名字本身仍不进事件。空白文字也读。空字符串落到另一种。空对象和布尔值仍不读发送者。选项文字仍按原来的正文。嵌套原投票仍不读。
