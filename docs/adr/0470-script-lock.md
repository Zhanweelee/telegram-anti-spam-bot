# ADR 0470：阿拉伯文和西里尔文按群删除

- 状态：已接受
- 日期：2026-11-04

## 背景

关键词和短链对不上时，整段阿拉伯文或西里尔文广告会留在群里。中文群里这是常见的一种垃圾。正文已经在事件里，不需要再从 Telegram 抽一个新字段。

阿拉伯语群和俄语群会正常使用这两种字母。默认不能删。

## 决策

- 检测器在 `@tasb/detector-script`。两种各一个 id：`script_arabic`、`script_cyrillic`。
- 只看 `message` 的正文。字母用 Unicode 的 `Script=Arabic` 或 `Script=Cyrillic`，并且类别是字母。数字、音标、标点和表情不计。比较前不做关键词那套折叠，所以西里尔形近字母仍算西里尔。
- 这种字母至少 4 个，并且多于其它字母合在一起，才返回 score 1。两边一样多时留下。证据是 `script:arabic` 或 `script:cyrillic`。正文不进证据。
- 默认规则用同样的 id，全部关闭。某个群用现有的私聊 `/rule` 打开一种，就只删除这一种。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。这两个 id 都不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉阿拉伯文和西里尔文 | 这两种语言的群会被清空。打开之前不改现有群。 |
| 两种合成一个开关 | 只想挡住阿拉伯文广告的群会把俄语一起删掉。 |
| 出现一个字母就删除 | 中文句子里夹一个形近字母也会被删。 |
| 新命令 `/script` | 菜单只剩一个空位。现有 `/rule` 已经能打开一条规则。 |

## 后果

- 不打开这些规则的群，阿拉伯文和西里尔文仍留下。关键词和短链仍会删除。
- 打开 `script_arabic` 后，这个群里阿拉伯字母占多数且至少 4 个的消息会删除。西里尔文、汉字和两边一样多的句子仍留下。付费帖仍留下。
- 入群服务消息的可见名字就是正文。打开后，够长的阿拉伯文或西里尔文名字会删掉那一行提示。入群验证仍走 `chat_member`。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把对应的 id 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这两条规则，才会有这些开关。
- 30 天保留期不动。
