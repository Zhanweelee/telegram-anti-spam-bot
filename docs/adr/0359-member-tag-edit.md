# ADR 0359：群里改掉的成员标签也要封禁

- 状态：已接受
- 日期：2026-11-04

## 背景

ADR 0358 把入群时的 `tag` 并进昵称。人已经在群里时，可以再改自己的标签。这次 `chat_member` 的状态往往仍是 `member` 或 `restricted`，不带 `membership`。新标签会立刻出现在成员列表里。ADR 0112 要等下一条消息上的 `sender_tag`。

## 决策

- 人还在群里，新的 `tag` 去掉首尾空白后和旧标签不同，就把新标签放进 `profile`。最长 256 字符。不带昵称、姓氏、用户名，也不设 `membership`。
- 旧标签缺失或只有空白，新标签有内容时，也放进去。
- 新旧标签相同、新标签只有空白、人已经离群，以及 bot，都不带 `profile`。
- 入群仍按 ADR 0358，标签接在昵称后面。默认规则仍是 `join_name` 和 `join_link`。不改 ADR 0026 的基础检测器。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 等下一条消息的 `sender_tag` | 标签在开口前已经出现在成员列表里。 |
| 任何带标签的状态变化都再查一次 | 验证把人收成 `restricted` 时，没改过的标签会被再封一次。 |

## 后果

- 把标签改成广告词或短链的人会被封禁，不发验证按钮。
- 标签改成默认正则能命中的写法后来由 ADR 0532 封禁。证据仍是 `regex:hit`。
- 清掉标签、或限制状态变了但标签没变，不会因此再封。
- 30 天保留期不动。
