# ADR 0667：频道改名不再读发送者的名字

- 状态：已接受
- 日期：2026-11-06

## 背景

频道改名时，Android 的 `MessageObject` 在 `TL_messageActionChatEditTitle` 上，频道且不是超级群时把这行设成 `ActionChannelChangedTitle`。英文是 “Channel name changed to un2”。`un2` 是新名字。这行不画改名的人。

群和超级群仍用 `replaceWithLink` 画出全名。见 ADR 0632。

Bot API 把频道放在 `chat.type === "channel"`。超级群是 `supergroup`，普通群是 `group`。ADR 0632 仍从 `from` 读名。名上的短链会删掉一条成员看不到这个名字的提示。新名字已经按原来的正文只留主机名。

## 决策

- `chat.type` 正好是 `channel`，并且 `new_chat_title` 是长度大于 0 的字符串时，不从 `from` 抽主机名。空白名字也算改名。名、姓和用户名都不读。
- 群和超级群仍按全名。没有 `chat`，或类型不是 `channel` 时仍按全名。
- 新名字仍只留主机名，排在发送者前面。空字符串仍不读。本群群名仍不读。
- 频道换头像仍按 ADR 0666。换背景仍只读名。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`chat_title` 仍默认关闭。8 个主机名的上限不变。不调用 `setChatTitle`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 频道继续按全名 | 这行不画人。名上的短链不是成员看到的字。 |
| 超级群也不读 | 超级群这行仍画全名。 |
| 新名字也不读 | 成员仍看得到新名字。 |
| 新命令 | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 频道改名时，发送者名字里的短链、邀请或裸 IP 不再删除这条消息。新名字里的短链仍会删。群和超级群仍按全名删除。
- 名字不进事件。内容哈希不变。关键词不命中这些名字。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 换背景仍只读名。空字符串和普通消息仍不读发送者。管理员仍豁免。干净的提示在 `chat_title` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
