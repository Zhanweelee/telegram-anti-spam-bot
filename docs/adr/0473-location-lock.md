# ADR 0473：纯位置按群删除

- 状态：已接受
- 日期：2026-11-04

## 背景

只有坐标、没有场馆标题的位置消息，正文是空字符串。坐标不进事件。见 ADR 0059。关键词、链接和重复都看不到这颗图钉。

场馆消息在 Bot API 里同时带 `location` 和 `venue`。标题已经是正文。打开纯位置时不能把场馆一起删掉。

## 决策

- `message.location` 同时有有限的纬度和经度，并且没有 `venue` 对象时，事件带 `asLocation: true`。不写坐标、精度、方向、实时时长和提醒半径。
- 空的 `location`、只有一个坐标、以及带 `venue` 的消息不带这个标记。场馆标题仍按 ADR 0059。
- 检测器在 `@tasb/detector-location`，id 是 `bare_location`。只在 `message.asLocation` 为 true 时返回 score 1。证据是 `location:pin`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这种图钉。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`bare_location` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部纯位置 | 有的群用图钉报位置。打开之前不改现有群。 |
| 把经纬度收成正文 | 坐标会进事件和哈希。见 ADR 0059。 |
| 连场馆一起删 | 场馆标题已经能被关键词和正则看到。 |
| 新命令 `/location` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，纯位置仍留下。场馆标题里的关键词仍删除。
- 打开 `bare_location` 后，这个群里只有坐标的位置消息会删除。实时位置同样删除。场馆消息仍留下。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `bare_location` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
- 富文本地图后来由 ADR 0504 另开 `rich_map`。打开纯位置仍不删除这种地图。坐标仍不进事件。
