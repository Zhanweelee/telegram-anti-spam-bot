# ADR 0799：消息说明不是字符串时不读按标识提及

- 状态：已接受
- 日期：2026-11-07

## 背景

按标识提及可以按群删除。用户编号不进事件。见 ADR 0514。说明是字符串时，按标识提及的起点必须落在说明里，长度必须大于 0。见 ADR 0755。消息正文不是字符串时不读按标识提及。见 ADR 0798。

Android 只能把实体画在一段字符串上。说明不是字符串时，没有可以落点的文字，按标识提及画不出来。

现在这种说明仍会把 `caption_entities` 整份读进来。打开 `text_mention` 后，没画出来的提及也会删掉这条消息。

## 决策

- `caption` 不是字符串时，不从 `caption_entities` 读取按标识提及。
- 说明是字符串时，仍要求起点大于或等于 0 且小于说明长度，长度大于 0。长度越过末尾时仍带 `asTextMention`。空字符串仍是字符串。
- 用户编号和名字仍不进事件。已有别的正文时，看得见的字仍是那段正文。
- 投票题干上的按标识提及不在这条里。自定义表情不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，提及不该在打开规则后删掉这条消息。 |
| 把数字说明当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 投票题干上的提及一起改 | 题干是另一段文字。这条只改说明。 |
| 自定义表情一起改 | 表情是另一种实体。这条只改按标识提及。 |
| 默认打开 | 有的群会点名。打开之前不改现有群。 |

## 后果

- 说明不是字符串时，不再带 `asTextMention`。
- 说明是字符串且起点落在说明里时，打开 `text_mention` 后仍删除。证据仍是 `entity:text_mention`。用户编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 自定义表情在说明不是字符串时仍按原来的方式读取。
