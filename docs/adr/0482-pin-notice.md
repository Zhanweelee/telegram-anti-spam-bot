# ADR 0482：置顶提示按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

管理员把一条消息置顶时，群里会出现一条服务消息。被置顶的原文在 `pinned_message` 里。那是另一条消息，不能并进这一条的正文。见 ADR 0061。服务消息自己的正文是空的，关键词看不到预览里的广告。

被置顶的原文、发送者名字和消息号仍然不能写进事件。删掉这条服务消息不会撤下置顶。撤下一条仍走 `/unpinmsg`，清空全部仍走 `/unpin`。见 ADR 0388 和 ADR 0378。

## 决策

- `pinned_message` 是对象，并且 `message_id` 是大于 0 的安全整数时，事件带 `asPin: true`。不写被置顶的原文、名字和消息号。不从这条嵌套消息里抽主机名。
- 空对象、字符串编号和非正数编号不带这个标记。已有正文时，正文仍按原来的优先级。
- 检测器在 `@tasb/detector-pin`，id 是 `pin_notice`。只在 `message.asPin` 为 true 时返回 score 1。证据是 `pin:notice`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这条置顶提示。没有新命令。菜单仍是 99 条。不调用 `unpinChatMessage`。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`pin_notice` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部置顶提示 | 有的群靠这条提示告诉成员看置顶。打开之前不改现有群。 |
| 把被置顶的原文抄进正文 | 那是另一条消息。关键词会按别人写过的句子删除这条提示。 |
| 删除提示时一并撤下置顶 | 撤下是 `/unpinmsg` 和 `/unpin` 的事。这条规则只删服务消息。 |
| 把消息号写进证据 | 消息号可以指向原文。不能进事件。 |
| 新命令 `/pin` | `/pin` 已经是把一条消息加进置顶的操作命令。菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，置顶提示仍留下。这条更新仍然不读被置顶的原文。
- 打开 `pin_notice` 后，这个群里的置顶提示会删除。置顶本身还在。`/unpinmsg` 仍撤下一条，`/unpin` 仍清空全部。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `pin_notice` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
- 置顶的人后来由 ADR 0586 只留下主机名。名字本身仍不进事件。不是真实置顶提示时，发送者仍不读。文字预览的前 20 个码元和游戏标题后来由 ADR 0653 只留主机名。第 21 个码元起、说明和被置顶的人仍不读。
