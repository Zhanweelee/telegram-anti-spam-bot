# ADR 0739：手动引用自己就是正文时，文字链接不能越过摘录

- 状态：已接受
- 日期：2026-11-07

## 背景

没有更前面的正文时，手动引用成为这条消息的正文。摘录上的短链在 `quote.entities`。见 ADR 0085。

Android 先把摘录里的换行换成空格，长度不变，再用 `addEntitiesToText` 把实体画到整段摘录上。文字链接的起点大于或等于这段文字时，链接不会画上去。

已有别的正文时，这段摘录已经要求起点落在摘录里。见 ADR 0732。没有别的正文时，另一条读取仍会收下全部文字链接。起点已经越过摘录的链接仍会留下主机名。

说明已经要求起点落在说明里。见 ADR 0738。手动引用成为正文是另一段文字。

## 决策

- 手动引用自己就是正文时，`quote.entities` 里的文字链接，起点必须小于这段摘录。
- 摘录里的普通网址仍读。仍只留主机名。原文按这段摘录计内容哈希，不另留 `quoteText`。
- 已有别的正文时仍按 ADR 0732。自动引用不走这条正文路径。
- 投票描述不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条消息。 |
| 成为正文后不再读摘录上的链接 | 落在摘录里的短链仍然画在正文上。 |
| 投票描述也按摘录长度丢掉链接 | 这份客户端还没有画出描述。这条只改成为正文的手动引用。 |

## 后果

- 起点越过摘录的文字链接不再留下主机名。仍落在摘录里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在摘录里的路径仍留在正文。关键词不命中没画上去的链接。内容哈希仍按这段摘录。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 投票描述上的文字链接后来由 ADR 0740 要求起点小于整段描述。描述不是字符串时仍按原来的方式读取。
