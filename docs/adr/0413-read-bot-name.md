# ADR 0413：私聊可以查看 bot 的默认名字

- 状态：已接受
- 日期：2026-11-04

## 背景

默认名字已经可以设置。查看调用是 `getMyName`。

`language_code` 可选。不送时返回给没有专用语言名字的人看的那个名字。已经有单独语言名字的人不在这次结果里。

返回值是 `BotName`。字段 `name` 是这个 bot 的名字。

## 决策

- 私聊命令 `/myname`。没有参数。多出来的参数不发出请求。别的单词回复「参数无效」。群聊里的同样文本不执行。
- 只有配置里的管理员可以看。接入目录里的人即使管着自己的群也不能看。
- 调用 `ModerationPort.readBotName`。适配器调用 `getMyName`。正文是空对象。不送 `language_code`。
- 名字是 0 到 64 个字符、没有换行的字符串时，回复带上这个名字。空字符串回复「名字 空」。
- 缺字段、非字符串、超长或带换行时整份回复是「参数无效」，不露出已经读到的名字。其它字段不进回复，也不进日志。
- 日志只写 `operator_rejected` 或命令名，带上 eventId、chatId 和命令名 `myname`。不写名字、异常文本或 token。
- 没有 token 的 Worker 不编一个名字。
- 不调用 `setMyName`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 查看某一个语言的名字 | 那要送 `language_code`。这次只读默认名字。 |
| 空名字当成失败 | 清掉默认名字之后，空字符串是当前状态。 |
| 回复里不写名字 | 管理员私聊来就是为了看到当前名字。日志仍然不写。 |

## 后果

- 成功只表示 Telegram 返回了默认名字。已有单独语言名字的人不受这次查看影响。
- 一次查看是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
