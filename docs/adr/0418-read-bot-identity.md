# ADR 0418：私聊可以查看 bot 的身份

- 状态：已接受
- 日期：2026-11-04

## 背景

反垃圾要知道这个 token 对应哪一个 bot，以及隐私模式有没有关掉。查看调用是 `getMe`。它不带参数，返回一个 `User`。

`id` 是 bot 编号。`username` 可选。`can_join_groups` 表示能否被拉进群。`can_read_all_group_messages` 为 true 时，隐私模式是关掉的，bot 看得到全部群消息。这两个开关只在 `getMe` 里出现。

同一个对象还带显示名字和一串别的可选开关。那些不进这次回复。

## 决策

- 私聊命令 `/who`。没有参数。多出来的参数不发出请求。别的单词回复「参数无效」。群聊里的同样文本不执行。
- 只有配置里的管理员可以看。接入目录里的人即使管着自己的群也不能看。
- 调用 `ModerationPort.readBotIdentity`。适配器调用 `getMe`。正文是空对象。
- 回复四行：编号、用户名、能否入群、是否看得到全部群消息。缺用户名写空。缺开关写未知。
- `is_bot` 不是 true、编号不是正的安全整数、用户名不是 1 到 32 位的字母数字或下划线、开关不是布尔值时，整份回复是「参数无效」，不露出已经读到的字段。
- 显示名字和其它字段不进回复，也不进日志。
- 日志只写 `operator_rejected` 或命令名，带上 eventId、chatId 和命令名 `who`。不写用户名、名字、异常文本或 token。
- 没有 token 的 Worker 不编一份身份。
- 不调用 `logOut` 或 `close`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 回复里带上显示名字 | 名字已经有 `/myname`。`getMe` 这里只回答身份和两个运营开关。 |
| 缺开关当成关闭 | 文档写这些字段可选。缺字段和明确的 false 不是同一件事。 |
| 顺手调用 `logOut` | 那会把 bot 登出云端，10 分钟内不能登回去。 |

## 后果

- 成功只表示 Telegram 返回了这个 token 对应的 bot。隐私模式是否关掉看「群消息」那一行。
- 一次查看是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
