# ADR 0076：富文本只留可见文字和链接主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

入站 `Message` 可以带 `rich_message`，正文不在 `text` 里。段落、列表和按钮里能放短链。`RichTextUrl.url` 可以和看得见的字不同。按钮还有 `url`、`web_app`、`login_url` 和 `copy_text`。这些字段现在不进归一化，关键词和链接规则都看不到。

官方 `Message.reply_markup` 只有内联键盘。回复键盘不出现在入站消息上。

## 决策

- 没有 `text` 和 `caption` 时，用富文本里看得见的字当正文。块与块之间用一个普通空格分开，同一块里的字直接连上。截断到 4096，并以此计算 `textSha256`。
- 只有按钮、没有其它可见文字时，按钮文字按同样的空格规则成为正文。已有段落时，按钮文字不并进去。
- 已有 `text` 或 `caption` 时，正文和哈希不变。富文本里的网址仍只留下主机名。
- 主机名来自 `RichTextUrl.url`、按钮 `url`、`login_url.url`、`web_app.url`，以及 `copy_text` 里抽出的网址。解析、折叠、邀请判断和 8 个主机名的上限与按钮相同。
- `callback_data` 不读。数学公式源码、锚点名字、提及用户、银行卡号、邮箱和电话号码这些字段不进事件。看得见的字仍然可以成为正文。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。不引入同形字库。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把富文本接在已有正文后面 | 同一条消息的哈希会变。 |
| 把整段富文本 JSON 放进事件 | 路径、公式和证件号会落下来。 |
| 只读段落里的纯字符串 | 隐藏的 `RichTextUrl` 和按钮网址仍会漏掉。 |

## 后果

- 富文本段落里的「免费领取」会命中现有关键词。同一段文字在重复窗口里按这段正文计次。
- 隐藏短链、邀请和按钮上的短链按现有链接规则命中。普通域名仍保留。
- 已有 caption 时，富文本不改哈希，里面的短链仍只留下主机名。
- 提及用户的 id、银行卡号、邮箱、电话和公式源码不进事件。`callback_data` 里的网址不进事件。
- 公式里的网址后来由 ADR 0122 只留主机名。源码仍不进事件。
- 自定义表情的替代文字后来由 ADR 0126 在没有别的正文时成为正文。已有正文时只留主机名。表情 id 仍不读。
- 代码块的语言标签后来由 ADR 0127 只留主机名。标签原文仍不进事件。
- 代码实体的语言标签后来由 ADR 0128 只留主机名。标签原文仍不进事件。
- 富文本里的动图、视频、音频和文件名后来由 ADR 0108 只留下主机名。照片和语音的文件 id 仍不读。
- 列表项标签里的网址后来由 ADR 0109 只留下主机名。勾选状态和序号仍不读。
- 回复键盘仍不读。投票选项、清单任务和游戏附加文字仍不进事件。
- 非空的电话和银行卡可以另开 `rich_phone` 和 `rich_card` 删除整条消息。号码仍不进事件。看得见的字仍是正文。邮箱仍不带标记。见 ADR 0501。
