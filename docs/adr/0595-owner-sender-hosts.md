# ADR 0595：交群的人，名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

群主换人，或群主离开时，客户端把操作的人画在服务消息上。名字写在 `from`。新群主的名字当时按正文处理。见 ADR 0120。没有下一位时正文是空的。短链可以只写在交群的人的名字里。

把 `from` 收成正文会让普通发言者的姓名也进检测。`owner_notice` 默认关闭，干净的提示仍留下。用户编号仍不读。空的换人对象和布尔值仍不是这条提示。

## 决策

- 只在已经会标成 `ownerNotice` 的提示上，从 `from` 的可见名字留主机名。换人要有新群主对象。离开只要是对象，空对象也读。两条同时出现时仍先认换人。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 新群主的名字仍按 ADR 0120 成为正文。已有别的正文时仍留在 `memberName`。交群的人的名字不进正文，也不改内容哈希。关键词因此不命中这个人的名字。用户编号不读。本群群名不读。
- 空的换人对象和布尔值不读发送者。普通消息不读 `from`。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`owner_notice` 仍默认关闭。8 个主机名的上限不变。不改群主。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把交群的人整段当成正文 | 关键词会命中人名。普通消息的 `from` 也会被打开。见 ADR 0120。 |
| 离开不读发送者 | 没有下一位时正文是空的。短链可以只写在离开的人的名字里。 |
| 把用户编号写进证据 | 编号不是这行看得见的字。见 ADR 0492。 |
| 新命令 `/ownername` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 交群或离开的人，名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。群主本身不变。
- 这个人的名字原文、路径和用户名不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。新群主的名字仍按原来的正文。用户编号仍不进事件。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 空的换人对象、布尔值和普通消息仍不读发送者。本群群名仍不读。干净的提示在 `owner_notice` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
- 交群或离开后来按全名只留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。见 ADR 0633。拉进视频聊天后来按全名。见 ADR 0634。换背景仍只读名。
- 发送者是聊天时后来只读聊天标题，不读 `from`。见 ADR 0687。
