# ADR 0795：游戏附加文字不是字符串时不读文字链接

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。游戏附加文字是字符串时，文字链接的起点必须落在附加文字里，长度必须大于 0。见 ADR 0770。礼物附言不是字符串时不读文字链接。见 ADR 0794。

Android 只能把实体画在一段字符串上。附加文字不是字符串时，没有可以落点的文字，文字链接和代码块语言都画不出来。

现在这种附加文字仍会把 `text_entities` 整份读进来。打开链接规则后，没画出来的链接也会删掉这条游戏消息。

## 决策

- `game.text` 不是字符串时，不读 `text_entities`。
- 附加文字是字符串时，仍要求起点落在附加文字里，长度是大于 0 的安全整数。长度越过末尾时仍留下主机名。
- 说明写在 `gameText` 前面时，不改变附加文字上的起点。
- 已有别的正文时，说明和附加文字仍各自只留前 4096 字，用一个空格接成 `gameText`。没有别的正文时，游戏标题成为正文，仍只留前 4096 字。
- 写在附加文字和说明里的普通网址仍各自抽取。
- 按标识提及和自定义表情不在这条里。消息说明不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，链接不该删掉这条游戏消息。 |
| 把数字附加文字当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 按拼好的 `gameText` 计算起点 | 说明写在前面，客户端仍把实体画在附加文字上。 |
| 消息说明一起改 | 说明是另一段文字。这条只改游戏附加文字。 |

## 后果

- 附加文字不是字符串时，文字链接和代码块语言不再留下主机名。
- 附加文字是字符串时，短链、邀请或裸 IP 仍删除。证据只有主机名。
- 按标识提及在附加文字不是字符串时，后来由 ADR 0807 不再读取。自定义表情在附加文字不是字符串时仍按原来的方式读取。
