# ADR 0446：客座 bot 回复上画出的召唤者名字只留主机名

- 状态：已接受
- 日期：2026-11-04

## 背景

群里的客座 bot 替人回复时，客户端在消息上画出「for {名字}」。桌面端用召唤者的完整名，频道或群则用标题。安卓在名为空时改用姓，频道或群只画标题。

这条回复作为普通 `message` 到达。召唤者写在 `guest_bot_caller_user` 或 `guest_bot_caller_chat`。带 `guest_query_id` 的是客座 bot 自己收到的查询，ADR 里已有的忽略路径仍先丢掉，不读名字。`via_bot` 的名字仍按 ADR 0033 不读。

## 决策

- `guest_bot_caller_user` 是对象，且 `first_name` 是非空字符串时，从这段名抽出网址，只留主机名。长度、折叠、邀请判断和 8 个主机名的上限不变。
- `first_name` 缺失或正好是空字符串，且 `last_name` 是非空字符串时，改从姓里留主机名。名是空白或不是字符串时不读姓。
- 没有用户对象时，`guest_bot_caller_chat.title` 是非空字符串则只留主机名。频道用户名、群的名和姓不读。
- 用户对象和群对象同时存在时只读用户。有名时不读姓，也不读群标题。
- 这段名字不进正文，也不改内容哈希。关键词因此不命中。
- 用户名、用户 id、群 id 和普通发言人的 `from` 不读。
- 不新增检测器，不新增命令。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 会改变哈希。短链只需要主机名。故事发布者的名字也只留主机名，见 ADR 0325。 |
| 连用户名一起抽 | 客户端画出的是名或标题，不是用户名。 |
| 姓只要存在就读 | 桌面端和安卓只在名为空时才画姓。 |
| 每条消息的 `from.first_name` 都读 | 普通发言人的名字仍留在事件外面。 |

## 后果

- 画出的名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。
- 名字原文、路径和邀请码不进事件，内容哈希不变。名字里的关键词不命中。
- 名不为空时，姓、用户名、频道用户名和群标题不进事件。
- 抬头上 bot 自己的短名后来由 ADR 0616 只留主机名。从下标 2 起的第一个空格后面不画。召唤者的完整名仍按本篇读取，并排在 bot 短名后面。没有客座召唤者对象时，普通 `from` 仍不读。
- `example.com` 留着。付费帖仍不删除。见 ADR 0356。
- 云额度的基础检测器名单没有改。30 天保留期没有改。
