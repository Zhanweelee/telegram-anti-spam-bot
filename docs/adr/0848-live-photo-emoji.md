# ADR 0848：实况照片里不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。地图高度里不读自定义表情。见 ADR 0847。实况照片不进正文。

现在实况照片块 `live_photo` 里如果嵌着自定义表情，仍会带 `asCustomEmoji`。打开 `custom_emoji` 后，没画在正文上的表情也会删掉这条消息。

## 决策

- 实况照片块 `live_photo` 里不读取自定义表情。
- 实况照片说明仍按原来的方式读取。画出来的段落、替代文字长度大于 0 的节点仍读。
- 编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。实况照片仍不进正文。
- 贴纸高级动画不在这条里。实体列表上的自定义表情仍按各自那段文字判断。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读实况照片 | 实况照片不进正文，里面的表情不会画在这段正文上。 |
| 整个实况照片块都不看 | 这条只改实况照片本身。说明仍可能画出来。 |
| 贴纸高级动画一起改 | 贴纸高级动画是另一段没画进正文的字段。 |
| 连实体列表一起改 | 实体列表已经按各自的文字判断。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 实况照片里的自定义表情不再带 `asCustomEmoji`。
- 旁边仍画出来的节点，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 实况照片里的自定义表情后来由 ADR 0848 不再读取。贴纸高级动画里的自定义表情后来由 ADR 0849 不再读取。贴纸遮罩里的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
