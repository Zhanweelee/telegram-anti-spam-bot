# ADR 0572：后加清单任务上的自定义表情也走同一条规则

- 状态：已接受
- 日期：2026-11-05

## 背景

别人往清单里补任务时，新任务以 `checklist_tasks_added` 到达。任务文字可以带自定义表情。原清单上的任务已经会让 `asCustomEmoji` 为 true。后加的这一条服务消息仍留下。

原清单在 `checklist_message` 里，是另一条消息。完成者名字和任务编号不在看得见的字里。

## 决策

- `checklist_tasks_added.tasks` 的 `text_entities` 里，`type` 正好是 `custom_emoji`，并且 `custom_emoji_id` 去掉空白后非空时，事件同样带 `asCustomEmoji: true`。
- 空白、布尔值和缺编号仍不带这个标记。嵌套的 `checklist_message` 不读。
- 编号、任务编号和完成者名字不进事件，也不进证据。任务看得见的字仍留在原来的字段。正文和 `textSha256` 不变。
- 仍用检测器 `custom_emoji`。证据仍是 `entity:custom_emoji`。不新增规则，不新增命令。菜单仍是 99 条。
- 规则仍默认关闭。打开之后，这种后加任务也删除。付费帖仍不删除。
- 不改 ADR 0026 的基础检测器名单。`custom_emoji` 仍不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 另开一条规则 | 这是同一处隐藏的表情编号。分开开关会让群管开漏一处。 |
| 连原清单一起扫 | `checklist_message` 是另一条消息。原清单发出时已经扫过。 |
| 把编号写进证据 | 编号不进事件。 |
| 把完成者名字写进正文 | 完成者不是任务上的字。 |

## 后果

- 规则关闭时，后加任务上的自定义表情留下。看得见的字仍参与关键词。编号仍不进事件。
- 打开 `custom_emoji` 后，这种后加任务会删除。任务编号和完成者名字仍不进事件。
- 付费帖仍留下。空白编号不带这个标记。原清单上的表情不因为嵌套再标一次。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `custom_emoji` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `custom_emoji`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
- 后加和删掉的投票选项上的自定义表情后来由 ADR 0573 也带上 `asCustomEmoji`。原投票和选项编号仍不进事件。
- 新加任务四条起，后来由 ADR 0660 不把第四条起的自定义表情算进 `asCustomEmoji`。前三条仍算。
- 前三条上的自定义表情后来由 ADR 0750 要求整段落在这条任务里。任务文字不是字符串时仍按原来的方式读取。第四条起仍不读。
