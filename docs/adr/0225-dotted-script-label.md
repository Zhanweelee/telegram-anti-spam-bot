# ADR 0225：点号后面的文字字母留在带协议的主机名里

- 状态：已接受
- 日期：2026-11-03

## 背景

ADR 0224 把紧贴在带协议主机名后面的希腊文、西里尔文、亚美尼亚文和非 ASCII 拉丁字母留在同一个标签里。点号再起一个标签时，这些字母仍被删掉。

`http://bit.ly.α/…`、`https://t.co.т?…`、`http://203.0.113.10.ա/…` 和 `http://bit.ly.œ:80/…` 在 Android 上各是一条链接。地址解析器给出的主机名不是前面的短链或裸 IP。`http://bit.ly.α/http://t.co/…` 的路径仍属于这一条。`see http://bit.ly.α/…` 也是。

`http://bit.ly.α.bit.ly/…` 的主机名仍以 `bit.ly` 结尾。没有协议的 `bit.ly.α/…`、`www.bit.ly.α/…` 和 `203.0.113.10.α/…` 只打开前面的短链或裸 IP。`http://bit.ly.α#…`、`http://bit.ly.α@evil.com/…`、空标签 `http://bit.ly..α/…` 和中间有空格的写法也退回前面的短链。新标签放不下第 64 个字母时，短链单独打开。`bαit.ly` 仍是短链。

## 决策

- 只改主机名扫描。公开的折叠不改。
- 写完的带协议主机名后面有一个点号时，下一段这类字母在 Android 仍把它算进这条链接时留下。
- 后面是 `#`、`@` 或空格，点号是空标签，或者这段字母让新标签超过 63 个字符时，仍删掉这些字母。
- 没有协议时仍删掉。夹在两个 ASCII 字母中间时仍删掉。
- 每段仍走现有的短链、裸 IP、邀请和 denylist 判断。只拆一层。最多 8 个。证据只留主机名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 点号后面继续删掉这些字母 | `http://bit.ly.α/…` 会按短链删除。Android 打开的不是 `bit.ly`。 |
| 没有协议也把点号后的字母留下 | `bit.ly.α/…` 会漏掉。Android 只打开 `bit.ly`。 |
| 空标签 `..` 也留下 | `http://bit.ly..α/…` 会漏掉。Android 只打开 `bit.ly`。 |

## 后果

- `http://bit.ly.α/…`、`https://t.co.т?…`、`http://www.bit.ly.α/…` 和 `http://203.0.113.10.ա/…` 留着。
- `http://bit.ly.α/http://t.co/…` 留着。路径里的短链不另记。
- `see http://bit.ly.α/…` 和 `http://bit.ly.α.evil.com/…` 留着。
- `bit.ly.α/…`、`www.bit.ly.α/…` 和 `203.0.113.10.α/…` 仍删除。
- `http://bit.ly.α#…`、`http://bit.ly.α@evil.com/…` 和 `http://bit.ly..α/…` 仍按短链删除。
- `http://bit.ly.α.bit.ly/…` 仍按短链删除。证据是带这个字母的主机名。
- `bαit.ly` 仍按短链删除。第 64 个字母仍让短链单独打开。路径不进证据。
- 句号、全角句点和半角句点后面的这类字母留在带协议的主机名里。见 ADR 0226。
