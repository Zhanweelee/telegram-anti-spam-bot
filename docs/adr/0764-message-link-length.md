# ADR 0764：正文上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。正文上的文字链接，起点必须落在正文里。见 ADR 0737。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达正文末尾的实体。起点落在正文里、长度越过末尾时，客户端把长度收到正文末尾，这段链接仍会画出来。

现在正文只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在正文里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条消息。代码块语言里的网址也走同一段实体。

说明不在这条里。

## 决策

- `text` 是字符串时，`entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于正文长度，长度必须是大于 0 的安全整数。
- 起点落在正文里、长度越过末尾时，仍留下主机名。
- `text` 不是字符串时，仍按原来的方式读取。
- 写在正文里的普通网址仍由链接检测从正文读取。仍只留主机名。
- 说明上的 `caption_entities` 不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条消息。 |
| 也要求长度落在正文里 | 起点在正文里时，客户端会把越过末尾的长度收回来再画。 |
| 说明一起改 | 说明是另一段文字。这条只改正文。 |
| 默认关掉短链 | 短链删除已经是默认行为。这条只丢掉没画出来的链接。 |

## 后果

- 正文上长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在正文里、长度越过末尾的短链、邀请或裸 IP 仍删除。证据只有主机名。
- 写在正文里的普通网址仍会删除。被截断的路径不进事件。
- 说明上长度不是正数的文字链接仍按原来的方式读取。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
