# ADR 0427：私聊可以查看用户的个人频道

- 状态：已接受
- 日期：2026-11-04

## 背景

私聊对象可以挂一个个人频道。反垃圾要知道这个人对外展示的是哪个频道，才不会把私聊和频道推广看成互不相干的入口。这个信息在 `getChat` 返回的 `ChatFullInfo.personal_chat` 里。值是一个 `Chat`，文档写明只给私聊返回。

标题、用户名和姓名可能带原文，不进这次回复。类型用来确认这是一份聊天对象，也不进回复。`parent_chat` 是直接消息聊天对应的频道，不是这一次要看的字段。

## 决策

- 私聊命令 `/personal <chatId>`。群 id 匹配 `^-?\d{1,20}$`。多出来的参数不发出请求。群聊里的同样文本不执行。
- 配置里的管理员可以看任意群。接入目录里的人只能看自己的群。
- 调用 `ModerationPort.readPersonalChat`。适配器调用 `getChat`，只带 `chat_id`。
- 回复两行：群号、个人频道编号。没有 `personal_chat` 时写无。
- 类型不是 private、group、supergroup、channel 之一，编号不是安全整数，或返回的群号和请求不一致时，整份回复是「参数无效」，不露出已经读到的字段。
- 标题、用户名、姓名和邀请链接不进回复，也不进日志。
- 日志只写 `operator_rejected` 或命令名，带上 eventId、chatId 和命令名 `personal`。不写标题、异常文本或 token。
- 没有 token 的 Worker 不编一个编号。
- 不调用 `setChatTitle`，也不改黑名单、封禁或禁言。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 缺字段写成未知 | 文档没有说这个字段只对管理员返回。缺字段就是没有个人频道。 |
| 回复里带上标题或用户名 | 标题和用户名可能是原文。编号够用来对上同一个频道。 |
| 并进 `/parent` | `parent_chat` 是直接消息聊天对应的频道。个人频道是另一件事。 |

## 后果

- 成功只表示 Telegram 返回了这个私聊当前的个人频道编号，或这个字段没有返回。
- 一次查看是一次 Telegram 子请求。`/parent` 仍单独回报直接消息聊天的对应频道。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
