# ADR 0780：回复的选项上的文字链接长度必须大于 0

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。回复投票里的某一个选项时，引用条画出那个选项的整段文字。编号对不上就改画问题。见 ADR 0702 与 ADR 0725。任务号对不上时的清单标题，文字链接长度必须大于 0。见 ADR 0779。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达选项末尾的实体。起点落在选项里、长度越过末尾时，客户端把长度收到选项末尾，这段链接仍会画出来。这行不进正文。整段选项都画，不按 150 个码元截断。

现在对上的选项只看起点。一个长度是 0、负数或不是整数的文字链接，只要起点落在选项里，仍会留下主机名。打开链接规则后，没画出来的链接也会删掉这条回复。代码块语言里的网址也走同一段实体。

编号对不上时的问题不在这条里。

## 决策

- `reply_to_poll_option_id` 对上的那一个选项，`text` 是字符串时，`text_entities` 里的文字链接和代码块语言，起点必须大于或等于 0 且小于这条选项的长度，长度必须是大于 0 的安全整数。
- 起点落在这条选项里、长度越过末尾时，仍留下主机名。
- 选项文字不是字符串时，仍按原来的方式读取。
- 整段选项仍读，不改按 150 个码元截断。这行仍不进正文。
- 写在这条选项里的普通网址仍从整段原文抽取。仍只留主机名。
- 编号对不上时仍改读问题。问题上的文字链接仍只看起点。其余选项仍不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读长度不是正数的链接 | 没画出来的链接会删掉这条回复。 |
| 也要求长度落在选项里 | 起点在选项里时，客户端会把越过末尾的长度收回来再画。 |
| 这行也只取前 150 个码元 | 引用条画出的是整段选项。 |
| 对不上的问题一起改 | 那是编号对不上时的另一行。这条只改对上的选项。 |

## 后果

- 对上的选项上，长度小于或等于 0、不是安全整数的文字链接和代码块语言不再留下主机名。
- 起点落在选项里、长度越过末尾的短链、邀请或裸 IP 仍删除。第 151 个码元上的链接，只要起点仍落在这条选项里、长度大于 0，也删除。证据只有主机名。
- 写在这条选项里的普通网址仍会删除。被截断的路径不进事件。这行仍不进正文。
- 选项文字不是字符串时，长度不是正数的文字链接仍按原来的方式读取。
- 编号对不上时，问题上长度不是正数的文字链接仍按原来的方式读取。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
