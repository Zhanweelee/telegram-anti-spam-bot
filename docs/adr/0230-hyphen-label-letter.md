# ADR 0230：连字符末尾的文字字母留在带协议的标签里

- 状态：已接受
- 日期：2026-11-03

## 背景

带协议的主机名以连字符结束时，后面的希腊文、西里尔文、亚美尼亚文和非 ASCII 拉丁字母会被删掉。连字符自己再被地址解析丢掉，短链或裸 IP 重新打开。

`http://bit.ly-α/…`、`http://bit.ly--α/…`、`http://www.bit.ly-α/…` 和 `http://203.0.113.10-ա/…` 在 Android 上各是一条链接。地址解析器给出的主机名不是前面的短链或裸 IP。`http://bit.ly-α/http://t.co/…` 的路径仍属于这一条。`see http://bit.ly-α/…` 也是。

`http://bit.ly-α.bit.ly/…` 的主机名仍以 `bit.ly` 结尾。没有协议的 `bit.ly-α/…` 和 `www.bit.ly-α/…` 只打开前面的短链。`http://bit.ly-α#…`、`http://bit.ly-α@evil.com/…`、换行和中间有空格的写法也退回短链。`http://bit.ly-/…` 和 `http://bit.ly-.α/…` 仍打开短链。标签放不下时，短链单独打开。`bαit.ly` 仍是短链。

## 决策

- 只改主机名扫描。公开的折叠不改。
- 带协议的主机名以一个或多个连字符结束，Android 仍把后面的这类字母算进这条链接时，这些字母留下。
- 后面是 `#`、`@` 或空格，或者这段字母让标签超过 63 个字符时，仍删掉这些字母。
- 没有协议时仍删掉。点号紧挨在连字符后面时仍删掉。
- 每段仍走现有的短链、裸 IP、邀请和 denylist 判断。只拆一层。最多 8 个。证据只留主机名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 连字符后面的字母一律删掉 | `http://bit.ly-α/…` 会按短链删除。Android 打开的不是 `bit.ly`。 |
| 没有协议也留下 | `bit.ly-α/…` 会漏掉。Android 只打开 `bit.ly`。 |
| 连字符后面的 `#` 也留下 | `http://bit.ly-α#…` 会漏掉。Android 只打开 `bit.ly`。 |

## 后果

- `http://bit.ly-α/…` 和 `http://bit.ly--α/…` 留着。
- `http://www.bit.ly-α/…` 和 `http://203.0.113.10-ա/…` 留着。
- `http://bit.ly-α/http://t.co/…` 留着。路径里的短链不另记。
- `see http://bit.ly-α/…` 留着。
- `bit.ly-α/…` 和 `www.bit.ly-α/…` 仍删除。
- `http://bit.ly-α#…`、`http://bit.ly-α@evil.com/…`、换行和空格后面的字母仍按短链删除。
- `http://bit.ly-/…` 和 `http://bit.ly-.α/…` 仍按短链删除。
- `http://bit.ly-α.bit.ly/…` 仍按短链删除。证据是带连字符的主机名。
- `bαit.ly` 仍按短链删除。放不下的标签仍让短链单独打开。路径不进证据。
