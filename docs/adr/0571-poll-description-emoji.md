# ADR 0571：投票描述上的自定义表情也走同一条规则

- 状态：已接受
- 日期：2026-11-05

## 背景

ADR 0563 让投票描述在已有题干时留在 `pollDescription`。`description_entities` 可以带用户名、网址和命令，也可以带自定义表情。编号不在看得见的字里。

打开 `custom_emoji` 的群会删掉题干和说明上的这种表情，描述上的同一处仍留下。

## 决策

- `poll.description_entities` 里，`type` 正好是 `custom_emoji`，并且 `custom_emoji_id` 去掉空白后非空时，事件同样带 `asCustomEmoji: true`。
- 空白、布尔值和缺编号仍不带这个标记。按标识提及仍只看 `text_mention`。
- 编号不进事件，也不进证据。描述看得见的字仍留在原来的字段。题干仍是正文。正文和 `textSha256` 不变。
- 仍用检测器 `custom_emoji`。证据仍是 `entity:custom_emoji`。不新增规则，不新增命令。菜单仍是 99 条。
- 规则仍默认关闭。打开之后，描述上的这种表情也删除。付费帖仍不删除。
- 不改 ADR 0026 的基础检测器名单。`custom_emoji` 仍不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 另开一条规则 | 这是同一处隐藏的表情编号。分开开关会让群管开漏一处。 |
| 把编号写进证据 | 编号不进事件。 |
| 把描述并进题干 | 题干已经是正文。并进去会改哈希。 |
| 连手动引用一起认 | 引用上的自定义表情仍按 ADR 0515 留下。 |

## 后果

- 规则关闭时，投票描述上的自定义表情留下。看得见的字仍参与关键词。编号仍不进事件。
- 打开 `custom_emoji` 后，这种描述会删除。编号仍不进事件。
- 付费帖仍留下。空白编号不带这个标记。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `custom_emoji` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `custom_emoji`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
- 后加清单任务上的自定义表情后来由 ADR 0572 也带上 `asCustomEmoji`。原清单、任务编号和完成者名字仍不进事件。
- 描述上的自定义表情后来由 ADR 0747 要求整段落在描述里。描述不是字符串时仍按原来的方式读取。事件里的描述仍只留前 1024 字。
