# ADR 0756：投票题干上的按标识提及必须从题干里开始

- 状态：已接受
- 日期：2026-11-07

## 背景

按标识提及可以按群删除。用户编号不进事件。见 ADR 0514。说明上的按标识提及必须从说明里开始。见 ADR 0755。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达题干末尾的实体。起点落在题干里、长度越过末尾时，客户端把长度收到题干末尾，这段提及仍会画出来。

已有别的正文时，事件里的题干只留前 300 字。题干自己就是正文时，事件正文只留前 4096 字。提及仍按整段题干判断。

现在题干会读全部 `question_entities`。一个起点已经越过题干的按标识提及仍会带上 `asTextMention`。打开这条规则后，没画出来的提及也会删掉这条投票。

测验说明、投票描述、清单、礼物和游戏不在这条里。

## 决策

- `poll.question` 是字符串时，`question_entities` 里的按标识提及，起点必须大于或等于 0 且小于题干长度，长度必须大于 0。
- 起点落在题干里、长度越过末尾时，仍带 `asTextMention`。
- 题干不是字符串时，仍按原来的方式读取。
- 已有别的正文时，第 301 字上的提及，只要起点仍落在题干里，就继续带 `asTextMention`。事件里的题干仍只留前 300 字。
- 题干自己就是正文时，第 4097 字上的提及，只要起点仍落在题干里，就继续带 `asTextMention`。事件正文仍只留前 4096 字。
- 测验说明上的按标识提及不在这条里。
- 仍落在题干里的提及继续带 `asTextMention`。用户编号和名字仍不进事件。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的提及会在打开规则后删掉这条投票。 |
| 也要求长度落在题干里 | 起点在题干里时，客户端会把越过末尾的长度收回来再画。 |
| 也按 300 字丢掉后面的提及 | 300 只是旁边题干的上限。整段题干更长时，后面的提及仍落在题干里。 |
| 测验说明也一起收 | 说明是另一段文字，这条只改题干。 |
| 默认打开 | 有的群会点名。打开之前不改现有群。 |

## 后果

- 起点已经到达或越过题干末尾的按标识提及不再带 `asTextMention`。空题干、长度为 0 和负起点也不带。
- 起点落在题干里的提及，打开 `text_mention` 后删除。证据仍是 `entity:text_mention`。用户编号不进事件。长度越过末尾的提及也删除。起点已经超过 300 或 4096、但仍落在题干里的提及也删除。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 题干不是字符串时，按标识提及后来由 ADR 0800 不再读取。
- 测验说明上的按标识提及后来由 ADR 0757 要求起点落在说明里。说明不是字符串时，按标识提及后来由 ADR 0801 不再读取。长度越过末尾时仍算画出来。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
