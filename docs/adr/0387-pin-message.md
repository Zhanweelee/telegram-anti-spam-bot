# ADR 0387：私聊可以把一条消息加到置顶

- 状态：已接受
- 日期：2026-11-04

## 背景

规则或公告要留在置顶列表里时，逐条处理其它置顶会把免费套餐的子请求花掉。官方有一次把一条消息加进置顶列表的调用。

`pinChatMessage` 把一条消息加到置顶列表。参数是必须的 `chat_id` 和 `message_id`。私聊和频道私聊里，非服务消息都可以置顶。群里 bot 要有 `can_pin_messages`，频道里要有 `can_edit_messages`。成功时返回 True。

`disable_notification` 不传时，群里可能通知成员。频道和私聊始终不通知。这次不传这个参数，也不传 `business_connection_id`。

这条调用不撤下已经存在的置顶，也不删除消息。撤下全部置顶仍走 `/unpin`。

没有 token 时，内存适配器可以把这次请求记下来。私聊如果复用这次成功，回复会写成消息已经置顶。

## 决策

- 私聊命令 `/pin <chatId> <messageId>`。群 id 匹配 `^-?\d{1,20}$`。消息号和 `/delete` 使用同一条规则：`/^[1-9]\d{0,15}$/`，并且是安全整数。少一个参数或多出来的参数都不发出请求。群聊里的同样文本不执行。
- 配置中的管理员可以操作任意群。接入目录里的人只能操作自己的群。
- 调用 `ModerationPort.pinMessage`。目标带 `chatId` 和 `messageId`。适配器调用 `pinChatMessage`，带上这两个字段。消息号 `1` 原样送出。
- 不传 `disable_notification` 和 `business_connection_id`。不调用 `unpinAllChatMessages` 或 `deleteMessage`。
- 回复写明这条消息加进置顶，群里可能收到通知，频道和私聊不会，消息还在，其它置顶还在。
- 没有 token、没有这个方法，群号或消息号不合法，或调用失败时回复「参数无效」。日志只写 `operator_rejected`，带上 eventId、chatId 和命令名。不写异常文本、token 或原文。
- 没有 token 的 Worker 不把内存里的记录回复成已经成功。
- 不修改黑名单、白名单、封禁或禁言。不读取消息正文。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 总是传 `disable_notification: true` | 群里置顶一条规则时，成员通常需要看见。官方不传这个参数时，群里会通知，频道和私聊本来就不通知。 |
| 先撤下全部置顶再置顶这一条 | `/unpin` 已经负责清空。这一次只把一条消息加进现有列表。 |
| 用话题号代替消息号 | 这条方法只收消息号。话题置顶仍走 `/untopic`。 |
| 没有 token 时也回复「已置顶」 | 消息并没有被置顶。管理员会以为已经完成。 |

## 后果

- 成功只表示 Telegram 接受了这一次置顶。服务消息、缺少置顶或编辑权限，或消息号不存在时，回复是「参数无效」。
- 群里可能收到一条置顶通知。频道和私聊不会。
- 其它置顶还在。这条消息还在。
- 一次置顶是一次 Telegram 子请求。封禁、禁言和黑名单都不变。
- 30 天保留期不动。
