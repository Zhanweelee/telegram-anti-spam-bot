# ADR 0093：点状间隔号在比较前收成点

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0064 去掉变体选择符，并留下间隔号。`免·费领取` 对不上关键词 `免费领取`。`https://bit·ly/…` 会被 URL 解析器收成另一套 punycode 主机名，短链名单对不上。全角句号 `。` 已经会被解析器收成点，但它也是中文句子的句号。

普通空格和全角加号仍按原决定留下。同形字母仍不引入对照表。

## 决策

- 新增 `foldInterpuncts`。关键词和正则在 `foldMatchText` 之后去掉这些字符：`U+00B7`、`U+2022`、`U+2027`、`U+2219`、`U+22C5`、`U+30FB`、`U+FF0E`、`U+FE52`、`U+FF61`。
- 新增 `foldDotLookalikes`。链接检测和 `hostFromUrl` 在 `foldMatchText` 之前把同一组字符收成 ASCII `.`。
- `U+0020`、`U+002E`、`U+3002` 和 `U+FF0B` 保留。只由这些间隔号组成的关键词折叠后是空字符串，不匹配任何消息。
- 事件里的正文和 `textSha256` 不变。百分号编码的 `%C2%B7` 仍不在这一层解释。
- 不新增检测器，也不改 ADR 0026 的基础检测器名单。不引入同形字库。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把间隔号从正文里删掉 | 哈希变了，重复计数会拆开。 |
| 连 `。` 一起删掉 | `不是免费。领取` 会命中关键词。URL 解析器已经把句号收成点。 |
| 引入同形字库 | ADR 0054 已经拒绝。这一项只处理点状字符。 |

## 后果

- `免·费领取`、`加·微信` 和 `免．费领取` 会命中现有关键词和默认正则。
- `https://bit·ly/…` 和 `https://t·me/+…` 会走现有短链和邀请规则。`https://example·com/…` 仍保留。
- `不是免费。领取` 仍不命中 `免费领取`。普通空格和全角加号仍按原样比较。
- 重复计数仍按原文哈希。`%C2%B7` 仍拆开主机名。全角拉丁字母后来由 ADR 0094 收成半角。全角数字仍保留。
