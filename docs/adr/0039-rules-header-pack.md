# ADR 0039：已订阅时 `/rules` 标题带上规则包 id

- 状态：已接受
- 日期：2026-11-01

## 背景

ADR 0038 让 `/rules` 列出检测正在执行的规则。标题仍只有群 id。管理员看到 `community_keywords` 时，还要再发一次 `/packs` 才知道这是哪一份包。刷新失败回到本地规则时，列表看起来和未订阅一样。

## 决策

- 这个群有订阅时，标题是 `rules {chatId} {pack}`。中英文用同一句，因为两边原来的标题都是 `rules {chatId}`。
- 未订阅、或者命令没有规则包来源时，标题仍是 `rules {chatId}`。
- 刷新失败但仍有订阅时，标题保留 pack id。列表可以是上一份或本地规则，标题说明订阅还在。
- 读订阅失败仍回复参数无效，不写标题。
- pack id 只来自订阅存储里已经通过 schema 的值。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 标题永远只写群 id | 订阅和回退后的列表都要再查一次 `/packs`。 |
| 回退到本地规则时去掉 pack id | 管理员会把这次失败看成已经退订。 |

## 后果

- 已订阅的 `/rules` 第一行能看出包 id。
- 未订阅的回复和以前相同。
- 另一个 isolate 的订阅最多晚 60 秒，标题也是这样。
