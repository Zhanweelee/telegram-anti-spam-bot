# ADR 0085：手动引用里的网址只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0061 在没有更前面的正文时，用手动引用当正文，并读取引用上的 `text_link`。已有正文时，引用留在事件外面。短链可以只写在手动引用的纯文本或隐藏链接里。

把引用拼进已有正文会改变 `textSha256`。自动引用和被回复的原消息是别人写的，不能算进这一条。

## 决策

- `quote.is_manual === true` 时，从 `quote.text` 抽出网址，并读取 `quote.entities` 里的 `text_link`。只留主机名。长度、折叠、邀请判断和 8 个主机名的上限不变。
- 已有正文时，引用原文不进正文，也不改内容哈希。`position` 不进事件。
- 没有更前面的正文时，手动引用仍整段成为正文。这条正文里的网址由链接规则从正文看见，同时也记在主机名列表里。
- 自动引用、`reply_to_message` 和 `external_reply` 上的引用不读。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 已有正文时把引用拼进去 | 引用会改变哈希。短链只需要主机名。 |
| 自动引用也抽主机名 | 回复别人的消息时，自己的正文会因为别人的短链被删掉。 |
| 只在引用不是正文时才抽 | 多一条分支。引用成为正文时，主机名列表仍应带上同一条网址。 |

## 后果

- 已有正文时，手动引用里的 `https://bit.ly/…` 会走现有短链删除。`https://t.me/+…` 和 `https://t.me/%2B…` 只留下 `t.me`，并记成邀请。
- 普通域名仍保留。引用原文、路径和邀请码在已有正文时不进事件。
- 引用成为正文时，整段引用仍参与关键词和内容哈希。
- 自动引用的原文仍不进事件。画出来的自动引用后来由 ADR 0712 只留主机名。关键词仍不命中。引用里的关键词后来由 ADR 0547 在已有正文时看见。原文不进审计。
- 付款成功这行会重画被回复账单的标题。这个标题后来由 ADR 0618 只留主机名。账单说明、回复正文和回复发送者仍不读。没有付款对象时，被回复账单的标题仍不读。
- 引用上的文字链接后来由 ADR 0732 要求起点小于摘录。摘录不是字符串时仍不读。投票描述、游戏说明和礼物仍读全部文字链接。
