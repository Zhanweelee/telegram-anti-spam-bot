# ADR 0744：投票选项上的自定义表情必须落在选项里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。投票题干上的表情必须整段落在题干里。见 ADR 0743。

选项是投票气泡上的另一行。选项文字目前只允许自定义表情。`replaceAnimatedEmoji` 只在 `offset + length` 不超过这段文字时才放上表情。起点已经越过选项，或表情越过选项末尾，都不会画出来。

现在每个选项会读全部 `text_entities`。一个越出选项的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条投票。

后加和删掉的选项、测验说明和投票描述不在这条里。

## 决策

- `poll.options` 里，`text` 是字符串时，这条选项的 `text_entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过这条选项。
- 选项文字不是字符串时，仍按原来的方式读取。
- 另一条选项里仍落得下的表情继续带 `asCustomEmoji`。
- 后加和删掉的选项不在这条里。编号仍不进事件。看得见的字仍是选项。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条投票。 |
| 只要求起点小于选项 | 表情越过末尾时，客户端同样不会画。 |
| 后加选项一起收 | 后加选项是另一条服务消息。 |
| 选项文字不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的选项。 |

## 后果

- 起点加长度越过选项的自定义表情不再带 `asCustomEmoji`。空选项和长度为 0 的实体也不带。
- 仍落在选项里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 后加和删掉的选项上越出文字的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
