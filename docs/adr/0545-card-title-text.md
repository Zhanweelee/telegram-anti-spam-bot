# ADR 0545：游戏、账单和场馆标题也走关键词和默认正则

- 状态：已接受
- 日期：2026-11-05

## 背景

ADR 0082 和 ADR 0081 在已有别的正文时，只从游戏标题、账单标题和场馆标题里抽出主机名。说明、附加文字和地址后来各自有了旁路字段。标题被别的正文挤开时，「免费领取」和「加微x」仍整段留在外面。短链会删，关键词看不见。卡片上的标题一直能看见。

Bot API 写明账单 `title` 是 1 到 32 字。游戏标题和场馆标题没有写长度。正文回退本来就截到 4096。

## 决策

- 已有别的正文时，按 `game.title`、`invoice.title`、`venue.title` 的顺序看。某一段去掉两端空白后仍有字，且自己不是正文时，另留对应字段。游戏和场馆各留前 4096 字，账单留前 32 字。这段自己就是正文时改看下一种。三段都是正文或都是空的，就不设这些字段。
- 字段名是 `gameTitle`、`invoiceTitle` 和 `venueTitle`。正文和 `textSha256` 仍按 ADR 0058 和 ADR 0059，先到的标题优先。
- 超出上限的字不进事件。主机名仍从整段标题抽取，包括被截掉的尾巴。
- 封面、动图文件名、币种、金额、`start_parameter`、坐标、地点编号和地点类型不进这三个字段。投票媒体里的场馆标题仍只留主机名。
- 关键词和 `regex` 同时看正文、`senderTag`、`buttonText`、`authorSignature`、`mirrorSignature`、`pollOption`、`checklistTask`、`mediaName`、`performer`、`gameText`、`invoiceText`、`venueAddress`、`pollExplanation`、`pollQuestion`、`prizeText`、`checklistTitle`、`gameTitle`、`invoiceTitle`、`venueTitle` 和 `profile`。证据仍是原来的摘要。标题原文不进证据，也不进日志。审计仍只留 `textSha256`。
- `regex` 命中时带上 `places`。这三个名字加入这份名单。`game_title_regex`、`invoice_title_regex` 和 `venue_title_regex` 只在 `places` 含有自己的字段时算命中。检测器没有 `places` 时仍按分数。
- 规则条件增加 `gameTitle: true`、`invoiceTitle: true` 和 `venueTitle: true`。消息上有对应字段时为真。
- 三条规则默认打开。条件是对应字段，检测器是现有的 `regex`，命中后 `delete`。
- 「免费领取」和「加微信」仍走已经打开的关键词规则。
- `regex_hint` 仍默认关闭。正文里的「加微x」不会因为旁边有干净的标题就被删掉。
- 不改 ADR 0026 的基础检测器名单。`keyword` 和 `regex` 已经在里面，超额后这三条仍会跑。
- `chats.json` 整份替换的群不会自动带上这三条规则。
- 不新增命令。菜单仍是 99 条。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认打开 `regex_hint` | 普通消息会被同一份模式删除。这次要读的是被别的正文挤开的标题。 |
| 把标题拼进已有正文 | 会改变 `textSha256`。ADR 0081 和 ADR 0082 已经拒绝。 |
| 三种标题放进同一个字段 | 账单只有 32 字。关掉其中一种时，另外两种还要留着。 |
| 给标题单独做一个检测器 | 关键词和正则已经会扫旁路字段。名单不用再加一项。 |
| 连投票媒体里的场馆标题一起收 | 那一层现在只留主机名。这条消息自己的地点卡片已经盖住看得见的标题。 |

## 后果

- 游戏、账单或场馆标题含「免费领取」或「加微信」时按关键词删除。含 `t.me/+`、「加微x」或「加微X」时按对应规则删除。证据不含标题原文。
- 标题干净时消息留下。它自己就是正文时，「加微x」仍要打开 `regex_hint`。后面另一种标题仍可以单独命中。
- 游戏和场馆从第 4097 个字符起不进事件。账单从第 33 个字符起不进事件。主机名仍从整段抽取。写在标题里的路径会留在对应字段，不进审计。
- 封面、动图文件名、币种、金额、启动参数、坐标和地点编号仍不进事件。投票媒体里的场馆标题仍不进这个字段。
- 关掉其中一条后，这一种标题回到只看关键词和短链。另外两种不受影响。
- 整份替换规则的群要自己加上这三条，才会删除标题上的「加微x」。
- 30 天保留期没有改。
