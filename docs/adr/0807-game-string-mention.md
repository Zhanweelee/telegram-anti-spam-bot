# ADR 0807：游戏附加文字不是字符串时不读按标识提及

- 状态：已接受
- 日期：2026-11-07

## 背景

按标识提及可以按群删除。用户编号不进事件。见 ADR 0514。附加文字是字符串时，按标识提及的起点必须落在附加文字里，长度必须大于 0。见 ADR 0763。礼物附言不是字符串时不读按标识提及。见 ADR 0806。

Android 只能把实体画在一段字符串上。附加文字不是字符串时，没有可以落点的文字，按标识提及画不出来。

现在这种附加文字仍会把 `text_entities` 整份读进来。打开 `text_mention` 后，没画出来的提及也会删掉这条游戏。

## 决策

- `game.text` 不是字符串时，不从 `text_entities` 读取按标识提及。
- 附加文字是字符串时，仍要求起点大于或等于 0 且小于附加文字长度，长度大于 0。长度越过末尾时仍带 `asTextMention`。空字符串仍是字符串。
- 用户编号和名字仍不进事件。封面和动图文件编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。事件里的附加文字仍只留前 4096 字。说明另留前 4096 字。
- 手动引用上的按标识提及仍不读取。自定义表情不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，提及不该在打开规则后删掉这条游戏。 |
| 把数字附加文字当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 按说明加附加文字的整段来量起点 | 实体画在附加文字上。说明是另一段。 |
| 手动引用也一起读 | 引用上的按标识提及仍不带这个标记。见 ADR 0574。 |
| 自定义表情一起改 | 表情是另一种实体。这条只改按标识提及。 |
| 默认打开 | 有的群会点名。打开之前不改现有群。 |

## 后果

- 附加文字不是字符串时，不再带 `asTextMention`。
- 附加文字是字符串且起点落在附加文字里时，打开 `text_mention` 后仍删除。证据仍是 `entity:text_mention`。用户编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 自定义表情在附加文字不是字符串时仍按原来的方式读取。
- 游戏附加文字不是字符串时，按标识提及后来由 ADR 0807 不再读取。正文不是字符串时，自定义表情后来由 ADR 0808 不再读取。说明不是字符串时，自定义表情后来由 ADR 0809 不再读取。投票题干不是字符串时，自定义表情后来由 ADR 0810 不再读取。测验说明不是字符串时，自定义表情后来由 ADR 0811 不再读取。投票描述不是字符串时，自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
