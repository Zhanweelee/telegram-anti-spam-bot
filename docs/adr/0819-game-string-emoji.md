# ADR 0819：游戏附加文字不是字符串时不读自定义表情

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。游戏附加文字是字符串时，自定义表情必须整段落在这段文字里。见 ADR 0752。礼物附言不是字符串时不读自定义表情。见 ADR 0818。

Android 只能把表情画在一段字符串上。附加文字不是字符串时，没有可以落点的文字，自定义表情画不出来。

现在这种游戏消息仍会把 `text_entities` 整份读进来。打开 `custom_emoji` 后，没画出来的表情也会删掉这条消息。

## 决策

- `game.text` 不是字符串时，不从 `text_entities` 读取自定义表情。
- 附加文字是字符串时，仍要求起点大于或等于 0，长度大于 0，并且起点加长度不能越过这段附加文字。空字符串仍是字符串。
- 第 4097 字起的表情，只要整段仍落在附加文字里，就继续带 `asCustomEmoji`。已有别的正文时，事件里的 `gameText` 仍只留前 4096 字。
- 编号仍不进事件。已有别的正文时，看得见的字仍是那段正文。
- 手动引用上的自定义表情不在这条里。按标识提及不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，表情不该在打开规则后删掉这条游戏消息。 |
| 把数字附加文字当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 游戏说明也按实体长度丢掉表情 | 说明没有自己的自定义表情列表。这条只改附加文字。 |
| 手动引用一起改 | 引用是另一段文字。这条只改游戏附加文字。 |
| 默认打开 | 有的群会用自定义表情。打开之前不改现有群。 |

## 后果

- 附加文字不是字符串时，不再带 `asCustomEmoji`。
- 附加文字是字符串且表情整段落在这段文字里时，打开 `custom_emoji` 后仍删除。证据仍是 `entity:custom_emoji`。编号不进事件。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 游戏附加文字不是字符串时，自定义表情后来由 ADR 0819 不再读取。手动引用不是字符串时，自定义表情后来由 ADR 0820 不再读取。富文本替代文字不是字符串时，自定义表情后来由 ADR 0821 不再读取。替代文字是空字符串时，自定义表情后来由 ADR 0822 不再读取。公式源码里的自定义表情后来由 ADR 0823 不再读取。预格式化块的语言标签里，自定义表情后来由 ADR 0824 不再读取。音频文件名里的自定义表情后来由 ADR 0825 不再读取。音频标题里的自定义表情后来由 ADR 0826 不再读取。音频表演者里的自定义表情后来由 ADR 0827 不再读取。视频文件名里的自定义表情后来由 ADR 0828 不再读取。动画文件名里的自定义表情后来由 ADR 0829 不再读取。文档文件名里的自定义表情仍按原来的方式读取。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
