# ADR 0109：富文本列表标签只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

富文本列表项有一个看得见的 `label`。没有别的正文时，这段标签会成为正文，链接规则能扫到里面的网址。已经有 `text` 或 `caption` 时，标签留在正文外面，里面的短链和邀请就对不上。

勾选状态和有序列表的序号不是网址。

## 决策

- 从每个列表项的 `label` 抽出网址，只留主机名。折叠、长度、邀请判断和 8 个主机名的上限与旁路纯文本相同。
- 嵌在别的块里的列表同样读取。
- 没有更前面的正文时，标签仍按 ADR 0076 成为正文。已有正文时，标签不并进去，也不改内容哈希。
- 不读取 `has_checkbox`、`is_checked` 和 `value`。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 已有正文时把标签拼进去 | 同一条消息的哈希会变，路径也会进事件。 |
| 只在标签成为正文时才扫描 | 短链可以只写在标签上，正文是另一句正常的话。 |
| 连勾选状态一起读 | 那不是网址。 |

## 后果

- 已有正文时，标签里的短链、邀请或裸 IP 按现有链接规则命中。路径和邀请码不进事件。
- 没有更前面的正文时，标签仍是正文，内容哈希按这段标签计算。
- 勾选状态和序号不进事件。
- 已有正文时，列表标签后来由 ADR 0564 另留在 `richText`。勾选状态和序号仍不进事件。
