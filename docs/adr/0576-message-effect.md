# ADR 0576：消息特效按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

一条消息可以带上 `effect_id`。这是客户端播放的特效编号，不是正文。广告常用它把一行普通文字变得显眼。现在没有开关，这种消息会留下。

被回复的原消息是另一条消息。付费帖仍不删除。

## 决策

- `effect_id` 是字符串，并且去掉空白后非空时，事件带 `asEffect: true`。空白、布尔值和缺字段不带这个标记。
- 嵌套的 `reply_to_message` 不读。编号不进事件，也不进证据。正文和 `textSha256` 不变。
- 检测器在 `@tasb/detector-effect`，id 是 `message_effect`。只在 `message.asEffect` 为 true 时返回 score 1。证据是 `effect:message`。
- 默认规则关闭。私聊 `/rule <chatId> message_effect on` 之后删除这种消息，`off` 回到留下。
- 不新增命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`message_effect` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认打开 | 正常群会用特效。打开之前不改现有群。 |
| 把编号写进证据 | 编号不是看得见的字。 |
| 连被回复的原消息一起扫 | `reply_to_message` 是另一条消息。原消息发出时已经扫过。 |
| 新命令 `/effect` | 菜单只剩一个空位。现有 `/rule` 已经能打开一条规则。 |

## 后果

- 规则关闭时，带特效的消息留下。正文仍参与关键词。编号仍不进事件。
- 打开 `message_effect` 后，这个群里带特效的消息会删除。没有特效的消息仍留下。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `message_effect` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `message_effect`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
