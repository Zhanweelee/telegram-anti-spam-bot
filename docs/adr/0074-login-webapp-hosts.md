# ADR 0074：登录按钮和小程序按钮只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0053 和 ADR 0055 从内联按钮的 `url` 和整段网址的 `copy_text` 取主机名，并明确不读 `login_url` 和 `web_app`。登录按钮会打开 `login_url.url`。小程序按钮会打开 `web_app.url`。短链或邀请可以只放在这两处，链接规则看不到。

## 决策

- `buttonUrls` 再读取 `login_url.url` 和 `web_app.url`。
- 这两条地址走和 `url` 相同的解析：长度、协议、折叠和邀请判断都不变。事件里只留主机名。
- `callback_data` 仍不读。复制句子仍只有整段是一条网址时才留下主机名。回复键盘仍不读。
- 不改 ADR 0026 的基础检测器名单。不引入同形字库。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 只在短链或邀请时才读取 | 普通域名的登录按钮也会被漏记。现有规则已经会放过普通域名。 |
| 连 `callback_data` 一起扫描 | 回调数据不是打开的网址，里面可以是任意字符串。ADR 0053 已经把它留在事件外面。 |
| 保存整段地址 | 路径和查询会进事件。现有证据只留主机名。 |

## 后果

- `login_url` 或 `web_app` 指向短链、邀请或裸 IP 时，按现有链接规则命中。
- 指向普通域名时仍保留。路径、查询和邀请码不进事件。
- `callback_data` 里的网址仍不进事件。
