# ADR 0321：分享的用户可见名字命中就删除

- 状态：已接受
- 日期：2026-11-03

## 背景

Bot API 的 `users_shared` 是用户通过按钮把若干用户分享给 bot 的服务消息。客户端会显示被请求的名字、姓氏和用户名。短链或关键词可以只放在这些名字里。这条消息通常没有 `text`。

发送者自己的 `from.first_name` 和这条消息所在聊天的 `chat.title` 不是这份分享名单。用户 id 和头像也不是看得见的字。

## 决策

- `users_shared.users` 里每个用户的 `first_name`、`last_name`、`username` 去掉首尾空白后，用一个普通空格拼起来，最长 4096 字符。
- 没有更前面的正文时，这段名字成为正文。关键词和链接规则因此能删除这条服务消息。路径留在正文里。
- 已有正文时，名字只贡献主机名。路径、用户名片段和关键词不进事件。
- 不读取 `request_id`、`user_id`、头像、`from` 上的姓名和 `chat.title`。
- 入群、视频聊天邀请、群主变更和靠近提醒仍走原来的名字。这份名单排在它们后面。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 名字永远只留主机名 | 关键词广告名会留在分享用户这行上。 |
| 读取每条消息的 `from` 姓名 | 会把普通发言者的姓名送进检测。 |
| 用户 id 或头像也进事件 | 它们不是打开的网址，也不该留在日志里。 |

## 后果

- 没有正文时，可见名字里的默认关键词、短链或邀请会删掉这条服务消息。证据仍只有关键词或主机名。路径留在正文里。
- 已有正文时，名字里的短链和邀请仍删除。正文和哈希不变。路径和用户名片段不进事件。
- `example.com` 和普通名字留着。用户 id、头像、请求编号、发送者姓名和所在聊天的标题不进事件。
- 云额度的基础检测器名单没有改。
- 新建受管 bot 的可见名字后来由 ADR 0322 按同一套规则处理。令牌和 bot id 不进事件。
- 已有别的正文时，分享来的用户名字后来由 ADR 0555 另留在 `sharedName`。关键词和默认正则可以删除。请求编号、用户编号和头像仍不进事件。
- 画出的名字后来按全名成为正文。名和姓都去掉两端空白，名在前。几个人用逗号分开。用户名不进。见 ADR 0644。
