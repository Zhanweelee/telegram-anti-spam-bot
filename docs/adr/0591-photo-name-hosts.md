# ADR 0591：换头像的人，名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

群头像被换掉或拿掉时，客户端把这个人的名字画在服务消息上。名字写在 `from`。新头像是一组图片尺寸，删头像是一个布尔值。文件号和尺寸当时留在事件外面。见 ADR 0479。这条消息通常没有正文。短链可以只写在换头像的人的名字里。

把 `from` 收成正文会让普通发言者的姓名也进检测。`chat_photo` 默认关闭，干净的提示仍留下。这次不调用 `deleteChatPhoto` 或 `setChatPhoto`。普通图片仍不读发送者。

## 决策

- 只在已经会标成 `photo` 的提示上，从 `from` 的可见名字留主机名。`new_chat_photo` 里至少有一个对象时读。`delete_chat_photo` 正好是 true 时也读。两条同时出现时仍先认换头像。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 空数组和 false 不读发送者。普通图片的 `photo` 数组因此仍不读 `from`。普通消息因此仍不读 `from`。
- 名字不进正文，也不改内容哈希。关键词因此不命中。文件号、唯一号和尺寸不读。本群群名不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`chat_photo` 仍默认关闭。8 个主机名的上限不变。不调用 `deleteChatPhoto` 或 `setChatPhoto`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把名字整段当成正文 | 关键词会命中人名。普通消息的 `from` 也会被打开。见 ADR 0479。 |
| 把文件号写进证据 | 文件号可以下载图片。见 ADR 0479。 |
| 普通图片也读 `from` | 发言人的名字会跟着每张图片重复计一次。 |
| 新命令 `/photoname` | 菜单只剩一个空位。现有 `links` 已经能删短链。`/delphoto` 仍负责拿掉群头像。 |

## 后果

- 换头像或删头像的人，名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。群头像本身不变。
- 名字原文、路径和用户名不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。文件号和尺寸不进事件。
- 换头像后来按全名只留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。见 ADR 0631。改群名后来按全名。见 ADR 0632。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 空数组、false 和普通图片仍不读发送者。干净的提示在 `chat_photo` 关闭时仍留下。拿掉群头像仍走 `/delphoto`。云额度的基础检测器名单没有改。30 天保留期没有改。
