# ADR 0044：超额后 `/rules` 标题带上窗口结束时间

- 状态：已接受
- 日期：2026-11-01

## 背景

ADR 0041 在超额后给不会跑的规则加上 `paused`。ADR 0043 把窗口结束时间放在 `/quota`。对照 `paused` 时还要再发一次 `/quota`。

## 决策

- `/rules` 仍只读额度，一次读取同时决定 `paused` 和标题。查看不计数。
- 快照已打开、已降级、带有 `basicDetectorIds`，并且带有 `resetsAt` 时，标题末尾加上 `until {resetsAt}`。中英文用同一个词。已订阅时 pack id 仍在 `until` 前面。
- 没超额、没有这份时间、读取失败或时间非法时，标题保持原样。失败记 `quota_failed`，不写异常文本，规则列表仍然返回，也不加 `paused`。
- 不改 ADR 0026 的默认基础检测器名单，也不把计数写进 KV 或 D1。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 没超额也在 `/rules` 标题上写结束时间 | 满额时标题变长。结束时间已经在 `/quota` 上。 |
| 另起一行写结束时间 | 标题已经是这组规则的状态，再拆一行更难扫。 |

## 后果

- 云上超额并且快照带有结束时间时，`/rules` 标题形如 `rules {chatId} until {resetsAt}`。已订阅时 pack id 夹在中间。
- 自定义的 `QuotaReader` 在降级快照里不带 `resetsAt` 时，标题不加 `until`，`paused` 仍按 ADR 0041。
- 重启后内存计数归零，标题回到没有 `until` 的样子。
