# ADR 0481：礼物卡片按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

成员收到普通礼物、独特礼物或升级购买时，看见一张卡片。附言和独特礼物的收藏名可以成为正文。见 ADR 0087 和 ADR 0324。没有附言的普通礼物只画出发布者用户名，用户名只留主机名，不进正文。用户名里没有短链时，关键词看不到这张卡片。

星星数量、礼物编号和贴纸文件号仍然不能写进事件。删掉这条服务消息不会退回星星。

## 决策

- `gift.gift` 是对象时，事件带 `gift: "card"`。`unique_gift.gift` 是对象时带 `unique`。`gift_upgrade_sent.gift` 是对象时带 `upgrade`。不写附言以外的名字、用户名、星星数量、编号和文件号。
- 几种同时出现时先认普通礼物，再认独特礼物，再认升级购买。空对象不带这个标记。已有正文时，正文仍按原来的优先级。附言、收藏名和发布者用户名仍按 ADR 0087 和 ADR 0324 处理。
- 检测器在 `@tasb/detector-gift`，id 是 `gift_card`。只在 `message.gift` 是这三种之一时返回 score 1。证据是 `gift:card`、`gift:unique` 或 `gift:upgrade`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这三种礼物卡片。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`gift_card` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部礼物 | 有的群用礼物打招呼。打开之前不改现有群。 |
| 只删没有附言的普通礼物 | 独特礼物和升级购买同样是成员看得见的卡片。 |
| 把星星数量或文件号写进证据 | 数量不是广告。文件号可以下载贴纸。都不能进事件。 |
| 新命令 `/gift` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，礼物卡片仍留下。附言和收藏名里的关键词、短链仍删除。发布者用户名里的短链仍删除。
- 打开 `gift_card` 后，这个群里的三种礼物卡片会删除。星星不退回。付费帖仍留下。
- `/guard` 只读这个群现在接不接受这些礼物，不改接受设置，也不改变这条删除规则。见 ADR 0530。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `gift_card` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
