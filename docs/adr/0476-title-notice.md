# ADR 0476：改名服务消息按群删除

- 状态：已接受
- 日期：2026-11-04

## 背景

群名被改掉时，成员看见一条服务消息。新名字只留主机名，不进正文。见 ADR 0114。名字里没有短链时，关键词看不到这句新名字，服务消息会留下。

新群名仍然不能写进事件。删掉这条服务消息也不会把群名改回去。

## 决策

- `new_chat_title` 是非空字符串时，事件带 `asTitle: true`。不写新群名。
- 空字符串、换头像和删头像不带这个标记。已有正文时，正文仍按原来的优先级。新名字里的主机名仍按 ADR 0114 抽取。
- 检测器在 `@tasb/detector-title`，id 是 `chat_title`。只在 `message.asTitle` 为 true 时返回 score 1。证据是 `title:rename`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这种改名服务消息。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`chat_title` 不在里面。不调用 `setChatTitle`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部改名提示 | 有的群会自己改名。打开之前不改现有群。 |
| 把新群名收成正文 | 群名会进事件和内容哈希。见 ADR 0114。 |
| 自动把群名改回去 | 这条更新里没有旧名字。改错群名比留下服务消息更重。 |
| 连社区名字和换头像一起删 | 那是另外的服务消息。这次只处理改名。 |
| 新命令 `/title` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，改名服务消息仍留下。新名字里的短链和邀请仍删除。
- 打开 `chat_title` 后，这个群里的改名服务消息会删除。群名本身不变。换头像仍留下。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `chat_title` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
- 社区服务消息后来由 ADR 0477 另开一条规则。换头像和删头像后来由 ADR 0479 另开一条规则。删掉服务消息仍不调用 `deleteChatPhoto`。
