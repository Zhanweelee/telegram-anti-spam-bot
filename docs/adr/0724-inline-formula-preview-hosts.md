# ADR 0724：富文本预览里的行内公式占满窗口

- 状态：已接受
- 日期：2026-11-07

## 背景

置顶提示和引用条上的富文本预览来自 `formatRichText`。行内公式画成 `fx` 加上一句本地化的公式说明，不画 LaTeX。

公式块已经按 ADR 0714 占满剩下的窗口。行内公式是同一种固定说法，却不占码元。公式后面的短链会被算进前 20 或 150 个码元，即使这句说明已经把它挤出窗口。

气泡里的整篇文章仍读公式原文里的主机名。

## 决策

- 置顶提示和引用条遇到行内 `mathematical_expression` 时，占满剩下的预览。公式原文不读。
- 公式前面已经画进窗口的短链仍读。
- 公式块仍占满窗口。气泡里的整篇文章仍读公式原文。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续不占码元 | 说明把短链挤出窗口后，没画出来的主机名仍会删掉这条消息。 |
| 预览也读 LaTeX | 短预览不画公式原文。原文里的地址没有出现在提示上。 |
| 气泡也不读公式 | 整篇文章会画出或展开公式。那条主机名仍要留下。 |

## 后果

- 行内公式后面的短链不再因为这条预览被删。公式前面的短链、邀请或裸 IP 仍会删除。证据只有主机名。
- 公式原文不进置顶提示和引用条。气泡里的文章仍读。内容哈希不变。关键词不命中预览。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- `pin_notice` 仍默认关闭。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
