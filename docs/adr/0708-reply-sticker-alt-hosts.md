# ADR 0708：贴纸预览行上的表情只留主机名

- 状态：已接受
- 日期：2026-11-06

## 背景

没有说明时，Android 把贴纸的表情和固定字样「Sticker」拼成这条消息的预览。聊天列表画这行。回复一条已经加载的贴纸时，引用条也画这行的前 150 个 UTF-16 码元。有说明时改画说明。

外部回复的贴纸不走这行。`getMediaTitle` 取的是当前消息自己的文件，不是外部贴纸的表情，所以那一行只剩固定字样。

ADR 0062、ADR 0084 和 ADR 0092 把 `sticker.emoji` 留在事件外面。短链可以只写在这个表情里。包名仍是标识，画不到这行上。

## 决策

- 没有 `caption` 和 `text`，并且这张贴纸占住预览行时，从 `sticker.emoji` 的前 150 个码元留主机名。
- 这条贴纸自己的列表预览，和已加载回复的引用条，都按这一行读。
- `caption` 或 `text` 的长度大于 0 时不读。说明和正文仍不进事件。
- 旁边还有动图、视频、图片或其他固定字样媒体时，不改读表情。
- 表情为空时，已加载的回复仍占住这一行，不改读附带的文件名。
- `external_reply.sticker.emoji` 不读。外部贴纸旁边的 `document.file_name` 仍不读。
- `set_name` 和 `custom_emoji_id` 不读。表情原文不进正文，也不改内容哈希。关键词因此不命中。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 外部贴纸的表情也读 | 外部回复那一行不画这张贴纸的表情。 |
| 有说明时也读表情 | 有说明时列表和引用条改画说明。 |
| 150 个码元之后也读 | 引用条只画前 150 个码元。 |
| 连贴纸包名一起读 | 包名不画在这行上，字符集也放不进网址。 |
| 把表情收进正文 | 它是预览行。关键词仍只看这条消息自己的正文。 |

## 后果

- 没有说明的贴纸，表情里的短链会删除这条消息。回复一张这样的贴纸时，也会删除这条回复。证据只有主机名。
- 有说明、外部回复，或表情只出现在第 151 个码元之后时，这条短链不删除。
- 包名、编号和附带文件名仍不进事件。表情不改内容哈希。关键词不命中表情。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
