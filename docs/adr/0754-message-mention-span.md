# ADR 0754：正文上的按标识提及必须从正文里开始

- 状态：已接受
- 日期：2026-11-07

## 背景

按标识提及可以按群删除。用户编号不进事件。见 ADR 0514。

Android 的 `addEntitiesToText` 会跳过长度小于或等于 0、起点小于 0，或起点已经到达正文末尾的实体。起点落在正文里、长度越过末尾时，客户端把长度收到正文末尾，这段提及仍会画出来。

现在正文会读全部 `entities`。一个起点已经越过正文的按标识提及仍会带上 `asTextMention`。打开这条规则后，没画出来的提及也会删掉这条消息。

说明、投票、清单、礼物和游戏不在这条里。

## 决策

- `text` 是字符串时，`entities` 里的按标识提及，起点必须大于或等于 0 且小于正文长度，长度必须大于 0。
- 起点落在正文里、长度越过末尾时，仍带 `asTextMention`。
- `text` 不是字符串时，仍按原来的方式读取。
- 说明上的按标识提及不在这条里。
- 仍落在正文里的提及继续带 `asTextMention`。用户编号和名字仍不进事件。看得见的字仍是正文。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的提及会在打开规则后删掉这条消息。 |
| 也要求长度落在正文里 | 起点在正文里时，客户端会把越过末尾的长度收回来再画。 |
| 说明也一起收 | 说明是另一段文字，这条只改正文。 |
| 默认打开 | 有的群会点名。打开之前不改现有群。 |

## 后果

- 起点已经到达或越过正文末尾的按标识提及不再带 `asTextMention`。空正文、长度为 0 和负起点也不带。
- 起点落在正文里的提及，打开 `text_mention` 后删除。证据仍是 `entity:text_mention`。用户编号不进事件。长度越过末尾的提及也删除。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 说明上的按标识提及后来由 ADR 0755 要求起点落在说明里。说明不是字符串时仍按原来的方式读取。长度越过末尾时仍算画出来。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
