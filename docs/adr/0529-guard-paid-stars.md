# ADR 0529：私聊可以看到这个群现在的付费门槛

- 状态：已接受
- 日期：2026-11-05

## 背景

超级群可以要求普通成员为每条消息支付星星。频道可以拒绝付费媒体。改价时的服务消息不留下数字，bot 晚加入时也看不到当时那条提示。`/guard` 已经读 `getChat`，但回复里没有这两项。

付费帖在 24 小时内不能删。管理员要先知道这个频道接不接受付费媒体，才知道为什么有的帖子会留下。

## 决策

- `/guard <chatId>` 在加速豁免后面多写两行。
- `paid_message_star_count` 是大于等于 0 的安全整数时，写成付费发言的星星数。字段缺失写未知。显式的 0 写成 0。
- `can_send_paid_media` 为 true 或 false 时，写成付费媒体开或关。字段缺失写未知。这个字段只在频道上出现，其它群写未知。
- 星星数不是非负安全整数，或付费媒体不是布尔值时，整份回复仍是「参数无效」，不露出已经读到的字段。
- 不把星星数写进事件，也不改价格。不调用 `setChatPermissions`。
- 不新增命令。菜单仍是 99 条。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 新命令只看星星数 | 菜单已经 99 条。这两项和慢速、自毁一样，都是这个群现在的门槛。 |
| 缺字段当成 0 或关闭 | 超级群经常不返回付费媒体。0 和没返回不是同一件事。 |
| 从改价服务消息记住数字 | 那条消息可以删，bot 没在场时也没有。`getChat` 才是现在的数。 |

## 后果

- `/guard -100` 能看到现在要付几颗星，以及频道是否接受付费媒体。
- 一次查看仍是一次 `getChat`。价格本身不变。
- 付费帖仍按原来的规则留下。30 天保留期没有改。
