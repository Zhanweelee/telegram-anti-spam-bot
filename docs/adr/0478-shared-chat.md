# ADR 0478：分享来的聊天按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

用户通过按钮把一个聊天分享给 bot 时，成员看见一张卡片。标题和用户名只留主机名，不进正文。见 ADR 0320。标题里没有短链时，关键词看不到这句名字，卡片会留下。

标题仍然不能写进事件。分享来的用户名字已经能成为正文，见 ADR 0321。这一轮不把两种分享放在同一个开关里。

## 决策

- `chat_shared.chat_id` 是有限安全整数时，事件带 `asSharedChat: true`。不写标题、用户名、请求编号、聊天编号和头像。
- 空的 `chat_shared`、`users_shared` 不带这个标记。已有正文时，正文仍按原来的优先级。标题和用户名里的主机名仍按 ADR 0320 抽取。
- 检测器在 `@tasb/detector-shared-chat`，id 是 `shared_chat`。只在 `message.asSharedChat` 为 true 时返回 score 1。证据是 `chat:shared`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这种分享卡片。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`shared_chat` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部分享卡片 | 有的群用按钮接收聊天。打开之前不改现有群。 |
| 把标题收成正文 | 聊天名字会进事件和内容哈希。见 ADR 0320 和 ADR 0027。 |
| 连分享来的用户一起删 | 用户的可见名字已经是正文。见 ADR 0321。 |
| 把聊天编号写进证据 | 编号不是广告，也不能进事件。 |
| 新命令 `/share` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，分享来的聊天仍留下。标题和用户名里的短链和邀请仍删除。
- 打开 `shared_chat` 后，这个群里的分享卡片会删除。分享来的用户仍留下。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `shared_chat` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
