# ADR 0480：聊天背景按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

群背景被换掉时，成员看见一条服务消息。壁纸和图案的文件名只留主机名，不进正文。见 ADR 0430。文件名里没有短链时，关键词看不到这句名字，服务消息会留下。纯色填充和内置主题同样没有可检测的正文。

删掉这条服务消息不会把背景改回去。文件名、文件号和主题名仍然不能写进事件。

## 决策

- `chat_background_set.type.type` 是 `wallpaper`、`pattern`、`fill` 或 `chat_theme` 时，事件带 `background`，取值是 `wallpaper`、`pattern`、`fill` 或 `theme`。不写文件名、文件号、颜色和主题名。
- 空的 `chat_background_set`，以及类型不是这四种时，不带这个标记。已有正文时，正文仍按原来的优先级。壁纸和图案文件名里的主机名仍按 ADR 0430 抽取。
- 检测器在 `@tasb/detector-background`，id 是 `chat_background`。只在 `message.background` 是这四种之一时返回 score 1。证据是 `background:` 加这一种。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这种服务消息。没有新命令。菜单仍是 99 条。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`chat_background` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部背景提示 | 有的群会自己换背景。打开之前不改现有群。 |
| 把文件名收成正文 | 文件名会进事件和内容哈希。见 ADR 0430。 |
| 只删壁纸和图案 | 纯色和内置主题同样是成员看得见的服务消息，正文同样是空的。 |
| 把文件号或主题名写进证据 | 文件号可以下载壁纸。主题名通常是表情。都不能进事件。 |
| 新命令 `/background` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，换背景的服务消息仍留下。壁纸和图案文件名里的短链和邀请仍删除。
- 打开 `chat_background` 后，这个群里的这四种背景服务消息会删除。背景本身不变。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `chat_background` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
- 换背景的人后来由 ADR 0593 只留下主机名。名字本身仍不进事件。文件号和主题名仍不读。空对象和其它类型仍不读发送者。普通消息的发送者仍不读。
