# ADR 0078：游戏和账单说明里的网址只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0058 让游戏标题和账单标题成为正文，并明确不读说明、附加文字和 `text_entities`。短链可以只放在 `game.description`、`game.text` 或账单 `description` 里，也可以藏在附加文字的 `text_link` 上。链接规则现在看不到。

把说明并进正文会改变 `textSha256`。封面文件 id 和启动参数也不能进事件。

## 决策

- 从 `game.description`、`game.text` 和 `invoice.description` 里抽出网址，只留主机名。
- `game.text_entities` 里的 `text_link` 走同一套解析。长度、折叠、邀请判断和 8 个主机名的上限不变。
- 说明和附加文字不进入 `message.text`，也不参与内容哈希。
- 不读取封面、`file_id`、币种、金额和 `start_parameter`。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把说明和附加文字拼进正文 | 哈希会变。ADR 0058 拒绝的就是这个。 |
| 只读 `text_link`，不扫说明里的纯文本网址 | 没有实体的短链仍会漏掉。 |
| 把封面文件 id 当成媒体 | 封面不是这条消息的附件。 |

## 后果

- 说明或附加文字里的短链、邀请按现有链接规则命中。普通域名仍保留。
- 标题仍是正文。说明里的关键词仍然看不到。
- 路径、邀请码、启动参数、币种和文件 id 不进事件。
