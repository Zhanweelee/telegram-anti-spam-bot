# ADR 0736：投票题干上的文字链接不能越过题干

- 状态：已接受
- 日期：2026-11-07

## 背景

投票气泡把题干画在标题上。短链在 `poll.question_entities`。见 ADR 0056 与 ADR 0083。

Android 先把题干收成一段文字，再用 `addEntitiesToText` 把实体画上去。文字链接的起点大于或等于题干时，链接不会画上去。

现在题干会读全部文字链接。起点已经越过题干的链接仍会留下主机名。

外部回复的清单标题已经要求起点落在标题里。见 ADR 0735。投票题干是另一段文字。引用条上对不上的问题已经按整段问题收过。见 ADR 0725。

## 决策

- `poll.question` 是字符串时，`question_entities` 里的文字链接，起点必须小于这段题干。题干不是字符串时，仍按原来的方式读取。
- 题干里的普通网址仍读。仍只留主机名。选项和测验说明仍按各自已经收过的长度读取。
- 投票描述不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条投票。 |
| 题干也只取前 150 个码元 | 气泡画出的是整段题干，不是引用条上的 150 个码元。 |
| 投票描述也按正文长度丢掉链接 | 这份客户端还没有画出描述。这条只改题干。 |

## 后果

- 起点越过题干的文字链接不再留下主机名。仍落在题干里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在题干里的路径仍留在正文或 `pollQuestion`。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 正文上的文字链接后来由 ADR 0737 同样要求起点落在正文里。说明仍不在那条里。
