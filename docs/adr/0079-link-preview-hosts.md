# ADR 0079：链接预览只留主机名

- 状态：已接受
- 日期：2026-11-02

## 背景

入站消息可以带 `link_preview_options.url`，用来指定链接预览打开的地址。正文里可以没有这条网址。现在归一化不读这个字段，短链或邀请只放在预览上时，链接规则看不到。

预览还有 `prefer_small_media`、`prefer_large_media` 和 `show_above_text`。这些不是网址。被回复消息上的预览属于另一条消息。

## 决策

- `message.link_preview_options.url` 走和按钮 `url` 相同的解析：长度、协议、折叠和邀请判断都不变。事件里只留主机名。
- 不保存预览开关和展示参数。
- 不读取 `external_reply.link_preview_options`。被回复的消息不进这条事件。
- 正文和内容哈希不变。预览网址里的路径和查询不进事件。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把预览网址拼进正文 | 同一条消息的哈希会变，路径也会进事件。 |
| 连被回复消息的预览一起读 | 那是另一条消息。回复本身可以是正常文字。 |
| 只在短链或邀请时才读取 | 普通域名的预览也会被漏记。现有规则已经会放过普通域名。 |

## 后果

- 预览指向短链、邀请或裸 IP 时，按现有链接规则命中。
- 指向普通域名时仍保留。路径、查询和邀请码不进事件。
- 被回复消息上的预览网址仍不进事件。
