# ADR 0471：别的频道代发按群删除

- 状态：已接受
- 日期：2026-11-04

## 背景

频道可以用自己的身份往超级群里发消息。`/bansender` 要知道频道号，而且不删已经发出的那一条。见 ADR 0370。正文没有关键词和短链时，这条代发会留下。

匿名管理员的 `sender_chat` 就是本群。讨论组里关联频道的自动转发也带着频道身份。这两类要留下。

## 决策

- `sender_chat.type` 正好是 `channel`，频道号和本群不同，并且 `is_automatic_forward` 不是 true 时，事件带 `asChannel: true`。不写频道号，不写标题。
- 本群自己的频道身份、没有 `type`、以及 `supergroup` 身份都不带这个标记。自动转发仍不记成频道转发。见 ADR 0443。
- 检测器在 `@tasb/detector-sender`，id 是 `channel_sender`。只在 `message.asChannel` 为 true 时返回 score 1。证据是 `sender:channel`。
- 默认规则用同样的 id，关闭。某个群用现有的私聊 `/rule` 打开后，删除这种代发。没有新命令。菜单仍是 99 条。
- 打开这条规则不调用 `banChatSenderChat`。按频道号禁止仍走 `/bansender`。
- 付费帖仍不删除。见 ADR 0356。
- 不改 ADR 0026 的基础检测器名单。`channel_sender` 不在里面。`forward` 仍在。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 默认删掉全部频道代发 | 有的群允许频道发言。打开之前不改现有群。 |
| 连讨论组自动转发一起删 | 关联频道的帖子会从讨论组消失。见 ADR 0443。 |
| 命中时自动 `banChatSenderChat` | 一次禁止会挡住这个主人名下的每个频道。删除这一条就够了。 |
| 新命令 `/sender` | 菜单只剩一个空位。现有 `/rule` 已经能打开这条规则。 |

## 后果

- 不打开这条规则的群，别的频道代发仍留下。关键词、短链和频道转发仍按原规则删除。
- 打开 `channel_sender` 后，这个群里别的频道发出的消息会删除。本群匿名管理员、普通成员和讨论组自动转发仍留下。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `channel_sender` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。频道转发仍用 `forward`，超额后还在。
- `chats.json` 整份替换的群要自己加上这条规则，才会有这个开关。
- 30 天保留期不动。
- 编号和本群不同的 `sender_chat.title` 后来由 ADR 0581 只留下主机名。标题本身仍不进事件。本群自己的身份、用户名和转发来源上的频道标题仍不读。
