# ADR 0673：聊天换背景时不读发送者的名字

- 状态：已接受
- 日期：2026-11-06

## 背景

换壁纸、图案、纯色或内置主题时，Android 的 `TL_messageActionSetChatWallPaper` 在发送者是聊天时不画人，也不画标题。句子是频道或群自己换了壁纸。发送者是用户时，才用 `UserObject.getFirstName`。

Bot API 把这条放在 `chat_background_set`。发送者是聊天时，`sender_chat` 是那个聊天，`from` 是占位用户。见 `telegram-bot-api` 的 `messageSenderChat`。单独的换主题动作 `messageChatSetTheme` 不会进 Bot API。

ADR 0593 仍从 `from` 留主机名。占位用户的名字不在这行里。本群群名仍不读。别的聊天代发时，标题仍按 ADR 0581 只留主机名。

## 决策

- 已经会标成 `background` 的提示上，`sender_chat` 是对象时不从 `from` 留主机名，也不从本群群名留主机名。壁纸、图案、纯色和内置主题都一样。
- 没有 `sender_chat` 时，仍从 `from` 的可见名字留主机名。名的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。
- 别的聊天标题仍按原来的代发规则。编号和本群相同时不读。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`chat_background` 仍默认关闭。短链仍走已有的 `links`。8 个主机名的上限不变。不改群背景。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读 `from` | 占位用户的名字不在这行里。短链会删掉一条没有这个名字的提示。 |
| 改读频道标题 | 这行不画标题。本群群名仍不收。 |
| 只跳过频道 | 群和超级群代发时同样不画人。 |
| 新命令 | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 聊天换背景时，占位用户名字里的短链、邀请或裸 IP 不再删除这条消息。别的聊天标题里的短链仍会删。
- 用户换背景时，可见名字里的短链仍会删。证据只有主机名。
- 名字原文、路径、用户名、文件号和主题名不进事件。内容哈希不变。关键词不命中这些名字。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 空对象、其它类型和普通消息仍不读发送者。本群群名仍不读。干净的提示在 `chat_background` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
