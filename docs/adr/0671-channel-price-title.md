# ADR 0671：改价的发送者是频道时只读频道标题

- 状态：已接受
- 日期：2026-11-06

## 背景

有人改付费发言的星星数量，或改频道私信开关时，Android 的 `MessageObject` 在 `TL_messageActionPaidMessagesPrice` 上先看发送者。发送者是广播频道时，`replaceWithLink` 画的是这个频道的标题，不是某个人的姓名。英文是 “un1 now accepts direct messages” 或 “un1 disabled direct messages”。群里其他人改价仍画这个人的全名。

Bot API 在广播频道里把这条放进 `direct_message_price_changed`，在其他聊天里放进 `paid_message_price_changed`。频道自己发出时，`sender_chat` 是这个频道，`from` 不出现。别的聊天里如果发送者是频道，`sender_chat.type` 是 `channel`，`from` 是占位用户。见 `telegram-bot-api` 的 `messageSenderChat`。

ADR 0629 仍从 `from` 留主机名。频道自己发出时 `from` 是空的，标题里的短链不会进主机名。占位用户的名字又不是这行画出的字。

## 决策

- 已经会标成 `priceNotice` 的提示上，`sender_chat.type` 正好是 `channel` 时，只从 `sender_chat.title` 留主机名，不从 `from` 留主机名。标题不截断。用户名不读。
- 发送者不是频道时，仍从 `from` 的全名留主机名。名和姓都去掉两端空白，名在前。空白名不挡住姓。空格不截断。
- 同时出现时仍先认付费发言。星星数量和开关不读。标题不进正文。
- 频道自己发出时，发送者和本群是同一个编号，仍按已有的管理员豁免。关掉豁免后，标题里的短链会删除这条提示。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`price_notice` 仍默认关闭。短链仍走已有的 `links`。8 个主机名的上限不变。不调用改价接口。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 频道标题继续不读 | 这行把频道标题画出来。标题上的短链会留在提示里。 |
| 频道也读 `from` | 频道自己发出时没有 `from`。占位用户的名字不在这行里。 |
| 本群群名一律都读 | 超级群匿名改价仍画群名，但那次决定不把本群群名收进来。这次只补广播频道。 |
| 新命令 | 菜单只剩一个空位。现有 `links` 已经能删除短链。 |

## 后果

- 改价的发送者是频道时，频道标题里的短链、邀请或裸 IP 会留下主机名。证据只有主机名。价格和私信开关不变。群和超级群后来由 ADR 0680 也只读这个聊天的标题。用户仍按全名。
- 频道自己发出的这条提示，默认仍因管理员豁免而留下。关掉豁免后会删。别的频道发到这个群时不豁免，标题里的短链会删。
- 占位用户的名字不再留下主机名。其他人的全名仍会删。
- 标题原文、路径和用户名不进事件。内容哈希不变。关键词不命中标题和全名。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 助推和付款成功仍只读名。空对象、负数、小数、字符串、布尔值和普通消息仍不读发送者。管理员仍豁免。干净的提示在 `price_notice` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
