# ADR 0505：富文本用户名提及按群删除

- 状态：已接受
- 日期：2026-11-05

## 背景

富文本里的用户名提及可以和看得见的字不同。字段是 `username`。ADR 0076 让这个字段不进事件，关键词看不见用户名。看得见的字已经可以成为正文。

按标识提及的用户是另一类字段。这一轮不给它加标记。

## 决策

- `type` 正好是 `mention`，并且 `username` 去掉空白后非空时，事件带 `asRichMention: true`。空白、布尔值和缺用户名不带标记。
- 按标识提及的用户不带这个标记。
- 用户名不进事件，也不进证据。看得见的字仍是正文。已有 `text` 或 `caption` 时正文不变，用户名不并进去。
- 检测器在 `@tasb/detector-rich`，id 是 `rich_mention`。只在 `message.asRichMention` 为 true 时返回 score 1。证据是 `rich:mention`。
- 默认规则关闭。私聊 `/rule <chatId> rich_mention on` 之后删除这种正文，`off` 回到留下。
- 不并进 `rich_email`、`rich_phone` 或 `rich_card`。不调用读取或改写用户名的方法。付费帖仍不删除。
- 不新增命令。菜单仍是 99 条。
- 不改 ADR 0026 的基础检测器名单。`rich_mention` 不在里面。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 并进邮箱 | 只想删邮箱的群会把用户名提及也删掉。 |
| 把用户名接到正文后面 | 同一条消息的哈希会变，用户名也会进事件。ADR 0076 已经拒绝。 |
| 把用户名写进证据 | 用户名不进事件。 |
| 默认打开 | 有的群用富文本点名。打开之前不改现有群。 |
| 新命令 `/mention` | 菜单还剩 1 个位置，留给以后的操作命令。 |

## 后果

- 规则关闭时，富文本用户名提及留下。看得见的字仍参与关键词。用户名仍不进事件。
- 打开 `rich_mention` 后，这个群里的富文本用户名提及会删除。打开邮箱仍不删除它。付费帖仍留下。
- 自部署没有额度，打开后就会删除。云模式超过当月次数后，还要把 `rich_mention` 写进 `QUOTA_BASIC`，否则超额时这条规则会停。
- `chats.json` 整份替换的群要自己加上 `rich_mention`，否则 `/rule` 会拒绝。
- 30 天保留期没有改。
