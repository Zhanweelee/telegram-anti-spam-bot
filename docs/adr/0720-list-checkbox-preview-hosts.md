# ADR 0720：富文本列表预览按复选框占位

- 状态：已接受
- 日期：2026-11-06

## 背景

置顶提示和引用条上的列表来自 `formatRichBlock`。无序列表没有复选框时画 `• `。有复选框时改画勾选框：勾上是 `✅ `，没勾上是 `☑️ `。`☑️` 后面还有变体选择符，比圆点多一个 UTF-16 码元。有序列表先画编号和 `. `，复选框画在编号后面。

ADR 0714 一律用圆点。没勾上的框会把窗口边上的短链多算进来。`has_checkbox` 不是 true 时仍用圆点。

## 决策

- 列表项 `has_checkbox` 正好是 true 时，短预览用勾选框。`is_checked` 正好是 true 时用 `✅ `，否则用 `☑️ `。
- 没有 `value` 时，勾选框代替圆点，再画标签。有 `value` 时，编号和 `. ` 仍在前面，勾选框画在后面。
- 只影响置顶提示和引用条的预览长度。气泡里的整篇文章仍读完整列表。预览不进正文，内容哈希不变。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续一律用圆点 | 没勾上的框多一个码元。窗口边上没画出来的短链会被删掉。 |
| 复选框占满剩下的预览 | 勾选框长度是固定的。后面画出来的短链会被漏掉。 |
| 气泡也改用勾选框当正文 | 整篇文章不靠这一个码元截断。 |

## 后果

- 复选框把短链推出前 20 或 150 个码元时，这条消息不再因为那个主机名被删。仍落在窗口里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。内容哈希不变。关键词不命中预览。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- `pin_notice` 仍默认关闭。管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
