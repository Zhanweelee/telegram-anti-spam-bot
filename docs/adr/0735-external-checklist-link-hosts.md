# ADR 0735：外部回复清单标题上的文字链接不能越过标题

- 状态：已接受
- 日期：2026-11-07

## 背景

原文不在本群时，引用条用 `getMediaTitle` 画外部清单。标题非空时走 `formatTextWithEntities`，再用 `addEntitiesToText` 把实体画到标题上。文字链接的起点大于或等于标题时，链接不会画上去。画完之后才按宽度省略，不按 150 个码元先截断。

已加载的清单回复仍先取前 150 个码元。见 ADR 0709。外部回复读的是整段标题。见 ADR 0704。

现在这段标题会读全部文字链接。起点已经越过标题的链接仍会留下主机名。

礼物附言已经要求起点落在附言里。见 ADR 0734。外部清单标题是另一段文字。

## 决策

- `external_reply.checklist.title` 是字符串时，`title_entities` 里的文字链接，起点必须小于这段标题。标题不是字符串时，仍按原来的方式读取。
- 标题里的普通网址仍读。仍只留主机名。任务不读。
- 起点落在标题里、但已经超过 150 个码元的文字链接仍读。宽度省略发生在实体画上之后。
- 投票描述不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条回复。 |
| 也只取前 150 个码元 | 外部回复先画整段标题，再按宽度省略。已加载回复才先截到 150。 |
| 投票描述也按正文长度丢掉链接 | 这份客户端还没有画出描述。这条只改外部清单标题。 |

## 后果

- 起点越过标题的文字链接不再留下主机名。仍落在标题里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在标题里的路径仍留在标题字段或正文。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
