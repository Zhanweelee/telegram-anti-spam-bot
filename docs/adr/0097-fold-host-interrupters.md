# ADR 0097：主机名扫描前去掉夹在标签里的字母

- 状态：已接受
- 日期：2026-11-02

## 背景

ADR 0096 收了乌克兰语 `і`。还没收的字母仍会把 ASCII 单词边界切开。`bтit.ly` 被扫成 `it.ly`，短链名单对不上。带协议时，URL 解析器把整段收成 punycode，主机名也不是 `bit.ly`。

`т` 仍不映成 `t`。汉字紧贴着短链，例如 `点击bit.ly`，必须继续命中。

## 决策

- 新增 `foldHostInterrupters`。只在抽主机名时使用。
- 它去掉非 ASCII 的西里尔字母、希腊字母和拉丁字母。这些字被删掉，不映成别的字母。
- 调用顺序在 `foldCyrillicLookalikes` 和 `foldFullwidthLatin` 之后。已经收成拉丁字母的字会留下。
- 关键词和正则不走这一层。
- ASCII、汉字、谚文、假名、全角数字、`U+FF0B`、`U+3002` 和普通空格保留。
- 事件里的正文和 `textSha256` 不变。不新增检测器，也不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 拒绝从任何非 ASCII 字母后面开始主机名 | `点击bit.ly` 会放行。 |
| 把 `т` 收成 `t` | `т.me` 会变成邀请。ADR 0095 已经拒绝。 |
| 在关键词里也删这些字母 | 俄文比较会被拆空。这一项只服务主机名。 |

## 后果

- `bтit.ly/…` 在扫描时变成 `bit.ly`，走现有短链规则。`点击bit.ly` 仍命中。
- `xтbit.ly` 变成 `xbit.ly`，不再被看成 `bit.ly`。
- `т.me/+…` 变成 `.me/+…`，仍不是邀请。
- 重复计数仍按原文哈希。
