# ADR 0316：主机名中间的忽略标记不影响草稿里的文字字母

- 状态：已接受
- 日期：2026-11-03

## 背景

Android 在带协议主机名中间遇到地址解析会忽略的标记时，仍把后面的希腊文、西里尔文、亚美尼亚文和非 ASCII 拉丁字母算进这条链接。`http://bit​.lyα/…`、`http://bit.l​yα/…`、`http://bi​t.lyα/…`、`http://bit.ly​.α/…` 和 `http://203.0.113​.10ա/…` 的主机名不是前面的短链或裸 IP。`http://bit​.lyα.bit.ly/…` 的主机名仍以 `bit.ly` 结尾。见 ADR 0228。

没有协议的 `bit​.lyα/…` 和 `bit.ly​.α/…` 只打开前面的短链。`#`、空格、换行和放不下的字母也退回短链。

`http://bit​.lyα@evil.com/…` 在看得见的正文里仍打开 `bit.ly`。隐藏草稿认主机名时停在标记上，字母被收掉之后 `@` 变成用户信息，主机名记成 `evil.com`。

## 决策

- 分享 `text`、私聊预填 `tg://msg` 的 `text` 和用户名草稿的 `text`，在判断 `http://` 或 `https://` 的主机名时先拿掉这种标记。后面的这类字母紧接着 `@` 时，先把字母换成空格。
- 这种标记是地址解析会忽略、并且 Android 标签类收得下的字符，包括 U+034F。制表符、换行和不换行空格不在里面。
- 主机名取最长的严格域名，不在中间的短链后缀停住。点分 IPv4 同样。结束位置指回原文。
- 路径、问号、结尾、写完的端口和再接一个域名时，字母仍交给主机名扫描。
- `#`、空格、换行和放不下的字母仍按原来的规则收掉。没有协议的主机名不改。
- 不改带协议网址的整段匹配。闭合分享链接里的网址不走这道切开。公开的折叠不改。
- 证据只留主机名。路径不进证据。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 标记仍让主机名停住 | `http://bit​.lyα/…` 会按短链删除。Android 打开的不是 `bit.ly`。 |
| `@` 前面的字母也留在标签里 | `http://bit​.lyα@evil.com/…` 会漏掉已经打开的短链。 |
| 换行也拿掉再判断 | `http://bit.ly` 换行再接 `α/…` 会漏掉。Android 只打开 `bit.ly`。 |

## 后果

- `t.me/share/url?text=http://bit​.lyα/…`、`http://bit.l​yα/…`、`http://bi​t.lyα/…`、`http://bit.ly​.α/…`、`http://203.0.113​.10ա/…` 和 `http://bit​.lyα/http://t.co/…` 留着。路径不进证据。
- `http://bit​.lyα.bit.ly/…` 仍按短链删除。证据是 `bit.lyx.bit.ly`。
- `bit​.lyα/…`、`bit.ly​.α/…`、`www.bit.ly​.α/…` 和 `203.0.113.10​.α/…` 仍按短链或裸 IP 删除。
- `http://bit​.lyα@evil.com/…`、`http://bit​.lyα#…`、换行和中间有空格的写法仍按短链删除。证据是 `bit.ly`。
- 放不下的标签仍让短链单独打开。`bαit.ly` 和 `bit​.ly` 仍按短链删除。
- 非间距标记写在标签末尾时，这类字母也留在带协议的主机名里。见 ADR 0229。
- 连字符贴在带协议主机名末尾时，后面的文字字母在隐藏草稿里也留在标签里。`http://bit.ly-α@evil.com/…` 仍按短链删除。见 ADR 0317。
