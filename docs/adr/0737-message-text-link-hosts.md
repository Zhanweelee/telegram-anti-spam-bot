# ADR 0737：正文上的文字链接不能越过正文

- 状态：已接受
- 日期：2026-11-07

## 背景

普通文字消息把正文画在气泡里。短链在 `entities`。见 ADR 0029。

Android 先收成 `messageText`，再调用 `addEntitiesToText`。文字链接的起点大于或等于这段正文时，链接不会画上去。

现在正文会读全部文字链接。起点已经越过正文的链接仍会留下主机名。

投票题干已经要求起点落在题干里。见 ADR 0736。正文是另一段文字。

## 决策

- `text` 是字符串时，`entities` 里的文字链接，起点必须小于这段正文。`text` 不是字符串时，仍按原来的方式读取。
- 写在正文里的普通网址仍由链接检测从正文读取。仍只留主机名。
- 说明上的 `caption_entities` 不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部文字链接 | 没画上去的链接会删掉这条消息。 |
| 说明一起按正文长度丢掉 | 说明是另一段文字。这条只改正文。 |
| 投票描述也按正文长度丢掉链接 | 这份客户端还没有画出描述。这条只改正文。 |

## 后果

- 起点越过正文的文字链接不再留下主机名。仍落在正文里的短链、邀请或裸 IP 会删除。证据只有主机名。
- 被截断的路径不进事件。写在正文里的路径仍留在正文。关键词不命中没画上去的链接。内容哈希不变。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
- 说明上的文字链接后来由 ADR 0738 要求起点小于这段说明。说明不是字符串时仍按原来的方式读取。
