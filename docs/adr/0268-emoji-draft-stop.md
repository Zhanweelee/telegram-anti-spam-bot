# ADR 0268：隐藏草稿里的表情后面仍留下主机名

- 状态：已接受
- 日期：2026-11-03

## 背景

ADR 0267 让隐藏草稿在竖线、控制符和替换字符处停住。表情是另一类停住字符：它落在 Android 路径类省略的代理区，后面的短链会另开一条。

同一段代理区里，还有 Android 仍算进路径的成对码位。把这些字符也换成空格，路径后半段的裸域名会被误报。

## 决策

- 分享 `text`、私聊预填 `tg://msg` 的 `text` 和用户名草稿的 `text`，遇到路径类省略的代理字符时换成空格，后面的网址另算一条。
- Android 留在路径里的成对增补字符保持原样，不拆开后面的网址。
- 查询值不进入正文，也不参与关键词。路径不进证据。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 表情继续留在同一条网址里 | 后面的短链会漏。 |
| 所有代理字符都换成空格 | 路径里留住的增补字符后面会被误报。 |
| 只处理看得见的正文 | 隐藏 `text_link` 仍会漏。 |

## 后果

- `t.me/share/url?text=https://example.com/` 接上表情再接 `http://bit.ly/…` 时删除。证据仍只有主机名。
- 路径里留住的增补字符后面的短链留着。
- `%2http://bit.ly` 仍不拆开。
