# ADR 0227：忽略标记后面的文字字母留在带协议的主机名里

- 状态：已接受
- 日期：2026-11-03

## 背景

ADR 0224 把紧贴在带协议主机名后面的希腊文、西里尔文、亚美尼亚文和非 ASCII 拉丁字母留在标签里。中间再插一个地址解析会忽略、Android 仍算进标签的标记时，这些字母仍被删掉。删掉以后标记自己也被折掉，短链重新打开。

`http://bit.ly​α/…`、`https://t.co​т?…`、`http://203.0.113.10​ա/…`、`http://bit.ly­α/…`、`http://bit.ly️α/…` 和 `http://bit.ly͏α/…` 在 Android 上各是一条链接。地址解析器给出的主机名不是前面的短链或裸 IP。`http://bit.ly​α/http://t.co/…` 的路径仍属于这一条。`see http://bit.ly​α/…` 也是。

`http://bit.ly​α.bit.ly/…` 的主机名仍以 `bit.ly` 结尾。没有协议的 `bit.ly​α/…` 只打开 `bit.ly`。`http://bit.ly​α#…`、`http://bit.ly​α@evil.com/…`、换行和中间有空格的写法也退回前面的短链。零宽字符再加第 61 个字母时，短链单独打开。`bαit.ly` 仍是短链。夹在 `bit` 和 `.ly` 中间的零宽字符仍收成 `bit.ly`。

## 决策

- 只改主机名扫描。公开的折叠不改。
- 写完的带协议主机名后面有一段这种标记时，下一段这类字母在 Android 仍把它算进这条链接时留下。句号和点号后面的同一段标记也算。
- 这种标记是地址解析会忽略、并且 Android 标签类收得下的字符，包括 U+034F。制表符、换行和不换行空格不在里面。
- 后面是 `#`、`@` 或空格，或者这段字母让标签超过 63 个字符时，仍删掉这些字母。
- 没有协议时仍删掉。夹在两个 ASCII 字母中间时仍删掉。
- 每段仍走现有的短链、裸 IP、邀请和 denylist 判断。只拆一层。最多 8 个。证据只留主机名。
- 不新增检测器。不改 ADR 0026 的基础检测器名单。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 标记后面继续删掉这些字母 | `http://bit.ly​α/…` 会按短链删除。Android 打开的不是 `bit.ly`。 |
| 换行后面也把字母留下 | `http://bit.ly` 换行再接 `α/…` 会漏掉。Android 只打开 `bit.ly`。 |
| 没有协议也留下 | `bit.ly​α/…` 会漏掉。Android 只打开 `bit.ly`。 |

## 后果

- `http://bit.ly​α/…`、`https://t.co​т?…`、`http://www.bit.ly​α/…` 和 `http://203.0.113.10​ա/…` 留着。
- `http://bit.ly­α/…`、`http://bit.ly️α/…` 和 `http://bit.ly͏α/…` 留着。
- `http://bit.ly​α/http://t.co/…` 留着。路径里的短链不另记。
- `see http://bit.ly​α/…` 和 `http://bit.ly​α.evil.com/…` 留着。
- `bit.ly​α/…`、`www.bit.ly​α/…` 和 `203.0.113.10​α/…` 仍删除。
- `http://bit.ly​α#…`、`http://bit.ly​α@evil.com/…` 和换行后面的字母仍按短链删除。
- `http://bit.ly​α.bit.ly/…` 仍按短链删除。证据是收成 `x` 的主机名。
- `bαit.ly` 仍按短链删除。第 61 个字母仍让短链单独打开。`bit​.ly` 仍按短链删除。路径不进证据。
