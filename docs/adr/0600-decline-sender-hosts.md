# ADR 0600：拒绝建议帖的人，名字只留主机名

- 状态：已接受
- 日期：2026-11-05

## 背景

有人拒绝一条建议帖时，客户端把这个人的名字画在服务消息上。名字写在 `from`。拒绝说明当时已经按原来的方式处理。见 ADR 0113。短链可以只写在拒绝的人的名字里。

把 `from` 收成正文会让普通发言者的姓名也进检测。`post_declined` 默认关闭，干净的说明仍留下。空对象仍然是这行拒绝。布尔值仍不是。嵌套的原帖仍不读。

## 决策

- 只在已经会标成 `asPostDeclined` 的提示上，从 `from` 的可见名字留主机名。`suggested_post_declined` 是对象时读。空对象也读。
- `first_name` 的长度大于 0 时只读名。空白也算有名。名缺失或正好是空字符串时改读姓。用户名不读。抽出之前不截断。
- 说明仍按 ADR 0113 成为正文。已有别的正文时仍留在 `declineComment`。拒绝的人的名字不进正文，也不改内容哈希。关键词因此不命中这个人的名字。嵌套的原帖不读。本群群名不读。
- 布尔值不读发送者。普通消息不读 `from`。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。`post_declined` 仍默认关闭。8 个主机名的上限不变。不调用 `declineSuggestedPost`。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 把拒绝的人整段当成正文 | 关键词会命中人名。普通消息的 `from` 也会被打开。见 ADR 0113。 |
| 并进 `post_declined` | 打开拒绝提示的群并不一定要按名字里的短链删。稿子状态仍不变。 |
| 读取嵌套原帖 | 原帖是另一条消息。说明仍按原来的正文。见 ADR 0113。 |
| 新命令 `/declinename` | 菜单只剩一个空位。现有 `links` 已经能删短链。 |

## 后果

- 拒绝建议帖的人，名字里出现短链、邀请或裸 IP 时，会删掉这一条。证据只有主机名。稿子状态不变。
- 这个人的名字原文、路径和用户名不进事件，内容哈希不变。名字里的关键词不命中。
- 名的长度大于 0 时，姓和用户名不进事件。说明仍按原来的正文。嵌套原帖仍不进事件。
- `example.com` 和公开的 `t.me/名字` 留着。付费帖仍不删除。见 ADR 0356。
- 布尔值和普通消息仍不读发送者。本群群名仍不读。干净的说明在 `post_declined` 关闭时仍留下。云额度的基础检测器名单没有改。30 天保留期没有改。
