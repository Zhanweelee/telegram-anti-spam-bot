# ADR 0797：消息正文不是字符串时不读文字链接

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。正文是字符串时，文字链接的起点必须落在正文里，长度必须大于 0。见 ADR 0764。消息说明不是字符串时不读文字链接。见 ADR 0796。

Android 只能把实体画在一段字符串上。正文不是字符串时，没有可以落点的文字，文字链接和代码块语言都画不出来。

现在这种正文仍会把 `entities` 整份读进来。打开链接规则后，没画出来的链接也会删掉这条消息。

## 决策

- `text` 不是字符串时，不读 `entities` 里的文字链接和代码块语言。
- 正文是字符串时，仍要求起点落在正文里，长度是大于 0 的安全整数。长度越过末尾时仍留下主机名。空字符串仍是字符串。
- 事件正文仍只留前 4096 字。链接仍按整段正文判断。
- 写在正文里的普通网址仍从正文抽取。正文不是字符串时，这段抽取本来就不会留下主机名。
- 引用条上的正文已经只在正文是非空字符串时读取。这条不改。
- 按标识提及和自定义表情不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，链接不该删掉这条消息。 |
| 把数字正文当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 按标识提及一起改 | 提及是另一种实体。这条只改正文上的文字链接。 |
| 引用条上的正文再改一次 | 那一行已经只在正文是非空字符串时读取。 |

## 后果

- 正文不是字符串时，文字链接和代码块语言不再留下主机名。
- 正文是字符串时，短链、邀请或裸 IP 仍删除。证据只有主机名。
- 按标识提及在正文不是字符串时，后来由 ADR 0798 不再读取。自定义表情在正文不是字符串时仍按原来的方式读取。
- 正文不是字符串时，按标识提及后来由 ADR 0798 不再读取。说明不是字符串时，按标识提及后来由 ADR 0799 不再读取。投票题干不是字符串时，按标识提及后来由 ADR 0800 不再读取。测验说明不是字符串时，按标识提及仍按原来的方式读取。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
