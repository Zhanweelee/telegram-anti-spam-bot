# ADR 0792：投票题干不是字符串时不读文字链接

- 状态：已接受
- 日期：2026-11-07

## 背景

短链可以按群删除。证据只留主机名。见 ADR 0029。投票题干是字符串时，文字链接的起点必须落在题干里，长度必须大于 0。见 ADR 0766。编号对不上时画出的问题，文字是字符串时同样要求长度大于 0。见 ADR 0781。投票描述不是字符串时不读文字链接。见 ADR 0791。

Android 只能把实体画在一段字符串上。题干不是字符串时，没有可以落点的文字，文字链接和代码块语言都画不出来。

现在这种题干仍会把 `question_entities` 整份读进来。打开链接规则后，没画出来的链接也会删掉这条消息。

## 决策

- `poll.question` 不是字符串时，不读 `question_entities`。
- `reply_to_poll_option_id` 对不上选项、改画问题时，问题不是字符串也不读 `question_entities`。
- 题干是字符串时，仍要求起点落在题干里，长度是大于 0 的安全整数。长度越过末尾时仍留下主机名。
- 已有别的正文时，事件里的题干仍只留前 300 字。题干自己就是正文时，事件正文仍只留前 4096 字，不再另留题干。写在题干里的普通网址仍从整段题干抽取。
- 引用条仍读整段问题，不按 150 个码元截断。选项编号对上时仍不读问题。
- 按标识提及和自定义表情不在这条里。清单标题不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续整份读取 | 没有画出的文字，链接不该删掉这条消息。 |
| 把数字题干当成空字符串再套起点 | 客户端没有这段文字，起点对不上。 |
| 提及和表情一起改 | 那是另一套标记。这条只改文字链接。 |
| 清单标题一起改 | 标题是另一段文字。 |

## 后果

- 投票题干不是字符串时，文字链接和代码块语言不再留下主机名。引用条上对不上的问题同样不再留下。
- 题干是字符串时，短链、邀请或裸 IP 仍删除。证据只有主机名。
- 按标识提及在题干不是字符串时，后来由 ADR 0800 不再读取。自定义表情在题干不是字符串时仍按原来的方式读取。
- 清单标题不是字符串时，文字链接后来由 ADR 0793 不再读取。礼物附言不是字符串时，文字链接后来由 ADR 0794 不再读取。游戏附加文字不是字符串时，文字链接后来由 ADR 0795 不再读取。消息说明不是字符串时，文字链接后来由 ADR 0796 不再读取。消息正文不是字符串时，文字链接后来由 ADR 0797 不再读取。正文不是字符串时，按标识提及后来由 ADR 0798 不再读取。说明不是字符串时，按标识提及后来由 ADR 0799 不再读取。投票题干不是字符串时，按标识提及后来由 ADR 0800 不再读取。测验说明不是字符串时，按标识提及后来由 ADR 0801 不再读取。投票描述不是字符串时，按标识提及后来由 ADR 0802 不再读取。清单标题不是字符串时，按标识提及后来由 ADR 0803 不再读取。清单任务文字不是字符串时，按标识提及后来由 ADR 0804 不再读取。后加任务文字不是字符串时，按标识提及后来由 ADR 0805 不再读取。礼物附言不是字符串时，按标识提及后来由 ADR 0806 不再读取。游戏附加文字不是字符串时，按标识提及后来由 ADR 0807 不再读取。正文不是字符串时，自定义表情后来由 ADR 0808 不再读取。说明不是字符串时，自定义表情后来由 ADR 0809 不再读取。投票题干不是字符串时，自定义表情后来由 ADR 0810 不再读取。测验说明不是字符串时，自定义表情后来由 ADR 0811 不再读取。投票描述不是字符串时，自定义表情仍按原来的方式读取。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
