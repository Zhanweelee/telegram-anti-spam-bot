# ADR 0707：固定字样的引用条不读附带文件名

- 状态：已接受
- 日期：2026-11-06

## 背景

动图、视频、音频、语音、圆形视频、贴纸和图片的引用条只画固定字样。Bot API 为了兼容，动图仍会同时带上 `document`。视频、音频、语音、圆形视频、贴纸和图片也可能再带一份 `document`。

ADR 0705 写明这些文件名不读，判断时只看了有没有 `document`。两份一起出现时，附带的 `file_name` 仍被收进主机名。外部回复也是先看见 `document`。见 ADR 0704。

## 决策

- `reply_to_message` 或 `external_reply` 上已经有动图、音频、语音、圆形视频、视频、贴纸、图片，或其余只会画固定字样的媒体时，不读旁边的 `document.file_name`。
- 外部回复上的清单标题和账单说明仍先读。
- 只有普通文件时，仍按 ADR 0705 和 ADR 0704 读文件名的前 150 个码元，或外部回复的整段文件名。
- 文件名不进正文，也不改内容哈希。关键词因此不命中。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。短链仍走已有的 `links`。8 个主机名的上限不变。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 两份都在时仍读 `document.file_name` | 引用条画的是固定字样，不是这个文件名。 |
| 只跳过动图 | 视频、音频、贴纸和图片也画固定字样。 |
| 把文件名收进正文 | 它没有画在引用条上。关键词仍只看这条消息自己的正文。 |

## 后果

- 固定字样占住引用条时，附带文件名里的短链不再删除这条回复。没有说明的贴纸，预览行上的表情后来由 ADR 0708 只留主机名。外部贴纸的表情仍不读。骰子这一行画的是表情，后来由 ADR 0710 只留主机名。点数仍不读。
- 没有这些媒体的普通文件，文件名里的短链仍会删除。证据只有主机名。
- 说明、正文和被回复的原文仍不进事件。文件名不改内容哈希。关键词不命中文件名。
- `example.com` 和公开的 `t.me/名字` 留下。付费帖仍不删除。见 ADR 0356。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
