# ADR 0748：清单标题上的自定义表情必须落在标题里

- 状态：已接受
- 日期：2026-11-07

## 背景

自定义表情可以按群删除。编号不进事件。见 ADR 0515。投票描述必须整段落在描述里。见 ADR 0747。

清单标题由 `formatTextWithEntities` 画出来。这个函数先按实体画文字，再交给 `replaceAnimatedEmoji`。表情只在 `offset + length` 不超过这段标题时才画出来。起点已经越过标题，或表情越过标题末尾，都不会画出来。预览文案 `MessageTodoName` 用的是整段标题。

已有别的正文时，事件里的 `checklistTitle` 只留前 255 字。标题自己就是正文时，正文最多留 4096 字。表情仍按整段标题判断。

现在标题会读全部 `title_entities`。一个越出标题的自定义表情仍会带上 `asCustomEmoji`。打开这条规则后，没画出来的表情也会删掉这条清单。

清单任务不在这条里。

## 决策

- `checklist.title` 是字符串时，`title_entities` 里的自定义表情，起点必须大于或等于 0，长度必须大于 0，并且起点加长度不能越过整段标题。
- 标题不是字符串时，仍按原来的方式读取。
- 第 256 字起的表情，只要整段仍落在标题里，就继续带 `asCustomEmoji`。已有别的正文时，事件里的 `checklistTitle` 仍只留前 255 字。
- 仍落在标题里的表情继续带 `asCustomEmoji`。编号仍不进事件。
- 清单任务不在这条里。
- 不新增检测器，不新增命令。菜单仍是 99 条。不改 ADR 0026 的基础检测器名单。规则仍默认关闭。

## 备选

| 方案 | 放弃原因 |
| --- | --- |
| 继续读全部实体 | 没画出来的表情会在打开规则后删掉这条清单。 |
| 只要求起点小于标题 | 表情越过末尾时，客户端同样不会画。 |
| 也按 255 字丢掉后面的表情 | 255 只是旁路字段的上限。整段标题更长时，后面的表情仍落在标题里。 |
| 按引用条的 150 字丢掉后面的表情 | 这条消息自己画出整段标题。150 是引用条的窗口。 |
| 标题不是字符串时也不读 | 现有消息仍会带上这种实体。这条只改画出的标题。 |
| 清单任务一起收 | 任务是另一段文字。 |

## 后果

- 起点加长度越过清单标题的自定义表情不再带 `asCustomEmoji`。空标题和长度为 0 的实体也不带。
- 仍落在标题里的表情，打开 `custom_emoji` 后删除。证据仍是 `entity:custom_emoji`。编号不进事件。起点已经超过 255、但仍整段落在标题里的表情也删除。
- 规则关闭时留下。付费帖仍不删除。见 ADR 0356。
- 清单标题不是字符串时，自定义表情后来由 ADR 0815 不再读取。
- 清单任务上的自定义表情后来由 ADR 0749 要求整段落在这条任务里。任务文字不是字符串时仍按原来的方式读取。已有别的正文时，事件里的任务仍只留前 3029 字。
- 管理员仍豁免。云额度的基础检测器名单没有改。30 天保留期没有改。
