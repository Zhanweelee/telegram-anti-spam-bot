# 规则文件

`default.json` 是每个群的默认 RuleSet。`chats.json` 的键是 `chatId`，值是一份完整 RuleSet，用来替换该群的默认规则，不是和默认规则合并。

Worker 每次检测先读缓存端口。未命中才读这两个文件，不读 D1。文件内容过不了 schema 时，该群放行，日志只有 `rules_invalid`。

内置关键词仍在检测器配置里。私聊 `/keyword` 可以给这个群追加词，内置词还在。见 ADR 0461。这里只决定阈值、启用状态和动作。动作可以是 `delete`、`warn`、`decline`、`mute`、`ban` 或 `captcha`。mute 的时长不在这份 JSON 里。没改过时是 3600 秒。私聊 `/rulemute` 可以按群改。见 ADR 0463。ban 不会自动删除消息。默认规则里的 `new_member` 在入群时要求按钮验证。没改过时是 300 秒。私聊 `/verifyfor` 可以按群改。见 ADR 0464。两颗按钮是加法的两个得数，点错的那颗不会通过，并会提示正确的得数。这条消息静音发出，成员仍看得到。见 ADR 0455。已经在群里的人可以由私聊 `/captcha <chatId> <actorId>` 再要求一次，时长和这个群的入群验证相同。没改过时是 300 秒。没改过时，到点后成员留下。私聊 `/verifyfail` 可以改成移出或封禁。见 ADR 0465。私聊 `/uncaptcha <chatId> <actorId>` 取消尚未完成的验证，打开发言并删掉按钮。没有待验证时不调用。私聊 `/warn <chatId> <actorId>` 记一次警告，第 3 次封禁，不删历史消息。未满 3 次不请求 Telegram。封禁失败时次数退回。`/unwarn` 只清次数。`/warns` 可以列出这个群，也可以只读一个人。`/warnlimit` 把上限改成 1 到 10，默认仍是 3。见 ADR 0456 和 ADR 0457。配了 DB 时次数在 D1，没配时仍在内存，重启后从 0 开始。规则写成 `warn` 时删掉这条未付费消息并共用这份次数，满 3 次封禁。默认 JSON 仍是 delete。见 ADR 0454。私聊 `/rule` 可以把这一条已有规则换成一个处置，`file` 回到 JSON 里的动作。见 ADR 0458。私聊 `/report` 可以把这个群的上报改到另一个编号。不设置时仍发给配置里的第一个管理员。见 ADR 0459。私聊 `/flood` 可以改这个群的洪泛条数和秒数。不设置时仍是 10 秒 5 条。见 ADR 0460。私聊 `/repeat` 可以改这个群的重复条数和秒数。不设置时仍是 60 秒 3 条。见 ADR 0462。`join_name` 在昵称、姓氏或用户名命中关键词时封禁，不再发验证按钮。`join_link` 在同一份可见名字里出现短链或邀请时封禁。进群用的邀请链接不读。公开的 `t.me/名字` 仍只验证。`bot_join` 封禁从群外加入的其它 bot，不封禁已经在群里的 bot。`shared_contact` 删除共享名片，证据是 `contact:card`。`join_request` 在入群申请的简介命中关键词或短链时拒绝申请。邀请链接和姓名不进事件。`flood` 是同一人 10 秒 5 条，`repeat` 是同一哈希 60 秒 3 次，动作都是 delete。默认阈值和窗口在检测器配置里，不在这份 JSON 里。私聊 `/flood` 和 `/repeat` 可以按群改。`links` 删除短链接、裸 IP、藏在 text_link 里的这些主机名，以及 `t.me` / `telegram.me` / `telegram.dog` 的邀请链接。公开的 `t.me/名字` 保留。私聊 `/allowhost` 可以让这个群放行其中一台主机，其它短链仍删除。见 ADR 0466。邀请码不进证据。入群服务消息的可见名字同样走关键词和链接规则，命中后删除这条服务消息。退群的人不读。视频聊天邀请里的可见名字同样走这两条规则。通话结束的时长不读。群主变更里的新群主名字同样走这两条规则。没有下一位时不读。靠近提醒里两个人的可见名字同样走这两条规则。距离不读。富文本数学公式里的短链或邀请同样删除，公式源码不进事件。没有说明的富文本图片、语音、动图、视频、音频和文件在 60
