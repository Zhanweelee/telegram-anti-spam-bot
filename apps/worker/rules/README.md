# 规则文件

`default.json` 是每个群的默认 RuleSet。`chats.json` 的键是 `chatId`，值是一份完整 RuleSet，用来替换该群的默认规则，不是和默认规则合并。

Worker 每次检测先读缓存端口。未命中才读这两个文件，不读 D1。文件内容过不了 schema 时，该群放行，日志只有 `rules_invalid`。

关键词列表仍在检测器配置里。这里只决定阈值、启用状态和动作。动作可以是 `delete`、`warn`、`decline`、`mute`、`ban` 或 `captcha`。mute 的时长不在这份 JSON 里，Worker 里的动作配置是 3600 秒。ban 不会自动删除消息。默认规则里的 `new_member` 在入群时要求按钮验证，时长 300 秒，写在动作配置里。两颗按钮是加法的两个得数，点错的那颗不会通过，并会提示正确的得数。这条消息静音发出，成员仍看得到。见 ADR 0455。已经在群里的人可以由私聊 `/captcha <chatId> <actorId>` 再要求一次，时长同样是 300 秒。私聊 `/uncaptcha <chatId> <actorId>` 取消尚未完成的验证，打开发言并删掉按钮。没有待验证时不调用。私聊 `/warn <chatId> <actorId>` 记一次警告，第 3 次封禁，不删历史消息。未满 3 次不请求 Telegram。封禁失败时次数退回。`/unwarn` 只清次数。`/warns` 可以列出这个群，也可以只读一个人。`/warnlimit` 把上限改成 1 到 10，默认仍是 3。见 ADR 0456 和 ADR 0457。配了 DB 时次数在 D1，没配时仍在内存，重启后从 0 开始。规则写成 `warn` 时删掉这条未付费消息并共用这份次数，满 3 次封禁。默认 JSON 仍是 delete。见 ADR 0454。`join_name` 在昵称、姓氏或用户名命中关键词时封禁，不再发验证按钮。`join_link` 在同一份可见名字里出现短链或邀请时封禁。进群用的邀请链接不读。公开的 `t.me/名字` 仍只验证。`bot_join` 封禁从群外加入的其它 bot，不封禁已经在群里的 bot。`shared_contact` 删除共享名片，证据是 `contact:card`。`join_request` 在入群申请的简介命中关键词或短链时拒绝申请。邀请链接和姓名不进事件。`flood` 是同一人 10 秒 5 条，`repeat` 是同一哈希 60 秒 3 次，动作都是 delete。阈值和窗口在检测器配置里，不在这份 JSON 里。`links` 删除短链接、裸 IP、藏在 text_link 里的这些主机名，以及 `t.me` / `telegram.me` / `telegram.dog` 的邀请链接。公开的 `t.me/名字` 保留。邀请码不进证据。入群服务消息的可见名字同样走关键词和链接规则，命中后删除这条服务消息。退群的人不读。视频聊天邀请里的可见名字同样走这两条规则。通话结束的时长不读。群主变更里的新群主名字同样走这两条规则。没有下一位时不读。靠近提醒里两个人的可见名字同样走这两条规则。距离不读。富文本数学公式里的短链或邀请同样删除，公式源码不进事件。没有说明的富文本图片、语音、动图、视频、音频和文件在 60 秒内第 3 次由现有 `repeat` 删除。文件 id 不进事件。没有说明的付费图片、视频和实况照片同样由现有 `repeat` 删除。文件 id、星星数量和预览尺寸不进事件。只给一个人看见的短链或关键词同样删除，删除请求带接收者 id。接收者姓名不进事件。自定义表情的替代文字里的短链或关键词同样删除。已有正文时只留主机名。表情 id 不进事件。代码块语言标签里的短链或邀请同样删除。标签原文不进事件。代码实体语言标签里的短链或邀请同样删除。标签原文不进事件。Telegram 代理和 socks 链接里的 server 主机名同样走链接规则。secret、端口、用户名和密码不进证据。分享链接和即时预览里的 url 同样走链接规则。路径和 rhash 不进证据。私聊预填链接里的 text 同样走链接规则。路径和收件人用户名不进证据。公开用户名和 `t.me/s/用户名` 上的 text 同样走链接规则。`t.me/用户名/数字` 和 `用户名.t.me` 的 text 同样走链接规则。讨论串不读 text。用户名后再加一段应用名时，text 只留主机名。更长的一段同样只留主机名。`tg://resolve?domain=s&appname=` 同样只留主机名。`s.t.me/用户名`、`share.t.me/url` 和 `msg.t.me/url` 同样只留主机名。去掉预览 `s` 之后的一段同样只留主机名。子域上的应用名、讨论串仍不读。Passport 不读 text。纯数字的 `t.me/+` 是电话链接，不是邀请，`text` 同样走链接规则。号码不进证据。带字母的加号路径仍是邀请。抽奖要加入的频道名字同样走链接规则。频道 id、用户名和中奖者姓名不进事件。官方分享链接的另外几种写法，以及 `tg://iv` 和私聊预填上的 `url`，同样走链接规则。用户名上的 `url` 不读。网页代理链接的 server 同样走链接规则。secret 不进证据。没有 server 时的 host 同样走链接规则。网页代理上 server 为空时改读 host。其它代理的空 server 不读。`domain`、`phone`、`server`、`host`、`invite` 和 `slug` 不区分大小写，先出现的值为准。空的 `SERVER` 仍算空。小写 `t.me/folder/` 记成邀请，邀请码不进证据。大写 `Folder` 和 `tg://folder` 不记。`folder.t.me/`、`addlist.t.me/` 和 `joinchat.t.me/` 上的一段邀请码同样记成邀请。没有第二段、`telegram.me` 上的同名子域和普通用户名子域不记。`JoinChat` 和 `AddList` 的大小写同样记成邀请。`Folder` 仍只认小写。`t.me/%20`、`telegram.me/%20` 和 `telegram.dog/%20` 同样记成邀请。末尾斜杠、`#` 和子域不记。Passport 的 `callback_url` 只留主机名。`nonce`、公钥和路径不进事件。`shared_blocklist` 在该群 opt-in 打开后删除共享名单里的 actor id 或内容哈希；默认关闭，关闭时这条规则不会读共享名单。`regex_hint` 默认关闭。打开后按检测器里的短模式删除，证据只有 `regex:hit`。`via_inline` 默认关闭。打开后删除经 inline bot 发出的消息，证据是 `via:bot`，不含 bot 用户名。`folder_join` 默认关闭。打开后封禁从文件夹邀请加入的人，证据是 `folder:invite`，邀请链接不进事件。私聊 `/rule` 可以打开 `via_inline` 或 `regex_hint`，不用复制 `default.json`。配了 `POLICY_KV` 时这个开关会留住，没配时重启回到文件。`chats.json` 整份替换仍然必须包含这条规则 id，否则命令会拒绝。`channel_forward` 默认开启，删除频道转发，不删除用户转发。讨论组里关联频道的自动转发留下。原帖来源上的作者签名只留主机名。客座 bot 回复上画出的召唤者名字只留主机名。`chats.json` 整份替换默认规则，所以 `-100777` 目前没有验证、入群昵称、入群短链、入群 bot、文件夹邀请、入群申请、名片、inline、洪泛、重复、链接、黑名单、正则和频道转发规则。
